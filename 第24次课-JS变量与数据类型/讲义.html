第24课：JS 变量与数据类型

变量是程序中存储数据的「容器」，数据类型决定了容器里能放什么。本课将教你如何声明变量、了解 JavaScript 中的基础数据类型，以及如何进行类型检测和转换。

let / const / var 变量命名 String 字符串 Number 数字 Boolean 布尔 Null / Undefined typeof 类型转换

一、什么是变量？

变量就像是一个「带标签的盒子」，你可以往里面放东西，也可以随时取出来用。在编程中，我们用变量来存储各种数据，比如用户名、年龄、分数等。

类比理解

想象你有一个储物柜：

  • 变量名 = 柜子上的标签（比如「我的书」「我的工具」）
  • 变量值 = 柜子里放的东西（书、工具等）
  • 赋值操作 = 把东西放进柜子（或换成别的东西）
// 声明一个变量，就像贴一个标签
let myName = '小明';   // 在 myName 这个"盒子"里放入"小明"

// 使用变量，就是取出盒子里的内容
console.log(myName);   // 输出: 小明

// 修改变量，就是换掉盒子里的东西
myName = '小红';       // 现在 myName 里是"小红"了
console.log(myName);   // 输出: 小红

1.1 声明变量：let、const、var

现代 JavaScript 中，我们主要使用 let 和 const 来声明变量。var 是旧的关键字，不推荐使用。

关键字 是否可重新赋值 作用域 推荐用法
let ✅ 可以 块级作用域 {} 用于声明可能会改变的变量，如计数器、状态值
const ❌ 不可以 块级作用域 {} 首选！用于声明不会改变的常量
var ✅ 可以 函数作用域 ❌ 不推荐使用，有变量提升等问题 
// 使用 let 声明一个可变的变量
let score = 100;
score = 150;  // ✅ 合法，可以重新赋值

// 使用 const 声明一个常量
const appName = 'MyGame';
// appName = 'NewGame';  // ❌ 错误！常量不能被重新赋值

// const 对于对象和数组的特殊性
const user = { name: 'Alice' };
user.name = 'Bob';  // ✅ 合法！可以修改对象内部的属性
// user = { name: 'Charlie' };  // ❌ 错误！不能指向新对象
为什么不推荐使用 var？
  • 变量提升 (Hoisting)：var 声明的变量会被"提升"到作用域顶部，可能导致意外行为
  • 没有块级作用域：在 if 或 for 中声明的变量会"泄露"到外部
// var 的问题示例
if (true) {
    var color = 'blue';
}
console.log(color);  // 输出 'blue' - color 泄露到外部！

// 如果使用 let
if (true) {
    let theme = 'dark';
}
// console.log(theme);  // ❌ 错误！theme 在这里无法访问

实践建议：默认使用 const，当确定需要改变值时再换成 let。完全忘记 var。

1.2 变量命名规则

给变量起一个好名字至关重要，它能极大提高代码的可读性。

规则 说明 示例
合法字符 只能使用字母、数字、下划线 _ 和 $ userName, _private, $element
开头字符 不能以数字开头 ✅ name1 ❌ 1name
关键字 不能使用 JS 保留关键字 ❌ let, if, for, function
大小写敏感 user 和 User 是不同的变量 user ≠ User ≠ USER
命名约定（Best Practices）：
  • 小驼峰命名法 (camelCase)：第一个单词小写，后续每个单词首字母大写。如：userName, totalPrice
  • 见名知意：变量名应准确描述所存储的数据。避免 a, b, temp 等无意义名称
  • 布尔值命名：通常以 is, has, can 开头。如：isLoggedIn, hasPermission
  • 常量命名：全大写加下划线。如：const MAX_COUNT = 100

二、JavaScript 数据类型概览

JavaScript 是「动态类型」语言，变量的类型由赋给它的值决定。数据类型分为基础类型和引用类型。

JavaScript 的 8 种数据类型：
类型分类描述示例
String 基础类型 文本数据 'Hello', "World", `Hi`
Number 基础类型 数字（整数、小数） 42, 3.14, NaN
Boolean 基础类型 真或假 true, false
Undefined 基础类型 未定义的值 undefined
Null 基础类型 空值 null
Symbol 基础类型 唯一标识符（ES6） Symbol('id')
BigInt 基础类型 大整数（ES2020） 9007199254740991n
Object 引用类型 对象、数组、函数等 {}, [], function(){}

本课重点：学习前 5 种最常用的基础类型（String, Number, Boolean, Undefined, Null）。

2.1 字符串 (String)

字符串用于表示文本，必须用引号包裹。JavaScript 支持三种引号：

引号类型示例说明
单引号 ' ' let name = 'Alice'; 最常用
双引号 " " let msg = "Hello"; 与单引号功能相同
反引号 ` ` let hi = `Hello, ${name}!`; 推荐！可以嵌入变量和多行 
const userName = 'Bob';
const userAge = 25;

// 传统拼接方式（繁琐）
const message1 = 'User ' + userName + ' is ' + userAge + ' years old.';

// 模板字符串（推荐！清晰直观）
const message2 = `User ${userName} is ${userAge} years old.`;

console.log(message2);  // "User Bob is 25 years old."

// 模板字符串支持多行
const html = `
  <div>
    <h1>${userName}</h1>
    <p>年龄：${userAge}</p>
  </div>
`;
字符串常用操作 
const str = 'Hello World';

str.length         // 11 (字符串长度)
str.toUpperCase()  // "HELLO WORLD" (转大写)
str.toLowerCase()  // "hello world" (转小写)
str.indexOf('World')  // 6 (查找位置)
str.includes('Hello') // true (是否包含)
str.slice(0, 5)    // "Hello" (截取)
str.split(' ')     // ["Hello", "World"] (分割)
str.replace('World', 'JS')  // "Hello JS" (替换)

2.2 数字 (Number)

JavaScript 中只有一种数字类型，不区分整数和浮点数。

let integer = 100;       // 整数
let float = 3.14;        // 小数
let negative = -50;      // 负数
let scientific = 2.5e6;  // 2500000 (科学计数法)

数字类型还包含几个特殊值：

  • Infinity：正无穷大，例如 1 / 0
  • -Infinity：负无穷大，例如 -1 / 0
  • NaN（Not-a-Number）：不是数字，例如 'abc' / 2
数字常用操作 
// 数学运算
10 + 5   // 15 (加法)
10 - 5   // 5  (减法)
10 * 5   // 50 (乘法)
10 / 5   // 2  (除法)
10 % 3   // 1  (取余)
2 ** 3   // 8  (幂运算)

// Math 对象
Math.round(4.7)    // 5 (四舍五入)
Math.floor(4.7)    // 4 (向下取整)
Math.ceil(4.3)     // 5 (向上取整)
Math.abs(-5)       // 5 (绝对值)
Math.max(1, 5, 3)  // 5 (最大值)
Math.min(1, 5, 3)  // 1 (最小值)
Math.random()      // 0-1 之间的随机数

// 数字方法
const num = 3.14159;
num.toFixed(2)     // "3.14" (保留小数位)
浮点数精度问题

JavaScript 中的小数运算可能存在精度问题：

0.1 + 0.2         // 0.30000000000000004 (不是 0.3!)
0.1 + 0.2 === 0.3 // false

// 解决方案：使用 toFixed()
(0.1 + 0.2).toFixed(2)  // "0.30"

2.3 布尔值 (Boolean)

布尔值只有两个：true（真）和 false（假）。通常用于条件判断。

let isLoggedIn = true;
let hasPermission = false;

let userAge = 20;
let isAdult = userAge >= 18;  // true

// 比较运算符返回布尔值
5 > 3      // true
10 === 10  // true
'a' !== 'b'  // true
真值 (Truthy) 和 假值 (Falsy)

在条件判断中，以下值会被视为 false（假值）：

  • false - 布尔值 false
  • 0 和 -0 - 数字零
  • '' - 空字符串
  • null - 空值
  • undefined - 未定义
  • NaN - 非数字

其他所有值都是真值，包括 "0"（字符串）、[]（空数组）、{}（空对象）

2.4 Null 和 Undefined

这两个类型都表示「没有值」，但语义不同：

类型含义典型场景
undefined 未定义 - 变量已声明但未赋值，是默认初始状态 let x; console.log(x); // undefined
null 空值 - 明确赋予的表示「没有对象」的值 let user = null; // 当前没有用户
简单区分

undefined 是 JavaScript 自动给的，表示"你忘了给值"

null 是程序员手动给的，表示"我确定这里现在什么都没有"

// undefined 的常见情况
let a;
console.log(a);  // undefined (声明但未赋值)

const obj = { name: 'Alice' };
console.log(obj.age);  // undefined (访问不存在的属性)

// null 的使用场景
let currentUser = null;  // 当前没有用户登录

// 比较
null == undefined   // true (相等运算符)
null === undefined  // false (严格相等，类型不同)
typeof null         // "object" (历史遗留 bug)
typeof undefined    // "undefined"

三、使用 typeof 检查类型

typeof 是一个运算符，可以返回表示操作数类型的字符串。

typeof 18          // "number"
typeof 'hello'     // "string"
typeof true        // "boolean"
typeof undefined   // "undefined"
typeof {}          // "object"
typeof []          // "object" (数组也是对象)
typeof null        // "object" (历史遗留 bug)
typeof function(){} // "function"
注意：

typeof null 返回 'object' 是 JavaScript 早期版本的一个错误。要检查 null，使用 value === null。

3.1 数据类型转换

在编程中，我们经常需要在不同数据类型之间进行转换。

显式类型转换（手动转换）

函数说明示例
Number() 转换为数字 Number('123') → 123
String() 转换为字符串 String(123) → '123'
Boolean() 转换为布尔值 Boolean(0) → false
parseInt() 解析为整数 parseInt('28.5px') → 28
parseFloat() 解析为浮点数 parseFloat('28.5px') → 28.5

隐式类型转换（自动转换）

// + 运算符的特殊性
'5' + 3       // "53" (字符串拼接优先)
5 + '3'       // "53"

// 其他数学运算符会转换为数字
'10' - 5      // 5
'10' * 2      // 20

// == 相等运算符会进行隐式转换（不推荐）
5 == '5'      // true

// === 严格相等不会转换（推荐！）
5 === '5'     // false
最佳实践
  • 在进行数学运算前，明确使用 Number() 或 parseInt() 转换
  • 比较值时，始终使用严格相等运算符 === 和 !==

四、本课小结

知识点回顾

  • 变量是程序中用于存储数据的命名容器
  • 使用 const 声明常量（优先），使用 let 声明可变变量，避免使用 var
  • 变量命名遵循小驼峰命名法，做到见名知意
  • JavaScript 有多种基础数据类型：String, Number, Boolean, Undefined, Null
  • 模板字符串（反引号）是拼接字符串的现代最佳实践
  • undefined（未赋值）和 null（主动赋空）的语义不同
  • 使用 typeof 检查变量类型，但注意 typeof null 的特例
  • 类型转换分为显式（手动）和隐式（自动），推荐使用 === 进行比较
