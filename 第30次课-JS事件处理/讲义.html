第30课：JS事件处理

点击按钮、输入文字、移动鼠标、提交表单……这些用户操作在浏览器中都会触发「事件」。本课你将学会监听这些事件，并用函数来响应它们。

click 点击 input 输入 addEventListener 事件回调函数

一、什么是事件？

事件就是「在浏览器中发生的一件事」，比如：

  • 用户点击了一个按钮（click）。
  • 用户在输入框中输入内容（input）。
  • 页面加载完成（load）。

二、如何监听事件？

最常用的方式是使用 addEventListener：

const btn = document.querySelector('button');

btn.addEventListener('click', function () {
  console.log('按钮被点击了！');
});
  • 第一个参数是事件类型，如 'click'。
  • 第二个参数是一个函数（回调函数），事件发生时会被调用。

三、常见的事件类型

  • click：鼠标点击。
  • input：输入框内容发生变化。
  • submit：表单提交。
  • change：值改变并失去焦点（如下拉框）。

四、实验：点击按钮切换背景颜色

🔬 实验1：切换背景色 基础
HTML
<button id="colorBtn">切换背景色</button> <div id="box" style="width:100px;height:100px;background:red;margin-top:10px;"></div>
JavaScript (可编辑)
const btn = document.getElementById('colorBtn'); const box = document.getElementById('box'); btn.addEventListener('click', function() { if (box.style.backgroundColor === 'red') { box.style.backgroundColor = 'blue'; } else { box.style.backgroundColor = 'red'; } });
🔬 实验2：点击计数器 进阶
HTML
<h3>点击次数: <span id="count">0</span></h3> <button id="addBtn">+1</button> <button id="resetBtn">重置</button>
JavaScript (可编辑)
let count = 0; const countSpan = document.getElementById('count'); const addBtn = document.getElementById('addBtn'); const resetBtn = document.getElementById('resetBtn'); addBtn.addEventListener('click', function() { count++; countSpan.innerText = count; }); resetBtn.addEventListener('click', function() { count = 0; countSpan.innerText = count; });

五、本课小结

  • 事件是用户与网页交互时触发的各种「动作」。
  • 使用 addEventListener 可以给元素绑定事件处理函数。
  • 结合 DOM 操作和事件，可以做出各种交互效果。
