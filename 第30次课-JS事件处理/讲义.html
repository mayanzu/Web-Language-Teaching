第30课：JS事件处理

点击按钮、输入文字、移动鼠标、提交表单……这些用户操作在浏览器中都会触发「事件」。本课你将学会监听这些事件，并用函数来响应它们，让网页真正与用户互动起来！

一、什么是事件？

事件是浏览器中发生的「动作」或「事情」，可以是用户触发的（如点击），也可以是浏览器触发的（如页面加载完成）。

💡 生活中的类比
  • 门铃：按下门铃（事件）→ 铃声响起（响应）
  • 电梯：按下楼层按钮（事件）→ 电梯运行（响应）
  • 手机：点击App图标（事件）→ 打开应用（响应）

网页事件也是一样：用户做了某个操作，网页做出相应的反应。

常见的事件类型：

  • 用户点击了一个按钮（click）
  • 用户在输入框中输入内容（input）
  • 鼠标移入/移出元素（mouseenter、mouseleave）
  • 按下键盘按键（keydown、keyup）
  • 表单提交（submit）
  • 页面加载完成（load）

1.2 事件绑定方式

方式一：HTML属性（不推荐）

<!-- 直接在HTML中绑定事件 -->
<button onclick="alert('点击了!')">点我</button>

<button onclick="handleClick()">点我</button>
<script>
function handleClick() {
    alert('点击了!');
}
</script>
不推荐这种方式！

HTML属性绑定混合了HTML和JavaScript，不利于维护。推荐使用addEventListener。

方式二：DOM属性

const btn = document.querySelector('button');

// 使用DOM属性绑定事件
btn.onclick = function() {
    alert('点击了!');
};

// 缺点：同一事件只能绑定一个处理函数
btn.onclick = function() {
    console.log('新的处理函数');
};
// 上面的函数会覆盖之前的

方式三：addEventListener（推荐）

const btn = document.querySelector('button');

// addEventListener(事件类型, 回调函数)
btn.addEventListener('click', function() {
    console.log('第一个处理函数');
});

// 可以绑定多个处理函数
btn.addEventListener('click', function() {
    console.log('第二个处理函数');
});

// 使用箭头函数
btn.addEventListener('click', () => {
    console.log('箭头函数处理');
});

// 使用命名函数（便于移除）
function handleClick() {
    console.log('命名函数处理');
}
btn.addEventListener('click', handleClick);

移除事件监听

// 要移除事件，必须使用命名函数
function handleClick() {
    console.log('点击了');
}

btn.addEventListener('click', handleClick);

// 移除事件监听
btn.removeEventListener('click', handleClick);
addEventListener的优势：
  • 可以为同一事件绑定多个处理函数
  • 可以控制事件在捕获或冒泡阶段触发
  • 可以方便地移除事件监听
  • HTML和JavaScript分离，代码更清晰

二、常用事件类型

2.1 鼠标事件

事件 触发时机 常用场景
click 鼠标点击（按下并释放） 按钮点击、链接跳转
dblclick 鼠标双击 双击编辑、双击放大
mouseenter 鼠标移入元素 显示提示、高亮效果
mouseleave 鼠标移出元素 隐藏提示、恢复样式
mousemove 鼠标在元素上移动 拖拽、跟随效果
mousedown 鼠标按下 拖拽开始
mouseup 鼠标释放 拖拽结束 
const box = document.getElementById('box');

// 鼠标移入
box.addEventListener('mouseenter', function() {
    this.style.backgroundColor = '#0066CC';
    this.style.color = 'white';
});

// 鼠标移出
box.addEventListener('mouseleave', function() {
    this.style.backgroundColor = '#f0f0f0';
    this.style.color = 'black';
});

// 鼠标移动
box.addEventListener('mousemove', function(e) {
    console.log(`鼠标位置: (${e.clientX}, ${e.clientY})`);
});

2.2 键盘事件

事件 触发时机 常用场景
keydown 按键按下 快捷键、游戏控制
keyup 按键释放 搜索建议、输入验证
keypress 按键按下（已废弃） 不推荐使用 
// 监听整个文档的键盘事件
document.addEventListener('keydown', function(e) {
    console.log('按下了:', e.key);      // 按键值，如 'a', 'Enter'
    console.log('键码:', e.keyCode);    // 键码（已废弃）
    console.log('按键代码:', e.code);   // 按键代码，如 'KeyA', 'Enter'
    
    // 检测特殊键
    if (e.ctrlKey) console.log('Ctrl被按下');
    if (e.shiftKey) console.log('Shift被按下');
    if (e.altKey) console.log('Alt被按下');
});

// 监听输入框的键盘事件
const input = document.getElementById('search');
input.addEventListener('keyup', function(e) {
    // 按下Enter键提交
    if (e.key === 'Enter') {
        console.log('提交搜索:', this.value);
    }
});

2.3 表单事件

事件 触发时机 常用场景
input 输入内容改变时（实时） 实时搜索、字数统计
change 值改变并失去焦点 下拉框选择、复选框
focus 获得焦点 显示提示、高亮输入框
blur 失去焦点 验证输入、隐藏提示
submit 表单提交 表单验证 
const input = document.getElementById('username');
const form = document.getElementById('myForm');

// input事件 - 实时监听输入
input.addEventListener('input', function() {
    console.log('当前输入:', this.value);
    // 实时字数统计
    document.getElementById('charCount').innerText = this.value.length;
});

// focus事件 - 获得焦点
input.addEventListener('focus', function() {
    this.style.borderColor = '#0066CC';
});

// blur事件 - 失去焦点
input.addEventListener('blur', function() {
    this.style.borderColor = '#ddd';
    // 验证输入
    if (this.value.length < 3) {
        alert('用户名至少3个字符');
    }
});

// submit事件 - 表单提交
form.addEventListener('submit', function(e) {
    e.preventDefault();  // 阻止默认提交
    console.log('表单数据:', new FormData(this));
});
💡 input vs change
  • input：每次输入内容改变都会触发，适合实时响应
  • change：值改变且失去焦点后触发，适合最终确认

三、事件对象

当事件发生时，浏览器会创建一个事件对象（event），包含了事件的详细信息。

3.1 事件对象的常用属性

属性 说明 适用事件
e.target 触发事件的元素 所有事件
e.currentTarget 绑定事件的元素 所有事件
e.type 事件类型 所有事件
e.clientX/Y 鼠标相对视口的位置 鼠标事件
e.pageX/Y 鼠标相对页面的位置 鼠标事件
e.key 按下的键 键盘事件
e.ctrlKey/shiftKey/altKey 是否按下修饰键 键盘/鼠标事件 
// 事件对象作为回调函数的参数
element.addEventListener('click', function(e) {
    // 或者写成 (event) 或 (evt)
    console.log('事件类型:', e.type);           // 'click'
    console.log('触发元素:', e.target);         // 被点击的元素
    console.log('绑定元素:', e.currentTarget);  // 绑定事件的元素
    console.log('鼠标位置:', e.clientX, e.clientY);
});

// 使用箭头函数
element.addEventListener('click', (e) => {
    console.log(e.target.innerText);
});
target vs currentTarget：
  • target：实际触发事件的元素（可能是子元素）
  • currentTarget：绑定事件处理函数的元素
  • 在事件委托中，两者通常不同

3.2 阻止默认行为和事件冒泡

阻止默认行为

// 阻止链接跳转
const link = document.querySelector('a');
link.addEventListener('click', function(e) {
    e.preventDefault();  // 阻止默认行为
    console.log('链接被点击，但不会跳转');
});

// 阻止表单提交
const form = document.querySelector('form');
form.addEventListener('submit', function(e) {
    e.preventDefault();  // 阻止表单提交
    // 进行表单验证...
    console.log('表单验证通过后再提交');
});

// 阻止右键菜单
document.addEventListener('contextmenu', function(e) {
    e.preventDefault();
    console.log('右键菜单被禁用');
});

阻止事件冒泡

// 事件冒泡：子元素的事件会向上传递到父元素
<div id="parent">
    <button id="child">点击</button>
</div>

document.getElementById('parent').addEventListener('click', function() {
    console.log('父元素被点击');
});

document.getElementById('child').addEventListener('click', function(e) {
    e.stopPropagation();  // 阻止冒泡
    console.log('子元素被点击');
    // 不会触发父元素的click事件
});
事件冒泡说明

默认情况下，事件会从触发元素向上"冒泡"到祖先元素。点击按钮时，按钮的click事件会依次触发父元素的click事件。使用e.stopPropagation()可以阻止这种传播。

四、事件委托

事件委托是利用事件冒泡机制，将子元素的事件处理委托给父元素。这样可以减少事件监听器的数量，提高性能。

// 传统方式：为每个按钮绑定事件
const buttons = document.querySelectorAll('.btn');
buttons.forEach(btn => {
    btn.addEventListener('click', function() {
        console.log(this.innerText);
    });
});

// 事件委托：只在父元素绑定一个事件
const container = document.getElementById('btn-container');
container.addEventListener('click', function(e) {
    // 判断点击的是否是按钮
    if (e.target.classList.contains('btn')) {
        console.log(e.target.innerText);
    }
});
💡 事件委托的优势
  • 减少内存占用：只需绑定一个事件监听器
  • 动态元素支持：新添加的子元素自动拥有事件处理
  • 代码更简洁：统一在一处处理
// 事件委托实际应用：动态列表
const todoList = document.getElementById('todo-list');

// 只在父元素绑定一次
todoList.addEventListener('click', function(e) {
    const target = e.target;
    
    // 点击删除按钮
    if (target.classList.contains('delete-btn')) {
        target.parentElement.remove();
    }
    
    // 点击完成按钮
    if (target.classList.contains('done-btn')) {
        target.parentElement.classList.toggle('completed');
    }
});

// 添加新项目时，不需要再绑定事件
function addTodo(text) {
    const li = document.createElement('li');
    li.innerHTML = `
        ${text}
        <button class="done-btn">完成</button>
        <button class="delete-btn">删除</button>
    `;
    todoList.appendChild(li);
    // 新元素自动继承父元素的事件处理
}

案例：网页交互中的应用 Real World

实际应用场景：

  • 表单验证：用户输入时实时验证，blur时显示错误提示
  • 下拉菜单：鼠标移入显示，移出隐藏
  • 图片轮播：点击按钮切换图片
  • 无限滚动：监听scroll事件，滚动到底部加载更多
  • 快捷键：监听keydown实现Ctrl+S保存等功能
  • 拖拽排序：组合mousedown、mousemove、mouseup实现
// 表单验证示例
const emailInput = document.getElementById('email');

emailInput.addEventListener('blur', function() {
    const email = this.value;
    const isValid = /^[^\s@]+@[^\s@]+\.[^\s@]+$/.test(email);
    
    if (!isValid) {
        this.style.borderColor = 'red';
        document.getElementById('error').innerText = '请输入有效的邮箱';
    } else {
        this.style.borderColor = 'green';
        document.getElementById('error').innerText = '';
    }
});
