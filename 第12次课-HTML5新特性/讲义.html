欢迎来到HTML5新特性的学习！HTML5是HTML的最新版本，它引入了许多实用的新功能。本节课我们将学习HTML5中最常用、最实用的新特性，包括新的表单控件和一些有趣的新元素。

一、什么是HTML5

HTML5是HTML的第五个主要版本，于2014年正式发布。它带来了许多新特性，让网页开发更加简单和强大。

📖 HTML5的主要改进

HTML5相比之前版本有很多改进：

  • 更简洁的语法：文档声明变得很简单
  • 语义化标签：header、nav、article等（第10课已学）
  • 多媒体支持：audio、video标签（第11课已学）
  • 新表单控件：日期、颜色、范围等（本课学习）
  • 新增实用元素：进度条、详情折叠等（本课学习）

1.1 HTML5的文档声明

HTML5的文档声明非常简洁：

<!-- HTML5的文档声明 -->
<!DOCTYPE html>

<!-- 之前版本的文档声明（很复杂） -->
<!DOCTYPE HTML PUBLIC "-//W3C//DTD HTML 4.01//EN" 
    "http://www.w3.org/TR/html4/strict.dtd">
💡 小提示

你在前面课程中一直使用的 <!DOCTYPE html> 就是HTML5的文档声明！是不是很简单？

1.2 HTML5的字符编码声明

HTML5简化了字符编码的声明方式：

<!-- HTML5的字符编码声明 -->
<meta charset="UTF-8">

<!-- 之前版本的写法 -->
<meta http-equiv="Content-Type" content="text/html; charset=UTF-8">

二、HTML5新增表单控件

HTML5新增了许多实用的表单输入类型，让用户输入数据变得更加方便。

📖 为什么需要新的表单控件？

在HTML5之前，如果想让用户选择日期或颜色，需要借助JavaScript插件。现在HTML5提供了原生支持，浏览器会自动显示相应的选择器界面！

2.1 日期相关输入

HTML5提供了多种日期时间相关的输入类型：

类型 说明 示例代码
date 日期选择器（年月日） <input type="date">
time 时间选择器（时分） <input type="time">
datetime-local 日期时间选择器 <input type="datetime-local">
month 年月选择器 <input type="month">
week 年周选择器 <input type="week"> 
<!-- 日期输入示例 -->
<label>选择日期：</label>
<input type="date" name="birthday">

<label>选择时间：</label>
<input type="time" name="meeting-time">

<label>选择日期和时间：</label>
<input type="datetime-local" name="event-time">

2.2 颜色选择器

type="color" 可以让用户通过颜色选择器选择颜色：

<label>选择颜色：</label>
<input type="color" name="favorite-color" value="#ff0000">
💡 默认颜色

可以通过 value 属性设置默认颜色，值必须是十六进制颜色值（如 #ff0000）。

2.3 范围滑块

type="range" 显示一个可以拖动的滑块，适合选择数值范围：

<label>音量：</label>
<input type="range" name="volume" min="0" max="100" value="50">

<label>评分（1-5）：</label>
<input type="range" name="rating" min="1" max="5" step="1" value="3">
属性 说明 示例
min 最小值 min="0"
max 最大值 max="100"
step 步长（每次变化的值） step="1"
value 默认值 value="50"

2.4 数字输入

type="number" 限制用户只能输入数字：

<label>数量：</label>
<input type="number" name="quantity" min="1" max="99" value="1">

<label>价格：</label>
<input type="number" name="price" min="0" step="0.01" placeholder="0.00">

2.5 搜索框

type="search" 专门用于搜索输入，在某些浏览器中会显示清除按钮：

<label>搜索：</label>
<input type="search" name="keyword" placeholder="输入关键词...">
⚠️ 浏览器兼容性提示

HTML5的新表单控件在不同浏览器中的显示效果可能略有不同。如果浏览器不支持某个类型，会自动回退为普通文本框，不会报错。

三、进度条与计量器

HTML5新增了两个用于显示数值进度的元素：进度条（progress）和计量器（meter）。

3.1 进度条 <progress>

进度条用于显示任务的完成进度，如文件下载、表单填写等：

<!-- 基本进度条 -->
<label>下载进度：</label>
<progress value="70" max="100">70%</progress>

<!-- 不确定进度（没有value属性） -->
<label>加载中：</label>
<progress></progress>
属性 说明 示例
value 当前进度值 value="70"
max 最大值（默认为1） max="100"

3.2 计量器 <meter>

计量器用于显示已知范围内的数值，如磁盘使用量、考试成绩等：

<!-- 基本计量器 -->
<label>磁盘使用：</label>
<meter value="0.6">60%</meter>

<!-- 带范围的计量器 -->
<label>考试成绩：</label>
<meter value="85" min="0" max="100" low="60" high="90" optimum="100">
    85分
</meter>
属性 说明
value 当前值（必需）
min 最小值（默认0）
max 最大值（默认1）
low 低值阈值
high 高值阈值
optimum 最优值
📌 progress vs meter 的区别
  • progress：表示任务的完成进度，值会变化（如下载进度）
  • meter：表示已知范围内的固定测量值（如磁盘空间）

四、详情与摘要

HTML5提供了原生的折叠/展开功能，无需JavaScript即可实现。

4.1 details和summary标签

<details> 和 <summary> 配合使用可以创建可折叠的内容区域：

<details>
    <summary>点击查看详情</summary>
    <p>这是被折叠的内容，点击标题可以展开或收起。</p>
</details>

<!-- 默认展开 -->
<details open>
    <summary>常见问题</summary>
    <p>这里是问题的答案...</p>
</details>
💡 使用场景

details标签非常适合用于：

  • FAQ（常见问题）页面
  • 产品参数展示
  • 代码示例的展开/收起
  • 隐私政策等长文本的折叠

4.2 属性说明

元素/属性 说明
<details> 折叠容器，包裹所有内容
<summary> 始终可见的摘要/标题
open 添加此属性则默认展开
