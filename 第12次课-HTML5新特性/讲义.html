一、语义化标签回顾

HTML5引入了一系列语义化标签，用于更清晰地描述页面结构。我们在第10次课已经详细学习了语义化标签，这里简单回顾一下核心概念。

提示

语义化标签的核心价值是让浏览器和开发者都能理解页面结构，提高可访问性和SEO友好性。

1.1 核心语义化标签结构

<!DOCTYPE html>
<html lang="zh-CN">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>语义化页面结构</title>
</head>
<body>
    <header>页面头部</header>
    <nav>导航菜单</nav>
    <main>
        <article>
            <h2>文章标题</h2>
            <section>文章章节1</section>
            <section>文章章节2</section>
        </article>
        <aside>侧边栏</aside>
    </main>
    <footer>页面底部</footer>
</body>
</html>

二、HTML5表单控件

HTML5引入了一系列新的表单控件，这些控件提供了更好的用户体验和内置验证功能。

2.1 新的表单输入类型

HTML5新增了多种专门用途的输入类型，让用户能够更方便地输入特定类型的数据。

<!DOCTYPE html>
<html lang="zh-CN">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>HTML5表单控件</title>
</head>
<body>
    <h2>HTML5表单控件示例</h2>
    <form>
        <p>
            <label for="email">邮箱：</label>
            <input type="email" id="email" name="email" placeholder="请输入邮箱" required>
        </p>
        <p>
            <label for="url">网址：</label>
            <input type="url" id="url" name="url" placeholder="请输入网址">
        </p>
        <p>
            <label for="tel">电话：</label>
            <input type="tel" id="tel" name="tel" placeholder="请输入电话号码">
        </p>
        <p>
            <label for="number">数量：</label>
            <input type="number" id="number" name="number" min="1" max="10" value="5">
        </p>
        <p>
            <label for="range">音量：</label>
            <input type="range" id="range" name="range" min="0" max="100" value="50">
            <span id="rangeValue">50</span>
        </p>
        <p>
            <label for="date">日期：</label>
            <input type="date" id="date" name="date">
        </p>
        <p>
            <label for="time">时间：</label>
            <input type="time" id="time" name="time">
        </p>
        <p>
            <label for="color">颜色：</label>
            <input type="color" id="color" name="color" value="#ff0000">
        </p>
        <p>
            <input type="submit" value="提交">
        </p>
    </form>
    <script>
        // 实时显示滑块值
        const range = document.getElementById('range');
        const rangeValue = document.getElementById('rangeValue');
        range.oninput = function() {
            rangeValue.textContent = this.value;
        }
    </script>
</body>
</html>
效果说明

这段代码展示了HTML5新增的表单控件，包括：

  • email：自动验证邮箱格式
  • url：自动验证网址格式
  • tel：适合输入电话号码
  • number：只能输入数字，支持min/max/step属性
  • range：滑块控件，用于选择范围值
  • date/time：日期和时间选择器
  • color：颜色选择器

三、HTML5多媒体支持

HTML5提供了内置的音频和视频标签，无需额外插件即可在网页中播放媒体内容。

3.1 音频播放

使用<audio>标签可以直接在网页中播放音频文件。

<!DOCTYPE html>
<html lang="zh-CN">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>HTML5音频示例</title>
</head>
<body>
    <h2>HTML5音频播放示例</h2>
    <audio controls>
        <source src="https://www.w3school.com.cn/i/horse.ogg" type="audio/ogg">
        <source src="https://www.w3school.com.cn/i/horse.mp3" type="audio/mpeg">
        您的浏览器不支持音频播放功能。
    </audio>
</body>
</html>

3.2 视频播放

使用<video>标签可以直接在网页中播放视频文件。

<!DOCTYPE html>
<html lang="zh-CN">
<head>

    <title>HTML5视频示例</title>

</html>

四、HTML5绘图技术

HTML5引入了两种绘图技术：Canvas和SVG，用于在网页中创建图形和动画。

4.1 Canvas绘图

Canvas是基于像素的绘图技术，通过JavaScript动态生成图形，适合绘制复杂的动画效果。

<!DOCTYPE html>
<html lang="zh-CN">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Canvas绘图示例</title>
</head>
<body>
    <h2>Canvas绘图示例</h2>
    <canvas id="myCanvas" width="300" height="200" style="border:1px solid #000000;">
        您的浏览器不支持Canvas元素。
    </canvas>
    <script>
        // 获取Canvas元素和绘图上下文
        const canvas = document.getElementById('myCanvas');
        const ctx = canvas.getContext('2d');
        
        // 绘制矩形
        ctx.fillStyle = '#FF0000';
        ctx.fillRect(20, 20, 150, 100);
        
        // 绘制圆形
        ctx.fillStyle = '#00FF00';
        ctx.beginPath();
        ctx.arc(200, 100, 50, 0, 2 * Math.PI);
        ctx.fill();
        
        // 绘制文本
        ctx.fillStyle = '#0000FF';
        ctx.font = '20px Arial';
        ctx.fillText('Hello Canvas!', 50, 170);
    </script>
</body>
</html>

4.2 SVG绘图

SVG是基于矢量的绘图技术，使用XML格式描述图形，适合绘制静态图标和图形。

<!DOCTYPE html>
<html lang="zh-CN">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>SVG绘图示例</title>
</head>
<body>
    <h2>SVG绘图示例</h2>
    <svg width="300" height="200" style="border:1px solid #000000;">
        
        <rect x="20" y="20" width="150" height="100" fill="#FF0000" />
        
        
        <circle cx="200" cy="100" r="50" fill="#00FF00" stroke="#000000" stroke-width="2" />
        
        
        <text x="50" y="170" font-family="Arial" font-size="20" fill="#0000FF">
            Hello SVG!
        </text>
    </svg>
</body>
</html>

五、HTML5地理定位

HTML5的地理定位API允许网页获取用户的地理位置信息，用于位置相关的应用开发。 

<!DOCTYPE html>
<html lang="zh-CN">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>地理定位示例</title>
</head>
<body>
    <h2>HTML5地理定位示例</h2>
    <button onclick="getLocation()">获取我的位置</button>
    <p id="demo"></p>
    <script>
        function getLocation() {
            // 检查浏览器是否支持地理定位
            if (navigator.geolocation) {
                // 请求获取用户位置
                navigator.geolocation.getCurrentPosition(showPosition, showError);
            } else {
                document.getElementById("demo").innerHTML = "您的浏览器不支持地理定位功能。";
            }
        }
        
        // 成功获取位置时的回调函数
        function showPosition(position) {
            document.getElementById("demo").innerHTML = 
                "纬度: " + position.coords.latitude + "<br>" +
                "经度: " + position.coords.longitude + "<br>" +
                "精度: " + position.coords.accuracy + " 米";
        }
        
        // 获取位置失败时的回调函数
        function showError(error) {
            switch(error.code) {
                case error.PERMISSION_DENIED:
                    document.getElementById("demo").innerHTML = "用户拒绝了地理定位请求。";
                    break;
                case error.POSITION_UNAVAILABLE:
                    document.getElementById("demo").innerHTML = "位置信息不可用。";
                    break;
                case error.TIMEOUT:
                    document.getElementById("demo").innerHTML = "获取位置超时。";
                    break;
                case error.UNKNOWN_ERROR:
                    document.getElementById("demo").innerHTML = "发生未知错误。";
                    break;
            }
        }
    </script>
</body>
</html>
注意事项

地理定位需要用户授权，浏览器会弹出提示窗口，询问用户是否允许网站获取位置信息。

六、HTML5 Web存储

HTML5的Web存储API允许网页在客户端本地存储数据，比传统的Cookie更安全、更高效。

6.1 Web存储的两种类型

存储类型 生命周期 适用场景
localStorage 长期存储，直到手动删除 用户偏好设置、主题选择
sessionStorage 会话期间，关闭浏览器后清除 临时表单数据、购物车会话

6.2 Web存储示例

<!DOCTYPE html>
<html lang="zh-CN">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Web存储示例</title>
</head>
<body>
    <h2>HTML5 Web存储示例</h2>
    <div>
        <h3>localStorage演示</h3>
        <p>localStorage数据会长期保存，关闭浏览器后重新打开仍然存在。</p>
        <input type="text" id="localInput" placeholder="输入要保存的内容">
        <button onclick="saveToLocal()">保存到localStorage</button>
        <button onclick="loadFromLocal()">从localStorage读取</button>
        <button onclick="clearLocal()">清除localStorage</button>
        <p>localStorage内容: <span id="localOutput"></span></p>
    </div>
    <div style="margin-top: 20px;">
        <h3>sessionStorage演示</h3>
        <p>sessionStorage数据只在当前会话有效，关闭浏览器后会清除。</p>
        <input type="text" id="sessionInput" placeholder="输入要保存的内容">
        <button onclick="saveToSession()">保存到sessionStorage</button>
        <button onclick="loadFromSession()">从sessionStorage读取</button>
        <button onclick="clearSession()">清除sessionStorage</button>
        <p>sessionStorage内容: <span id="sessionOutput"></span></p>
    </div>
    <script>
        // localStorage操作
        function saveToLocal() {
            const input = document.getElementById('localInput');
            localStorage.setItem('userData', input.value);
            alert('数据已保存到localStorage');
        }
        function loadFromLocal() {
            const output = document.getElementById('localOutput');
            output.textContent = localStorage.getItem('userData') || '空';
        }
        function clearLocal() {
            localStorage.removeItem('userData');
            document.getElementById('localOutput').textContent = '';
            alert('localStorage数据已清除');
        }
        
        // sessionStorage操作
        function saveToSession() {
            const input = document.getElementById('sessionInput');
            sessionStorage.setItem('tempData', input.value);
            alert('数据已保存到sessionStorage');
        }
        function loadFromSession() {
            const output = document.getElementById('sessionOutput');
            output.textContent = sessionStorage.getItem('tempData') || '空';
        }
        function clearSession() {
            sessionStorage.removeItem('tempData');
            document.getElementById('sessionOutput').textContent = '';
            alert('sessionStorage数据已清除');
        }
        
        // 页面加载时自动读取数据
        window.onload = function() {
            loadFromLocal();
            loadFromSession();
        };
    </script>
</body>
</html>

七、HTML与响应式设计

响应式设计是一种使网页能够适应不同设备屏幕尺寸的设计方法。HTML5提供了基础支持，主要通过视口元标签实现。

7.1 视口元标签

视口元标签是实现响应式设计的基础，它告诉浏览器如何缩放页面以适应不同设备。

<!DOCTYPE html>
<html lang="zh-CN">
<head>
    <meta charset="UTF-8">
    <!-- 视口元标签：设置页面宽度等于设备宽度，初始缩放比例为1 -->
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>响应式设计基础</title>
</head>
<body>
    <h2>响应式设计基础</h2>
    <p>添加视口元标签后，页面将根据不同设备屏幕尺寸自动调整。</p>

</body>
</html>

八、HTML最佳实践

遵循HTML最佳实践可以提高代码质量、可读性和可维护性，确保页面符合现代Web标准。

8.1 基础最佳实践

核心原则

编写HTML代码时，要做到：语义化、简洁性、可访问性和兼容性。

8.2 文档结构规范

<!DOCTYPE html> <!-- 必须放在第一行 -->
<html lang="zh-CN"> <!-- 指定页面语言 -->
<head>
    <meta charset="UTF-8"> <!-- 指定字符编码 -->
    <meta name="viewport" content="width=device-width, initial-scale=1.0"> <!-- 视口设置 -->
    <title>页面标题</title> <!-- 必须包含 -->
    <link rel="stylesheet" href="style.css"> <!-- 外部CSS放在顶部 -->
</head>
<body>
    <!-- 使用语义化标签组织页面结构 -->
    <header>页面头部</header>
    <nav>导航菜单</nav>
    <main>主要内容</main>
    <footer>页面底部</footer>
    
    <script src="script.js"></script> <!-- 外部JavaScript放在底部 -->
</body>
</html>

8.3 代码编写规范

  • 使用小写字母编写标签和属性
  • 使用双引号包裹属性值
  • 闭合所有标签（包括自闭合标签）
  • 使用缩进和换行提高可读性（建议使用4个空格缩进）
  • 为图片添加alt属性，描述图片内容
  • 为表单控件添加label标签
  • 避免使用过时的HTML标签（如<font>、<center>）

8.4 HTML验证工具

使用HTML验证工具可以检查代码是否符合标准，帮助发现和修复错误。

推荐工具：W3C HTML验证器
