第8课：HTML表单基础

在本节课中，我们将学习HTML表单的基础知识。表单是网页中用于收集用户输入的重要元素，它允许用户提交数据到服务器， 如注册表单、登录表单、搜索表单等。通过本节课的学习，你将掌握HTML表单的基本结构、常用输入控件和按钮，以及如何创建简单的表单。

一、表单结构

HTML表单是网页中用于收集用户输入的重要组件，它允许用户提交数据到服务器，如注册表单、登录表单、搜索表单等。表单使用<form>标签定义，它是一个容器，包含各种表单控件和相关元素。

表单的核心组成部分
  • 表单容器：<form>标签，定义表单的边界和属性
  • 表单控件：如输入框、按钮、选择框等，用于收集用户输入
  • 表单标签：<label>标签，用于关联表单控件和文本描述
  • 表单组：使用<fieldset>和<legend>标签对相关控件进行分组
  • 辅助元素：如提示文本、错误信息、帮助文本等

1.1 表单的基本语法

一个完整的HTML表单通常具有以下结构：

<form action="url" method="method" enctype="encoding" target="target">
    <!-- 表单控件和其他元素 -->
</form>

1.2 表单的重要属性

<form>标签支持多种属性，用于控制表单的行为和外观：

属性 描述 默认值 示例
action 指定表单提交的目标URL，表单数据将发送到该URL 当前页面URL action="https://example.com/submit"
method 指定表单提交的HTTP方法 get method="post"
enctype 指定表单数据的编码类型，用于文件上传等场景 application/x-www-form-urlencoded enctype="multipart/form-data"
target 指定表单提交后在哪里显示响应 _self target="_blank"
autocomplete 指定表单是否启用自动完成功能 on autocomplete="off"
novalidate 指定表单提交时是否跳过浏览器的默认验证 不设置时启用验证 novalidate

1.3 GET vs POST：表单提交方法对比

method属性用于指定表单提交的HTTP方法，主要有两种：GET和POST。它们在数据传输方式、安全性、缓存等方面有明显区别。

特性 GET 方法 POST 方法
数据传输方式 数据附加在URL中，以问号分隔 数据包含在HTTP请求体中
URL长度限制 有限制（取决于浏览器，通常约2KB） 无限制，可传输大量数据
安全性 较低，数据可见于URL和浏览器历史记录 较高，数据不可见，适合敏感信息
缓存 可被浏览器缓存 不可被浏览器缓存
书签 可添加为书签 不可添加为书签
后退/刷新 无副作用，可安全刷新 会提示重新提交表单
数据类型 只能发送ASCII字符 可发送二进制数据（如文件）
适用场景 搜索表单、获取数据、页面导航 注册表单、登录表单、提交数据、文件上传

1.4 表单的语义化结构

为了提高表单的可访问性和可读性，我们应该使用语义化的表单结构，包括：

1.4.1 fieldset 和 legend：表单分组

<fieldset>标签用于对相关的表单控件进行分组，<legend>标签用于定义分组的标题。

使用 fieldset 和 legend 分组的表单
<form>
    <fieldset>
        <legend>个人信息</legend>
        
        <label for="name">姓名：</label>
        <input type="text" id="name" name="name">
        
        <label for="email">邮箱：</label>
        <input type="email" id="email" name="email">
    </fieldset>
    
    <fieldset>
        <legend>登录信息</legend>
        
        <label for="username">用户名：</label>
        <input type="text" id="username" name="username">
        
        <label for="password">密码：</label>
        <input type="password" id="password" name="password">
    </fieldset>
</form>

1.4.2 label：表单标签

<label>标签用于关联表单控件和文本描述，它有以下优点：

  • 提高可访问性：屏幕阅读器可以将标签文本与控件关联
  • 改善用户体验：用户可以点击标签来激活控件
  • 增强可维护性：清晰地表明控件的用途
label标签的两种使用方式
<!-- 方式1：使用for属性关联控件id -->
<label for="username">用户名：</label>
<input type="text" id="username" name="username">

<!-- 方式2：将控件包裹在label标签内 -->
<label>
    密码：
    <input type="password" id="password" name="password">
</label>

1.5 表单的可访问性

创建可访问的表单是Web开发的重要组成部分，它确保所有用户，包括使用辅助技术的用户，都能有效地使用表单。以下是一些提高表单可访问性的建议：

表单可访问性最佳实践
  • 为所有表单控件添加<label>标签
  • 使用for属性将标签与控件关联
  • 使用<fieldset>和<legend>对相关控件进行分组
  • 提供清晰的错误信息和帮助文本
  • 使用适当的输入类型，如email、tel等
  • 为必填字段添加明确的标识
  • 确保表单可以通过键盘导航
  • 使用ARIA属性增强可访问性（高级主题）

二、文本输入控件

<input>标签是表单中最常用的控件，它可以根据type属性的值呈现不同的输入类型。 以下是一些常用的文本输入类型：

2.1 文本输入框

type="text"用于创建单行文本输入框，它是<input>标签的默认类型。 

<label for="username">用户名：</label>
<input type="text" id="username" name="username" placeholder="请输入用户名">

2.2 密码输入框

type="password"用于创建密码输入框，输入的内容会被隐藏（显示为星号或圆点）。 

<label for="password">密码：</label>
<input type="password" id="password" name="password" placeholder="请输入密码">

2.3 数字输入框

type="number"用于创建数字输入框，它只允许输入数字。 

<label for="age">年龄：</label>
<input type="number" id="age" name="age" min="0" max="120" step="1">

2.4 邮箱输入框

type="email"用于创建邮箱输入框，它会自动验证输入的内容是否符合邮箱格式。 

<label for="email">邮箱：</label>
<input type="email" id="email" name="email" placeholder="请输入邮箱">

2.5 网址输入框

type="url"用于创建网址输入框，它会自动验证输入的内容是否符合网址格式。 

<label for="website">个人网站：</label>
<input type="url" id="website" name="website" placeholder="请输入网址">

2.6 电话输入框

type="tel"用于创建电话输入框，它会在移动设备上显示数字键盘。 

<label for="phone">电话：</label>
<input type="tel" id="phone" name="phone" placeholder="请输入电话号码">

2.7 日期和时间输入框

HTML5提供了多种日期和时间输入类型：

  • type="date"：日期选择器
  • type="time"：时间选择器
  • type="datetime-local"：日期和时间选择器
  • type="month"：月份选择器
  • type="week"：周选择器
<label for="birthday">生日：</label>
<input type="date" id="birthday" name="birthday">

<label for="meeting">会议时间：</label>
<input type="datetime-local" id="meeting" name="meeting">

三、单选按钮与复选框

在HTML中，我们可以使用单选按钮和复选框来收集用户的选择。

3.1 单选按钮

type="radio"用于创建单选按钮，它允许用户从一组选项中选择一个选项。 同一组的单选按钮必须具有相同的name属性。 

<label>性别：</label>
<input type="radio" id="male" name="gender" value="male" checked>
<label for="male">男</label>

<input type="radio" id="female" name="gender" value="female">
<label for="female">女</label>

3.2 复选框

type="checkbox"用于创建复选框，它允许用户从一组选项中选择多个选项。 同一组的复选框通常具有相同的name属性。 

<label>爱好：</label>
<input type="checkbox" id="reading" name="hobby" value="reading">
<label for="reading">阅读</label>

<input type="checkbox" id="music" name="hobby" value="music">
<label for="music">音乐</label>

<input type="checkbox" id="sports" name="hobby" value="sports">
<label for="sports">运动</label>

四、提交与重置按钮

表单通常包含提交按钮和重置按钮，用于提交表单数据和重置表单内容。

4.1 提交按钮

type="submit"用于创建提交按钮，点击它会提交表单数据到action属性指定的URL。 

<input type="submit" value="提交">

4.2 重置按钮

type="reset"用于创建重置按钮，点击它会将表单中的所有控件重置为默认值。 

<input type="reset" value="重置">

4.3 普通按钮

type="button"用于创建普通按钮，它不会自动提交表单，通常用于触发JavaScript事件。 

<input type="button" value="点击我" onclick="alert('Hello!')">

4.4 button标签

除了使用<input>标签创建按钮外，我们还可以使用<button>标签创建按钮。 <button>标签提供了更灵活的样式和内容支持。 

<button type="submit">提交</button>
<button type="reset">重置</button>
<button type="button" onclick="alert('Hello!')">点击我</button>
