第8课：HTML表单基础

在本节课中，我们将学习HTML表单的基础知识。表单是网页中用于收集用户输入的重要元素，它允许用户提交数据到服务器， 如注册表单、登录表单、搜索表单等。通过本节课的学习，你将掌握HTML表单的基本结构、常用输入控件和按钮，以及如何创建简单的表单。

表单结构 文本输入控件 单选按钮 复选框 提交按钮 重置按钮

一、表单结构

HTML表单是网页中用于收集用户输入的重要组件，它允许用户提交数据到服务器。表单使用<form>标签定义，是一个包含各种表单控件的容器。

生活类比

HTML表单就像现实生活中的纸质表格：

  • 表单容器：相当于整张表格纸
  • 输入框：相当于填写姓名、地址的空白行
  • 单选按钮：相当于"是/否"选择题
  • 复选框：相当于"可多选"的选项
  • 提交按钮：相当于"确认提交"盖章
表单的核心组成部分
  • 表单容器：<form>标签，定义表单的边界和属性
  • 表单控件：如输入框、按钮等，用于收集用户输入
  • 表单标签：<label>标签，用于关联表单控件和文本描述
  • name属性：每个控件的名称，提交数据时作为键名

1.1 表单的基本语法

一个完整的HTML表单通常具有以下结构：

示例：基本表单结构 只读 
<form action="url" method="method">
    <!-- 表单控件和其他元素 -->
    <label for="name">姓名：</label>
    <input type="text" id="name" name="name">
    
    <input type="submit" value="提交">
</form>

1.2 表单的重要属性

<form>标签的核心属性：

属性 描述 示例
action 指定表单提交的目标URL action="https://example.com/submit"
method 指定表单提交的HTTP方法 method="post"
enctype 指定数据编码类型（上传文件时需要） enctype="multipart/form-data"
target 指定提交结果在哪里显示 target="_blank"（新窗口）
autocomplete 是否启用自动完成 autocomplete="off"
novalidate 禁用浏览器自动验证 novalidate

1.3 GET vs POST：核心区别

表单提交主要有两种方法：GET和POST，选择正确的方法非常重要。

特性 GET 方法 POST 方法
数据位置 数据在URL中可见（?name=value） 数据在请求体中，URL不可见
数据长度 受URL长度限制（约2048字符） 几乎无限制
安全性 较低，会被浏览器历史记录保存 较高，不会被浏览器缓存
书签 可以收藏为书签 不能收藏为书签
适用场景 搜索表单、简单查询、分享链接 登录表单、注册表单、文件上传
安全提示
  • 永远不要用GET提交密码：密码会显示在URL中
  • 敏感数据使用POST：如信用卡信息、个人身份信息
  • 搜索可用GET：方便分享搜索结果链接

1.4 label标签的使用

<label>标签用于关联表单控件和文本描述，是表单可访问性的关键。

为什么要使用label？
  • 可访问性：屏幕阅读器可以正确读出控件用途
  • 更大点击区域：点击label文字也能聚焦到输入框
  • 更好的用户体验：尤其对于小尺寸的单选/复选框
示例：label的两种写法 只读 
<!-- 方式1：使用for属性关联控件id（推荐） -->
<label for="username">用户名：</label>
<input type="text" id="username" name="username">

<!-- 方式2：将控件包裹在label标签内 -->
<label>
    密码：
    <input type="password" name="password">
</label>

<!-- 方式1更灵活，方式2更简洁 -->

1.5 name属性的重要性

name属性是表单控件提交数据时的键名，没有name的控件不会被提交。

示例：表单提交的数据格式 只读 
<!-- 假设表单如下 -->
<form action="/search" method="get">
    <input type="text" name="keyword" value="HTML">
    <input type="text" name="page" value="1">
</form>

<!-- 提交后URL会变成 -->
/search?keyword=HTML&page=1

<!-- 键=值 的格式，多个用&连接 -->

二、文本输入控件

<input>标签是表单中最常用的控件，通过设置不同的type属性，可以创建各种类型的输入控件。这是表单的核心元素。

input标签的特点
  • 自闭合标签，不需要结束标签
  • 通过type属性决定显示什么类型的输入框
  • HTML5新增了很多type类型，提供更好的用户体验

2.1 常用文本输入控件

以下是最常用的文本输入控件：

类型 描述 示例场景 浏览器特殊处理
text 单行文本输入框 用户名、姓名 无特殊处理
password 密码输入框 登录密码 显示为圆点/星号
email 邮箱输入框 用户邮箱 自动验证邮箱格式
number 数字输入框 年龄、数量 只允许数字，有加减按钮
tel 电话输入框 手机号码 移动端弹出数字键盘
url 网址输入框 个人网站 自动验证URL格式
search 搜索输入框 搜索关键词 可能显示清除按钮
date 日期选择器 生日、预约日期 弹出日历选择器
time 时间选择器 预约时间 弹出时间选择器
color 颜色选择器 选择颜色 弹出调色板

2.2 输入控件的常用属性

输入控件支持多种属性，以下是最常用的几个：

属性 描述 示例
name 控件名称，提交时作为键名 name="username"
value 控件的默认值 value="默认文本"
placeholder 输入框中的提示文本 placeholder="请输入用户名"
required 标记为必填项 required
disabled 禁用控件 disabled
readonly 只读，不可编辑 readonly
maxlength 最大字符数 maxlength="20"
min/max 数值的最小/最大值 min="0" max="120"
pattern 正则表达式验证 pattern="[0-9]{11}"
autofocus 页面加载时自动聚焦 autofocus
placeholder vs value
  • placeholder：提示文本，用户输入后消失，不会被提交
  • value：默认值，用户可以修改，会被提交

2.3 表单验证属性

HTML5提供了内置的表单验证功能，无需JavaScript即可实现基本验证。

示例：常用验证属性 只读 
<!-- 必填验证 -->
<input type="text" name="username" required>

<!-- 邮箱格式验证（type="email"自带） -->
<input type="email" name="email" required>

<!-- 数字范围验证 -->
<input type="number" name="age" min="18" max="60">

<!-- 长度限制 -->
<input type="text" name="nickname" minlength="2" maxlength="10">

<!-- 正则表达式验证（手机号） -->
<input type="tel" name="phone" pattern="1[3-9][0-9]{9}" 
       title="请输入11位手机号">

<!-- 提交时浏览器会自动检查，不通过会提示错误 -->
前端验证的局限性

HTML5验证只是辅助性的，用户可以通过禁用JavaScript或修改HTML绕过。服务器端验证是必须的，永远不要完全信任前端提交的数据。

三、单选按钮与复选框

在HTML中，我们可以使用单选按钮和复选框来收集用户的选择。这两种控件是表单中非常重要的选择类输入。

单选 vs 复选的区别
特性 单选按钮 (radio) 复选框 (checkbox)
选择数量 只能选一个 可以选多个
外观 圆形 ○ 方形 □
分组 同name必须互斥 同name可多选
典型场景 性别、是否同意 爱好、权限

3.1 单选按钮

type="radio"用于创建单选按钮，允许用户从一组选项中选择一个选项。 关键点：同一组的单选按钮必须具有相同的name属性。

示例：单选按钮 只读 
<!-- 性别选择 - 同一组name相同 -->
<p>性别：</p>
<input type="radio" id="male" name="gender" value="male" checked>
<label for="male">男</label>

<input type="radio" id="female" name="gender" value="female">
<label for="female">女</label>

<input type="radio" id="other" name="gender" value="other">
<label for="other">其他</label>

<!-- 
  关键属性说明：
  - name="gender" : 相同name的radio互斥
  - value="male"  : 提交时发送的值
  - checked       : 默认选中
  - id 配合 label的for : 点击文字也能选中
-->
单选按钮要点
  • 同组单选按钮name属性必须相同
  • value属性是提交给服务器的值
  • checked属性设置默认选中项
  • 使用label关联可以扩大点击区域

3.2 复选框

type="checkbox"用于创建复选框，允许用户从一组选项中选择多个选项。 同一组的复选框通常具有相同的name属性（服务器会收到数组）。

示例：复选框 只读 
<!-- 爱好选择 - 可多选 -->
<p>爱好：</p>
<input type="checkbox" id="reading" name="hobby" value="reading">
<label for="reading">阅读</label>

<input type="checkbox" id="music" name="hobby" value="music" checked>
<label for="music">音乐</label>

<input type="checkbox" id="sports" name="hobby" value="sports">
<label for="sports">运动</label>

<input type="checkbox" id="travel" name="hobby" value="travel" checked>
<label for="travel">旅行</label>

<!-- 
  提交时，选中的项会发送：
  hobby=music&hobby=travel （选了音乐和旅行）
-->

3.3 单个复选框的应用

单个复选框常用于"同意协议"这类场景：

示例：同意协议复选框 只读 
<!-- 同意协议 -->
<input type="checkbox" id="agree" name="agree" value="yes" required>
<label for="agree">
    我已阅读并同意<a href="/terms">用户协议</a>
</label>

<!-- required属性确保必须勾选才能提交 -->

3.4 常见错误与最佳实践

常见错误
  • 忘记设置name属性：导致数据无法提交
  • 单选按钮name不同：导致可以多选（失去互斥性）
  • 忘记设置value：服务器收到的是"on"而不是有意义的值
  • 没有使用label：用户只能点击小圆圈/方块，体验差
最佳实践
  • 始终使用label关联每个选项
  • 为每个选项设置有意义的value
  • 单选按钮组通常需要一个默认选中项
  • 必选场景使用required属性

四、表单按钮

表单通常包含提交按钮和重置按钮，用于提交表单数据和重置表单内容。按钮是表单交互的核心元素。

4.1 按钮类型概览

按钮类型 功能 input写法 button写法
提交按钮 提交表单数据 <input type="submit"> <button type="submit">
重置按钮 重置表单为初始状态 <input type="reset"> <button type="reset">
普通按钮 自定义行为（配合JS） <input type="button"> <button type="button">

4.2 提交按钮

type="submit"用于创建提交按钮，点击它会提交表单数据到action属性指定的URL。

示例：提交按钮的两种写法 只读 
<!-- 使用input -->
<input type="submit" value="提交">
<input type="submit" value="注册" disabled>  <!-- 禁用状态 -->

<!-- 使用button -->
<button type="submit">提交</button>
<button type="submit">
    <img src="icon.png" alt=""> 立即注册  <!-- 可包含图片/图标 -->
</button>

4.3 重置按钮

type="reset"用于创建重置按钮，点击它会将表单中的所有控件重置为默认值（不是清空，而是回到初始状态）。

示例：重置按钮 只读 
<input type="reset" value="重置">
<button type="reset">重置表单</button>

<!-- 注意：重置是恢复到默认值，不是清空 -->
<input type="text" name="name" value="张三">
<!-- 重置后会变回"张三"，而不是空 -->
重置按钮的注意事项

现代网页设计中，重置按钮使用率越来越低，原因：

  • 用户可能误点击，丢失已填写的数据
  • 浏览器的"后退"功能更安全
  • 如果需要清空，建议用JavaScript实现，并添加确认提示

4.4 input vs button 按钮的区别

特性 <input type="submit"> <button type="submit">
内容 只能是纯文本（value属性） 可包含HTML（图片、图标等）
样式 自定义能力有限 更容易自定义样式
推荐度 传统方式 ⭐ 更推荐使用

4.5 普通按钮

type="button"创建普通按钮，不会自动提交或重置，需要配合JavaScript使用。

示例：普通按钮 只读 
<!-- 普通按钮，需要JS处理点击事件 -->
<button type="button" onclick="alert('点击了!')">点我试试</button>

<!-- 常见应用场景 -->
<button type="button" onclick="validateForm()">检查表单</button>
<button type="button" onclick="showPreview()">预览</button>
按钮使用建议
  • 优先使用<button>标签，更灵活
  • 提交按钮放在表单最后，方便用户操作
  • 按钮文字要清晰明确：用"提交订单"而不是"提交"
  • 考虑添加loading状态，防止重复提交
