第8课：HTML表单基础

在本节课中，我们将学习HTML表单的基础知识。表单是网页中用于收集用户输入的重要元素，它允许用户提交数据到服务器， 如注册表单、登录表单、搜索表单等。通过本节课的学习，你将掌握HTML表单的基本结构、常用输入控件和按钮，以及如何创建简单的表单。

表单结构 文本输入控件 单选按钮 复选框 提交按钮 重置按钮

一、表单结构

HTML表单是网页中用于收集用户输入的重要组件，它允许用户提交数据到服务器。表单使用<form>标签定义，是一个包含各种表单控件的容器。

表单的核心组成部分
  • 表单容器：<form>标签，定义表单的边界和属性
  • 表单控件：如输入框、按钮等，用于收集用户输入
  • 表单标签：<label>标签，用于关联表单控件和文本描述

1.1 表单的基本语法

一个完整的HTML表单通常具有以下结构：

<form action="url" method="method">
    <!-- 表单控件和其他元素 -->
</form>

1.2 表单的重要属性

<form>标签的两个核心属性：

属性 描述 示例
action 指定表单提交的目标URL action="https://example.com/submit"
method 指定表单提交的HTTP方法 method="post"

1.3 GET vs POST：核心区别

表单提交主要有两种方法：GET和POST

特性 GET 方法 POST 方法
数据位置 数据在URL中可见 数据在请求体中
安全性 较低，不适合敏感信息 较高，适合敏感信息
适用场景 搜索表单、简单查询 注册表单、登录表单

1.4 label标签的使用

<label>标签用于关联表单控件和文本描述，提高可访问性和用户体验。

<!-- 方式1：使用for属性关联控件id -->
<label for="name">姓名：</label>
<input type="text" id="name" name="name">

<!-- 方式2：将控件包裹在label标签内 -->
<label>
    密码：
    <input type="password" id="password" name="password">
</label>

二、文本输入控件

<input>标签是表单中最常用的控件，通过设置不同的type属性，可以创建各种类型的输入控件。

2.1 常用文本输入控件

以下是最常用的文本输入控件：

类型 描述 示例
text 单行文本输入框 用户名、姓名等
password 密码输入框，内容隐藏 登录密码
email 邮箱输入框，支持邮箱验证 用户邮箱
number 数字输入框，只允许输入数字 年龄、数量等
tel 电话输入框，支持电话格式 手机号码
date 日期选择器 生日、预约日期等

2.2 输入控件的常用属性

输入控件支持多种属性，以下是最常用的几个：

属性 描述 示例
placeholder 输入框中的提示文本 placeholder="请输入用户名"
required 标记为必填项 required
min/max 设置数值或日期的最小/最大值 min="0" max="120"

三、单选按钮与复选框

在HTML中，我们可以使用单选按钮和复选框来收集用户的选择。

3.1 单选按钮

type="radio"用于创建单选按钮，允许用户从一组选项中选择一个选项。 同一组的单选按钮必须具有相同的name属性。 

<label>性别：</label>
<input type="radio" id="male" name="gender" value="male" checked>
<label for="male">男</label>

<input type="radio" id="female" name="gender" value="female">
<label for="female">女</label>

3.2 复选框

type="checkbox"用于创建复选框，允许用户从一组选项中选择多个选项。 同一组的复选框通常具有相同的name属性。 

<label>爱好：</label>
<input type="checkbox" id="reading" name="hobby" value="reading">
<label for="reading">阅读</label>

<input type="checkbox" id="music" name="hobby" value="music">
<label for="music">音乐</label>

<input type="checkbox" id="sports" name="hobby" value="sports">
<label for="sports">运动</label>

四、表单按钮

表单通常包含提交按钮和重置按钮，用于提交表单数据和重置表单内容。

4.1 提交按钮

type="submit"用于创建提交按钮，点击它会提交表单数据到action属性指定的URL。 

<input type="submit" value="提交">

4.2 重置按钮

type="reset"用于创建重置按钮，点击它会将表单中的所有控件重置为默认值。 

<input type="reset" value="重置">

4.3 button标签

除了使用<input>标签创建按钮外，我们还可以使用<button>标签创建按钮。 

<button type="submit">提交</button>
<button type="reset">重置</button>
