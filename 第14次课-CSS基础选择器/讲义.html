📝 课程小结

第14课：CSS基础选择器

CSS选择器是CSS的核心，它允许你选择要样式化的HTML元素。本节课我们将学习CSS基础选择器，包括元素选择器、ID选择器、类选择器、分组选择器和通配符选择器。

元素选择器 ID选择器 类选择器 分组选择器 通配符选择器 CSS选择器

1. 元素选择器

元素选择器是最基本的选择器，它根据HTML元素的名称来选择元素。例如，p选择器会选择所有的<p>元素。

/* 选择所有 <p> 元素 */
p {
    color: blue;
    font-size: 16px;
}
实验 01：元素选择器 动手实践

CSS (可编辑)
/* 元素选择器 */ p { color: blue; font-size: 18px; line-height: 1.5; }

2. ID选择器

ID选择器使用HTML元素的id属性来选择元素，ID选择器以#开头。每个HTML文档中的ID应该是唯一的。

/* 选择id为 "special" 的元素 */
#special {
    background-color: #ffffcc;
    padding: 10px;
    border: 1px solid #ffcc00;
}
实验 02：ID选择器 动手实践
HTML (可编辑)
<p>普通段落</p> <p id="special">这个段落有ID "special"，会被ID选择器选中。</p> <p>另一个普通段落</p>
CSS (可编辑)
/* ID选择器 */ #special { background-color: #ffffcc; padding: 10px; border: 1px solid #ffcc00; font-weight: bold; }
预览效果

3. 类选择器

类选择器使用HTML元素的class属性来选择元素，类选择器以.开头。一个HTML元素可以有多个类，多个HTML元素可以共享同一个类。

/* 选择所有class为 "highlight" 的元素 */
.highlight {
    color: red;
    font-weight: bold;
    text-decoration: underline;
}
实验 03：类选择器 动手实践
HTML (可编辑)
<p>普通段落</p> <p class="highlight">带highlight类的段落</p> <div class="highlight">带highlight类的div</div> <p class="highlight">另一个带highlight类的段落</p>
CSS (可编辑)
/* 类选择器 */ .highlight { color: red; font-weight: bold; text-decoration: underline; }
预览效果

4. 分组选择器

分组选择器允许你将多个选择器组合在一起，共享相同的样式，选择器之间用逗号分隔。

/* 同时选择 h1, h2, h3 元素 */
h1, h2, h3 {
    color: #333;
    font-family: Arial, sans-serif;
    margin-top: 20px;
}
实验 04：分组选择器 动手实践
HTML (可编辑)
<h1>一级标题</h1> <h2>二级标题</h2> <h3>三级标题</h3> <p>普通段落</p>
CSS (可编辑)
/* 分组选择器 */ h1, h2, h3 { color: #333; font-family: Arial, sans-serif; margin-top: 20px; border-bottom: 1px solid #ccc; }
预览效果

5. 通配符选择器

通配符选择器*会选择文档中的所有HTML元素。它通常用于设置全局样式或重置样式。

/* 选择所有元素 */
* {
    margin: 0;
    padding: 0;
    box-sizing: border-box;
}
注意事项

通配符选择器会影响所有元素，因此使用时要小心，避免不必要的性能开销。通常只在CSS重置或设置全局样式时使用。

6. 选择器性能优化

选择器的性能直接影响浏览器的渲染速度，特别是在大型网页中。了解选择器的性能特性可以帮助我们编写更高效的CSS代码。

6.1 选择器性能等级

CSS选择器的性能从高到低可以分为以下几个等级：

  1. 高性能选择器：ID选择器（#id）、类选择器（.class）、元素选择器（element）
  2. 中性能选择器：伪类选择器（:hover, :active）、属性选择器（[attribute]）
  3. 低性能选择器：后代选择器（.parent .child）、通用选择器（*）、兄弟选择器（~）

6.2 性能优化建议

📌 选择器性能优化
  • 避免使用过于复杂的选择器，如深层嵌套的后代选择器
  • 优先使用ID选择器和类选择器，它们的查找速度最快
  • 避免使用通配符选择器，尤其是在大型页面中
  • 避免使用属性选择器，如 [class^="btn"]，它比类选择器慢很多
  • 减少选择器的长度，选择器越短，性能越好
  • 避免使用 !important，它会破坏样式的正常优先级关系

6.3 选择器性能测试

你可以使用浏览器的开发者工具来测试选择器的性能：

  1. 打开浏览器开发者工具（F12）
  2. 切换到"Performance"或"性能"面板
  3. 点击"Record"按钮开始记录
  4. 刷新页面或与页面交互
  5. 停止记录，查看CSS选择器的执行时间

📌 选择器性能优化建议

1. 优先使用类选择器（.class），它的性能最好

2. 避免使用ID选择器（#id）作为样式选择器，应保留用于JS交互

3. 避免使用复杂的嵌套选择器，尤其是后代选择器

4. 避免使用属性选择器，如 [class^="btn-"]

5. 避免使用通配符选择器（*），尤其是在大型页面中

6. 减少选择器的长度，选择器越短，性能越好

8. 选择器最佳实践

遵循以下最佳实践可以帮助你编写更高效、更易维护的CSS代码：

8.1 命名规范

  • 使用语义化的类名：类名应该反映元素的用途，而不是样式，如 .btn-primary 比 .blue-button 更好
  • 保持类名简洁：类名应该简短明了，如 .nav 比 .navigation-menu 更好
  • 使用连字符分隔：如 .main-content，避免使用下划线或驼峰命名法

8.2 选择器组织

  • 按功能组织选择器：将相关的选择器放在一起，如布局选择器、组件选择器、响应式选择器等
  • 按重要性排序：将全局样式放在前面，局部样式放在后面
  • 使用注释分隔：使用注释将不同部分的选择器分隔开，提高代码的可读性

8.3 选择器使用原则

  • 单一职责原则：一个选择器应该只负责一个功能，避免一个选择器包含多个不相关的样式
  • DRY原则：Don't Repeat Yourself，避免重复的CSS代码，使用变量、混合宏等技术重用样式
  • KISS原则：Keep It Simple, Stupid，选择器应该尽可能简单，避免过于复杂的选择器

9. 课程小结

本节课我们学习了CSS基础选择器，它们是CSS的核心，用于选择要样式化的HTML元素。

9.1 知识点回顾

  • 元素选择器：根据HTML元素名称选择元素，如p选择所有段落
  • ID选择器：使用#符号，选择特定ID的元素，如#special
  • 类选择器：使用.符号，选择具有特定类的元素，如.highlight
  • 分组选择器：使用逗号分隔多个选择器，共享相同样式，如h1, h2, h3
  • 通配符选择器：使用*选择所有元素，通常用于CSS重置
  • 选择器优先级：ID选择器 > 类选择器 > 元素选择器
  • 选择器性能：优先使用ID选择器和类选择器，避免使用复杂的选择器

9.2 重点记忆

📌 选择器优先级

ID选择器 > 类选择器 > 元素选择器

分组选择器不改变优先级，每个选择器独立计算

通配符选择器优先级最低

9.3 最佳实践

  1. 优先使用类选择器，因为它们更灵活，可重用性高
  2. ID选择器只用于唯一元素，如页面主要容器或特定功能元素
  3. 合理使用分组选择器减少重复代码
  4. 谨慎使用通配符选择器，避免性能问题
  5. 选择器名称要语义化，便于理解和维护
  6. 避免使用过于复杂的选择器，保持选择器简洁
  7. 按功能组织选择器，提高代码的可读性和可维护性

9.4 学习建议

  • 多练习使用不同类型的选择器，熟悉它们的用法和优先级
  • 使用浏览器的开发者工具来调试和测试选择器
  • 学习CSS预处理器，如Sass、Less等，它们提供了更强大的选择器功能
  • 关注CSS的最新发展，了解新的选择器类型和特性
  • 阅读优秀的CSS代码，学习他人的最佳实践
