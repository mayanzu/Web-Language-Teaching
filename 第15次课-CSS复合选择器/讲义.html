第15课：CSS复合选择器

CSS复合选择器是由两个或多个基础选择器组合而成的选择器，它可以更精确地选择HTML元素。本节课我们将学习各种复合选择器，包括后代选择器、子选择器、兄弟选择器、交集选择器和并集选择器。

1. 后代选择器

后代选择器用于选择某个元素的所有后代元素，选择器之间用空格分隔。例如，div p会选择所有在<div>元素内的<p>元素。

/* 选择所有 <div> 内的 <p> 元素 */
div p {
    color: blue;
    font-size: 16px;
}

2. 子选择器

子选择器用于选择某个元素的直接子元素，选择器之间用>分隔。例如，div > p会选择所有直接作为<div>元素子元素的<p>元素。

/* 选择所有直接作为 <div> 子元素的 <p> 元素 */
div > p {
    color: red;
    font-weight: bold;
}

3. 相邻兄弟选择器

相邻兄弟选择器用于选择某个元素的下一个直接相邻的兄弟元素，选择器之间用+分隔。例如，h2 + p会选择所有在<h2>元素后面直接相邻的<p>元素。

/* 选择所有在 <h2> 后面直接相邻的 <p> 元素 */
h2 + p {
    color: green;
    font-style: italic;
}

4. 通用兄弟选择器

通用兄弟选择器用于选择某个元素后面的所有兄弟元素，选择器之间用~分隔。例如，h2 ~ p会选择所有在<h2>元素后面的<p>元素。

/* 选择所有在 <h2> 后面的 <p> 元素 */
h2 ~ p {
    color: purple;
    text-decoration: underline;
}

5. 交集选择器

交集选择器用于选择同时满足多个条件的元素，选择器之间直接连接，没有分隔符。例如，p.highlight会选择所有同时具有highlight类的<p>元素。

/* 选择所有具有 highlight 类的 <p> 元素 */
p.highlight {
    color: orange;
    font-weight: bold;
    background-color: #fff3cd;
    padding: 10px;
    border: 1px solid #ffeeba;
    border-radius: 4px;
}

6. 并集选择器

并集选择器用于选择多个选择器匹配的元素，选择器之间用逗号分隔。例如，h1, h2, h3会选择所有的<h1>、<h2>和<h3>元素。

/* 选择所有 <h1>、<h2> 和 <h3> 元素 */
h1, h2, h3 {
    color: #333;
    font-family: Arial, sans-serif;
    margin-top: 20px;
    border-bottom: 1px solid #ccc;
    padding-bottom: 5px;
}

CSS选择器详解

CSS选择器是CSS的核心，它允许你选择要样式化的HTML元素。

基础选择器

基础选择器包括元素选择器、ID选择器和类选择器。

复合选择器

复合选择器是由两个或多个基础选择器组合而成的选择器。

复合选择器可以更精确地选择HTML元素。

响应式设计

响应式设计是一种网页设计方法，使网页能够适应不同设备的屏幕尺寸。

使用媒体查询可以实现响应式设计。

响应式设计可以提供更好的用户体验。
