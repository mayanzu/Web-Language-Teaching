第15课：CSS复合选择器

CSS复合选择器是由两个或多个基础选择器组合而成的选择器，它可以更精确地选择HTML元素。本节课我们将学习各种复合选择器，包括后代选择器、子选择器、兄弟选择器、交集选择器和并集选择器。

后代选择器 子选择器 相邻兄弟选择器 通用兄弟选择器 交集选择器 并集选择器

一、后代选择器

后代选择器用于选择某个元素的所有后代元素，无论层级有多深，选择器之间用空格分隔。

1.1 后代选择器的语法

/* 语法：祖先选择器 后代选择器 { 样式规则 } */
祖先选择器 后代选择器 {
    属性1: 值1;
    属性2: 值2;
}

/* 示例：选择所有 <div> 内的 <p> 元素 */
div p {
    color: blue; /* 设置文字颜色为蓝色 */
    font-size: 16px; /* 设置字体大小为16像素 */
    line-height: 1.5; /* 设置行高为1.5倍 */
}

1.3 后代选择器的特点

  • 选择器之间用空格分隔
  • 选择所有层级的后代元素，无论嵌套多深
  • 优先级高于单独的选择器
  • 可以连续使用多个选择器，如 div ul li a

二、子选择器

子选择器用于选择某个元素的直接子元素，只匹配第一层嵌套关系，选择器之间用>分隔。

2.1 子选择器的语法

/* 语法：父选择器 > 子选择器 { 样式规则 } */
父选择器 > 子选择器 {
    属性1: 值1;
    属性2: 值2;
}

/* 示例：选择所有直接作为 <div> 子元素的 <p> 元素 */
div > p {
    color: red; /* 设置文字颜色为红色 */
    font-weight: bold; /* 设置文字加粗 */
    background-color: #f0f0f0; /* 设置背景色 */
    padding: 5px; /* 设置内边距 */
}

  • 选择器之间用>符号分隔
  • 只选择直接子元素，不匹配深层嵌套的后代元素
  • 优先级高于后代选择器
  • 适合精确选择特定层级的元素

三、相邻兄弟选择器

相邻兄弟选择器用于选择某个元素的下一个直接相邻的兄弟元素，两个元素必须拥有相同的父元素，选择器之间用+分隔。

3.1 相邻兄弟选择器的语法

/* 语法：元素1 + 元素2 { 样式规则 } */
元素1 + 元素2 {
    属性1: 值1;
    属性2: 值2;
}

/* 示例：选择所有在 <h2> 后面直接相邻的 <p> 元素 */
h2 + p {
    color: green; /* 设置文字颜色为绿色 */
    font-style: italic; /* 设置文字斜体 */
    background-color: #e8f5e8; /* 设置背景色 */
    padding: 8px; /* 设置内边距 */
    border-radius: 4px; /* 设置圆角 */
}

  • 选择器之间用+符号分隔
  • 只选择紧接在第一个元素后面的直接相邻的兄弟元素
  • 两个元素必须拥有相同的父元素
  • 只匹配下一个兄弟元素，不匹配前面的兄弟元素

四、通用兄弟选择器

通用兄弟选择器用于选择某个元素后面的所有兄弟元素，两个元素必须拥有相同的父元素，选择器之间用~分隔。

4.1 通用兄弟选择器的语法

/* 语法：元素1 ~ 元素2 { 样式规则 } */
元素1 ~ 元素2 {
    属性1: 值1;
    属性2: 值2;
}

/* 示例：选择所有在 <h2> 后面的 <p> 元素 */
h2 ~ p {
    color: purple; /* 设置文字颜色为紫色 */
    text-decoration: underline; /* 设置文字下划线 */
    font-size: 18px; /* 设置字体大小为18像素 */
}

4.3 通用兄弟选择器的特点

  • 选择器之间用~符号分隔
  • 选择某个元素后面的所有兄弟元素，无论中间有多少其他元素
  • 两个元素必须拥有相同的父元素
  • 只匹配后面的兄弟元素，不匹配前面的兄弟元素
  • 可以匹配多个兄弟元素

五、交集选择器

交集选择器用于选择同时满足多个条件的元素，选择器之间直接连接，没有分隔符。

5.1 交集选择器的语法

/* 语法：选择器1选择器2选择器3 { 样式规则 } */
选择器1选择器2选择器3 {
    属性1: 值1;
    属性2: 值2;
}

/* 示例：选择所有具有 highlight 类的 <p> 元素 */
p.highlight {
    color: orange; /* 设置文字颜色为橙色 */
    font-weight: bold; /* 设置文字加粗 */
    background-color: #fff3cd; /* 设置背景色 */
    padding: 10px; /* 设置内边距 */
    border: 1px solid #ffeeba; /* 设置边框 */
    border-radius: 4px; /* 设置圆角 */
}

5.2 交集选择器示例

预览效果

5.3 交集选择器的特点

  • 选择器之间没有分隔符，直接连接
  • 可以组合多种选择器，如元素选择器+类选择器+ID选择器
  • 所有条件必须同时满足才会被选中
  • 优先级高于单个选择器
  • 常见的组合：元素选择器+类选择器（如 p.highlight）

六、并集选择器

并集选择器用于选择多个选择器匹配的元素，选择器之间用逗号分隔。例如，h1, h2, h3会选择所有的<h1>、<h2>和<h3>元素。

/* 选择所有 <h1>、<h2> 和 <h3> 元素 */
h1, h2, h3 {
    color: #333;
    font-family: Arial, sans-serif;
    margin-top: 20px;
    border-bottom: 1px solid #ccc;
    padding-bottom: 5px;
}

八、课程小结

本节课我们学习了CSS复合选择器，它们是由两个或多个基础选择器组合而成，可以更精确地选择HTML元素。

8.1 知识点回顾

  • 后代选择器：使用空格分隔，选择所有后代元素，如div p
  • 子选择器：使用>分隔，选择直接子元素，如div > p
  • 相邻兄弟选择器：使用+分隔，选择下一个直接相邻元素，如h2 + p
  • 通用兄弟选择器：使用~分隔，选择所有后面的兄弟元素，如h2 ~ p
  • 交集选择器：直接连接选择器，选择同时满足条件的元素，如p.highlight
  • 并集选择器：使用逗号分隔，选择多个选择器匹配的元素，如h1, h2, h3

8.2 重点记忆

📌 选择器组合技巧

1. 后代选择器 vs 子选择器：后代选择器选择所有后代，子选择器只选择直接子元素

2. 兄弟选择器：相邻兄弟选择器只选择下一个元素，通用兄弟选择器选择所有后面的元素

3. 交集选择器：可以结合多种条件，如元素+类+ID

4. 并集选择器：用于简化代码，共享相同样式

8.3 最佳实践

  1. 选择器要简洁明了，避免过度复杂的嵌套
  2. 优先使用类选择器，结合适当的复合选择器
  3. 考虑选择器的性能，避免不必要的通配符和复杂选择器
  4. 选择器名称要语义化，便于理解和维护
