一、颜色表示法

CSS提供了多种方式来表示颜色，每种方式都有其特点和适用场景。

📖 生活类比

颜色表示法就像不同的语言描述同一个东西：

  • 颜色关键字：像说"红色"、"蓝色"，简单直接
  • 十六进制：像颜色的"身份证号码"，精确但需要记忆
  • RGB：像用红、绿、蓝三种颜料调配，直观可控

1.1 颜色关键字

CSS预定义了140多个颜色名称，可以直接使用英文单词表示颜色：

颜色名 中文 说明
red 红色 纯红色
blue 蓝色 纯蓝色
green 绿色 纯绿色
white 白色 纯白色
black 黑色 纯黑色
gray 灰色 中灰色
orange 橙色 橙色
pink 粉色 粉红色
💡 使用建议

颜色关键字适合快速测试或简单项目，但在正式项目中建议使用十六进制或RGB，因为：

  • 颜色关键字数量有限，无法表示所有颜色
  • 不同浏览器对颜色名的解析可能略有差异

1.2 十六进制颜色（Hex）

十六进制是最常用的颜色表示法，格式为 #RRGGBB，其中RR、GG、BB分别表示红、绿、蓝三个通道的值（00-FF）。

/* 十六进制颜色示例 */
.text-red { color: #FF0000; }     /* 纯红色 */
.text-green { color: #00FF00; }   /* 纯绿色 */
.text-blue { color: #0000FF; }    /* 纯蓝色 */
.text-black { color: #000000; }   /* 黑色 */
.text-white { color: #FFFFFF; }   /* 白色 */

/* 简写形式：当每两位相同时可以简写 */
.text-red { color: #F00; }        /* 等同于 #FF0000 */
.text-gray { color: #888; }       /* 等同于 #888888 */
📌 理解十六进制颜色

十六进制使用0-9和A-F共16个字符，其中：

  • 00 = 最小值（0），表示该颜色通道关闭
  • FF = 最大值（255），表示该颜色通道全开
  • #FF0000 = 红色全开，绿蓝关闭 = 纯红色

1.3 RGB颜色

RGB使用十进制数值表示颜色，更直观易懂，格式为 rgb(红, 绿, 蓝)，每个值范围是0-255。

/* RGB颜色示例 */
.text-red { color: rgb(255, 0, 0); }      /* 纯红色 */
.text-green { color: rgb(0, 255, 0); }    /* 纯绿色 */
.text-blue { color: rgb(0, 0, 255); }     /* 纯蓝色 */
.text-gray { color: rgb(128, 128, 128); } /* 灰色 */

/* RGBA：带透明度的RGB */
.text-transparent { color: rgba(255, 0, 0, 0.5); } /* 半透明红色 */
/* 第四个参数是透明度：0=完全透明，1=完全不透明 */
表示法 格式 优点 适用场景
颜色关键字 red 简单易记 快速测试、简单项目
十六进制 #FF0000 最常用、简洁 正式项目、设计稿还原
RGB rgb(255,0,0) 直观、易调整 动态颜色、JavaScript操作
RGBA rgba(255,0,0,0.5) 支持透明度 需要透明效果的场景

二、常用颜色属性

CSS提供了多个属性来控制页面元素的颜色。

2.1 color属性（文字颜色）

color属性用于设置文字的颜色：

/* 设置文字颜色 */
p {
    color: #333333;    /* 深灰色文字，比纯黑色更柔和 */
}

a {
    color: #0066CC;    /* 链接用蓝色 */
}

.warning {
    color: #FF0000;    /* 警告文字用红色 */
}

2.2 background-color属性（背景颜色）

background-color属性用于设置元素的背景颜色：

/* 设置背景颜色 */
body {
    background-color: #F5F5F5;    /* 浅灰色背景 */
}

.header {
    background-color: #333333;    /* 深色头部 */
    color: white;                  /* 白色文字 */
}

.highlight {
    background-color: #FFFF00;    /* 黄色高亮 */
}

2.3 border-color属性（边框颜色）

border-color属性用于设置边框的颜色：

/* 设置边框颜色 */
.box {
    border: 2px solid;           /* 先设置边框样式 */
    border-color: #CCCCCC;       /* 再设置边框颜色 */
}

/* 也可以一起写 */
.box {
    border: 2px solid #CCCCCC;
}
⚠️ 常见错误
  • ❌ color: #F5F5F5 用于背景 → 应该用 background-color
  • ❌ 忘记设置 border-style → 边框不会显示
  • ❌ 深色背景配深色文字 → 文字看不清

三、字体属性

CSS提供了丰富的字体控制属性，让我们可以精确控制文字的显示效果。

📖 生活类比

设置字体就像选择写字用的笔：

  • font-family：选择什么牌子的笔（宋体、黑体）
  • font-size：笔尖的粗细（字号大小）
  • font-weight：下笔的力度（字体粗细）

3.1 font-family（字体族）

font-family属性用于设置文字使用的字体：

/* 设置字体 */
body {
    /* 字体栈：浏览器会按顺序查找可用字体 */
    font-family: "Microsoft YaHei", "微软雅黑", Arial, sans-serif;
}

/* 常用字体组合 */
.chinese-text {
    font-family: "PingFang SC", "Microsoft YaHei", sans-serif;
}

.code-text {
    font-family: "Consolas", "Monaco", monospace;
}
字体类型 常用字体 特点
无衬线体 Arial, 微软雅黑, 苹方 现代、简洁，适合屏幕阅读
衬线体 Times, 宋体, Georgia 传统、正式，适合印刷品
等宽字体 Consolas, Monaco 每个字符宽度相同，适合代码

3.2 font-size（字号）

font-size属性用于设置文字的大小：

/* 设置字号 */
h1 { font-size: 32px; }    /* 大标题 */
h2 { font-size: 24px; }    /* 二级标题 */
h3 { font-size: 18px; }    /* 三级标题 */
p { font-size: 16px; }     /* 正文 */
small { font-size: 14px; } /* 小字 */
💡 字号建议

网页正文的最小字号建议不小于14px，否则在某些设备上可能难以阅读。常见的正文字号为16px。

3.3 font-weight（字体粗细）

font-weight属性用于设置文字的粗细程度：

/* 设置字体粗细 */
.normal { font-weight: normal; }   /* 正常，等于400 */
.bold { font-weight: bold; }       /* 粗体，等于700 */

/* 也可以用数值表示 */
.light { font-weight: 300; }       /* 细体 */
.regular { font-weight: 400; }     /* 正常 */
.medium { font-weight: 500; }      /* 中等 */
.bold { font-weight: 700; }        /* 粗体 */

3.4 font-style（字体样式）

font-style属性用于设置文字是否倾斜：

/* 设置字体样式 */
.normal { font-style: normal; }    /* 正常 */
.italic { font-style: italic; }    /* 斜体 */

/* 常用于强调文字 */
em {
    font-style: italic;
}

四、文本样式

除了字体属性，CSS还提供了控制文本显示方式的属性。

4.1 text-align（文本对齐）

text-align属性用于设置文本的水平对齐方式：

值 效果 使用场景
left 左对齐（默认） 普通文本内容
center 居中对齐 标题、按钮文字
right 右对齐 日期、价格
justify 两端对齐 报纸、杂志排版 
/* 文本对齐示例 */
.title { text-align: center; }     /* 标题居中 */
.price { text-align: right; }      /* 价格右对齐 */
.article { text-align: justify; }  /* 文章两端对齐 */

4.2 line-height（行高）

line-height属性用于设置文本的行间距，可以提高文本的可读性：

/* 设置行高 */
p {
    line-height: 1.6;    /* 推荐值：1.5-1.8 */
}

/* 不同的写法 */
.px { line-height: 24px; }    /* 像素值 */
.ratio { line-height: 1.6; }  /* 比例值（推荐）*/
.percent { line-height: 160%; }/* 百分比 */
💡 行高建议

中文网页的行高建议设置为1.5-1.8倍，这样段落阅读起来会更加舒适。

4.3 text-decoration（文本装饰）

text-decoration属性用于添加或移除文本的装饰线：

/* 文本装饰示例 */
a { text-decoration: none; }              /* 移除下划线 */
.underline { text-decoration: underline; } /* 添加下划线 */
.del { text-decoration: line-through; }   /* 删除线 */

4.4 text-indent（首行缩进）

text-indent属性用于设置段落首行的缩进：

/* 首行缩进 */
p {
    text-indent: 2em;    /* 缩进2个字符宽度 */
}

五、本课小结

知识点回顾

  • 颜色关键字：使用英文单词表示颜色，如 red、blue
  • 十六进制颜色：最常用的颜色表示法，如 #FF0000
  • RGB/RGBA颜色：使用数值表示颜色，支持透明度
  • font-family：设置字体，使用字体栈确保兼容性
  • font-size：设置字号，网页正文建议16px左右
  • text-align：设置文本对齐方式
  • line-height：设置行高，建议1.5-1.8倍

重点记忆

属性 作用 常用值

background-color 背景颜色 #F5F5F5
font-size 字号 16px
line-height 行高 1.6
text-align 文本对齐 left/center/right
