第27课：JS函数

如果把程序比作工厂流水线，函数就是一台台专用机器：输入原料（参数），机器内部按步骤处理（函数体），再输出产品（返回值）。本课将学习如何"造机器"和"用机器"，让代码更加模块化、可复用、易维护。

函数声明 函数调用 参数与返回值 箭头函数 作用域 闭包

一、为什么需要函数？

想象你正在开发一个程序，需要多次计算两个数的和。如果每次都重复写相同的代码：

// 第一次计算
let result1 = 3 + 5;
console.log('结果1:', result1);

// 第二次计算
let result2 = 10 + 20;
console.log('结果2:', result2);

// 第三次计算...代码不断重复

这样做有什么问题？

  • 代码重复：相同逻辑写了很多遍
  • 难以维护：如果计算方式要改，每处都得改
  • 可读性差：看不出代码的意图

函数的解决方案：把重复的代码封装起来，给它一个名字，需要时调用即可。

生活中的类比
  • 洗衣机：放入脏衣服（参数），按下开始键，内部执行洗涤程序（函数体），得到干净的衣服（返回值）
  • 菜谱：食材是参数，烹饪步骤是函数体，做好的菜是返回值
  • ATM取款：输入金额（参数），ATM执行验证、扣款（函数体），返回现金（返回值）

使用函数后，代码变得简洁高效：

// 定义函数（造机器）
function add(a, b) {
    return a + b;
}

// 调用函数（用机器）
let result1 = add(3, 5);     // 8
let result2 = add(10, 20);   // 30
let result3 = add(100, 200); // 300

二、函数声明与调用

2.1 函数声明的语法

创建函数的标准方式是函数声明：

function 函数名(参数1, 参数2, ...) {
    // 函数体：要执行的代码
    return 返回值;  // 可选
}
组成部分 说明 示例
function 关键字 声明这是一个函数 function
函数名 遵循变量命名规则，应有描述性 calculateTotal
参数列表 小括号内，多个参数用逗号分隔 (price, quantity)
函数体 大括号内，包含要执行的代码 { return price * quantity; }
返回值 使用 return 返回结果（可选） return total;

2.2 函数调用

函数定义后不会自动执行，需要调用才能运行：

// 定义函数
function sayHello() {
    console.log('Hello, World!');
}

// 调用函数（函数名后加括号）
sayHello();  // 输出: Hello, World!
sayHello();  // 可以多次调用
定义 vs 调用
  • 定义函数：只是告诉 JavaScript "有这么一个函数"，不会执行
  • 调用函数：函数名 + ()，才会真正执行函数体
function greet() {
    console.log('Hi!');
}

greet;    //  只是引用函数，不会执行
greet();  //  调用函数，输出 Hi!

三、参数详解

参数让函数更加灵活，可以处理不同的输入数据。

3.1 形参与实参

术语 定义 位置 示例
形参 (Parameter) 函数定义时的占位符 函数声明 function add(a, b)
实参 (Argument) 函数调用时传入的实际值 函数调用 add(3, 5) 
// a, b 是形参（定义时）
function multiply(a, b) {
    return a * b;
}

// 10, 5 是实参（调用时）
let result = multiply(10, 5);  // 50

3.2 参数默认值

ES6 允许为参数设置默认值，当调用时未传入该参数时使用默认值：

function greet(name = '访客', greeting = '你好') {
    return `${greeting}，${name}！`;
}

console.log(greet());              // "你好，访客！"
console.log(greet('小明'));        // "你好，小明！"
console.log(greet('小明', '早上好')); // "早上好，小明！"

3.3 多个参数

函数可以接收任意数量的参数，但参数过多会使函数难以使用：

// 计算商品总价
function calculateTotal(price, quantity, discount = 0) {
    let total = price * quantity;
    total = total - total * discount;
    return total;
}

// 原价100，买2件，打8折（0.2的折扣）
let total = calculateTotal(100, 2, 0.2);
console.log(total);  // 160
参数数量建议

一般建议函数参数不超过 3 个。如果需要更多参数，考虑使用对象来传递：

//  参数太多，难以记住顺序
function createUser(name, age, email, phone, address) { }

//  使用对象，清晰明了
function createUser(options) {
    const { name, age, email } = options;
    // ...
}
createUser({ name: '小明', age: 18, email: 'test@example.com' });

3.4 返回值

return 语句用于从函数中返回一个值，并立即结束函数执行。

function divide(a, b) {
    if (b === 0) {
        return '错误：除数不能为0';  // 提前返回
    }
    return a / b;
}

console.log(divide(10, 2));  // 5
console.log(divide(10, 0));  // "错误：除数不能为0"

返回值的特点

  • 函数只能返回一个值（可以是数组或对象来包含多个值）
  • return 后的代码不会执行
  • 没有 return 或只写 return;，函数返回 undefined
// 返回多个值：使用数组
function getMinMax(numbers) {
    const min = Math.min(...numbers);
    const max = Math.max(...numbers);
    return [min, max];  // 返回数组
}

const [min, max] = getMinMax([3, 1, 4, 1, 5, 9]);
console.log(min, max);  // 1 9

// 没有返回值的函数
function logMessage(msg) {
    console.log(msg);
    // 没有 return，返回 undefined
}

let result = logMessage('Hello');
console.log(result);  // undefined

四、函数表达式

除了函数声明，还可以用函数表达式创建函数：

// 函数声明
function add1(a, b) {
    return a + b;
}

// 函数表达式（将函数赋值给变量）
const add2 = function(a, b) {
    return a + b;
};

// 两种方式调用相同
add1(1, 2);  // 3
add2(1, 2);  // 3

函数声明 vs 函数表达式

特性 函数声明 函数表达式
语法 function name() {} const name = function() {}
提升 (Hoisting) 会提升，可以在声明前调用 不会提升，必须先定义再调用
使用场景 通用函数 回调函数、立即执行函数
什么是提升 (Hoisting)？

JavaScript 会在代码执行前，先把函数声明"提升"到作用域顶部：

//  函数声明：可以先调用
sayHi();  // "Hi!"
function sayHi() {
    console.log('Hi!');
}

//  函数表达式：不能先调用
sayBye();  // 报错：Cannot access 'sayBye' before initialization
const sayBye = function() {
    console.log('Bye!');
};

4.2 箭头函数 (Arrow Function)

ES6 引入了更简洁的函数写法——箭头函数：

// 传统函数
const add1 = function(a, b) {
    return a + b;
};

// 箭头函数
const add2 = (a, b) => {
    return a + b;
};

// 箭头函数简写（单行返回时可省略 {} 和 return）
const add3 = (a, b) => a + b;

// 单参数时可省略括号
const double = x => x * 2;

// 无参数时必须写空括号
const sayHi = () => console.log('Hi!');

箭头函数的简写规则

情况 完整写法 简写
无参数 () => { return 1; } () => 1
单参数 (x) => { return x * 2; } x => x * 2
多参数 (a, b) => { return a + b; } (a, b) => a + b
多行函数体 不能简写，必须用 {} 和 return
何时使用箭头函数？
  • 简单的单行函数
  • 回调函数（如数组方法中的回调）
  • 箭头函数没有自己的 this，在需要 this 的场景要小心使用

五、作用域 (Scope)

作用域决定了变量在代码中的可访问范围。理解作用域对于编写正确、无 bug 的代码至关重要。

5.1 全局作用域与局部作用域

作用域类型 定义位置 可访问范围
全局作用域 函数外部 整个程序任何地方
函数作用域 函数内部 仅在函数内部
块级作用域 {} 内部（let/const） 仅在该代码块内 
// 全局变量
let globalVar = '我是全局变量';

function myFunction() {
    // 局部变量（函数作用域）
    let localVar = '我是局部变量';
    
    console.log(globalVar);  //  可以访问全局变量
    console.log(localVar);   //  可以访问局部变量
    
    if (true) {
        // 块级作用域
        let blockVar = '我是块级变量';
        console.log(blockVar);  //  可以访问
    }
    // console.log(blockVar);  //  错误：blockVar 不存在
}

myFunction();
console.log(globalVar);  //  可以访问
// console.log(localVar);   //  错误：localVar 不存在
避免全局变量污染

过多的全局变量会导致命名冲突和难以调试的 bug。尽量将变量限制在需要的作用域内：

//  不好：污染全局作用域
var count = 0;
var name = 'test';

//  好：封装在函数内
function createCounter() {
    let count = 0;  // 局部变量
    // ...
}

5.2 闭包 (Closure) 初探

闭包是 JavaScript 中一个强大但容易让人困惑的概念。简单来说：

闭包 = 函数 + 函数能访问的外部变量

function createCounter() {
    let count = 0;  // 这个变量被"闭包"了
    
    // 返回一个函数
    return function() {
        count++;
        return count;
    };
}

const counter = createCounter();
console.log(counter());  // 1
console.log(counter());  // 2
console.log(counter());  // 3

// 每次调用 createCounter() 都会创建新的闭包
const counter2 = createCounter();
console.log(counter2());  // 1（独立的 count）
闭包的作用
  • 数据私有化：外部无法直接访问 count，只能通过返回的函数操作
  • 状态保持：count 的值在多次调用间得以保持
  • 模块化：可以创建独立的、互不干扰的实例
闭包何时形成？

当一个函数内部定义了另一个函数，且内部函数引用了外部函数的变量时，闭包就形成了。即使外部函数已经执行完毕，内部函数仍然可以访问那些变量。

本课小结

知识点回顾

  • 函数是可重复使用的代码块，接收参数、执行任务、返回结果
  • 函数声明使用 function 关键字，会被提升
  • 函数表达式将函数赋值给变量，不会被提升
  • 箭头函数是更简洁的函数写法，适合回调和简单函数
  • 参数让函数更灵活，可以设置默认值
  • 返回值使用 return，会立即结束函数执行
  • 作用域决定变量的可访问范围（全局、函数、块级）
  • 闭包让函数可以"记住"其定义时的作用域

重点记忆

概念 语法/示例 要点
函数声明 function name() {} 会提升，可先调用后声明
箭头函数 (a, b) => a + b 简洁，无自己的 this
默认参数 function f(x = 10) 未传参时使用默认值
闭包 函数 + 外部变量 数据私有化、状态保持

常见错误提醒
  • 函数提升：函数声明会被提升，可以在定义之前调用；但函数表达式不会被提升
  • return换行：return后换行，JavaScript会自动在行尾添加分号，导致返回undefined
  • 箭头函数this：箭头函数没有自己的this，会继承外层函数的this
  • 参数个数：调用函数时传入的参数个数可以少于或多于定义时的参数，不会报错
