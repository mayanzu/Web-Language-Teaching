第29课：JS DOM操作

DOM（文档对象模型）是JavaScript操作网页的核心接口。通过DOM，我们可以动态地修改网页内容、改变样式、创建和删除元素，让网页真正"活"起来！

DOM树结构 元素选择 内容读写 样式操作 classList 元素创建删除

一、什么是DOM？

DOM（Document Object Model，文档对象模型）是浏览器提供的一套编程接口，它将HTML文档表示为一个树形结构，让JavaScript可以访问和操作网页中的每个元素。

💡 生活中的类比
  • DOM操作 = 遥控器：就像用遥控器控制电视（换台、调音量），JavaScript通过DOM控制网页（改文字、换颜色）
  • 没有DOM = 静态海报：网页只能展示固定内容，无法响应用户操作
  • 有了DOM = 智能显示屏：网页可以根据用户操作实时更新

DOM操作让我们能够：

  • 响应用户交互：点击、输入、滚动等操作触发页面变化
  • 动态更新内容：无需刷新页面就能显示新数据
  • 创建交互体验：实现下拉菜单、轮播图、表单验证等功能
  • 构建单页应用：像微信网页版、Gmail这样的复杂应用

没有DOM vs 有DOM

<!-- 没有DOM：购物车数量写死，无法更新 -->
<span>购物车(0)</span>
<button>加入购物车</button>
<!-- 点击按钮什么都不会发生 -->
// 有了DOM：点击按钮，数字实时增加！
let count = 0;
function addToCart() {
    count++;
    document.getElementById('cart-count').innerText = `购物车(${count})`;
}

1.2 DOM树结构

浏览器解析HTML代码时，会将每个标签转换为DOM节点，构建成树状结构：

<!DOCTYPE html>
<html>
  <head>
    <title>我的网页</title>
  </head>
  <body>
    <h1>标题</h1>
    <p>段落文本</p>
  </body>
</html>

对应的DOM树结构：

document (根节点)
  └─ html
      ├─ head
      │   └─ title
      │       └─ "我的网页" (文本节点)
      └─ body
          ├─ h1
          │   └─ "标题" (文本节点)
          └─ p
              └─ "段落文本" (文本节点)

DOM节点类型

节点类型 说明 示例
元素节点 HTML标签 <div>、<p>、<button>
文本节点 标签内的文本内容 "Hello World"
属性节点 标签的属性 id="box"、class="btn"
文档节点 整个文档 document
核心概念：
  • DOM将HTML文档转换为JavaScript可以操作的对象
  • 每个HTML标签都是一个DOM元素节点
  • document对象是访问DOM的入口

二、选择元素的方法

要操作网页元素，第一步是选中它们。JavaScript提供了多种选择器方法。

2.1 通过ID选择 - getElementById

// getElementById() - 通过ID选择单个元素
// 参数：ID字符串（不需要#号）
// 返回：匹配的元素，找不到返回null

const header = document.getElementById('main-header');
console.log(header);  // 返回id为main-header的元素

// 如果元素不存在
const notExist = document.getElementById('not-exist');
console.log(notExist);  // null

2.2 通过标签名选择 - getElementsByTagName

// getElementsByTagName() - 通过标签名选择多个元素
// 参数：标签名字符串
// 返回：HTMLCollection（动态集合）

const allDivs = document.getElementsByTagName('div');
console.log(allDivs.length);  // div元素的数量

const allParagraphs = document.getElementsByTagName('p');

2.3 通过类名选择 - getElementsByClassName

// getElementsByClassName() - 通过class选择多个元素
// 参数：类名字符串（不需要.号）
// 返回：HTMLCollection（动态集合）

const boxes = document.getElementsByClassName('box');
console.log(boxes.length);  // class为box的元素数量

2.2 CSS选择器方法（推荐）

querySelector - 选择第一个匹配元素

// querySelector() - 通过CSS选择器选择第一个匹配元素
// 参数：CSS选择器字符串（和CSS写法完全一样）
// 返回：第一个匹配的元素，找不到返回null

// 选择标签
const firstDiv = document.querySelector('div');

// 选择类（需要加.）
const box = document.querySelector('.box');

// 选择ID（需要加#）
const header = document.querySelector('#main-header');

// 复杂选择器
const activeItem = document.querySelector('ul li.active');
const firstButton = document.querySelector('.container > button');

querySelectorAll - 选择所有匹配元素

// querySelectorAll() - 选择所有匹配的元素
// 参数：CSS选择器字符串
// 返回：NodeList（静态集合）

const allButtons = document.querySelectorAll('button');
console.log(allButtons.length);

// 遍历所有匹配的元素
allButtons.forEach(button => {
    console.log(button.innerText);
});

// 选择所有class为item的元素
const items = document.querySelectorAll('.item');

选择器方法对比

方法 返回值 适用场景
getElementById 单个元素或null 有明确ID的元素，最快
querySelector 单个元素或null 复杂选择器，只要第一个
querySelectorAll NodeList（静态） 需要选择多个元素
getElementsByClassName HTMLCollection（动态） 按class选择
getElementsByTagName HTMLCollection（动态） 按标签名选择
注意区别！
  • getElementById：参数不需要 # 号
  • querySelector：参数需要完整的CSS选择器（#id、.class）
  • 如果元素不存在，返回null或空集合，使用前最好检查

三、操作元素内容

3.1 读取元素内容

元素内容有多种表现形式，要根据需求选择合适的属性。

属性 返回内容 适用场景
innerText 可见的纯文本 获取/设置用户可见文本
textContent 所有文本（包括隐藏） 纯文本操作，性能更好
innerHTML HTML代码 需要读取或设置HTML结构 
// 假设有这样的HTML：
// <div id="box">Hello <strong>World</strong></div>

const box = document.getElementById('box');

// innerText - 纯文本（忽略HTML标签）
console.log(box.innerText);   // "Hello World"

// textContent - 所有文本
console.log(box.textContent); // "Hello World"

// innerHTML - 包含HTML标签
console.log(box.innerHTML);   // "Hello <strong>World</strong>"

读取元素属性

// <img id="avatar" src="photo.jpg" alt="头像" data-user="123">

const img = document.getElementById('avatar');

// getAttribute() - 获取属性值
console.log(img.getAttribute('src'));       // "photo.jpg"
console.log(img.getAttribute('alt'));       // "头像"
console.log(img.getAttribute('data-user')); // "123"

// 也可以直接访问属性
console.log(img.src);  // 完整URL
console.log(img.alt);  // "头像"

3.2 修改元素内容

const title = document.getElementById('title');
const content = document.getElementById('content');

// 修改文本
title.innerText = '新标题';
title.textContent = '新标题';

// 修改HTML（可以插入标签）
content.innerHTML = '<strong>加粗</strong>的内容';

// 追加内容
content.innerHTML += '<p>追加的段落</p>';

// 清空内容
content.innerHTML = '';
innerHTML的安全风险！

使用innerHTML设置用户输入的内容时要小心XSS攻击：

// ❌ 危险！用户输入可能包含恶意脚本
element.innerHTML = userInput;

// ✅ 安全！使用innerText会转义HTML
element.innerText = userInput;

修改元素属性

const img = document.getElementById('avatar');
const link = document.getElementById('link');

// setAttribute() - 设置属性
img.setAttribute('src', 'new-photo.jpg');
img.setAttribute('alt', '新图片');

// 直接设置属性
img.src = 'new-photo.jpg';
link.href = 'https://example.com';

// 添加自定义属性
img.setAttribute('data-id', '456');

// removeAttribute() - 删除属性
img.removeAttribute('alt');

3.3 操作元素样式

方式一：通过style属性

const box = document.getElementById('box');

// 修改样式（注意：CSS属性名用驼峰命名）
box.style.color = 'white';
box.style.backgroundColor = '#0066CC';  // background-color
box.style.fontSize = '20px';            // font-size
box.style.marginTop = '10px';           // margin-top

方式二：通过classList操作（推荐）

const box = document.getElementById('box');

// add() - 添加class
box.classList.add('highlight');
box.classList.add('big', 'bold');  // 添加多个

// remove() - 删除class
box.classList.remove('old-class');

// toggle() - 切换class（有则删，无则加）
box.classList.toggle('active');

// contains() - 检查是否包含某class
if (box.classList.contains('highlight')) {
    console.log('有高亮样式');
}

// replace() - 替换class
box.classList.replace('old', 'new');
💡 推荐使用classList

classList比直接修改style更好：

  • 样式定义在CSS文件中，便于维护
  • 可以一次切换多个样式
  • 代码更清晰，关注点分离

四、创建和删除元素

4.1 创建元素

// createElement() - 创建新元素
const newDiv = document.createElement('div');
newDiv.innerText = '新创建的div';
newDiv.className = 'box';
newDiv.id = 'new-box';

// 设置属性和样式
newDiv.setAttribute('data-id', '123');
newDiv.style.backgroundColor = '#e0e0e0';

// appendChild() - 添加到父元素末尾
const container = document.getElementById('container');
container.appendChild(newDiv);

// insertBefore() - 在指定元素前插入
const firstChild = container.firstChild;
container.insertBefore(newDiv, firstChild);

创建复杂结构

// 创建一个带按钮的卡片
function createCard(title) {
    // 创建卡片容器
    const card = document.createElement('div');
    card.className = 'card';
    
    // 创建标题
    const h3 = document.createElement('h3');
    h3.innerText = title;
    
    // 创建删除按钮
    const btn = document.createElement('button');
    btn.innerText = '删除';
    btn.onclick = function() {
        card.remove();  // 点击删除整个卡片
    };
    
    // 组装
    card.appendChild(h3);
    card.appendChild(btn);
    
    return card;
}

// 使用
const newCard = createCard('我的卡片');
document.body.appendChild(newCard);

4.2 删除元素

// 方式一：remove() - 直接删除元素本身
const box = document.getElementById('box');
box.remove();

// 方式二：removeChild() - 从父元素中删除子元素
const parent = document.getElementById('parent');
const child = document.getElementById('child');
parent.removeChild(child);

// 清空所有子元素
const container = document.getElementById('container');
container.innerHTML = '';  // 简单但可能有性能问题

// 或者循环删除
while (container.firstChild) {
    container.removeChild(container.firstChild);
}
常用DOM操作总结：
操作 方法
创建元素 document.createElement('div')
添加到末尾 parent.appendChild(child)
插入到前面 parent.insertBefore(new, ref)
删除元素 element.remove()
替换元素 parent.replaceChild(new, old)

实验 04：待办事项列表 综合实战
HTML 预览
<h3>📋 待办事项</h3> <div> <input id="todoInput" placeholder="输入待办事项"> <button onclick="addTodo()">添加</button> <button onclick="clearAll()">清空</button> </div> <div id="todoList"></div>

function addTodo() { const input = document.getElementById('todoInput'); const text = input.value.trim(); if (!text) { alert('请输入内容'); return; } // 创建待办项 const item = document.createElement('div'); item.className = 'todo-item'; // 创建文本 const span = document.createElement('span'); span.innerText = text; // 创建完成按钮 const doneBtn = document.createElement('button'); doneBtn.innerText = '✓'; doneBtn.className = 'done-btn'; doneBtn.onclick = function() { span.classList.toggle('completed'); }; // 创建删除按钮 const delBtn = document.createElement('button'); delBtn.innerText = '✕'; delBtn.className = 'del-btn'; delBtn.onclick = function() { item.remove(); }; // 组装 item.appendChild(doneBtn); item.appendChild(span); item.appendChild(delBtn); document.getElementById('todoList').appendChild(item); input.value = ''; } function clearAll() { if (confirm('确定清空所有待办？')) { document.getElementById('todoList').innerHTML = ''; } }

五、真实案例展示

案例：动态网页中的应用 Real World

实际应用场景：

  • 社交媒体：发布新动态后，使用DOM动态添加到列表顶部
  • 购物车：添加商品后更新数量和总价显示
  • 表单验证：输入时实时显示错误提示
  • 无限滚动：滚动到底部时动态加载更多内容
  • 评论系统：提交评论后立即显示在页面上
// 评论系统示例
function postComment(text) {
    const comment = document.createElement('div');
    comment.className = 'comment';
    comment.innerHTML = `
        <span class="time">${new Date().toLocaleString()}</span>
        <p>${text}</p>
        <button onclick="this.parentElement.remove()">删除</button>
    `;
    
    // 插入到最前面
    const list = document.getElementById('comment-list');
    list.insertBefore(comment, list.firstChild);
}
