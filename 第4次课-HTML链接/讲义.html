📝 课程小结

第4课：HTML链接

在本节课中，我们将学习HTML中的链接元素。链接是互联网的核心，它允许用户从一个页面跳转到另一个页面，连接起整个万维网。HTML提供了强大的链接功能，通过本节课的学习，你将掌握如何创建各种类型的链接，包括外部链接、内部链接、锚点链接、邮件链接和电话链接等。

基本链接 链接属性 内部链接 锚点链接 邮件链接 电话链接

一、基本链接语法

在HTML中，链接使用<a>标签（anchor的缩写）定义。链接的基本语法如下：

<a href="url">链接文本</a>
  • href属性：指定链接的目标URL
  • 链接文本：用户可以点击的可见文本

1.1 外部链接

外部链接是指向其他网站的链接，它的URL通常以http://或https://开头。

二、链接属性

<a>标签支持多种属性，用于控制链接的行为和外观。以下是一些常用的链接属性：

属性 描述 示例
href 指定链接的目标URL href="https://www.baidu.com"
target 指定在何处打开链接 target="_blank"
title 指定链接的提示文本 title="访问百度首页"
rel 指定当前文档与目标文档的关系 rel="noopener noreferrer"

2.1 target属性

target属性用于指定在何处打开链接，常用值包括：

  • _self：默认值，在当前窗口打开链接
  • _blank：在新窗口或新标签页打开链接
  • _parent：在父框架中打开链接
  • _top：在整个窗口中打开链接，忽略所有框架

2.2 title属性

title属性用于指定链接的提示文本，当用户将鼠标悬停在链接上时，会显示该提示文本。

2.3 rel属性

rel属性用于指定当前文档与目标文档的关系，对于外部链接，我们通常使用noopener noreferrer来提高安全性。

安全提示

当使用target="_blank"打开新窗口时，新窗口可以通过window.opener访问原始窗口。为了防止安全问题，我们应该始终在外部链接中添加rel="noopener noreferrer"属性。

<a href="https://www.baidu.com" target="_blank" rel="noopener noreferrer">百度一下</a>

三、内部链接与锚点

内部链接是指向同一网站内其他页面的链接，它使用相对路径。锚点链接是指向同一页面内特定位置的链接，它使用#符号加上目标元素的id属性值。

3.1 内部链接

内部链接使用相对路径，它相对于当前页面的位置。例如，如果我们有两个页面：index.html和about.html，它们在同一目录下，那么从index.html到about.html的链接可以写为：

<a href="about.html">关于我们</a>

如果about.html在pages目录下，那么链接应该写为：

<a href="pages/about.html">关于我们</a>

3.2 锚点链接

锚点链接用于跳转到同一页面内的特定位置，它由两部分组成：

  • 目标元素：需要添加id属性，例如<h2 id="section1">第一部分</h2>
  • 链接：使用#符号加上目标元素的id属性值，例如<a href="#section1">跳转到第一部分</a>

四、邮件与电话链接

HTML支持创建特殊类型的链接，例如邮件链接和电话链接，它们可以直接调用用户设备上的邮件客户端或电话应用。

4.1 邮件链接

邮件链接使用mailto:协议，当用户点击邮件链接时，会打开默认的邮件客户端，并自动填写收件人地址。

4.2 电话链接

电话链接使用tel:协议，当用户点击电话链接时，会打开默认的电话应用，并自动填写电话号码。

六、本课小结

知识点回顾

  • 基本链接语法：使用<a>标签定义链接，href属性指定目标URL
  • 链接属性：学习了href、target、title和rel等常用属性
  • 内部链接：指向同一网站内其他页面的链接，使用相对路径
  • 锚点链接：指向同一页面内特定位置的链接，使用#符号加上目标元素的id属性值
  • 邮件链接：使用mailto:协议，用于发送邮件
  • 电话链接：使用tel:协议，用于拨打电话

重点记忆

链接类型 语法 用途 示例
外部链接 <a href="URL"> 指向其他网站的链接 <a href="https://www.baidu.com">百度一下</a>
新窗口打开 target="_blank" 在新窗口或标签页打开链接 <a href="https://www.baidu.com" target="_blank">百度一下</a>
锚点链接 <a href="#id"> 指向同一页面内特定位置 <a href="#section1">跳转到第一部分</a>
邮件链接 mailto:邮箱地址 发送邮件 <a href="mailto:example@example.com">发送邮件</a>
电话链接 tel:电话号码 拨打电话 <a href="tel:10086">拨打10086</a>
