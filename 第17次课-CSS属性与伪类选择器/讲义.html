📝 课程小结

第17课：CSS属性与伪类选择器

CSS属性选择器和伪类选择器是CSS中强大的选择器类型，它们允许我们根据元素的属性和状态来精确选择和样式化元素。本节课将学习各种属性选择器和伪类选择器的用法，帮助你创建更灵活、更智能的CSS样式。

属性选择器 伪类选择器 交互状态 LVHA链接伪类 结构位置伪类 伪元素

一、基础属性选择器

基础属性选择器允许我们根据元素的属性来选择元素，包括属性存在匹配和属性值精确匹配。

1.1 属性存在匹配：[属性名]

存在匹配选择器用于选择所有带有指定属性的元素，无论属性值是什么。语法为 [属性名]。

简单理解

就像在超市找东西，只要商品标签上有"有机"这个属性，不管具体是什么有机食品，都能被找到。

/* 选择所有带有 disabled 属性的元素 */
[disabled] {
    background-color: #f5f5f5;
    color: #aaaaaa;
    border: 1px dashed #ccc;
    cursor: not-allowed;
}

1.2 属性值精确匹配：[属性="值"]

精确匹配选择器用于选择属性值完全等于指定值的元素。语法为 [属性="值"]。

简单理解

就像在超市找特定品牌的牛奶，只有标签上明确写着"某品牌"的牛奶才会被选中。

/* 选择 type 属性等于 password 的 input 元素 */
input[type="password"] {
    border: 2px solid #FF3B30;
    background-color: #FFF0F0;
    color: red;
}
实验 01：基础属性选择器 动手实践
HTML (可编辑)
<!-- 1. 普通按钮 --> <button>普通按钮</button> <!-- 2. 禁用按钮 (有 disabled 属性) --> <button disabled>我被禁用了</button> <br><br> <!-- 3. 文本框 (type="text") --> <input type="text" value="普通文本"> <!-- 4. 密码框 (type="password") --> <input type="password" value="123456">
CSS (可编辑)
/* 1. 存在匹配：选择所有带有 disabled 属性的元素 */ [disabled] { background-color: #f5f5f5; color: #aaaaaa; border: 1px dashed #ccc; cursor: not-allowed; padding: 8px 16px; } /* 2. 精确匹配：选择 type 等于 password 的 input 元素 */ input[type="password"] { border: 2px solid #FF3B30; background-color: #FFF0F0; color: red; padding: 8px; } /* 给所有按钮和输入框添加基础样式 */ button, input { padding: 8px 16px; border: 1px solid #ccc; border-radius: 4px; font-size: 14px; margin-right: 10px; }

二、字符串匹配属性选择器

字符串匹配选择器允许我们根据属性值的部分内容来选择元素，包括开头匹配、结尾匹配和包含匹配。

2.1 开头匹配：[属性^="值"]

开头匹配选择器用于选择属性值以指定字符串开头的元素。语法为 [属性^="值"]。

简单理解

就像找名字以"张"开头的同学，不管后面叫什么，只要姓张就能被选中。

/* 选择 href 以 "https" 开头的链接 */
a[href^="https"] {
    color: #34C759;
    font-weight: bold;
}

2.2 结尾匹配：[属性$="值"]

结尾匹配选择器用于选择属性值以指定字符串结尾的元素。语法为 [属性$="值"]。

简单理解

就像找文件扩展名为".pdf"的文档，不管文件名是什么，只要以.pdf结尾就能被选中。

/* 选择 href 以 ".pdf" 结尾的链接 */
a[href$=".pdf"] {
    color: #FF9500;
}

/* 使用伪元素添加文本 */
a[href$=".pdf"]::after {
    content: " [PDF文档]";
    font-size: 12px;
    color: #999;
}

2.3 包含匹配：[属性*="值"]

包含匹配选择器用于选择属性值包含指定字符串的元素。语法为 [属性*="值"]。

简单理解

就像在文章中找包含"关键词"的句子，不管关键词在句子的哪个位置，只要包含就能被选中。

/* 选择 src 包含 "logo" 的图片 */
img[src*="logo"] {
    width: 100px;
    height: auto;
}
实验 02：字符串匹配属性选择器 动手实践
HTML (可编辑)
<div class="link-list"> <!-- 安全链接 (https开头) --> <a href="https://bank.com">安全支付</a> <br> <!-- 普通链接 (http开头) --> <a href="http://game.com">网页游戏</a> <br> <!-- PDF文件 (pdf结尾) --> <a href="report.pdf">下载报告</a> <br> <!-- 图片链接 (包含image关键词) --> <a href="image-gallery.html">查看图片</a> </div>
CSS (可编辑)
/* 1. ^= (开头匹配) */ /* 选中所有 href 以 "https" 开头的链接，设为绿色 */ a[href^="https"] { color: #34C759; /* 绿色 */ font-weight: bold; } /* 2. $= (结尾匹配) */ /* 选中所有 href 以 ".pdf" 结尾的链接，设为橙色 */ a[href$=".pdf"] { color: #FF9500; /* 橙色 */ } /* 高级技巧：使用伪元素自动加文字 */ a[href$=".pdf"]::after { content: " [PDF文档]"; font-size: 12px; color: #999; } /* 3. *= (包含匹配) */ /* 选中所有 href 包含 "image" 的链接，设为蓝色 */ a[href*="image"] { color: #0066CC; /* 蓝色 */ } /* 基础样式优化 */ a { text-decoration: none; font-size: 16px; line-height: 2; color: #333; display: inline-block; margin: 5px 0; }

三、交互状态伪类

交互状态伪类用于选择处于特定状态的元素，如悬停、焦点和激活状态。

3.1 悬停状态：:hover

悬停状态伪类用于选择鼠标悬停在上面的元素。语法为 :hover。

简单理解

就像你走到自动门面前，门会感应到你并自动打开一样，鼠标悬停在元素上时，元素会触发特定样式。

/* 鼠标悬停在按钮上时的样式 */
button:hover {
    background-color: #0066CC;
    color: white;
    transform: scale(1.1);
    border-color: #0066CC;
}

3.2 焦点状态：:focus

焦点状态伪类用于选择获得焦点的元素，通常用于表单元素。语法为 :focus。

简单理解

就像你在考试中，老师的注意力集中在某个同学身上，这个同学就是"焦点"，会被特殊关注。

/* 输入框获得焦点时的样式 */
input:focus {
    outline: none;
    border: 2px solid #0066CC;
    background-color: #E8F2FF;
}

3.3 激活状态：:active

激活状态伪类用于选择正在被点击的元素。语法为 :active。

简单理解

就像你按电梯按钮时，按钮会被按下并变色，这个按下的瞬间就是激活状态。

/* 按钮被点击时的样式 */
button:active {
    transform: scale(0.95);
    background-color: #0052A3;
}
实验 03：交互状态伪类 动手实践
HTML (可编辑)
<!-- 一个普通的按钮 --> <button class="magic-btn"> 鼠标悬停我 </button> <br><br> <!-- 一个普通的输入框 --> <input class="magic-input" placeholder="点击输入...">
CSS (可编辑)
/* 按钮的基础样式 */ .magic-btn { padding: 12px 24px; background: #fff; border: 1px solid #ccc; border-radius: 4px; font-size: 16px; transition: all 0.3s; /* 让变化有动画过程，看起来更平滑 */ } /* 1. :hover (鼠标悬停) */ /* 当鼠标移上去时，变蓝并放大 */ .magic-btn:hover { background-color: #0066CC; color: white; transform: scale(1.1); /* 放大1.1倍 */ border-color: #0066CC; box-shadow: 0 4px 8px rgba(0,102,204,0.2); /* 添加阴影效果 */ } /* 2. :active (鼠标点击) */ /* 当按钮被点击时，稍微缩小 */ .magic-btn:active { transform: scale(0.95); /* 缩小到0.95倍 */ box-shadow: 0 2px 4px rgba(0,102,204,0.3); /* 调整阴影 */ } /* 输入框基础样式 */ .magic-input { padding: 10px 15px; border: 1px solid #ccc; border-radius: 4px; font-size: 16px; transition: all 0.3s; } /* 3. :focus (获得焦点) */ /* 当输入框被点击激活时 */ .magic-input:focus { outline: none; /* 移除默认的焦点轮廓 */ border: 2px solid #0066CC; background-color: #E8F2FF; box-shadow: 0 0 0 3px rgba(0,102,204,0.1); /* 焦点光环效果 */ }

四、链接伪类（LVHA）

链接伪类用于控制超链接在不同状态下的样式。LVHA是四个链接状态伪类的首字母缩写，代表了它们应该遵循的顺序。

4.1 LVHA顺序

LVHA的顺序是 :link、:visited、:hover、:active。这个顺序非常重要，因为CSS遵循后写的样式覆盖先写的样式的规则。

为什么顺序很重要？

就像穿衣服一样，先穿内衣，再穿毛衣，最后穿外套。CSS样式也是后面的会覆盖前面的，所以必须按照LVHA的顺序来写。

/* LVHA顺序必须正确 */
a:link { color: #0066CC; }      /* 未访问的链接 */
a:visited { color: #9C27B0; }   /* 已访问的链接 */
a:hover { color: #FF9500; }      /* 鼠标悬停 */
a:active { color: #F44336; }     /* 正在点击 */
实验 04：LVHA链接伪类 动手实践
HTML (可编辑)
<div class="link-demo"> <h4>试试点击下面的链接：</h4> <a href="#link1">链接 1：关于我们</a> <br> <a href="#link2">链接 2：产品介绍</a> <br> <a href="#link3">链接 3：联系方式</a> </div>
CSS (可编辑)
/* === LVHA 顺序（必须按这个顺序写！） === */ /* 1. :link - 未访问的链接 */ a:link { color: #0066CC; /* 蓝色 */ text-decoration: none; /* 去掉下划线 */ } /* 2. :visited - 已访问的链接 */ a:visited { color: #9C27B0; /* 紫色 */ } /* 3. :hover - 鼠标悬停 */ a:hover { color: #FF9500; /* 橙色 */ text-decoration: underline; /* 加下划线 */ font-weight: bold; /* 加粗 */ transform: translateX(5px); /* 向右移动5像素 */ } /* 4. :active - 正在点击 */ a:active { color: #F44336; /* 红色 */ transform: scale(0.95); /* 稍微缩小 */ } /* 基础样式 */ .link-demo a { display: block; padding: 10px 0; font-size: 16px; transition: all 0.2s; /* 所有变化都有0.2秒的过渡动画 */ }

五、结构位置伪类

结构位置伪类用于根据元素在文档结构中的位置来选择元素。

5.1 第一个和最后一个子元素

使用 :first-child 和 :last-child 可以选择第一个和最后一个子元素。

简单理解

就像一排座位，第一个座位和最后一个座位会被特殊标记一样，列表中的第一个和最后一个元素也能被单独选中。

/* 选择第一个 li 元素 */
li:first-child {
    color: red;
    font-weight: bold;
}

/* 选择最后一个 li 元素 */
li:last-child {
    color: blue;
    font-weight: bold;
}

5.2 第N个子元素：:nth-child(N)

使用 :nth-child(N) 可以选择第N个子元素，N可以是数字、关键字或表达式。

简单理解

就像在教室里找第5排第3个座位的同学一样，可以精确地找到指定位置的元素。

/* 选择第2个 li 元素 */
li:nth-child(2) {
    color: green;
}

/* 选择所有偶数位置的 li 元素 */
li:nth-child(2n) {
    background-color: #f9f9f9;
}

/* 选择所有奇数位置的 li 元素 */
li:nth-child(2n+1) {
    background-color: #e9e9e9;
}

5.3 奇数和偶数快捷方式

CSS提供了 odd 和 even 关键字来简化奇数和偶数的选择。

/* 等价于 :nth-child(2n+1) */
li:nth-child(odd) {
    background-color: #e9e9e9;
}

/* 等价于 :nth-child(2n) */
li:nth-child(even) {
    background-color: #f9f9f9;
}
实验 05：结构位置伪类 动手实践
HTML (可编辑)
<ul class="list-demo"> <li>第1个列表项</li> <li>第2个列表项</li> <li>第3个列表项</li> <li>第4个列表项</li> <li>第5个列表项</li> <li>第6个列表项</li> </ul>

/* 列表基础样式 */ .list-demo { list-style: none; padding: 0; margin: 0; border: 1px solid #ddd; border-radius: 4px; overflow: hidden; } .list-demo li { padding: 12px 15px; border-bottom: 1px solid #eee; transition: all 0.2s; } .list-demo li:last-child { border-bottom: none; } /* 1. 第一个子元素 */ .list-demo li:first-child { color: red; font-weight: bold; background-color: #fff5f5; } /* 2. 最后一个子元素 */ .list-demo li:last-child { color: blue; font-weight: bold; background-color: #f0f8ff; } /* 3. 偶数位置的子元素 */ .list-demo li:nth-child(even) { background-color: #f9f9f9; } /* 4. 第3个子元素 */ .list-demo li:nth-child(3) { font-style: italic; color: green; background-color: #f0fff4; } /* 5. 所有3的倍数位置的子元素 */ .list-demo li:nth-child(3n) { border-left: 4px solid #0066cc; }

六、排除逻辑伪类

排除逻辑伪类用于选择不匹配特定条件的元素。

6.1 排除选择器：:not()

排除选择器用于选择不匹配指定选择器的元素。语法为 :not(选择器)。

简单理解

就像在班级里选班干部，要求是"不是班长的同学"，那么除了班长之外的所有同学都会被选中。

/* 选择所有不是 button 元素的元素 */
:not(button) {
    margin: 5px;
}

/* 选择所有没有 disabled 属性的 input 元素 */
input:not([disabled]) {
    background-color: white;
    cursor: text;
}
实验 06：排除逻辑伪类 动手实践

七、伪元素选择器

伪元素选择器用于选择元素的特定部分，如首字母、第一行或在元素前后插入内容。

7.1 ::before 和 ::after

::before 和 ::after 伪元素用于在元素前后插入内容。它们必须配合 content 属性使用。

简单理解

就像在照片的前后添加相框一样，可以在元素的前后添加装饰性内容，而不需要修改HTML结构。

/* 在链接前添加箭头 */
a::before {
    content: "→ ";
    color: #999;
}

/* 在段落后添加句号 */
p::after {
    content: ".";
    color: #666;
}

7.2 ::first-letter

::first-letter 伪元素用于选择文本的第一个字母。

简单理解

就像书籍中每章开头的第一个字母会放大并装饰一样，可以单独设置段落首字母的样式。

/* 段落首字母放大 */
p::first-letter {
    font-size: 2em;
    font-weight: bold;
    color: #0066CC;
    float: left;
    margin-right: 5px;
}

7.3 ::first-line

::first-line 伪元素用于选择文本的第一行。

简单理解

就像报纸标题下方的第一行文字会加粗一样，可以单独设置段落第一行的样式。

/* 段落第一行加粗 */
p::first-line {
    font-weight: bold;
    color: #0066CC;
}

七、课程小结

CSS属性选择器和伪类选择器是CSS中强大的选择器类型，它们允许我们根据元素的属性和状态来精确选择和样式化元素。

7.1 属性选择器总结

选择器 语法 描述
存在匹配 [属性名] 选择所有带有指定属性的元素
精确匹配 [属性="值"] 选择属性值完全等于指定值的元素
开头匹配 [属性^="值"] 选择属性值以指定字符串开头的元素
结尾匹配 [属性$="值"] 选择属性值以指定字符串结尾的元素
包含匹配 [属性*="值"] 选择属性值包含指定字符串的元素

7.2 伪类选择器总结

类型 选择器 描述
交互状态 :hover 鼠标悬停在元素上
:focus 元素获得焦点
:active 元素被激活（点击）
链接状态 :link 未访问的链接
:visited 已访问的链接
:hover 鼠标悬停在链接上
:active 链接被点击
结构位置 :first-child 第一个子元素
:last-child 最后一个子元素
:nth-child(N) 第N个子元素
:nth-child(odd) 奇数位置的子元素
:nth-child(even) 偶数位置的子元素
排除逻辑 :not(选择器) 排除匹配选择器的元素

7.3 伪元素选择器总结

选择器 描述
::before 在元素前插入内容
::after 在元素后插入内容
::first-letter 选择文本的第一个字母
::first-line 选择文本的第一行

7.4 最佳实践

  1. 使用属性选择器来样式化表单元素，如不同类型的输入框
  2. 使用伪类选择器来提升用户体验，如悬停效果和焦点状态
  3. 使用结构位置伪类来创建奇偶行不同的列表样式
  4. 使用伪元素来添加装饰性内容，避免修改HTML结构
  5. 注意选择器的优先级和性能，避免过度使用复杂选择器
  6. 遵循LVHA顺序编写链接样式
  7. 使用过渡效果（transition）让状态变化更平滑
