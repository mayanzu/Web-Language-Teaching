第17课：CSS属性与伪类选择器

CSS属性选择器和伪类选择器是CSS中强大的选择器类型，它们允许我们根据元素的属性和状态来精确选择和样式化元素。本节课将学习各种属性选择器和伪类选择器的用法。

1. 基础属性选择器

基础属性选择器允许我们根据元素的属性来选择元素，包括属性存在匹配和属性值精确匹配。

1.1 存在匹配：[属性名]

存在匹配选择器用于选择所有带有指定属性的元素，无论属性值是什么。语法为 [属性名]。

/* 选择所有带有 disabled 属性的元素 */
[disabled] {
    background-color: #f5f5f5;
    color: #aaaaaa;
    border: 1px dashed #ccc;
    cursor: not-allowed;
}

1.2 精确匹配：[属性="值"]

精确匹配选择器用于选择属性值完全等于指定值的元素。语法为 [属性="值"]。

/* 选择 type 属性等于 password 的 input 元素 */
input[type="password"] {
    border: 2px solid #FF3B30;
    background-color: #FFF0F0;
    color: red;
}

2. 字符串匹配选择器

字符串匹配选择器允许我们根据属性值的部分内容来选择元素，包括开头匹配、结尾匹配和包含匹配。

2.1 开头匹配：[属性^="值"]

开头匹配选择器用于选择属性值以指定字符串开头的元素。语法为 [属性^="值"]。

/* 选择 href 以 "https" 开头的链接 */
a[href^="https"] {
    color: #34C759;
    font-weight: bold;
}

2.2 结尾匹配：[属性$="值"]

结尾匹配选择器用于选择属性值以指定字符串结尾的元素。语法为 [属性$="值"]。

/* 选择 href 以 ".pdf" 结尾的链接 */
a[href$=".pdf"] {
    color: #FF9500;
}

/* 使用伪元素添加文本 */
a[href$=".pdf"]::after {
    content: " [PDF文档]";
    font-size: 12px;
    color: #999;
}

2.3 包含匹配：[属性*="值"]

包含匹配选择器用于选择属性值包含指定字符串的元素。语法为 [属性*="值"]。

/* 选择 src 包含 "logo" 的图片 */
img[src*="logo"] {
    width: 100px;
    height: auto;
}

3. 交互状态伪类

交互状态伪类用于选择处于特定状态的元素，如悬停、焦点和激活状态。

3.1 悬停状态：:hover

悬停状态伪类用于选择鼠标悬停在上面的元素。语法为 :hover。

/* 鼠标悬停在按钮上时的样式 */
button:hover {
    background-color: #0066CC;
    color: white;
    transform: scale(1.1);
    border-color: #0066CC;
}

3.2 焦点状态：:focus

焦点状态伪类用于选择获得焦点的元素，通常用于表单元素。语法为 :focus。

/* 输入框获得焦点时的样式 */
input:focus {
    outline: none;
    border: 2px solid #0066CC;
    background-color: #E8F2FF;
}

3.3 激活状态：:active

激活状态伪类用于选择正在被点击的元素。语法为 :active。

/* 按钮被点击时的样式 */
button:active {
    transform: scale(0.95);
    background-color: #0052A3;
}

4. LVHA链接伪类

LVHA是四个链接状态伪类的首字母缩写，用于控制超链接在不同状态下的样式。

4.1 LVHA顺序

LVHA的顺序是 :link、:visited、:hover、:active。这个顺序非常重要，因为CSS遵循后写的样式覆盖先写的样式的规则。

/* LVHA顺序必须正确 */
a:link { color: #0066CC; }      /* 未访问的链接 */
a:visited { color: #9C27B0; }   /* 已访问的链接 */
a:hover { color: #FF9500; }      /* 鼠标悬停 */
a:active { color: #F44336; }     /* 正在点击 */

5. 结构位置伪类

结构位置伪类用于根据元素在文档结构中的位置来选择元素。

5.1 第一个和最后一个子元素

使用 :first-child 和 :last-child 可以选择第一个和最后一个子元素。

/* 选择第一个 li 元素 */
li:first-child {
    color: red;
    font-weight: bold;
}

/* 选择最后一个 li 元素 */
li:last-child {
    color: blue;
    font-weight: bold;
}

5.2 第N个子元素：:nth-child(N)

使用 :nth-child(N) 可以选择第N个子元素，N可以是数字、关键字或表达式。

/* 选择第2个 li 元素 */
li:nth-child(2) {
    color: green;
}

/* 选择所有偶数位置的 li 元素 */
li:nth-child(2n) {
    background-color: #f9f9f9;
}

/* 选择所有奇数位置的 li 元素 */
li:nth-child(2n+1) {
    background-color: #e9e9e9;
}

5.3 奇数和偶数快捷方式

CSS提供了 odd 和 even 关键字来简化奇数和偶数的选择。

/* 等价于 :nth-child(2n+1) */
li:nth-child(odd) {
    background-color: #e9e9e9;
}

/* 等价于 :nth-child(2n) */
li:nth-child(even) {
    background-color: #f9f9f9;
}

6. 排除逻辑伪类

排除逻辑伪类用于选择不匹配特定条件的元素。

6.1 排除选择器：:not()

排除选择器用于选择不匹配指定选择器的元素。语法为 :not(选择器)。

/* 选择所有不是 button 元素的元素 */
:not(button) {
    margin: 5px;
}

/* 选择所有没有 disabled 属性的 input 元素 */
input:not([disabled]) {
    background-color: white;
    cursor: text;
}

7. 伪元素选择器

伪元素选择器用于选择元素的特定部分，如首字母、第一行或在元素前后插入内容。

7.1 ::before 和 ::after

::before 和 ::after 伪元素用于在元素前后插入内容。它们必须配合 content 属性使用。

/* 在链接前添加箭头 */
a::before {
    content: "→ ";
    color: #999;
}

/* 在段落后添加句号 */
p::after {
    content: ".";
    color: #666;
}

7.2 ::first-letter

::first-letter 伪元素用于选择文本的第一个字母。

/* 段落首字母放大 */
p::first-letter {
    font-size: 2em;
    font-weight: bold;
    color: #0066CC;
    float: left;
    margin-right: 5px;
}

7.3 ::first-line

::first-line 伪元素用于选择文本的第一行。

/* 段落第一行加粗 */
p::first-line {
    font-weight: bold;
    color: #0066CC;
}

8. 总结与实践

CSS属性选择器和伪类选择器是CSS中强大的选择器类型，它们允许我们根据元素的属性和状态来精确选择和样式化元素。

8.1 属性选择器总结

选择器 语法 描述
存在匹配 [属性名] 选择所有带有指定属性的元素
精确匹配 [属性="值"] 选择属性值完全等于指定值的元素
开头匹配 [属性^="值"] 选择属性值以指定字符串开头的元素
结尾匹配 [属性$="值"] 选择属性值以指定字符串结尾的元素
包含匹配 [属性*="值"] 选择属性值包含指定字符串的元素

8.2 伪类选择器总结

类型 选择器 描述
交互状态 :hover 鼠标悬停在元素上
:focus 元素获得焦点
:active 元素被激活（点击）
链接状态 :link 未访问的链接
:visited 已访问的链接
:hover 鼠标悬停在链接上
:active 链接被点击
结构位置 :first-child 第一个子元素
:last-child 最后一个子元素
:nth-child(N) 第N个子元素
:nth-child(odd/even) 奇数/偶数位置的子元素
排除逻辑 :not(选择器) 排除匹配选择器的元素

8.3 伪元素选择器总结

选择器 描述
::before 在元素前插入内容
::after 在元素后插入内容
::first-letter 选择文本的第一个字母
::first-line 选择文本的第一行

8.4 实践建议

  • 使用属性选择器来样式化表单元素，如不同类型的输入框
  • 使用伪类选择器来提升用户体验，如悬停效果和焦点状态
  • 使用结构位置伪类来创建奇偶行不同的列表样式
  • 使用伪元素来添加装饰性内容，避免修改HTML结构
  • 注意选择器的优先级和性能，避免过度使用复杂选择器
