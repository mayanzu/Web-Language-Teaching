第5课:函数

如果把程序看成工厂流水线,函数就是一台台专用机器:输入原料,机器内部按步骤处理,再输出结果。本课将学习如何「造机器」和「用机器」,让代码更加模块化、可复用、易维护。

一、为什么需要函数?

想象你正在开发一个计算器程序,需要多次计算两个数的和。如果每次都重复写相同的代码,不仅麻烦,而且一旦计算逻辑需要修改,就要改很多地方。

函数,就是把重复的代码封装起来,给它一个名字,需要时调用这个名字即可。

💡 生活中的类比
  • 洗衣机:放入脏衣服和洗衣液(输入/参数),按下开始键,内部执行洗涤程序(函数体),最后得到干净的衣服(输出/返回值)
  • 菜谱:一道菜的做法就是一个"函数",食材是参数,烹饪步骤是函数体,做好的菜是返回值
  • ATM取款:输入金额(参数),ATM执行验证、扣款、出钞等步骤(函数体),返回现金和凭条(返回值)

没有函数,我们的代码将充满重复、难以维护。函数让我们能够:

  • 避免重复:写一次代码,多次调用
  • 易于维护:修改功能时只需改一处
  • 降低复杂度:把大问题拆分成小问题
  • 提高可读性:通过函数名清晰表达代码意图

二、函数是什么?

2.1 函数的本质

从技术角度看,函数是一段可以重复使用的代码块,它接收输入(参数),执行特定任务,并可能产生输出(返回值)。

一个函数的生命周期可以分为几个阶段:

阶段解释示例代码
定义 (Definition) 创建函数,告诉JavaScript这个函数叫什么、做什么 function add(a, b) { return a + b; }
调用 (Invocation) 使用函数,传入实际参数,执行函数体 add(3, 5)
执行 (Execution) 函数体内的代码逐行运行 a + b 计算结果
返回 (Return) 函数执行完毕,将结果返回给调用者 return 8

2.2 函数的组成部分

一个完整的函数包含以下要素:

  • function 关键字:声明这是一个函数
  • 函数名:遵循变量命名规则,应该具有描述性(如 calculateTotal、validateEmail)
  • 参数列表:小括号内,多个参数用逗号分隔
  • 函数体:大括号内,包含要执行的代码
  • 返回值:使用 return 语句返回结果(可选)

2.3 函数的基本语法

// 函数声明
function functionName(参数1, 参数2) {
  // 函数体：执行的代码
  return 结果; // 返回值（可选）
}

// 函数调用
functionName(实参1, 实参2);

2.4 简单示例

// 定义一个问候函数
function greet(name) {
  return "你好，" + name + "！";
}

// 调用函数
console.log(greet("小明"));  // 输出：你好，小明！
console.log(greet("小红"));  // 输出：你好，小红！
📌 重要术语
术语含义示例
形参 (Parameter) 函数定义时的占位符变量 function greet(name) 中的 name
实参 (Argument) 调用函数时传入的实际值 greet("小明") 中的 "小明"
返回值 (Return Value) 函数执行后返回的结果 return "你好，" + name
函数体 (Function Body) 大括号内要执行的代码 { return "你好，" + name + "！"; }

三、函数的声明方式

JavaScript 提供了多种方式来定义函数,每种方式都有其特点和适用场景。理解它们的区别能帮助你写出更优雅的代码。

3.1 函数声明 (Function Declaration)

这是最传统、最常见的函数定义方式。使用 function 关键字声明的函数具有一个重要特性:函数提升 (Hoisting)。

💡 什么是函数提升?

JavaScript 引擎在执行代码前,会先扫描整个作用域,将所有函数声明"提升"到作用域顶部。这意味着你可以在函数声明之前调用它。

优点:代码组织更灵活,可以把主要逻辑放在前面,辅助函数放在后面。

注意:只有函数声明会提升,函数表达式不会。

// 函数声明
function add(a, b) {
  return a + b;
}

// ✅ 可以在声明前调用（函数提升）
console.log(multiply(3, 4));  // 12

function multiply(x, y) {
  return x * y;
}
💡 函数提升（Hoisting）

函数声明会被提升到作用域顶部，因此可以在声明之前调用函数。这是与函数表达式的重要区别。

3.2 无参数与多参数函数

// 无参数函数
function sayHello() {
  console.log("Hello World!");
}

sayHello();  // 输出：Hello World!

// 多参数函数
function calculateRectangleArea(width, height) {
  return width * height;
}

let area = calculateRectangleArea(5, 10);
console.log(area);  // 输出：50

四、函数表达式 (Function Expression)

除了函数声明,我们还可以把函数作为一个值赋给变量。这种方式创建的函数叫做函数表达式。

4.1 匿名函数表达式

将函数赋值给变量,函数本身没有名称。重要:函数表达式不会被提升!

⚠️ 注意

函数表达式必须先定义,后调用。如果在定义前调用,会报错:ReferenceError: Cannot access before initialization

// 函数表达式
const subtract = function(a, b) {
  return a - b;
};

console.log(subtract(10, 3));  // 7

// ❌ 不能在声明前调用
// console.log(divide(10, 2));  // 错误！

const divide = function(a, b) {
  return a / b;
};

console.log(divide(10, 2));  // 5

4.2 命名函数表达式

函数表达式也可以有名字，这在递归调用时特别有用。

const factorial = function fact(n) {
  if (n <= 1) return 1;
  return n * fact(n - 1);  // 递归调用自身
};

console.log(factorial(5));  // 120
💡 函数声明 vs 函数表达式
特性 函数声明 函数表达式
语法 function name() {} const name = function() {}
提升 ✅ 提升（可先调用后声明） ❌ 不提升
使用场景 顶层独立函数 需要条件性创建函数时

五、箭头函数 (Arrow Function - ES6)

ES6(2015年)引入了一种全新的、更简洁的函数语法:箭头函数。它使用 => 符号,特别适合用于简短的函数和回调函数。

5.1 箭头函数的语法演进

让我们看看同一个功能如何从传统函数一步步简化为箭头函数:

// 传统函数表达式
const square1 = function(x) {
  return x * x;
};

// 箭头函数
const square2 = (x) => {
  return x * x;
};

// 单参数可省略括号，单表达式可省略return和大括号
const square3 = x => x * x;

console.log(square3(5));  // 25

5.2 箭头函数的各种形式

箭头函数根据参数数量和函数体复杂度，有多种简写形式：

// 无参数
const greet = () => "Hello!";

// 单个参数
const double = n => n * 2;

// 多个参数
const add = (a, b) => a + b;

// 多行函数体
const calculateDiscount = (price, discount) => {
  const discountAmount = price * discount;
  return price - discountAmount;
};

// 返回对象（需要用括号包裹）
const createUser = (name, age) => ({ name: name, age: age });
📌 箭头函数的特点
  • 更简洁的语法
  • 没有自己的 this（继承外层作用域的this）
  • 不能用作构造函数
  • 没有 arguments 对象
  • 适合用于回调函数和方法链

六、函数参数的高级特性

ES6 为函数参数引入了许多强大的新特性,让参数处理更加灵活和优雅。

6.1 默认参数 (Default Parameters)

在函数定义时,可以为参数指定默认值。如果调用时没有传递该参数(或传入 undefined),将使用默认值。

💡 默认参数的优势
  • 避免了 ES5 中冗长的 name = name || '默认值' 写法
  • 代码更清晰、易读
  • 可以使用表达式作为默认值
// ES6 默认参数
function greet(name = "访客", greeting = "你好") {
  return `${greeting}，${name}！`;
}

console.log(greet());                    // "你好，访客！"
console.log(greet("小明"));              // "你好，小明！"
console.log(greet("小红", "欢迎"));      // "欢迎，小红！"

// ES5 实现默认参数的方式
function greetOld(name, greeting) {
  name = name || "访客";
  greeting = greeting || "你好";
  return greeting + "，" + name + "！";
}

6.2 剩余参数 (Rest Parameters)

使用 ...参数名 可以将不定数量的参数收集到一个数组中。这在参数数量不确定时非常有用。

📌 剩余参数 vs arguments

ES5 中可以使用 arguments 对象访问所有参数，但它不是真正的数组。剩余参数是真正的数组，可以直接使用数组方法。

// 计算任意数量数字的和
function sum(...numbers) {
  let total = 0;
  for (let num of numbers) {
    total += num;
  }
  return total;
}

console.log(sum(1, 2, 3));           // 6
console.log(sum(1, 2, 3, 4, 5));     // 15
console.log(sum());                  // 0

// 结合普通参数和剩余参数
function introduce(firstName, lastName, ...hobbies) {
  console.log(`我叫${firstName} ${lastName}`);
  console.log(`爱好：${hobbies.join(", ")}`);
}

introduce("张", "三", "篮球", "编程", "旅游");
// 我叫张 三
// 爱好：篮球, 编程, 旅游

6.3 参数解构 (Destructuring Parameters)

可以在参数位置直接使用解构语法，从对象或数组中提取值。这让函数接收复杂数据时更加简洁。

// 对象解构参数
function createUser({ name, age, city = "未知" }) {
  console.log(`${name}，${age}岁，来自${city}`);
}

createUser({ name: "小明", age: 20, city: "北京" });
// 小明，20岁，来自北京

createUser({ name: "小红", age: 22 });
// 小红，22岁，来自未知

// 数组解构参数
function getCoordinates([x, y]) {
  return `坐标：(${x}, ${y})`;
}

console.log(getCoordinates([10, 20]));  // 坐标：(10, 20)

七、返回值详解

返回值是函数与外界通信的主要方式。理解 return 语句的工作机制对于编写高质量函数至关重要。

7.1 return 的双重作用

return 语句有两个重要作用:

  • 返回结果:将值返回给函数的调用者
  • 终止执行:一旦执行到 return,函数立即结束,后续代码不会执行
function calculateTotal(price, quantity) {
  let total = price * quantity;
  return total;  // 返回计算结果
  console.log("这行代码不会执行");  // ❌ 永远不会运行
}

let amount = calculateTotal(50, 3);
console.log(amount);  // 150

7.2 多个返回点

函数可以有多个 return 语句，通常用于不同条件下返回不同结果。

function checkAge(age) {
  if (age < 0) {
    return "年龄不能为负数";
  }
  if (age < 18) {
    return "未成年";
  }
  if (age < 60) {
    return "成年";
  }
  return "老年";
}

console.log(checkAge(15));   // "未成年"
console.log(checkAge(30));   // "成年"
console.log(checkAge(-5));   // "年龄不能为负数"

7.3 返回复杂数据类型

函数不仅可以返回基本类型（数字、字符串等），还可以返回对象、数组等复杂数据结构。

// 返回对象
function getUserInfo(id) {
  return {
    id: id,
    name: "用户" + id,
    status: "active"
  };
}

const user = getUserInfo(101);
console.log(user.name);  // "用户101"

// 返回数组
function getTopThree(scores) {
  return scores.sort((a, b) => b - a).slice(0, 3);
}

const top = getTopThree([85, 92, 78, 95, 88]);
console.log(top);  // [95, 92, 88]

7.4 没有返回值的情况

如果函数没有 return 语句，或者 return 后面没有值，函数会返回 undefined。

// 无return语句的函数返回 undefined
function logMessage(msg) {
  console.log(msg);
  // 没有return
}

const result = logMessage("Hello");
console.log(result);  // undefined

// 空return
function emptyReturn() {
  return;  // 提前结束，返回undefined
}

console.log(emptyReturn());  // undefined

八、作用域与闭包

作用域决定了变量的可见性和生命周期。理解作用域是掌握JavaScript的关键,而闭包则是JavaScript最强大也最容易误解的特性之一。

8.1 什么是作用域?

作用域(Scope)是变量的可访问范围。可以把它想象成一个个嵌套的房间,每个房间都有自己的"可见区域"。

💡 作用域的类型
  • 全局作用域:整个程序都能访问
  • 函数作用域:只在函数内部可访问
  • 块级作用域:只在代码块(如 if、for)内可访问(let/const)

8.2 全局作用域与局部作用域

// 全局作用域
let globalVar = "我是全局变量";

function testScope() {
  // 局部作用域
  let localVar = "我是局部变量";
  console.log(globalVar);  // ✅ 可以访问全局变量
  console.log(localVar);   // ✅ 可以访问局部变量
}

testScope();
console.log(globalVar);  // ✅ 可以访问
// console.log(localVar);   // ❌ 错误！局部变量在函数外不可访问

8.3 块级作用域 (ES6)

ES6 引入了 let 和 const，它们具有块级作用域，而 var 只有函数作用域。

// let 和 const 具有块级作用域
if (true) {
  let blockVar = "块级变量";
  const blockConst = "块级常量";
  console.log(blockVar);  // ✅ 可以访问
}

// console.log(blockVar);  // ❌ 错误！块外不可访问

// var 没有块级作用域
if (true) {
  var oldVar = "var变量";
}
console.log(oldVar);  // ✅ 可以访问（不推荐）

8.4 作用域链 (Scope Chain)

当访问一个变量时，JavaScript 会按照由内向外的顺序查找：

  1. 先在当前作用域查找
  2. 如果找不到，去外层作用域查找
  3. 一直找到全局作用域
  4. 如果还是找不到，报 ReferenceError 错误
let level1 = "全局";

function outer() {
  let level2 = "外层";
  
  function inner() {
    let level3 = "内层";
    console.log(level3);  // ✅ 内层变量
    console.log(level2);  // ✅ 外层变量
    console.log(level1);  // ✅ 全局变量
  }
  
  inner();
  // console.log(level3);  // ❌ 无法访问inner的变量
}

outer();

8.5 闭包 (Closure) - JavaScript的精髓

闭包是JavaScript最强大的特性之一。简单来说，闭包就是函数能够"记住"它被创建时的环境。

📌 闭包的定义

当一个函数可以访问并"记住"其外层作用域的变量时，即使外层函数已经执行完毕，就形成了闭包。

// 经典计数器闭包
function createCounter() {
  let count = 0;  // 私有变量
  
  return function() {
    count++;
    return count;
  };
}

const counter = createCounter();
console.log(counter());  // 1
console.log(counter());  // 2
console.log(counter());  // 3

// 每个计数器都有独立的count
const counter2 = createCounter();
console.log(counter2());  // 1
📌 闭包的应用场景
  • 数据隐藏和封装（私有变量）
  • 创建函数工厂
  • 回调函数中保留状态
  • 模块化模式

九、高阶函数 (Higher-Order Functions)

JavaScript中的函数是"一等公民"(First-Class Citizens),这意味着函数可以像普通值一样被传递、赋值、作为参数或返回值。这为我们带来了强大的编程范式。

9.1 什么是高阶函数?

高阶函数是满足以下至少一个条件的函数:

  • 接受一个或多个函数作为参数
  • 返回一个函数
💡 为什么需要高阶函数?

高阶函数让代码更加抽象、灵活和可复用。例如,map、filter、reduce 等数组方法都是高阶函数。

// 接受函数作为参数
function repeat(n, action) {
  for (let i = 0; i < n; i++) {
    action(i);
  }
}

repeat(3, function(i) {
  console.log(`第 ${i + 1} 次执行`);
});
// 第 1 次执行
// 第 2 次执行
// 第 3 次执行

9.2 回调函数 (Callback Functions)

回调函数是作为参数传递给另一个函数的函数。它让我们可以定制函数的行为，是异步编程的基础。

📌 回调函数的应用场景
  • 数组方法：map、filter、forEach、reduce 等
  • 事件处理：按钮点击、鼠标移动等
  • 异步操作：setTimeout、Ajax 请求等
  • 自定义行为：根据传入的函数执行不同操作
// 数组方法中的回调
const numbers = [1, 2, 3, 4, 5];

// forEach()方法：遍历数组的每个元素
// 参数是一个回调函数，对每个元素执行一次
numbers.forEach(function(num) {
  console.log(num * 2);
});

// map()方法：转换数组，返回新数组
// 回调函数的返回值组成新数组
const doubled = numbers.map(function(num) {
  return num * 2;
});
console.log(doubled);  // [2, 4, 6, 8, 10]

// filter()方法：筛选数组，返回符合条件的元素
// 回调函数返回true的元素会被保留
const evens = numbers.filter(function(num) {
  return num % 2 === 0;
});
console.log(evens);  // [2, 4]

// reduce()方法：累积计算，将数组归约为单个值
// 第一个参数是回调函数(累积值, 当前值)，第二个参数是初始值
const sum = numbers.reduce(function(total, num) {
  return total + num;
}, 0);
console.log(sum);  // 15

9.3 使用箭头函数简化回调

箭头函数的简洁语法特别适合用作回调函数，让代码更加优雅。

const numbers = [1, 2, 3, 4, 5];

// 使用箭头函数更简洁
numbers.forEach(num => console.log(num * 2));

const doubled = numbers.map(num => num * 2);
const evens = numbers.filter(num => num % 2 === 0);
const sum = numbers.reduce((total, num) => total + num, 0);

console.log(doubled);  // [2, 4, 6, 8, 10]
console.log(evens);    // [2, 4]
console.log(sum);      // 15

9.4 返回函数的函数 (Function Factory)

函数可以返回另一个函数，这种模式叫做"函数工厂"。它可以根据参数创建定制化的函数。

// 函数工厂
function createMultiplier(factor) {
  return function(number) {
    return number * factor;
  };
}

const double = createMultiplier(2);
const triple = createMultiplier(3);

console.log(double(5));  // 10
console.log(triple(5));  // 15

// 柯里化示例
function curry(a) {
  return function(b) {
    return function(c) {
      return a + b + c;
    };
  };
}

console.log(curry(1)(2)(3));  // 6

// 箭头函数版本
const curryArrow = a => b => c => a + b + c;
console.log(curryArrow(1)(2)(3));  // 6
