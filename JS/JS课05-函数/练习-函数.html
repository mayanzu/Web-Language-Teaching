📦 第5课：函数 - 练习

创建几个简单的函数，练习函数声明、参数传递和返回值的使用。

📋 任务要求

创建三个函数：1) 两数相加 2) 问候语生成 3) 判断是否成年，并在按钮点击时调用这些函数。

知识点：
  • 函数声明：function 函数名(参数) { ... }
  • 参数传递和使用
  • 返回值：return
  • 函数调用

📝 实现步骤

步骤 1：创建 HTML 结构

创建包含以下元素的 HTML：

  • 一个标题 <h1>函数练习</h1>
  • 三个按钮：测试加法、测试问候、测试判断成年
  • 结果显示区域 <div id="result"></div>

步骤 2：声明加法函数（关键代码）

创建一个函数，接收两个数字参数，返回它们的和：

function add(a, b) {
  const sum = a + b;
  return sum;
}
💡 函数使用 function 关键字声明，a 和 b 是参数

步骤 3：声明问候函数（关键代码）

创建一个函数，接收一个名字参数，返回问候语：

function greet(name) {
  return `你好，${name}！欢迎学习 JavaScript。`;
}
💡 函数可以返回字符串，使用模板字符串可以插入参数值

步骤 4：声明判断成年函数（关键代码）

创建一个函数，接收年龄参数，返回是否成年的布尔值：

function isAdult(age) {
  if (age >= 18) {
    return true;
  } else {
    return false;
  }
  // 或者更简洁的写法：return age >= 18;
}
💡 函数可以返回布尔值，return 会立即结束函数执行

步骤 5：调用函数（关键代码）

为三个按钮添加点击事件，调用对应的函数：

const resultDiv = document.getElementById('result');

// 测试加法
document.getElementById('addBtn').addEventListener('click', function() {
  const result = add(10, 20);
  resultDiv.textContent = `10 + 20 = ${result}`;
});

// 测试问候
document.getElementById('greetBtn').addEventListener('click', function() {
  const message = greet("小明");
  resultDiv.textContent = message;
});

// 测试判断成年
document.getElementById('adultBtn').addEventListener('click', function() {
  const check = isAdult(16);
  resultDiv.textContent = `16岁是否成年：${check}`;
});
💡 调用函数时传入具体的值（实参），函数会返回结果
