本练习是一道综合任务，你需要创建一个完整的 HTML 文件，包含 JavaScript 代码。请按照步骤指导完成，最后将完整的 HTML 代码保存并在浏览器中测试。

综合练习：制作一个"点击变色"互动网页 适合初学者

你将创建一个包含标题和按钮的网页。当点击按钮时，标题会改变文字和颜色。这个练习将帮助你理解 HTML、CSS 和 JavaScript 如何配合工作。

📋 最终效果：
  • 页面上有一个标题显示"欢迎学习 JavaScript"
  • 有一个按钮，文字是"点击我变色"
  • 点击按钮后，标题文字变成"太棒了！"
  • 同时标题颜色从蓝色变成绿色

📝 详细步骤指导

第 1 步：创建 HTML 基础结构

新建一个 HTML 文件，写入以下代码：

<!DOCTYPE html>
<html lang="zh-CN">
<head>
  <meta charset="UTF-8">
  <title>我的第一个互动网页</title>
</head>
<body>
  
  <!-- 接下来的内容将在这里添加 -->
  
</body>
</html>

第 2 步：添加 CSS 样式

在 <head> 标签里，</head> 之前，添加样式代码：

<style>
  h1 {
    color: blue;
    font-size: 32px;
  }
  
  button {
    padding: 10px 20px;
    font-size: 16px;
    cursor: pointer;
  }
</style>
💡 解释：<style> 标签用来写 CSS 代码。color: blue; 设置文字颜色为蓝色，font-size 设置字体大小。

第 3 步：添加页面内容

在 <body> 标签里面，添加标题和按钮：

<h1 id="title">欢迎学习 JavaScript</h1>
<button id="btn">点击我变色</button>
💡 注意：id="title" 和 id="btn" 是给元素起的名字，JavaScript 会用这些名字来找到它们。

第 4 步：添加 JavaScript 代码

在按钮代码下面，</body> 之前，添加 <script> 标签：

<script>
  const title = document.getElementById('title');
  const btn = document.getElementById('btn');
  
  btn.addEventListener('click', function() {
    title.textContent = '太棒了！';
    title.style.color = 'green';
  });
</script>
💡 解释：
• document.getElementById('title') 找到 id 为 'title' 的元素（标题）
• btn.addEventListener('click', ...) 给按钮添加点击事件
• title.textContent = '太棒了！' 修改标题文字
• title.style.color = 'green' 修改标题颜色为绿色

🧪 如何测试

  1. 将以上步骤的代码按顺序写到你的 HTML 文件中
  2. 保存文件，命名为 interactive-page.html
  3. 双击文件，用浏览器打开
  4. 检查：页面上是否有蓝色标题和按钮？
  5. 点击"点击我变色"按钮
  6. 检查：标题文字是否变成"太棒了！"？颜色是否变成绿色？

💡 常见问题

Q: 点击按钮没有反应？

  • 确保 <script> 标签在按钮代码的后面
  • 检查 id 是否拼写正确，区分大小写
  • 按 F12 打开控制台，看看有没有错误提示

Q: 样式没有生效？

  • 确保 <style> 标签写在 <head> 里面
  • 检查 CSS 代码的花括号 {} 是否完整
