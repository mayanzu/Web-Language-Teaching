一、什么是网页？

从用户角度看，网页就是在浏览器里看到的一页内容：文字、图片、按钮、视频……从开发者角度看，网页其实就是一堆文件：

文件类型后缀名主要作用
HTML 文件 .html 负责「内容结构」，比如标题、段落、图片、表单。
CSS 文件 .css 负责「外观样式」，比如颜色、字体、布局、动画。
JavaScript 文件 .js 负责「行为和逻辑」，比如按钮点击、表单校验、交互效果。
💡 一个简单类比

可以把网页理解成一部话剧：

  • HTML = 剧本的大纲：有哪些角色、分几幕、每幕的台词。
  • CSS = 舞美和灯光：决定舞台长什么样、角色穿什么衣服。
  • JavaScript = 导演和演员的动作：什么时候上场，说什么台词，如何与观众互动。

二、网页是如何运行的？

当你在浏览器地址栏输入一个网址并按下回车，大致会发生以下几件事：

  1. 浏览器向服务器发出请求，索要对应的 HTML 文件。
  2. 服务器把 HTML 文件返回给浏览器。
  3. 浏览器从上到下读取 HTML：遇到 CSS，就去下载并应用样式；遇到 JavaScript，就去执行脚本。
  4. 最终，你看到的是浏览器「渲染」之后的成品页面。

2.1 请求 - 响应流程一图看懂

步骤参与者发生了什么
1. 输入网址 浏览器 你在地址栏输入网址，浏览器准备发起请求。
2. 发送请求 浏览器 → 服务器 浏览器根据域名找到服务器 IP，并发出 HTTP 请求。
3. 返回文件 服务器 → 浏览器 服务器读取磁盘上的 HTML 文件，发回给浏览器。
4. 解析和渲染 浏览器 浏览器一边下载 CSS/JS，一边构建页面，最后展示给用户。
重点记住：
  • 浏览器只认识「文件」，所以我们写代码本质上就是在写文件。
  • HTML 是入口文件，CSS 和 JS 都是通过 HTML 被「引用」进来的。
  • JavaScript 是在「浏览器里」运行的程序，可以直接操作页面上的内容。

三、HTML / CSS / JavaScript 的分工

下面用一个最小示例来看三者如何协同工作：

示例：三者协作的最小网页 Read Only

HTML 结构（index.html）：

<!DOCTYPE html>
<html lang="zh-CN">
<head>
  <meta charset="UTF-8">
  <title>我的第一个网页</title>
  <link rel="stylesheet" href="style.css">
</head>
<body>
  <h1 id="page-title">你好，JavaScript！</h1>
  <button id="hello-btn">点我试试</button>

  <script src="main.js"></script>
</body>
</html>

CSS 样式（style.css）：

body {
  font-family: -apple-system, BlinkMacSystemFont, "Segoe UI", sans-serif;
  background-color: #f5f5f7;
  text-align: center;
  padding-top: 60px;
}

button {
  padding: 10px 20px;
  font-size: 16px;
  border-radius: 8px;
  border: none;
  cursor: pointer;
}

button:hover {
  background-color: #e0e0e0;
}

JavaScript 行为（main.js）：

const btn = document.getElementById('hello-btn');

btn.addEventListener('click', function () {
  alert('欢迎来到 JavaScript 的世界！');
});
三兄弟的协作方式
  • HTML 定义「有哪些元素」以及「它们的层级关系」。
  • CSS 通过 <link> 链接进来，为这些元素添加样式。
  • JavaScript 通过 <script> 链接进来，给按钮等元素添加行为。

四、JavaScript 到底做什么？

从功能上看，JavaScript 让网页从「静态的说明书」变成「可以互动的应用」。你每天访问的网站，几乎所有的交互功能都离不开 JavaScript。

4.1 有 JS 和没有 JS 的网页差别有多大？

场景没有 JS有 JS
表单提交 用户填错只能提交后才知道。 输入时就能即时提示错误，阻止错误提交。
导航菜单 只能跳转页面。 可以展开/折叠菜单、下拉动画、返回顶部。
数据展示 只能看到固定内容。 可以按条件筛选、排序、分页显示。
购物车 每次加减商品都要刷新整个页面。 点击加减，数量和总价立即更新，无需刷新。
地图导航 只能显示静态图片。 可以拖拽、缩放、搜索地点、规划路线。

4.2 JavaScript 在真实网站中的应用

让我们看看你熟悉的网站都用 JavaScript 做了什么：

案例 1：社交媒体（微博、微信朋友圈） Real World

JavaScript 实现的功能：

案例 2：电商网站（淘宝、京东） Real World

JavaScript 实现的功能：

  • 商品筛选：勾选"仅显示有货"、"价格区间"，商品列表立即更新
  • 图片放大镜：鼠标移到商品图上，旁边显示放大的细节图
  • 购物车计算：加减商品数量，总价自动重新计算

  • 倒计时：限时抢购的倒计时，每秒自动更新

💡 想象一下，如果每次改数量都要刷新页面，你还会愿意网购吗？

案例 3：在线地图（百度地图、高德地图） Real World

JavaScript 实现的功能：

  • 地图拖拽：用鼠标拖动地图，查看不同区域
  • 缩放控制：滚轮放大缩小，双击放大
  • 路线规划：输入起点终点，自动计算并绘制路线
  • 实时定位：显示你当前的位置，跟随你移动而更新
  • 搜索建议：输入地点名称时，下方自动显示相关建议

💡 在线地图如果没有 JavaScript，基本上就只能看静态图片，完全无法使用。

案例 4：视频网站（Bilibili、YouTube） Real World

JavaScript 实现的功能：

  • 视频播放器：播放、暂停、进度条拖拽、音量调节

💡 没有 JavaScript，你连播放/暂停按钮都点不了。

4.3 JavaScript 的五大核心能力

归纳一下，JavaScript 在网页中主要负责以下五类工作：

能力具体作用日常例子

6.1 方式一：直接写在 HTML 文件里（最简单）

6.5 重要！script 标签应该放在哪里？

这是初学者最容易困惑的问题：<script> 标签应该放在 <head> 里还是 <body> 里？答案是：通常放在 <body> 的最底部，原因如下：

script 标签位置对比 Important
放置位置优点缺点推荐程度
放在 <head> 中 • 代码组织清晰
• 逻辑上与 CSS 并列		 • 会阻塞页面加载
• JS 可能找不到 body 中的元素
• 用户看到空白页时间更长		 ❌ 不推荐
放在 <body> 底部 • 页面内容先加载，用户体验好
• 能找到所有 HTML 元素
• 不会阻塞页面渲染		 • 大型项目文件较多时管理稍复杂 ✅ 强烈推荐
放在 <head> 中
但加 defer 属性		 • 兼具清晰性和性能
• 异步下载，不阻塞渲染
• 在页面解析完后执行		 • 需要理解 defer 的工作原理
• 旧浏览器可能不支持		 ⭐ 现代最佳实践

示例 1：放在 <head> 中（不推荐）

<!DOCTYPE html>
<html>
<head>
  <meta charset="UTF-8">
  <title>示例</title>
  <!-- ❌ 不推荐：这时 body 还没加载，找不到 #myButton -->
  <script>
    const btn = document.getElementById('myButton'); // 结果是 null！
    console.log(btn); // 输出：null
  </script>
</head>
<body>
  <button id="myButton">点我</button>
</body>
</html>

示例 2：放在 <body> 底部（推荐）

<!DOCTYPE html>
<html>
<head>
  <meta charset="UTF-8">
  <title>示例</title>
</head>
<body>
  <button id="myButton">点我</button>

  <!-- ✅ 推荐：此时 button 已经加载完成 -->
  <script>
    const btn = document.getElementById('myButton'); // 能找到！
    btn.addEventListener('click', function() {
      alert('按钮被点击了！');
    });
  </script>
</body>
</html>

示例 3：放在 <head> 中，但加 defer 属性（现代最佳实践）

<!DOCTYPE html>
<html>
<head>
  <meta charset="UTF-8">
  <title>示例</title>
  <!-- ⭐ 最佳实践：defer 让脚本在页面解析完后再执行 -->
  <script src="main.js" defer></script>
</head>
<body>
  <button id="myButton">点我</button>
</body>
</html>
💡 理解页面加载顺序

浏览器解析 HTML 的过程是从上到下、逐行执行的：

  • 遇到 <script> 就停下来：浏览器会立即下载并执行脚本，暂停解析 HTML
  • 脚本执行完才继续：执行完 JS 代码后，才会继续解析后面的 HTML
  • 如果脚本在 <head> 里：页面内容还没加载，用户看到空白页，体验很差
  • 如果脚本在 <body> 底部：页面内容先显示，JS 最后执行，体验更好
⚠️ 常见错误示范

错误：把需要操作 DOM 的脚本放在 <head> 里

<head>
  <script>
    // ❌ 错误！这时 #demo 还不存在
    document.getElementById('demo').textContent = 'Hello';
  </script>
</head>
<body>
  <div id="demo">原始内容</div>
</body>

解决方法 1：移到 <body> 底部

<body>
  <div id="demo">原始内容</div>
  
  <script>
    // ✅ 正确！此时 #demo 已经存在
    document.getElementById('demo').textContent = 'Hello';
  </script>
</body>

解决方法 2：使用 defer 属性

<head>
  <script src="app.js" defer></script>
</head>
<body>
  <div id="demo">原始内容</div>
</body>
本课程的约定：
  • 在第 1-3 课的示例中，我们会把 <script> 写在 <body> 底部，这样最直观
  • 从第 4 课开始，我们会使用外部 JS 文件 + defer 属性，这是真实项目的标准做法
  • 记住原则：如果 JS 需要操作页面元素，要么放在元素后面，要么使用 defer

七、进阶实验：在网页里修改内容和响应点击

7.2 实验 02：给按钮添加点击事件

这个实验会教你如何让按钮「可以点击」，并在点击时执行你想要的代码。

实验 02：点击按钮弹出欢迎信息 Hands-on
HTML 预览
<h3>欢迎实验</h3> <p>点击下面的按钮，会执行右侧的 JavaScript 代码：</p> <button id="welcome-btn">点我弹出欢迎信息</button>
JavaScript (可编辑)
// 第 1 步：找到按钮元素 const btn = document.getElementById('welcome-btn'); // 第 2 步：给按钮添加「点击」事件监听器 // 意思是：当用户点击这个按钮时，执行下面花括号里的代码 if (btn) { btn.addEventListener('click', function () { // TODO：修改这里的提示语，变成你自己的欢迎语 alert('欢迎来到 JavaScript 的世界！'); }); }
// 提示：先点击「绑定点击事件」，再点击上方按钮，查看弹窗效果。
💡 代码解释
  • addEventListener('click', function() {...}) 的意思是：给元素添加一个事件监听器，监听「点击」事件
  • function() {...} 是一个函数，里面的代码会在按钮被点击时执行
  • 你可以在函数里写任何代码，不只是 alert()，也可以修改页面内容、改变颜色等等

八、本课小结与下一课预告

8.1 本课小结

  • 网页本质上是一组文件，HTML 负责结构，CSS 负责样式，JavaScript 负责行为。
  • 浏览器会先请求 HTML，再根据 HTML 中的引用去加载 CSS 和 JS。
  • HTML 是入口文件，所有资源最终都要通过 HTML 串起来。
  • 通过 <script> 标签可以把 JavaScript 引入到页面中。
  • 你已经学会了三种写 JS 代码的方式：写在 HTML 文件里、用浏览器控制台、引用外部 JS 文件。
  • 你已经通过实验，亲手体验了「JS 修改页面内容」和「JS 响应点击事件」。
