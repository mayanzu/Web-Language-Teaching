综合练习答案：点击变色互动网页 完整实现

完整代码：

<!DOCTYPE html>
<html lang="zh-CN">
<head>
  <meta charset="UTF-8">
  <title>我的第一个互动网页</title>
  <style>
    h1 {
      color: blue;
      font-size: 32px;
    }
    
    button {
      padding: 10px 20px;
      font-size: 16px;
      cursor: pointer;
    }
  </style>
</head>
<body>
  <h1 id="title">欢迎学习 JavaScript</h1>
  <button id="btn">点击我变色</button>
  
  <script>
    const title = document.getElementById('title');
    const btn = document.getElementById('btn');
    
    btn.addEventListener('click', function() {
      title.textContent = '太棒了！';
      title.style.color = 'green';
    });
  </script>
</body>
</html>

欢迎学习 JavaScript

💡 代码逐行解析：

  • <style> 部分：
    • h1 { color: blue; } - 设置标题初始颜色为蓝色
    • font-size: 32px; - 设置字体大小
    • button { padding: 10px 20px; } - 设置按钮内边距，让按钮更大
    • cursor: pointer; - 鼠标移到按钮上时显示手型光标
  • <body> 部分：
    • <h1 id="title"> - 创建标题，给它 id 方便 JS 查找
    • <button id="btn"> - 创建按钮，给它 id
  • <script> 部分：
    • document.getElementById('title') - 通过 id 查找标题元素
    • btn.addEventListener('click', function() {...}) - 给按钮添加点击事件监听器
    • title.textContent = '太棒了！' - 修改标题文字内容
    • title.style.color = 'green' - 通过 JavaScript 修改 CSS 颜色

🔍 关键知识点：

  • HTML、CSS、JavaScript 的配合：
    • HTML 定义结构（有什么元素）
    • CSS 定义样式（元素长什么样）
    • JavaScript 定义行为（点击后做什么）
  • 两种设置样式的方法：
    • 方法1：在 <style> 中写 CSS（如 h1 { color: blue; }）- 初始样式
    • 方法2：用 JavaScript 动态修改（如 title.style.color = 'green'）- 交互后的样式
  • 为什么要用 id？id 像元素的"身份证号"，让 JavaScript 能准确找到它。每个 id 在页面中必须唯一。
  • 事件监听器的作用：addEventListener 就像给按钮安装一个"侦听器"，时刻监听用户是否点击，点击后立即执行函数里的代码。

🎯 学习要点总结

  • HTML 结构：定义网页的内容和框架
  • CSS 样式：控制网页的外观（颜色、大小、间距等）
  • JavaScript 行为：让网页能响应用户操作
  • getElementById()：通过 id 查找页面元素
  • addEventListener()：给元素添加事件监听器
  • textContent：修改元素的文字内容
  • style.color：通过 JavaScript 动态修改 CSS 样式

⚠️ 常见错误及解决方法

错误 1：样式没有生效

// ❌ 错误：style 标签位置错误
<body>
  <style>...</style>  <!-- ❌ 不应该在 body 里 -->
</body>
// ✅ 正确：style 标签在 head 里
<head>
  <style>...</style>  <!-- ✅ 应该在 head 里 -->
</head>

错误 2：JavaScript 找不到元素

// ❌ 错误：script 在元素之前
<script>
  const btn = document.getElementById('btn');  // ❌ 此时按钮还不存在
</script>
<button id="btn">点击我</button>
// ✅ 正确：script 在元素之后
<button id="btn">点击我</button>
<script>
  const btn = document.getElementById('btn');  // ✅ 能找到按钮
</script>

错误 3：id 不匹配

// ❌ 错误：id 大小写不一致
<h1 id="Title">标题</h1>  <!-- ❌ 大写 T -->
<script>
  const title = document.getElementById('title');  // ❌ 小写 t，找不到！
</script>
// ✅ 正确：id 完全一致
<h1 id="title">标题</h1>  <!-- ✅ 小写 -->
<script>
  const title = document.getElementById('title');  // ✅ 小写，能找到
</script>
