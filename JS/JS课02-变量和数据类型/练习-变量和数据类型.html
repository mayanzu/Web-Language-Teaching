📦 第2课：变量和数据类型 - 练习

制作一个"学生信息展示器"，练习 const 声明、三种基本数据类型和模板字符串的使用。

📋 任务要求

创建一个网页，点击按钮后显示学生信息（姓名、年龄、是否团员）。

知识点：
  • 使用 const 声明常量
  • 字符串类型（String）、数字类型（Number）、布尔类型（Boolean）
  • 模板字符串拼接（`${变量}`）

📝 实现步骤

步骤 1：创建 HTML 结构

创建一个 HTML 文件，包含以下元素：

  • 一个标题 <h1>
  • 一个按钮 <button id="showBtn">
  • 一个显示区域 <div id="result">
💡 在 <head> 中添加简单的 CSS，设置 body 的 padding、按钮的样式等

步骤 2：声明变量（关键代码）

在 <script> 标签中声明三种类型的变量：

// 字符串类型 - 用引号包裹
const studentName = "李华";

// 数字类型 - 不用引号
const studentAge = 16;

// 布尔类型 - true 或 false
const isLeagueMember = true;
💡 注意：字符串用引号，数字不用引号，布尔值是关键字 true/false

步骤 3：使用模板字符串拼接信息（关键代码）

获取页面元素，添加点击事件，使用模板字符串拼接信息：

const showBtn = document.getElementById('showBtn');
const resultDiv = document.getElementById('result');

showBtn.addEventListener('click', function() {
  // 使用模板字符串（反引号 ` 和 ${} ）
  let message = `姓名：${studentName}
年龄：${studentAge} 岁
是否团员：${isLeagueMember}`;
  
  resultDiv.textContent = message;
});
💡 关键：模板字符串使用反引号 ` (键盘 Esc 下方)，用 ${变量名} 插入变量值

🧪 测试

  1. 保存文件并用浏览器打开
  2. 点击按钮，查看是否正确显示信息
  3. 尝试修改变量的值，刷新页面测试
