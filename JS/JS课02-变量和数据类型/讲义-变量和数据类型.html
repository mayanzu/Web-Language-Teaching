一、为什么需要变量？

想象一下，你在玩一个游戏，游戏需要记录你的得分、用户名和剩余生命值。如果程序没有办法"记住"这些信息，那么每次分数变化，或者你下次登录时，所有数据都将丢失。

变量，就是程序用来存储和管理这些动态信息的机制。

💡 生活中的类比
  • 游戏存档： 你的角色名、等级、金币数量，这些都是变量。游戏过程中，这些值会不断改变。
  • 手机联系人： 你为每个朋友存储了名字（变量名）和电话号码（变量值）。
  • 购物清单： 你写下要买的"苹果"，数量是"5个"。"苹果数量"就是一个变量，它的值是5。

没有变量，程序将是静态的、一次性的，无法处理任何需要追踪和记忆的任务。因此，变量是所有编程语言的基石。

二、变量是什么？

在技术上，变量是计算机内存中一个被命名的“存储空间”。你可以把数据放进去，之后通过这个名字来访问或修改这些数据。

我们可以把一个变量的生命周期分为几个阶段：

阶段解释示例代码
声明 (Declaration) 在程序中创建一个变量，告诉 JavaScript：“嘿，我要用这个名字了！” let score;
初始化 (Initialization) 在声明变量的同时，给它一个初始值。 let score = 0;
赋值 (Assignment) 更新一个已经存在的变量的值。 score = 100;
读取 (Read) 使用变量名来获取它当前存储的值。 console.log(score);
核心思想：变量的核心作用是为数据提供一个易于记忆和引用的名称，让我们不必关心数据在计算机内存中的具体位置。
💻 动手试试：变量的生命周期 Interactive Demo

在控制台运行以下代码，观察变量从声明到使用的完整过程：

// 1. 声明变量（只是告诉 JavaScript 这个名字要用了）
let myScore;
console.log('刚声明时的值:', myScore); // undefined

// 2. 初始化（第一次赋值）
myScore = 0;
console.log('初始化后的值:', myScore); // 0

// 3. 赋值（修改变量的值）
myScore = 100;
console.log('第一次修改:', myScore); // 100

myScore = 200;
console.log('第二次修改:', myScore); // 200

// 4. 读取并使用变量
let bonus = 50;
myScore = myScore + bonus; // 用旧值计算新值
console.log('加上奖励后:', myScore); // 250

// 5. 声明并同时初始化（最常用的方式）
let finalScore = 999;
console.log('最终得分:', finalScore); // 999

// 变量可以参与运算
let totalScore = myScore + finalScore;
console.log('总分:', totalScore); // 1249

四、如何声明变量？

现在你已经了解了 JavaScript 的基础数据类型，知道了变量里可以存储字符串、数字、布尔值等不同类型的数据。接下来让我们学习如何创建和使用这些变量。

现代 JavaScript 中，我们主要使用 let 和 const 来声明变量。var 是一个较旧的关键字，虽然仍能使用，但通常不推荐。

let, const, 和 var 的区别

这三者在“可变性”和“作用域”上有所不同。

关键字是否允许重新赋值作用域是否存在变量提升推荐用法
let ✅ 可以 块级作用域 {} ❌ 否 (存在暂时性死区) 用于声明未来可能需要改变值的变量，如循环计数器、状态值。
const ❌ 不可以 块级作用域 {} ❌ 否 (存在暂时性死区) 首选。 用于声明不希望被重新赋值的常量，如配置项、引用的DOM元素。
var ✅ 可以 函数作用域 ✅ 是 不推荐在现代项目中使用，除非需要兼容非常旧的浏览器。 
// 使用 let 声明一个可变的变量
let score = 100;
score = 150; // ✅ 合法，可以重新赋值

// 使用 const 声明一个常量
const appName = 'MyGame';
// appName = 'NewGame'; // ❌ 错误！常量不能被重新赋值

// const 对于对象和数组的特殊性
const user = { name: 'Alice' };
user.name = 'Bob'; // ✅ 合法！可以修改对象内部的属性
// user = { name: 'Charlie' }; // ❌ 错误！不能将 user 指向一个全新的对象
⚠️ 为什么不推荐使用 `var`？

var 存在两个主要问题，容易导致意外的 bug：

  • 变量提升 (Hoisting): var 声明的变量会被“提升”到其作用域的顶部，你可以在声明前使用它（值为 `undefined`），这不符合直觉。
  • 没有块级作用域: var 只认函数作用域，在 if 或 for 循环中声明的变量会“泄露”到外部。
// var 的问题示例
if (true) {
  var color = 'blue';
}
console.log(color); // 输出 'blue'。color 泄露到了 if 外部！

// 如果使用 let
if (true) {
  let theme = 'dark';
}
// console.log(theme); // ❌ 错误！theme 在这里无法访问，更安全！
实践建议： 默认使用 const。当你确定这个变量的值需要被改变时，再换成 let。完全忘记 var。

变量命名规则

给变量起一个好名字至关重要，它能极大提高代码的可读性。

  • 合法字符： 只能使用字母、数字、下划线 _ 和美元符号 $。
  • 开头字符： 不能以数字开头。例如 1stPlace 是非法的。
  • 关键字： 不能使用 JavaScript 的保留关键字，例如 let, if, for, function 等。
  • 大小写敏感： user 和 User 是两个完全不同的变量。
命名约定 (Best Practices):
  • 小驼峰命名法 (camelCase): 推荐用于变量和函数名。第一个单词小写，后续每个单词首字母大写。例如：userName, totalPrice, calculateFinalScore。
  • 见名知意: 变量名应准确描述它所存储的数据。避免使用 a, b, temp 等无意义的名称。
  • 布尔值命名: 通常以 is, has, can 开头，使其读起来像一个问题。例如：isLoggedIn, hasPermission。
  • 常量命名: 对于永不改变的硬编码值（如数学常数），有时会使用全大写加下划线。例如：const PI = 3.14;, const MAX_CONNECTIONS = 5;。

三、JavaScript 数据类型概览

JavaScript 是一种"动态类型"语言，意味着你不需要在声明变量时指定它的类型，变量的类型由赋给它的值决定。

数据类型主要分为两大类：基础数据类型 (Primitive Types) 和 引用数据类型 (Reference Types)。

JavaScript 的 8 种数据类型：
类型分类描述示例
String 基础类型 文本数据 'Hello', "World", `Hi`
Number 基础类型 数字（整数、小数） 42, 3.14, NaN, Infinity
Boolean 基础类型 真或假 true, false
Undefined 基础类型 未定义的值 undefined
Null 基础类型 空值 null
Symbol 基础类型 唯一标识符（ES6） Symbol('id')
BigInt 基础类型 大整数（ES2020） 9007199254740991n
Object 引用类型 对象、数组、函数等 {}, [], function(){}

本课重点：我们将详细学习前 5 种最常用的基础类型（String, Number, Boolean, Undefined, Null），Symbol 和 BigInt 在进阶课程中介绍，Object 类型将在后续课程深入学习。

字符串 (String)

字符串用于表示文本，必须用引号包裹。

用法示例说明

双引号 let message = "Hello, world!"; 与单引号功能相同，方便在字符串中包含另一种引号。

const userName = 'Bob';

数字 (Number)

JavaScript 中只有一种数字类型，不区分整数和浮点数（小数）。

let integer = 100;
let float = 3.14;
let negative = -50;
let scientific = 2.5e6; // 2500000 (科学计数法)

数字类型还包含几个特殊值：

  • Infinity: 表示正无穷大，例如 1 / 0。
  • -Infinity: 表示负无穷大，例如 -1 / 0。
  • NaN (Not-a-Number): 表示"不是一个数字"。当一个数学运算无法返回有效数字时，就会得到 NaN。
console.log('abc' / 2); // NaN

// Number()函数：将其他类型的值转换为数字类型
// 如果无法转换，返回NaN
console.log(Number('hello')); // NaN
console.log(Number('123'));   // 123

// 注意：NaN 与任何值（包括它自己）都不相等
console.log(NaN === NaN); // false

// isNaN()函数：检查一个值是否为NaN
// 这是判断NaN的标准方法
console.log(isNaN('abc' / 2)); // true
console.log(isNaN(123));       // false
💡 数字常用操作与方法 
// 数学运算
console.log(10 + 5);  // 15 (加法)
console.log(10 - 5);  // 5  (减法)
console.log(10 * 5);  // 50 (乘法)
console.log(10 / 5);  // 2  (除法)
console.log(10 % 3);  // 1  (取余)
console.log(2 ** 3);  // 8  (幂运算，2的3次方)

// Math 对象的常用方法
console.log(Math.round(4.7));    // 5 (四舍五入)
console.log(Math.floor(4.7));    // 4 (向下取整)
console.log(Math.ceil(4.3));     // 5 (向上取整)
console.log(Math.abs(-5));       // 5 (绝对值)
console.log(Math.max(1, 5, 3));  // 5 (最大值)
console.log(Math.min(1, 5, 3));  // 1 (最小值)
console.log(Math.random());      // 0-1之间的随机数

// 数字方法
const num = 3.14159;
console.log(num.toFixed(2));     // "3.14" (保留2位小数，返回字符串)
console.log(num.toPrecision(3)); // "3.14" (保留3位有效数字)

// 检查是否为有限数字
console.log(isFinite(100));      // true
console.log(isFinite(Infinity)); // false

// 检查是否为整数
console.log(Number.isInteger(10));   // true
console.log(Number.isInteger(10.5)); // false
⚠️ 浮点数精度问题

JavaScript 中的小数运算可能存在精度问题，这是由于计算机使用二进制表示数字导致的：

console.log(0.1 + 0.2);        // 0.30000000000000004 (而不是 0.3)
console.log(0.1 + 0.2 === 0.3); // false

// 解决方案：使用 toFixed() 或乘以倍数再除回去
console.log((0.1 + 0.2).toFixed(2)); // "0.30"
console.log((0.1 * 10 + 0.2 * 10) / 10); // 0.3

布尔 (Boolean)

布尔值只有两个：true (真) 和 false (假)。它通常是条件判断和逻辑运算的结果。

let isLoggedIn = true;
let hasPermission = false;

let userAge = 20;
let isAdult = userAge >= 18; // isAdult 的值将是 true

// 比较运算符返回布尔值
console.log(5 > 3);   // true
console.log(10 === 10); // true
console.log('a' !== 'b'); // true
真值 (Truthy) 和假值 (Falsy)

在 JavaScript 中，所有值都可以在条件判断中被转换为布尔值。以下值会被视为 false（假值）：

  • false - 布尔值 false
  • 0 - 数字零
  • -0 - 负零
  • '' 或 "" - 空字符串
  • null - 空值
  • undefined - 未定义
  • NaN - 非数字

除此之外的所有值都是真值（truthy），包括："0"（字符串）、"false"（字符串）、[]（空数组）、{}（空对象）等。

// 使用 Boolean() 函数测试真假值
console.log(Boolean(0));        // false
console.log(Boolean(''));       // false
console.log(Boolean(null));     // false
console.log(Boolean(undefined)); // false
console.log(Boolean(NaN));      // false

console.log(Boolean(1));        // true
console.log(Boolean('hello'));  // true
console.log(Boolean([]));       // true (空数组也是真值！)
console.log(Boolean({}));       // true (空对象也是真值！)
console.log(Boolean('0'));      // true (字符串 "0" 是真值！)

Null 和 Undefined

这两个类型都表示“没有值”，但它们的语义有所不同，是初学者常见的困惑点。

类型含义典型场景
undefined “未定义” - 变量已被声明，但尚未被赋值。这是变量的默认初始状态。 let x; console.log(x); // undefined
函数没有返回值时，默认返回 `undefined`。
null “空值” - 一个被明确赋予的、表示“没有对象”或“空”的值。 当你期望一个变量将来会指向一个对象，但现在还没有时，可以手动设置为 `null`。
let user = null;
💡 简单区分

undefined 是 JavaScript 自动给的，表示"你忘了给值"或"这个东西不存在"。
null 是我们程序员手动给的，表示"我确定这里现在什么都没有"。

// undefined 的常见情况
let a;
console.log(a); // undefined (声明但未赋值)

function test() {
  // 没有 return 语句
}
console.log(test()); // undefined (函数无返回值)

const obj = { name: 'Alice' };
console.log(obj.age); // undefined (访问不存在的属性)

// null 的使用场景
let currentUser = null; // 当前没有用户登录

function findUser(id) {
  // 如果找不到用户，返回 null 表示"查找失败"
  return null;
}

// 比较 null 和 undefined
console.log(null == undefined);  // true (相等运算符)
console.log(null === undefined); // false (严格相等运算符，类型不同)
console.log(typeof null);        // "object" (历史遗留bug)
console.log(typeof undefined);   // "undefined"
🎯 现在你已经了解了数据类型！

你已经知道了 JavaScript 中有哪些基础数据类型（String, Number, Boolean, Null, Undefined），以及它们各自的特点和用法。

接下来，让我们学习如何用 let 和 const 来声明变量，把这些不同类型的数据存储起来并使用它们。

五、使用 typeof 检查类型

typeof 是一个一元运算符，可以返回一个表示操作数类型的字符串。在调试时非常有用。

console.log(typeof 18);         // "number"
console.log(typeof 'hello');    // "string"
console.log(typeof true);       // "boolean"
console.log(typeof undefined);  // "undefined"
console.log(typeof {});         // "object" (对象)
console.log(typeof []);         // "object" (数组也是一种特殊的对象)
console.log(typeof null);       // "object" (这是一个著名的历史遗留问题)
注意：
  • typeof null 返回 'object' 是 JavaScript 早期版本的一个错误，现在为了兼容性被保留了下来。要检查一个值是否为 null，最可靠的方法是 value === null。

六、数据类型转换

在编程中，我们经常需要在不同数据类型之间进行转换。

显式类型转换

通过函数手动进行转换。

函数说明示例
Number() 将任何类型的值转换为数字。无法转换时返回 NaN。 Number('123') // 123
Number('hi') // NaN
Number(true) // 1
String() 将任何类型的值转换为字符串。 String(123) // '123'
String(true) // 'true'
Boolean() 将任何类型的值转换为布尔值。 Boolean(0) // false
Boolean('hi') // true
Boolean('') // false
parseInt() 解析字符串并返回一个整数。 parseInt('28.5px') // 28
parseFloat() 解析字符串并返回一个浮点数。 parseFloat('28.5px') // 28.5

隐式类型转换

当运算符与不同类型的值一起使用时，JavaScript 会自动进行类型转换。这虽然方便，但也可能导致意外结果。

// + 运算符的特殊性
console.log('5' + 3); // "53" (字符串拼接优先)
console.log(5 + '3'); // "53"

// 其他数学运算符 (- * /) 会尝试将字符串转为数字
console.log('10' - 5); // 5
console.log('10' * 2); // 20

// == 相等运算符会进行隐式转换
console.log(5 == '5'); // true (不推荐使用)

// === 严格相等运算符不会进行类型转换，更安全
console.log(5 === '5'); // false (推荐使用)
💡 最佳实践

为了避免隐式转换带来的不确定性，建议：

  • 在进行数学运算前，明确使用 Number(), parseInt() 或 parseFloat() 转换类型。
  • 在比较值时，始终使用严格相等运算符 === 和 !==。

九、本课小结

  • 变量是程序中用于存储数据的命名空间，是编程的基石。
  • 使用 let 声明可变变量，使用 const 声明常量，并优先使用 const。避免使用旧的 var。
  • 变量命名应遵循小驼峰命名法并做到见名知意。
  • JavaScript 有多种基础数据类型：String, Number, Boolean, Undefined, Null。
  • 模板字符串 (`` ` ``) 是拼接字符串和嵌入变量的现代最佳实践。
  • 理解 undefined (未赋值) 和 null (主动赋空值) 的语义区别。
  • 使用 typeof 可以检查变量的类型，但要注意 typeof null 的特例。
  • 类型转换分为显式 (手动转换) 和隐式 (自动转换)，为避免意外，推荐使用 === 进行比较并手动转换数据。
