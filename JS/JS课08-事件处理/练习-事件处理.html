⚡ 第8课：事件处理 - 练习

创建一个互动页面，练习 addEventListener 监听点击事件和输入事件，结合 DOM 操作实现交互效果。

📋 任务要求

创建一个网页，包含：1) 点击按钮切换背景颜色 2) 输入框实时显示字符数 3) 点击计数器按钮。

知识点：
  • 事件监听：addEventListener()
  • 点击事件：click
  • 输入事件：input
  • 结合 DOM 操作修改内容和样式

📝 实现步骤

步骤 1：创建 HTML 结构

创建包含以下元素的 HTML：

<h2>任务1：切换背景色</h2>
<button id="colorBtn">切换背景色</button>

<h2 style="margin-top: 30px;">任务2：字符计数器</h2>
<textarea id="textInput" rows="4" style="width: 100%; padding: 10px;"></textarea>
<p id="charCount">字符数：0</p>

<h2 style="margin-top: 30px;">任务3：点击计数器</h2>
<button id="countBtn">点击我</button>
<p id="clickCount">点击次数：0</p>

步骤 2：任务1 - 切换背景色（关键代码）

使用 addEventListener 监听按钮点击，切换背景色：

const colorBtn = document.getElementById('colorBtn');

// 监听点击事件
colorBtn.addEventListener('click', function() {
  // 获取当前背景色
  const currentColor = document.body.style.backgroundColor;
  
  // 切换颜色
  if (currentColor === 'lightblue' || currentColor === '') {
    document.body.style.backgroundColor = 'lightgreen';
  } else {
    document.body.style.backgroundColor = 'lightblue';
  }
});
💡 addEventListener('click', function) 监听点击事件，点击时执行函数

步骤 3：任务2 - 字符计数器（关键代码）

监听 input 事件，实时统计字符数：

const textInput = document.getElementById('textInput');
const charCount = document.getElementById('charCount');

// 监听输入事件（每次输入都会触发）
textInput.addEventListener('input', function() {
  // 获取输入框的值
  const text = textInput.value;
  
  // 获取字符数
  const count = text.length;
  
  // 更新显示
  charCount.innerText = `字符数：${count}`;
});
💡 input 事件在用户输入时实时触发，value 获取输入框的值

步骤 4：任务3 - 点击计数器（关键代码）

创建一个计数器，每次点击按钮增加 1：

const countBtn = document.getElementById('countBtn');
const clickCountDisplay = document.getElementById('clickCount');

// 创建变量存储点击次数
let count = 0;

// 监听点击事件
countBtn.addEventListener('click', function() {
  // 点击次数加1
  count++;
  
  // 更新显示
  clickCountDisplay.innerText = `点击次数：${count}`;
});
💡 使用变量存储点击次数，每次点击时递增并更新显示
