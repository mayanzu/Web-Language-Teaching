第8课：事件处理

点击按钮、输入文字、移动鼠标、提交表单……这些用户操作在浏览器中都会触发「事件」。本课你将学会监听这些事件，并用函数来响应它们。

click 点击 input 输入 addEventListener 事件回调函数

一、什么是事件？

事件就是「在浏览器中发生的一件事」，比如：

  • 用户点击了一个按钮（click）。
  • 用户在输入框中输入内容（input）。
  • 页面加载完成（load）。

二、如何监听事件？

最常用的方式是使用 addEventListener：

const btn = document.querySelector('button');

btn.addEventListener('click', function () {
  console.log('按钮被点击了！');
});
  • 第一个参数是事件类型，如 'click'。
  • 第二个参数是一个函数（回调函数），事件发生时会被调用。

三、常见的事件类型

  • click：鼠标点击。
  • input：输入框内容发生变化。
  • submit：表单提交。
  • change：值改变并失去焦点（如下拉框）。

四、实验：点击按钮切换背景颜色

实验 09：事件驱动的样式变化 Hands-on
  1. 新建一个 HTML 文件，包含一个按钮，按钮文字为「切换背景色」。
  2. 使用 querySelector 选中该按钮。
  3. 给按钮添加 click 事件监听。
  4. 在事件回调函数中，切换 document.body.style.backgroundColor 的值（例如在白色和浅蓝色之间切换）。

五、本课小结

  • 事件是用户与网页交互时触发的各种「动作」。
  • 使用 addEventListener 可以给元素绑定事件处理函数。
  • 结合 DOM 操作和事件，可以做出各种交互效果。
