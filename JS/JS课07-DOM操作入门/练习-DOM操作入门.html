🎨 第7课：DOM操作入门 - 练习

创建一个简单的个人名片编辑器，练习选择元素、修改内容和样式。

📋 任务要求

创建一个网页，包含一张个人名片（姓名、职业、简介），点击按钮可以修改名片内容和样式（颜色、字体大小等）。

知识点：
  • 选择元素：getElementById()、querySelector()
  • 修改内容：innerText 或 textContent
  • 修改样式：element.style.属性名

📝 实现步骤

步骤 1：创建 HTML 结构

创建包含以下元素的 HTML：

<div id="card" style="padding: 20px; border: 2px solid #0066cc; border-radius: 8px;">
  <h2 id="name">张三</h2>
  <p id="job">Web开发工程师</p>
  <p id="bio">热爱编程，喜欢学习新技术。</p>
</div>

<div style="margin-top: 20px;">
  <button id="changeNameBtn">修改姓名</button>
  <button id="changeColorBtn">改变颜色</button>
  <button id="changeSizeBtn">放大字体</button>
</div>

步骤 2：选择元素（关键代码）

使用 getElementById() 选择需要操作的元素：

// 选择名片中的元素
const nameElement = document.getElementById('name');
const jobElement = document.getElementById('job');
const bioElement = document.getElementById('bio');
const cardElement = document.getElementById('card');

// 选择按钮
const changeNameBtn = document.getElementById('changeNameBtn');
const changeColorBtn = document.getElementById('changeColorBtn');
const changeSizeBtn = document.getElementById('changeSizeBtn');
💡 getElementById() 通过元素的 id 属性选择元素，参数不需要 # 号

步骤 3：修改文本内容（关键代码）

使用 innerText 或 textContent 修改元素内容：

changeNameBtn.addEventListener('click', function() {
  // 修改姓名
  nameElement.innerText = "李四";
  
  // 也可以使用 textContent
  // nameElement.textContent = "李四";
});
💡 innerText 和 textContent 都可以修改元素的文本内容

步骤 4：修改样式（关键代码）

使用 element.style.属性名 修改元素样式：

changeColorBtn.addEventListener('click', function() {
  // 修改文字颜色
  nameElement.style.color = "red";
  jobElement.style.color = "blue";
  
  // 修改背景色
  cardElement.style.backgroundColor = "#f0f8ff";
});
💡 CSS 中的 background-color 在 JavaScript 中写成驼峰式：backgroundColor

步骤 5：修改字体大小（关键代码）

使用 style.fontSize 修改字体大小：

changeSizeBtn.addEventListener('click', function() {
  // 修改字体大小（注意要带单位）
  nameElement.style.fontSize = "32px";
  jobElement.style.fontSize = "18px";
  bioElement.style.fontSize = "16px";
});
💡 设置样式值时要加单位，如 "32px"、"2em" 等

步骤 6：使用 querySelector（可选）

也可以使用 querySelector() 选择元素：

// 使用 querySelector 选择（需要加 # 号）
const name = document.querySelector('#name');

// 选择 class（需要加 . 号）
const card = document.querySelector('.card');

// 选择标签
const firstH2 = document.querySelector('h2');
💡 querySelector() 使用 CSS 选择器语法，更灵活但稍慢

🧪 测试

  1. 保存并打开网页
  2. 点击"修改姓名"，查看姓名是否变成"李四"
  3. 点击"改变颜色"，查看颜色是否改变
  4. 点击"放大字体"，查看字体是否变大
