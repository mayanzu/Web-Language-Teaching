一、为什么需要DOM操作?

想象你在使用一个购物网站:点击"加入购物车"按钮,购物车图标上的数字立即增加;删除商品,页面上的商品卡片消失;输入搜索关键词,下方实时显示匹配结果。这些都离不开DOM操作。

💡 生活中的类比
  • DOM操作 = 遥控器:就像用遥控器控制电视(换台、调音量、开关),JavaScript通过DOM控制网页(改文字、换颜色、增删元素)
  • 没有DOM = 静态海报:网页只能展示固定内容,无法响应用户操作
  • 有了DOM = 智能显示屏:网页可以根据用户操作实时更新,提供交互体验

没有DOM操作的网页:

<!-- 这个购物车数量是写死的,无法动态更新 -->
<div class="cart">
  <span>购物车(0)</span>
</div>
<button>加入购物车</button>
<!-- 点击按钮什么都不会发生 -->

使用DOM操作后:

<div class="cart">
  <span id="cart-count">购物车(0)</span>
</div>
<button onclick="addToCart()">加入购物车</button>

<script>
let count = 0;
function addToCart() {
  count++;
  // document.getElementById()方法：通过id属性选中元素
  // 返回匹配的DOM元素对象，如果找不到返回null
  const cartElement = document.getElementById('cart-count');
  // innerText属性：获取或设置元素的文本内容
  cartElement.innerText = `购物车(${count})`;
}
</script>
<!-- 现在点击按钮,数字会实时增加! -->

DOM操作让我们能够:

  • 响应用户交互:点击、输入、滚动等操作触发页面变化
  • 动态更新内容:无需刷新页面就能显示新数据
  • 创建交互体验:实现下拉菜单、轮播图、表单验证等功能
  • 构建单页应用:像微信网页版、Gmail这样的复杂应用

二、DOM是什么?

2.1 DOM的定义

DOM（Document Object Model，文档对象模型）是浏览器提供的一套API,用于将HTML文档表示为一个树形结构,让JavaScript可以访问和操作网页中的每个元素。

💡 理解DOM树

想象一个家族族谱:最上面是祖先,下面是子孙,每个人都有父母、兄弟姐妹、子女。DOM树也是这样:

  • 根节点:整个HTML文档(document)
  • 父子关系:标签嵌套关系(<div>包含<p>,div是父,p是子)
  • 兄弟关系:同一层级的标签

2.2 HTML如何变成DOM树

浏览器解析HTML代码时,会将每个标签转换为DOM节点,构建成树状结构:

<!DOCTYPE html>
<html>
  <head>
    <title>我的网页</title>
  </head>
  <body>
    <h1>标题</h1>
    <p>段落文本</p>
  </body>
</html>

对应的DOM树结构:

document (根节点)
  └─ html
      ├─ head
      │   └─ title
      │       └─ "我的网页" (文本节点)
      └─ body
          ├─ h1
          │   └─ "标题" (文本节点)
          └─ p
              └─ "段落文本" (文本节点)

2.3 DOM节点类型

节点类型说明示例
元素节点 HTML标签,如div、p、span等 <div>、<p>、<button>
文本节点 标签内的文本内容 "Hello World"
属性节点 标签的属性 id="box"、class="btn"
文档节点 整个文档,即document对象 document
📌 重要概念
  • DOM将HTML文档转换为JavaScript可以操作的对象
  • 每个HTML标签都是一个DOM元素节点
  • 通过DOM API可以查找、修改、创建、删除这些节点
  • document对象是访问DOM的入口

三、选择元素的方法

要操作网页元素,第一步是选中它们。JavaScript提供了多种选择器方法,各有适用场景。

3.1 通过ID选择 - getElementById

// document.getElementById(id)方法：通过元素的id属性选中元素
// 参数：id字符串（不需要#符号）
// 返回：匹配的DOM元素对象，如果找不到返回null
// 特点：最快的选择方法，因为id是唯一的
const header = document.getElementById('main-header');
console.log(header);  // 返回id为main-header的元素

// 如果元素不存在
const notExist = document.getElementById('not-exist');
console.log(notExist);  // null

3.2 通过CSS选择器 - querySelector

// document.querySelector(selector)方法：通过CSS选择器选中第一个匹配的元素
// 参数：CSS选择器字符串（和CSS写法完全一样）
// 返回：第一个匹配的元素，如果找不到返回null
// 特点：最灵活，支持所有CSS选择器语法

// 选择标签
const firstDiv = document.querySelector('div');

// 选择类（需要加.）
const box = document.querySelector('.box');

// 选择ID（需要加#）
const header = document.querySelector('#main-header');

// 复杂选择器
const firstButton = document.querySelector('div.container > button');
const active = document.querySelector('li.active');

3.3 选择多个元素 - querySelectorAll

// document.querySelectorAll(selector)方法：通过CSS选择器选中所有匹配的元素
// 参数：CSS选择器字符串
// 返回：NodeList对象（类似数组），包含所有匹配的元素
// 即使只有一个或没有匹配，也返回NodeList（可能为空）

const allButtons = document.querySelectorAll('button');
console.log(allButtons.length);  // 返回按钮数量

// 遍历所有匹配的元素
allButtons.forEach(button => {
  console.log(button.innerText);
});

// 选择所有class为item的元素
const items = document.querySelectorAll('.item');

// 选择所有li标签
const listItems = document.querySelectorAll('li');

3.4 其他选择方法

// document.getElementsByClassName(className)方法：通过class名称选择元素
// 参数：类名字符串（不需要.符号）
// 返回：HTMLCollection对象（类似数组的动态集合）
const boxes = document.getElementsByClassName('box');

// document.getElementsByTagName(tagName)方法：通过标签名选择元素
// 参数：标签名字符串
// 返回：HTMLCollection对象
const allDivs = document.getElementsByTagName('div');
const allParagraphs = document.getElementsByTagName('p');

3.5 选择器方法对比

方法返回值适用场景性能
getElementById 单个元素或null 有明确id的元素 最快
querySelector 单个元素或null 需要CSS选择器,只要第一个 较快
querySelectorAll NodeList(静态) 需要选择多个元素 较快
getElementsByClassName HTMLCollection(动态) 按class选择,需要动态更新 快
getElementsByTagName HTMLCollection(动态) 按标签名选择 快
⚠️ 注意事项
  • getElementById:参数不需要#号
  • querySelector:参数需要完整的CSS选择器(#id、.class)
  • NodeList vs HTMLCollection:都类似数组,但NodeList是静态的,HTMLCollection是动态的
  • 如果元素不存在,返回null或空集合,使用前最好检查

四、读取元素内容

选中元素后,我们需要读取它的内容。元素内容有多种表现形式,要根据需求选择合适的属性。

4.1 innerText - 纯文本内容

<div id="box">
  Hello <strong>World</strong>
</div>

<script>
const box = document.getElementById('box');

// innerText属性：获取元素的纯文本内容
// 会忽略HTML标签,只返回可见文本
// 注意：会触发重排,性能较textContent稍差
console.log(box.innerText);  // "Hello World"
</script>

4.2 textContent - 所有文本

<div id="box">
  Hello <strong>World</strong>
  <style>.hidden { display: none; }</style>
</div>

<script>
const box = document.getElementById('box');

// textContent属性：获取元素及其后代的所有文本内容
// 包括隐藏元素的文本和<script>、<style>标签中的内容
// 性能比innerText好,不会触发重排
console.log(box.textContent);  
// 包含所有文本,包括样式代码
</script>

4.3 innerHTML - HTML内容

<div id="box">
  Hello <strong>World</strong>
</div>

<script>
const box = document.getElementById('box');

// innerHTML属性：获取或设置元素内部的HTML代码
// 返回完整的HTML字符串,包括所有标签
console.log(box.innerHTML);  
// "  Hello World"
</script>

4.4 三种属性的对比

属性返回内容包含HTML标签性能适用场景
innerText 可见的纯文本 否 较慢 获取/设置用户可见文本
textContent 所有文本(包括隐藏) 否 快 纯文本操作,追求性能
innerHTML HTML代码 是 中等 需要读取或设置HTML结构

4.5 读取元素属性

<img id="avatar" src="photo.jpg" alt="头像" data-user="123">

<script>
const img = document.getElementById('avatar');

// getAttribute()方法：获取元素的属性值
// 参数：属性名字符串
// 返回：属性值字符串，如果属性不存在返回null
const src = img.getAttribute('src');
console.log(src);  // "photo.jpg"

const alt = img.getAttribute('alt');
console.log(alt);  // "头像"

// 也可以直接访问属性
console.log(img.src);   // 完整URL
console.log(img.alt);   // "头像"

// 自定义属性(data-*)
const userId = img.getAttribute('data-user');
console.log(userId);  // "123"
</script>

五、修改元素内容

读取元素内容后,更重要的是修改它们,让网页动态更新。

5.1 修改文本内容

<h1 id="title">旧标题</h1>
<p id="desc">旧描述</p>

<script>
const title = document.getElementById('title');
const desc = document.getElementById('desc');

// 使用innerText修改文本(已学习)
title.innerText = '新标题';

// 使用textContent修改文本(已学习)
desc.textContent = '新描述';

// 两者的区别:
// innerText会解析换行,textContent不会
title.innerText = '第一行\n第二行';    // 会换行显示
desc.textContent = '第一行\n第二行';  // 也会换行
</script>

5.2 修改HTML内容

<div id="content">旧内容</div>

<script>
const content = document.getElementById('content');

// 使用innerHTML修改HTML结构(已学习)
content.innerHTML = '<strong>加粗的</strong> 新内容';

// 追加内容
content.innerHTML += '<p>追加的段落</p>';

// 清空内容
content.innerHTML = '';
</script>
⚠️ innerHTML的安全风险

使用innerHTML设置用户输入的内容时要特别小心,可能导致XSS(跨站脚本)攻击:

// 危险!如果userInput包含<script>标签会被执行
const userInput = '<script>alert("攻击!")</script>';
element.innerHTML = userInput;  // ❌ 不安全!

// 安全的做法:使用innerText或textContent
element.innerText = userInput;  // ✅ 安全,会显示为纯文本

5.3 修改元素属性

<img id="avatar" src="old.jpg" alt="旧图片">
<a id="link" href="https://old.com">链接</a>

<script>
const img = document.getElementById('avatar');
const link = document.getElementById('link');

// setAttribute()方法：设置元素的属性
// 参数：(属性名, 属性值)
// 如果属性不存在则创建,存在则更新
img.setAttribute('src', 'new.jpg');
img.setAttribute('alt', '新图片');

// 也可以直接设置属性
img.src = 'new.jpg';
link.href = 'https://new.com';

// 添加自定义属性
img.setAttribute('data-id', '456');

// removeAttribute()方法：删除元素的属性
// 参数：属性名字符串
img.removeAttribute('alt');
</script>

六、操作元素样式

除了修改内容,改变元素的外观(颜色、大小、位置等)也是DOM操作的重要部分。

6.1 通过style属性修改样式

<div id="box">彩色盒子</div>

<script>
const box = document.getElementById('box');

// style属性：访问元素的内联样式对象
// 可以读取或设置任何CSS属性
// 注意：CSS属性名要用驼峰命名法(background-color → backgroundColor)

// 修改颜色
box.style.color = 'white';
box.style.backgroundColor = '#0066CC';

// 修改尺寸
box.style.width = '200px';
box.style.height = '100px';

// 修改字体
box.style.fontSize = '20px';
box.style.fontWeight = 'bold';
</script>

6.2 通过classList操作样式(推荐)

<div id="box" class="box">盒子</div>

<script>
const box = document.getElementById('box');

// classList.add()方法：添加一个或多个class (已学习)
box.classList.add('highlight');

// classList.remove()方法：删除class (已学习)
box.classList.remove('border');

// classList.toggle()方法：切换class的存在状态 (已学习)
box.classList.toggle('active');

// classList.contains()方法：检查是否包含某个class (已学习)
if (box.classList.contains('highlight')) {
  console.log('包含highlight类');
}
</script>

七、创建和删除元素

DOM操作不仅可以修改现有元素,还可以动态创建新元素或删除元素。

7.1 创建和添加元素

<div id="container"></div>

<script>
// document.createElement(tagName)方法：创建一个新的HTML元素
// 参数：标签名字符串
// 返回：新创建的元素节点
const newDiv = document.createElement('div');
newDiv.innerText = '新创建的div';
newDiv.className = 'box';

const container = document.getElementById('container');

// appendChild()方法：将子元素添加到父元素的末尾
// 参数：要添加的元素节点
container.appendChild(newDiv);
</script>

7.2 删除元素

<div id="box">要删除的盒子</div>

<script>
const box = document.getElementById('box');

// remove()方法：直接删除元素本身
box.remove();
</script>

let cardId = 0; function addCard() { const titleInput = document.getElementById('cardTitle'); const title = titleInput.value.trim(); if (!title) { alert('⚠️ 请输入卡片标题'); return; } const card = document.createElement('div'); card.className = 'card'; card.id = 'card-' + (++cardId); const cardTitle = document.createElement('div'); cardTitle.className = 'card-title'; cardTitle.innerText = title; const deleteBtn = document.createElement('button'); deleteBtn.className = 'card-btn'; deleteBtn.innerText = '删除'; deleteBtn.onclick = function() { card.remove(); }; card.appendChild(cardTitle); card.appendChild(deleteBtn); document.getElementById('cardGrid').appendChild(card); titleInput.value = ''; } function clearAll() { if (confirm('确定要删除所有卡片吗?')) { document.getElementById('cardGrid').innerHTML = ''; cardId = 0; } }
