📚 第6课：数组和对象 - 练习

创建一个购物清单管理器，练习数组的创建、访问、增删操作和遍历，以及对象的创建和属性访问。

📋 任务要求

创建一个购物清单，可以添加商品（push）、删除最后一个商品（pop）、删除第一个商品（shift）、在开头添加商品（unshift），并能显示所有商品。同时创建商品对象，包含名称和价格属性。

知识点：
  • 数组的创建和访问：const arr = []、arr[0]
  • 数组方法：push()、pop()、shift()、unshift()
  • 数组遍历：for 循环或 forEach()
  • 对象的创建和属性访问：const obj = {}、obj.key

📝 实现步骤

步骤 1：创建 HTML 结构

创建包含以下元素的 HTML：

  • 一个输入框：<input id="itemInput" placeholder="输入商品名称">
  • 四个按钮：添加到末尾、删除最后一个、删除第一个、添加到开头、显示全部
  • 结果显示区域：<div id="result"></div>

步骤 2：创建数组（关键代码）

创建一个空数组存储购物清单：

// 创建空数组
const shoppingList = [];

// 获取页面元素
const itemInput = document.getElementById('itemInput');
const resultDiv = document.getElementById('result');
💡 数组使用 [] 创建，可以存储多个值

步骤 3：实现添加到末尾（关键代码）

使用 push() 方法在数组末尾添加元素：

document.getElementById('pushBtn').addEventListener('click', function() {
  const item = itemInput.value;
  if (item) {
    shoppingList.push(item);  // 添加到数组末尾
    itemInput.value = '';  // 清空输入框
    resultDiv.textContent = `已添加：${item}，当前清单：${shoppingList}`;
  }
});
💡 push() 在数组末尾添加一个元素

步骤 4：实现删除最后一个（关键代码）

使用 pop() 方法删除并返回数组最后一个元素：

document.getElementById('popBtn').addEventListener('click', function() {
  if (shoppingList.length > 0) {
    const removed = shoppingList.pop();  // 删除并返回最后一个元素
    resultDiv.textContent = `已删除：${removed}，剩余：${shoppingList}`;
  } else {
    resultDiv.textContent = '清单已空！';
  }
});
💡 pop() 删除并返回数组最后一个元素

步骤 5：实现其他数组方法

参考上面的代码，实现：

  • shift() - 删除第一个元素
  • unshift() - 在开头添加元素
💡 shift() 和 pop() 类似，但删除第一个；unshift() 和 push() 类似，但添加到开头

步骤 6：遍历数组显示（关键代码）

使用 forEach() 遍历数组并显示所有商品：

document.getElementById('showBtn').addEventListener('click', function() {
  if (shoppingList.length === 0) {
    resultDiv.textContent = '清单为空！';
    return;
  }
  
  let display = '购物清单：\n';
  shoppingList.forEach(function(item, index) {
    display += `${index + 1}. ${item}\n`;
  });
  
  resultDiv.textContent = display;
});
💡 forEach() 可以遍历数组的每个元素，第一个参数是元素值，第二个是索引

步骤 7：创建对象（进阶）

尝试创建包含商品信息的对象：

// 创建商品对象
const product = {
  name: "苹果",
  price: 5.5,
  quantity: 10
};

// 访问对象属性
console.log(product.name);   // "苹果"
console.log(product.price);  // 5.5

// 修改对象属性
product.quantity = 20;
💡 对象使用 {} 创建，包含键值对，使用 对象.属性名 访问属性
