🔀 第4课：控制结构 - 练习

制作一个成绩等级判定器，练习 if...else if...else 条件分支的使用。

📋 任务要求

创建一个网页，用户输入分数（0-100），点击按钮后判定成绩等级：优秀（90-100）、良好（80-89）、中等（70-79）、及格（60-69）、不及格（0-59）。

知识点：
  • 条件分支：if...else if...else
  • 比较运算符：>=、<
  • 逻辑运算符：&&（且）

📝 实现步骤

步骤 1：创建 HTML 结构

创建包含以下元素的 HTML：

  • 一个输入框：<input type="number" id="scoreInput" placeholder="请输入分数(0-100)">
  • 一个按钮：<button id="checkBtn">查询等级</button>
  • 结果显示区域：<div id="result"></div>

步骤 2：获取页面元素

const scoreInput = document.getElementById('scoreInput');
const checkBtn = document.getElementById('checkBtn');
const resultDiv = document.getElementById('result');

步骤 3：实现判定逻辑（关键代码）

为按钮添加点击事件，使用 if...else if...else 判定等级：

checkBtn.addEventListener('click', function() {
  const score = Number(scoreInput.value);
  let grade;
  
  // 多分支条件判断
  if (score >= 90 && score <= 100) {
    grade = "优秀";
  } else if (score >= 80 && score < 90) {
    grade = "良好";
  } else if (score >= 70 && score < 80) {
    grade = "中等";
  } else if (score >= 60 && score < 70) {
    grade = "及格";
  } else if (score >= 0 && score < 60) {
    grade = "不及格";
  } else {
    grade = "输入无效，请输入0-100的分数";
  }
  
  resultDiv.textContent = `成绩等级：${grade}`;
});
💡 注意：&& 表示"且"，两个条件都满足才执行

🧪 测试

  1. 输入 95，查看是否显示"优秀"
  2. 输入 85，查看是否显示"良好"
  3. 输入 75，查看是否显示"中等"
  4. 输入 65，查看是否显示"及格"
  5. 输入 50，查看是否显示"不及格"
  6. 输入 120，查看是否显示"输入无效"
