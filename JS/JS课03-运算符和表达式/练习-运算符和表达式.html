🧮 第3课：运算符和表达式 - 练习

制作一个简单的计算器，练习四则运算符（+、-、*、/）的使用。

📋 任务要求

创建一个网页，用户输入两个数字后，点击不同的按钮进行加减乘除运算并显示结果。

知识点：
  • 算术运算符：+、-、*、/
  • 获取输入框的值：input.value
  • 数据类型转换：Number()

📝 实现步骤

步骤 1：创建 HTML 结构

创建包含以下元素的 HTML：

  • 两个输入框：<input type="number" id="num1"> 和 <input type="number" id="num2">
  • 四个按钮：<button id="addBtn">+</button>、-、*、/
  • 结果显示区域：<div id="result"></div>
💡 添加适当的 CSS 美化页面，设置输入框和按钮的样式

步骤 2：获取页面元素（关键代码）

const num1Input = document.getElementById('num1');
const num2Input = document.getElementById('num2');
const resultDiv = document.getElementById('result');

const addBtn = document.getElementById('addBtn');
const subBtn = document.getElementById('subBtn');
const mulBtn = document.getElementById('mulBtn');
const divBtn = document.getElementById('divBtn');

步骤 3：实现加法运算（关键代码）

为加法按钮添加点击事件：

addBtn.addEventListener('click', function() {
  // 获取输入框的值并转换为数字
  const a = Number(num1Input.value);
  const b = Number(num2Input.value);
  
  // 进行加法运算
  const sum = a + b;
  
  // 显示结果
  resultDiv.textContent = `结果：${sum}`;
});
💡 Number() 用于将字符串转换为数字，否则 + 会变成字符串拼接

步骤 4：实现减法、乘法、除法

参考加法的代码，为其他三个按钮添加事件：

  • 减法按钮：使用 - 运算符
  • 乘法按钮：使用 * 运算符
  • 除法按钮：使用 / 运算符
💡 代码结构和加法完全一样，只需要改变运算符即可

🧪 测试

  1. 输入两个数字，如 10 和 5
  2. 依次点击 +、-、*、/ 按钮
  3. 查看结果是否正确（15、5、50、2）
  4. 尝试更多数字组合
