0. 布局基础概念

0.1 什么是布局 (Layout)？

简单来说，布局就是把网页元素（文字、图片、盒子）摆放在正确位置的技术。

想象你在装修房子：

  • 📦 默认文档流 (Document Flow)：就像把家具全部堆在门口，先进去的在里面，后进去的在外面，从上到下傻傻地堆叠，无法满足复杂设计。
  • 📐 CSS 布局：就是利用各种 CSS 属性（如 Flex, Grid, Position），把沙发（导航栏）放客厅，床（侧边栏）放卧室，餐桌（主要内容）放中间，让页面既美观又实用。

0.2 常见的布局场景

经典 T 型布局

顶部导航 + 侧边栏 + 内容区。
应用： 博客、新闻网站、后台管理系统。

卡片网格布局

像商品列表一样整齐排列。
应用： 电商网站、图片画廊、视频列表。

全屏居中布局

内容死死钉在屏幕正中间。
应用： 登录注册页、全屏引导页。

1. 浮动 (Float)

float 属性最初是为了实现“文字环绕图片”的效果而设计的。但在 Flexbox 出现之前，它是网页多列布局的主力军。

1.1 基本概念

  • float: left; 元素向左浮动。
  • float: right; 元素向右浮动。
  • 脱离文档流：浮动元素会“漂浮”在普通元素上方（这会导致父容器高度塌陷问题）。

1.2 核心痛点：清除浮动 (Clearfix)

当一个父盒子里的所有子元素都浮动了，父盒子会感知不到子元素的高度，变成“一条线”（高度塌陷）。我们需要“清除浮动”来撑开父盒子。

实验 01：浮动与清除浮动 (Clearfix) 未运行
HTML (只读)
<!-- 父容器 --> <div class="container clearfix"> <div class="box left">左浮动</div> <div class="box right">右浮动</div> </div> <p>我是下面的内容，如果清除浮动失败，我会跑上去。</p>
CSS (可编辑)
.container { background-color: #eee; border: 2px dashed #999; /* 如果不清除浮动，这个灰色背景将看不见（高度为0） */ } .box { width: 100px; height: 100px; color: white; text-align: center; line-height: 100px; } .left { background: #ff5252; float: left; /* 尝试注释掉这行看看 */ } .right { background: #2196f3; float: right; /* 尝试改为 left 看看 */ } /* --- 经典 Clearfix Hack (必背) --- */ /* 向容器末尾添加一个看不见的“墙”来撑开高度 */ .clearfix::after { content: ""; display: block; clear: both; }

2. 定位 (Position)

定位属性允许你从正常的文档流中“抽出”元素，并将其精准地放置在页面的任意位置。

2.1 四大金刚

  • static (默认值)：按照正常文档流排列。
  • relative (相对定位)：相对于原本在文档流中的位置进行微调。不脱离文档流（原来的位置坑位还在）。
  • absolute (绝对定位)：相对于最近的“非 static”祖先元素进行定位。脱离文档流。
  • fixed (固定定位)：相对于浏览器窗口定位。滚动页面时它不会动。

2.2 黄金搭档：子绝父相

即“子元素绝对定位，父元素相对定位”。这是实现 UI 组件（如角标、关闭按钮、下拉菜单）最常用的技巧。

3. Flexbox 弹性盒布局 (必学!)

💡 为什么叫弹性盒？
因为它非常灵活。子元素可以自动放大填充剩余空间，也可以自动缩小适应小屏幕。它是“一维布局”（处理一行或一列）的神器。

3.1 开启 Flex

只需给父容器添加 display: flex;，其直接子元素就会变成 flex item，默认横向排列。

3.2 对齐三剑客

  • justify-content: 主轴（通常是水平方向）对齐。常用值：center (居中), space-between (两端对齐), space-around (分散对齐)。
  • align-items: 交叉轴（通常是垂直方向）对齐。常用值：center (垂直居中), stretch (拉伸)。
  • flex-direction: 改变主轴方向。常用值：row (默认，横向), column (纵向)。
实验 03：Flexbox 完美居中与分布 未运行
HTML (只读)
<!-- 模拟一个导航栏 --> <div class="navbar"> <div class="logo">LOGO</div> <div class="menu"> <span>首页</span> <span>产品</span> <span>关于</span> </div> <div class="user">登录</div> </div>
CSS (可编辑)
.navbar { height: 60px; background: #333; color: white; padding: 0 20px; /* 1. 开启弹性布局 */ display: flex; /* 2. 垂直居中 (交叉轴) */ align-items: center; /* 3. 水平两端对齐 (主轴) */ /* 尝试改为 center, flex-start, space-around */ justify-content: space-between; } .menu span { margin: 0 10px; cursor: pointer; color: #ccc; } .logo { font-weight: bold; font-size: 1.2em; } .user { background: #0066cc; padding: 5px 15px; border-radius: 4px; }

4. Grid 网格布局

如果说 Flexbox 是一维的（一条线），那么 Grid 就是二维的（面）。它能同时处理行和列，非常适合页面整体骨架的搭建。

4.1 核心属性

  • display: grid;: 开启网格布局。
  • grid-template-columns: 定义列宽。例如 100px 1fr 100px 表示左侧100px，中间自适应剩余空间(1fr)，右侧100px。
  • grid-gap (或 gap): 定义网格之间的间距。
实验 04：经典网页骨架布局 未运行
HTML (只读)
<div class="grid-container"> <div class="header">Header</div> <div class="sidebar">Sidebar</div> <div class="main">Main Content</div> <div class="footer">Footer</div> </div>
CSS (可编辑)
.grid-container { display: grid; height: 300px; gap: 10px; /* 间隙 */ /* 定义两列：侧边栏25%，内容区自适应(1fr) */ grid-template-columns: 1fr 3fr; /* 定义三行：头、中间、底 */ grid-template-rows: 50px 1fr 40px; /* 定义区域名称 (高级技巧) */ grid-template-areas: "header header" "sidebar main" "footer footer"; } .header { grid-area: header; background: #ff7675; } .sidebar { grid-area: sidebar; background: #74b9ff; } .main { grid-area: main; background: #55efc4; } .footer { grid-area: footer; background: #dfe6e9; } /* 基础样式 */ .grid-container > div { display: flex; justify-content: center; align-items: center; color: #fff; font-weight: bold; }

5. 响应式设计 (Responsive Design)

现在的网站必须能适应手机、平板和电脑。我们使用“媒体查询” (Media Query) 来实现这一点。

5.1 媒体查询 @media

语法结构：@media (条件) { CSS规则 }。例如：@media (max-width: 600px) { ... } 表示当屏幕宽度小于等于600px时，执行大括号里的CSS。

5.2 常用技巧

  • 相对单位：尽量少用 px 定死宽度，多用 %、vw (视口宽度)、rem。
  • 图片自适应：img { max-width: 100%; height: auto; }。
  • 布局转换：在手机端将 Flexbox/Grid 的方向改为单列。
实验 05：响应式卡片 (请调整浏览器宽度测试) 未运行
HTML (只读)
<div class="responsive-box"> <p>我是响应式盒子</p> <p class="info">当前：电脑模式</p> </div>
CSS (可编辑)
.responsive-box { background: #6c5ce7; color: white; padding: 40px; font-size: 20px; text-align: center; transition: all 0.5s; border-radius: 8px; } /* --- 媒体查询核心 --- */ /* 当宽度小于 600px 时 (模拟手机) */ @media (max-width: 600px) { .responsive-box { background: #e17055; /* 变红 */ font-size: 14px; /* 字体变小 */ } .responsive-box .info::after { content: " (手机模式)"; display: block; font-weight: bold; } }
