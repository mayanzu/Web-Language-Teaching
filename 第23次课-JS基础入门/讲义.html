一、网页是什么？

当你用浏览器打开一个网页时，你看到的页面其实是由一组文件组成的。这些文件通过网络从远程服务器下载到你的电脑上，然后由浏览器解析和渲染，最终呈现出你看到的效果。

类比理解

把网页想象成一份报纸：

  • HTML = 文章的文字和图片（内容和结构）
  • CSS = 排版和美化（字体、颜色、布局）
  • JavaScript = 让报纸变成「互动杂志」（点击、动画、实时更新）

1.1 浏览器与服务器

要理解 JavaScript 的作用，先要了解网页是如何工作的。

角色 说明 类比
服务器 存放网页文件的远程电脑，24小时运行，等待用户请求 图书馆的书库
浏览器 用户电脑上的软件（Chrome、Firefox 等），负责请求和显示网页 图书馆的借阅窗口
HTTP 请求 浏览器向服务器发送的「请求信」，要求获取某个页面 借书申请单
HTTP 响应 服务器返回的「回复」，包含网页文件 图书馆把书递给你
网页加载流程：
  1. 你在浏览器地址栏输入网址，按回车
  2. 浏览器向服务器发送 HTTP 请求
  3. 服务器找到对应的 HTML 文件，返回给浏览器
  4. 浏览器解析 HTML，发现里面引用了 CSS 和 JS 文件
  5. 浏览器再次向服务器请求这些 CSS 和 JS 文件
  6. 所有文件下载完成后，浏览器渲染页面，执行 JS 代码

1.2 HTML、CSS、JavaScript 的分工

一个网页由三种核心技术组成，它们各司其职：

技术 职责 比喻 示例
HTML 定义网页的结构和内容，告诉浏览器「有什么」 房子的骨架和砖墙 标题、段落、图片、按钮
CSS 定义网页的外观和样式，告诉浏览器「长什么样」 房子的装修和粉刷 颜色、字体、间距、布局
JavaScript 定义网页的行为和交互，告诉浏览器「能做什么」 房子里的电器和智能系统 点击响应、表单验证、动画
它们必须一起用吗？
  • 只有 HTML：能显示页面，但是非常简陋，像纯文字的文档
  • HTML + CSS：页面好看了，但没有交互，用户只能看，不能「用」
  • HTML + CSS + JS：完整的现代网页，既好看又能交互

二、JavaScript 到底能做什么？

从功能上看，JavaScript 让网页从「静态的说明书」变成「可以互动的应用」。你每天访问的网站，几乎所有的交互功能都离不开 JavaScript。

有 JS 和没有 JS 的网页差别有多大？

场景没有 JS有 JS
表单提交 用户填错只能提交后才知道 输入时就能即时提示错误，阻止错误提交
导航菜单 只能跳转页面 可以展开/折叠菜单、下拉动画、返回顶部
数据展示 只能看到固定内容 可以按条件筛选、排序、分页显示
购物车 每次加减商品都要刷新整个页面 点击加减，数量和总价立即更新，无需刷新
地图导航 只能显示静态图片 可以拖拽、缩放、搜索地点、规划路线

2.1 JavaScript 在真实网站中的应用

让我们看看你熟悉的网站都用 JavaScript 做了什么：

案例 1：社交媒体（微博、微信朋友圈） Real World

JavaScript 实现的功能：

  • 无限滚动加载：你往下刷，新内容自动加载出来，不用点"下一页"
  • 点赞动画：点赞时爱心变红、数字+1，还有小动画效果
  • 实时评论：发表评论后立即显示在页面上，不用刷新
  • 图片预览：点击图片弹出大图浏览器，可以左右切换

如果没有 JavaScript，你每次点赞都要刷新整个页面，体验会非常糟糕。

案例 2：电商网站（淘宝、京东） Real World

JavaScript 实现的功能：

  • 商品筛选：勾选"仅显示有货"、"价格区间"，商品列表立即更新
  • 图片放大镜：鼠标移到商品图上，旁边显示放大的细节图
  • 购物车计算：加减商品数量，总价自动重新计算
  • 倒计时：限时抢购的倒计时，每秒自动更新

想象一下，如果每次改数量都要刷新页面，你还会愿意网购吗？

案例 3：视频网站（Bilibili、YouTube） Real World

JavaScript 实现的功能：

  • 视频播放器：播放、暂停、进度条拖拽、音量调节
  • 弹幕系统：实时显示和发送弹幕，可以调整弹幕速度和透明度
  • 自动播放下一集：当前视频结束后，倒计时自动播放下一集
  • 进度记忆：记录你看到第几分钟，下次打开自动跳转到上次位置

没有 JavaScript，你连播放/暂停按钮都点不了。

2.2 JavaScript 的五大核心能力

归纳一下，JavaScript 在网页中主要负责以下五类工作：

能力具体作用日常例子
1. 响应用户操作 监听用户的点击、输入、滚动、拖拽等动作，并作出反应 点击按钮弹出菜单、表单验证
2. 修改页面内容 动态改变网页上的文字、图片、样式，无需刷新整个页面 点赞数+1、切换标签页内容
3. 与服务器通信 向服务器发送请求获取数据，或提交用户输入的信息 搜索建议、加载更多评论
4. 数据处理和计算 对用户输入或服务器返回的数据进行计算、筛选、排序 购物车总价计算、商品筛选
5. 本地存储数据 在用户浏览器中保存信息，下次访问时还能读取 记住登录状态、主题偏好设置
JavaScript 的更多应用场景

现代 JavaScript 的应用范围已经远超网页，它几乎无处不在：

  • 服务器开发：用 Node.js 可以开发后端服务器
  • 移动应用：用 React Native 可以开发 iOS 和 Android App
  • 桌面软件：用 Electron 可以开发跨平台桌面应用（如 VS Code）
  • 小程序开发：微信小程序、支付宝小程序都是用 JavaScript 写的

3.2 script 标签应该放在哪里？

这是初学者最容易困惑的问题：<script> 标签应该放在哪里？

放置位置优点缺点推荐
放在 <head> 中 代码组织清晰 会阻塞页面加载
JS 可能找不到 body 中的元素		 ❌ 不推荐
放在 <body> 底部 页面内容先加载
能找到所有 HTML 元素		 大型项目文件较多时管理稍复杂 ✅ 强烈推荐
放在 <head> 中加 defer 兼具清晰性和性能
异步下载，不阻塞渲染		 需要理解 defer 的工作原理 ✅ 现代最佳实践
记住原则：

如果 JS 需要操作页面元素，要么放在元素后面，要么使用 defer。

// ❌ 错误：这时 #demo 还不存在
<head>
  <script>
    document.getElementById('demo').textContent = 'Hello';
  </script>
</head>

// ✅ 正确：此时 #demo 已经存在
<body>
  <div id="demo">原始内容</div>
  <script>
    document.getElementById('demo').textContent = 'Hello';
  </script>
</body>

实验 02：用 JavaScript 修改网页内容

真正的网页程序不只是弹窗，更重要的是能直接修改页面上的内容。这个实验会教你如何找到页面元素并修改它。

实验 02：修改页面文字 动手实践
HTML 结构
<!-- 页面上有这些元素 --> <h2 id="demo-title">原始标题</h2> <p id="demo-text">这是原始文字</p> <!-- JS 会修改这些元素的内容 -->
JavaScript (可编辑)
// 第 1 步：通过 id 找到页面上的元素 const titleElement = document.getElementById('demo-title'); const textElement = document.getElementById('demo-text'); // 第 2 步：修改元素的文字内容 // TODO：把下面这行的文字改成你想要的内容 if (titleElement) { titleElement.textContent = '我的第一个 JS 实验成功了！'; titleElement.style.color = '#4285f4'; } if (textElement) { textElement.textContent = 'JavaScript 真的可以修改页面！'; textElement.style.fontSize = '18px'; }

原始标题

这是原始文字，运行代码后会被修改

代码解释
  • document.getElementById('demo-title') 的意思是：在整个网页（document）里，找到 id 为 'demo-title' 的元素
  • element.textContent = '...' 的意思是：把这个元素的文字内容改成引号里的内容
  • element.style.color = '...' 可以修改元素的样式

实验 03：给按钮添加点击事件

这个实验会教你如何让按钮「可以点击」，并在点击时执行你想要的代码。

实验 03：点击按钮改变内容 动手实践
HTML 结构
<!-- 页面上有这些元素 --> <p id="click-text">点击按钮试试！</p> <button id="my-btn">点我变色</button> <!-- JS 会给按钮添加点击事件 -->
JavaScript (可编辑)
// 第 1 步：找到按钮和文字元素 const btn = document.getElementById('my-btn'); const text = document.getElementById('click-text'); // 第 2 步：给按钮添加「点击」事件监听器 if (btn && text) { btn.addEventListener('click', function() { // 点击时执行的代码 text.textContent = '🎉 你点击了按钮！'; text.style.color = 'red'; text.style.fontSize = '24px'; // 弹出提示 alert('恭喜你触发了点击事件！'); }); }

点击按钮试试！

代码解释
  • addEventListener('click', function() {...}) 的意思是：给元素添加一个事件监听器，监听「点击」事件
  • function() {...} 是一个函数，里面的代码会在按钮被点击时执行
  • 你可以在函数里写任何代码，不只是 alert()，也可以修改页面内容、改变颜色等等
重要提示：

先点击「绑定点击事件」运行代码，然后再点击预览区的「点我变色」按钮，才能看到效果！

综合实验：计数器

这是一个综合运用本课所学知识的实验：创建一个简单的计数器，点击按钮可以增加或减少数字。

综合实验：计数器 综合实战
HTML 结构
<h3>计数器演示</h3> <p id="counter-display">当前计数: 0</p> <button onclick="increment()">+1</button> <button onclick="decrement()">-1</button> <button onclick="resetCounter()">重置</button>
JavaScript (可编辑)
// 定义一个变量存储计数 let count = 0; // 获取显示元素 const display = document.getElementById('counter-display'); // 增加计数的函数 function increment() { count++; display.textContent = '当前计数: ' + count; display.style.color = count > 0 ? 'green' : (count < 0 ? 'red' : 'black'); } // 减少计数的函数 function decrement() { count--; display.textContent = '当前计数: ' + count; display.style.color = count > 0 ? 'green' : (count < 0 ? 'red' : 'black'); } // 重置计数的函数 function resetCounter() { count = 0; display.textContent = '当前计数: ' + count; display.style.color = 'black'; }

计数器演示

当前计数: 0

知识点回顾：
  • let count = 0 - 声明一个变量存储数据
  • count++ - 让变量的值加 1
  • count-- - 让变量的值减 1
  • function 函数名() {...} - 定义一个可重复调用的函数
  • onclick="函数名()" - 点击时调用指定函数

四、本课小结

知识点回顾

  • 网页组成：网页本质上是一组文件，HTML 负责结构，CSS 负责样式，JavaScript 负责行为
  • 浏览器与服务器：浏览器会先请求 HTML，再根据 HTML 中的引用去加载 CSS 和 JS
  • JS 的作用：让网页从静态变成可交互，实现响应操作、修改内容、通信、计算、存储
  • 引入 JS 的方式：页面内脚本、浏览器控制台、外部 JS 文件
  • script 位置：推荐放在 body 底部，确保能找到页面元素
  • 基础操作：使用 alert() 弹窗、getElementById() 获取元素、修改 textContent 和 style
  • 事件监听：使用 addEventListener() 给元素添加交互行为
