练习1：多彩按钮组 - 答案

/* 练习1：多彩按钮组 */ .btn-primary, .btn-success, .btn-warning { padding: 10px 20px; border-radius: 6px; border: none; cursor: pointer; margin-right: 10px; font-size: 14px; transition: opacity 0.3s; } .btn-primary { background-color: #0066cc; color: white; } .btn-success { background-color: #28a745; color: white; } .btn-warning { background-color: #ffc107; color: black; } .btn-primary:hover, .btn-success:hover, .btn-warning:hover { opacity: 0.8; }
关键知识点：
  • 使用十六进制颜色值定义背景色
  • opacity 属性控制元素透明度（0-1）
  • transition 添加平滑过渡效果
  • 群组选择器可减少代码重复

  • 常用于边框、阴影、SVG 图标等需要与文字颜色保持一致的场景

练习3：渐变色卡片 - 答案

通知标题

这是一条使用 HSL 颜色模式创建的信息卡片，所有颜色使用相同的色相（200），通过调整饱和度和亮度实现配色和谐。

/* 练习3：渐变色卡片 */ .info-card { width: 300px; padding: 20px; background-color: hsl(200, 100%, 95%); /* 浅蓝背景 */ border: 2px solid hsl(200, 100%, 70%); /* 中蓝边框 */ border-radius: 8px; } .card-title { color: hsl(200, 100%, 30%); /* 深蓝标题 */ font-size: 18px; margin-bottom: 10px; } .card-content { color: hsl(200, 20%, 40%); /* 灰蓝内容 */ font-size: 14px; line-height: 1.6; }
关键知识点：
  • HSL 格式：hsl(色相, 饱和度%, 亮度%)
  • 色相（H）：0-360，代表色轮上的角度（0=红，120=绿，240=蓝）
  • 饱和度（S）：0%-100%，0% 是灰色，100% 是纯色
  • 亮度（L）：0%-100%，0% 是黑色，50% 是正常，100% 是白色
  • 优势：保持色相一致，只调整 S 和 L，可轻松创建和谐配色

/* 练习4：响应式字体大小 */ .main-title { font-size: 2.5rem; /* 40px (假设 html font-size 为 16px) */ font-weight: 700; font-family: sans-serif; margin-bottom: 15px; } .sub-title { font-size: 1.5rem; /* 24px */ font-weight: 600; font-family: sans-serif; margin-bottom: 12px; } .body-text { font-size: 1rem; /* 16px */ line-height: 1.6; font-family: sans-serif; margin-bottom: 10px; } .small-text { font-size: 0.875rem; /* 14px */ color: #666; font-family: sans-serif; }
关键知识点：
  • rem 单位相对于根元素（html）的字体大小
  • 默认情况下，浏览器根元素字体大小为 16px
  • 使用 rem 的优势：用户可以通过浏览器设置调整字体大小，页面会自动缩放
  • 推荐使用 rem 设置字体大小，px 设置边框等固定尺寸

练习5：文章排版 - 答案

中文排版之美

中文排版是一门艺术，需要注意字体大小、行高、首行缩进等多个方面。良好的排版能够提升阅读体验，让读者更加专注于内容本身。

在网页设计中，我们通常使用 CSS 来控制文字的样式。通过合理运用各种属性，可以创造出既美观又易读的页面效果。

/* 练习5：文章排版 */ .article { width: 600px; margin: 0 auto; /* 居中显示 */ color: #333; } .article-title { text-align: center; font-size: 24px; font-weight: bold; padding-bottom: 10px; border-bottom: 2px solid #0066cc; margin-bottom: 20px; } .paragraph { text-align: justify; /* 两端对齐 */ text-indent: 2em; /* 首行缩进 */ line-height: 1.8; margin-bottom: 15px; }
关键知识点：
  • text-align: justify 实现两端对齐，文本更加整齐
  • text-indent: 2em 是中文段落的标准首行缩进
  • 行高（line-height）建议设置为 1.5-1.8，提升可读性
  • margin: 0 auto 配合固定宽度实现水平居中

练习7：单行文本溢出 - 答案

这是一条非常长的新闻标题，它会被截断并在末尾显示省略号
/* 练习7：单行文本溢出 */ .news-title { width: 250px; padding: 10px; background-color: #f8f9fa; border-radius: 4px; /* 单行溢出省略三件套 */ white-space: nowrap; /* 强制不换行 */ overflow: hidden; /* 隐藏溢出内容 */ text-overflow: ellipsis; /* 显示省略号 */ }
关键知识点：
  • 单行文本溢出省略必须同时使用三个属性
  • white-space: nowrap 防止文本换行
  • overflow: hidden 隐藏超出容器的部分
  • text-overflow: ellipsis 用省略号表示被截断的内容
  • 容器必须有明确的宽度

练习8：多行文本溢出 - 答案

这是一段新闻摘要内容，包含了较多的文字信息。在实际应用中，我们经常需要限制摘要的显示行数，超出部分用省略号表示。这样可以保持页面布局的整洁，同时给用户提供足够的信息预览。用户如果想查看完整内容，可以点击进入详情页面。
/* 练习8：多行文本溢出 */ .news-summary { width: 300px; padding: 15px; background-color: #fff; border: 1px solid #ddd; line-height: 1.5; /* 多行溢出省略（Webkit 方案）*/ display: -webkit-box; -webkit-line-clamp: 3; /* 显示3行 */ -webkit-box-orient: vertical; overflow: hidden; }
关键知识点：
  • 多行文本溢出目前主要使用 Webkit 私有属性
  • -webkit-line-clamp 指定显示的行数
  • 必须配合 display: -webkit-box 和 -webkit-box-orient: vertical
  • 兼容性：Chrome、Safari、Edge 等现代浏览器支持良好
  • Firefox 在较新版本中也开始支持这些属性
