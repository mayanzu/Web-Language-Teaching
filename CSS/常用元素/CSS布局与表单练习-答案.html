📝 练习 1：长度单位实验 Units

任务说明

通过调整根字号、比较 px / rem / vw / vh，体会响应式排版的差异。

📋 要求：
  • 将 html 根字号改为 18px，再让 .unit-card.rem 使用 1.5rem 字号
  • .unit-card.px 保持 24px 字号，用于对比
  • .unit-card.vw 的 padding 使用 vw/vh 组合，确保在不同宽度下有弹性间距
  • 统一将卡片标题加粗，说明文字颜色设为 #6B7280

PX 固定

始终 24px，不随用户设置变化。

REM 自适应

随根字号成比例缩放。

视口单位

适合 hero banner、首屏模块。

💡 提示：记得为 .unit-card 统一设定过渡效果，观察在调试器中修改根字号的反应。
