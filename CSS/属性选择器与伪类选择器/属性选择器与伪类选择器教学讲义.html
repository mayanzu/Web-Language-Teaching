CSS 选择器实验室

观察 HTML 结构，编写并运行 CSS，见证样式从无到有的过程。

🎯 开始之前：你需要知道的基础概念

1️⃣ 什么是 CSS 选择器？

想象你在一个教室里，老师说："穿红色衣服的同学，请站起来。"
这里的"穿红色衣服"就是一个选择条件，CSS 选择器的作用就是这样——
帮你在网页中找到符合条件的元素，然后给它们添加样式。

2️⃣ 什么是属性（Attribute）？

在 HTML 中，属性就像是给元素贴的"标签"，用来描述它的特征。
比如：<button disabled> 这里的 disabled 就是一个属性，表示"这个按钮被禁用了"。

<input type="text" placeholder="请输入用户名">
↑ 这里有两个属性：type 和 placeholder

3️⃣ 什么是伪类（Pseudo-class）？

伪类是一种特殊的选择器，它会根据元素的状态或位置来选择。
比如：:hover 表示"鼠标悬停时"，:first-child 表示"第一个孩子"。
重点：伪类前面有一个冒号 :

4️⃣ 如何使用这个实验室？

  • 📖 左侧：HTML 代码（只读，不能修改）
  • ✏️ 右侧：CSS 代码（可以编辑，你可以修改试试）
  • ▶️ 点击"运行代码"：查看样式效果
  • ↺ 点击"重置"：恢复到初始状态

1. 基础属性选择器

📌 1.1 HTML 属性是什么？

HTML 元素可以有很多属性，就像人有姓名、年龄、性别一样。
比如一个按钮： 

<button disabled>我被禁用了</button>
<input type="password" placeholder="请输入密码">

✅ disabled、type、placeholder 都是属性
✅ 属性可以有值（如 type="password"），也可以没有值（如 disabled）

📌 1.2 存在匹配：[属性名]

语法：[disabled]
含义：选择所有带有 disabled 属性的元素，不管它的值是什么。
应用场景：让所有禁用的按钮变成灰色，提示用户"这个按钮不能点"。

💡 记忆技巧：只要这个元素"有"这个属性，不管值是啥，都会被选中。

📌 1.3 精确匹配：[属性="值"]

语法：input[type="password"]
含义：选择type 属性等于 "password" 的 input 元素。
应用场景：给密码输入框加上特殊的红色边框，提醒用户"这是敏感信息"。

⚠️ 注意：等号两边不能有空格，type="password" ✅，type = "password" ❌

👇 动手实践：点击"运行代码"，观察按钮和输入框的变化。然后试着修改颜色值！

实验 01：精确匹配与存在匹配 当前状态：无样式 (Raw)
HTML (只读)
<!-- 1. 普通按钮 --> <button>普通按钮</button> <!-- 2. 禁用按钮 (有 disabled 属性) --> <button disabled>我被禁用了</button> <br><br> <!-- 3. 文本框 (type="text") --> <input type="text" value="普通文本"> <!-- 4. 密码框 (type="password") --> <input type="password" value="123456">
CSS (可编辑)
/* --- 实验目标 --- */ /* 1. 让禁用的按钮变成灰色，鼠标变成禁止符号 */ /* 2. 给密码输入框加上红色边框，以示区分 */ /* [属性名] 选择所有带有 disabled 属性的元素 */ [disabled] { background-color: #f5f5f5; /* 浅灰背景 */ color: #aaaaaa; /* 灰色文字 */ border: 1px dashed #ccc; /* 虚线边框 */ cursor: not-allowed; /* 禁止鼠标 */ } /* [属性名="值"] 精确选择 type 等于 password 的元素 */ input[type="password"] { border: 2px solid #FF3B30; /* 红色边框 */ background-color: #FFF0F0; /* 浅红背景 */ color: red; }

2. 字符串匹配选择器

🤔 为什么需要字符串匹配？

有时候属性值很长，比如网址 https://www.example.com/page.html。
如果每次都要写完整的值，太麻烦了！
CSS 提供了模糊匹配的方法，只需要匹配开头、结尾或中间的一部分就行。

📌 2.1 开头匹配：[属性^="开头"]

符号：^= (键盘 Shift+6，像一个"箭头向上")
含义：选择属性值以某个字符串开头的元素
例子：a[href^="https"] → 选择所有以 https 开头的链接

✅ 实际应用：把所有 HTTPS 安全链接显示成绿色，提示用户"这是安全网站"

📌 2.2 结尾匹配：[属性$="结尾"]

符号：$= (美元符号，像"结束"的意思)
含义：选择属性值以某个字符串结尾的元素
例子：a[href$=".pdf"] → 选择所有指向 PDF 文件的链接

✅ 实际应用：给 PDF 链接加上橙色和"[PDF文档]"标签，方便用户识别

📌 2.3 包含匹配：[属性*="包含"]

符号：*= (星号，代表"任意位置")
含义：选择属性值包含某个字符串的元素（不管在开头、中间还是结尾）
例子：img[src*="logo"] → 选择所有图片路径中包含 "logo" 的图片

✅ 实际应用：找出所有 logo 图片，统一设置宽度
选择器 含义 记忆技巧
^= 以...开头 箭头向上 ↑ = 从头开始
$= 以...结尾 $ = 结束符号
*= 包含... * = 通配符，任意位置

<div class="link-list"> <!-- 安全链接 (https开头) --> <a href="https://bank.com">安全支付</a> <br> <!-- 普通链接 (http开头) --> <a href="http://game.com">网页游戏</a> <br> <!-- PDF文件 (pdf结尾) --> <a href="report.pdf">下载报告</a> </div>

3. 交互状态伪类

🎭 3.0 什么是"伪类"？

伪类（Pseudo-class）就像是元素的"状态标签"。
比如：一个按钮有很多状态——

  • 🖱️ 正常状态：鼠标没碰它
  • ✨ 悬停状态：鼠标移上去了（hover）
  • 👆 激活状态：正在被点击（active）
  • 🔍 焦点状态：被选中了（focus）

重点：伪类前面有一个冒号 :，比如 :hover、:focus

💡 为什么叫"伪"类？
因为它不是真正的 class 属性，而是浏览器根据用户操作自动添加的"虚拟类"。

📌 3.1 悬停状态：:hover

语法：button:hover { }
触发条件：当鼠标移动到元素上方时
应用场景：按钮变色、链接下划线、图片放大等

✅ 最常用场景：给按钮添加悬停效果，提升用户体验

📌 3.2 焦点状态：:focus

语法：input:focus { }
触发条件：当元素被点击或通过 Tab 键选中时
应用场景：输入框高亮、文本框边框变色

✅ 用户体验：让用户知道"我现在正在操作这个输入框"

📌 3.3 激活状态：:active

语法：button:active { }
触发条件：当元素正在被点击（鼠标按下但还没松开）
应用场景：按钮按下效果、链接点击反馈

⚠️ 持续时间：只在鼠标按下的瞬间出现，很短暂！
📝 三者对比：
:hover → 鼠标悬停（移上去）
:focus → 元素被选中（可以输入）
:active → 正在点击（按下瞬间）

👇 动手实验：运行代码后，用鼠标悬停按钮、点击输入框，观察变化！

实验 03：悬停与焦点 当前状态：无样式 (Raw)
HTML (只读)
<!-- 一个普通的按钮 --> <button class="magic-btn"> 鼠标悬停我 </button> <br><br> <!-- 一个普通的输入框 --> <input class="magic-input" placeholder="点击输入...">
CSS (可编辑)
/* --- 按钮的基础样式 --- */ .magic-btn { padding: 10px 20px; background: #fff; border: 1px solid #ccc; transition: 0.3s; /* 让变化有动画过程 */ } /* 1. :hover (鼠标悬停) */ /* 当鼠标移上去时，变蓝并放大 */ .magic-btn:hover { background-color: #0066CC; color: white; transform: scale(1.1); border-color: #0066CC; } /* 2. :focus (获得焦点) */ /* 当输入框被点击激活时 */ .magic-input:focus { outline: none; border: 2px solid #0066CC; background-color: #E8F2FF; }

4. LVHA 链接伪类

🔗 4.1 什么是 LVHA？

LVHA 是四个链接状态伪类的首字母缩写，专门用来控制超链接（<a>标签）在不同状态下的样式：

L :link → 未访问过的链接（Link）
V :visited → 已访问过的链接（Visited）
H :hover → 鼠标悬停的链接（Hover）
A :active → 正在点击的链接（Active）
💡 记忆口诀："Love Hate" 或 "LoVe Hates All"（爱恨情仇）

📌 4.2 顺序为什么重要？

CSS 有一个规则：后写的样式会覆盖先写的样式（如果优先级相同）。
如果顺序写错，某些状态就会失效！

❌ 错误示例（顺序混乱）： 
a:hover { color: blue; }
a:link { color: green; }  ← 写在后面，会覆盖 hover！

结果：hover 效果失效 ❌
✅ 正确顺序（LVHA）： 
a:link    { }  ← 1️⃣ 先写 link
a:visited { }  ← 2️⃣ 再写 visited
a:hover   { }  ← 3️⃣ 然后 hover
a:active  { }  ← 4️⃣ 最后 active
💡 为什么这样排列？
因为一个链接可能同时处于多个状态（比如"已访问 + 正在悬停"），
按 LVHA 顺序，最具体的状态（active）会显示在最上层。

📌 4.3 实际应用场景

  • :link → 设置默认的链接颜色（通常是蓝色）
  • :visited → 已访问的链接变紫色，帮助用户记住"我看过这个页面"
  • :hover → 鼠标悬停时加下划线或变色，提示"这是可点击的"
  • :active → 点击瞬间变色，给用户"按下按钮"的反馈

👇 实验任务：运行代码，点击链接并观察颜色变化。然后回到页面再次悬停，看看已访问链接的样式！

实验 3.5：LVHA 链接状态 当前状态：无样式 (Raw)

5. 结构位置伪类

🏗️ 什么是"结构位置"？

想象一个家庭有 5 个孩子，我们想让老大穿红衣服、老幺穿蓝衣服、老二老四穿黄衣服（偶数）。
这就是结构位置选择器的作用——根据元素的排列顺序来选择。

<ul>
  <li>第1个孩子</li> ← :first-child
  <li>第2个孩子</li> ← :nth-child(2)
  <li>第3个孩子</li>
  <li>第4个孩子</li>
  <li>第5个孩子</li> ← :last-child
</ul>

📌 4.1 第一个和最后一个

:first-child → 选择第一个孩子
:last-child → 选择最后一个孩子

✅ 常见用法：
  • 让列表第一项加粗显示
  • 去掉最后一个元素的底边框（避免多余的线）

📌 4.2 选择第 N 个：:nth-child(N)

语法：li:nth-child(3) → 选择第 3 个 li
N 可以是：

  • :nth-child(1) → 第 1 个
  • :nth-child(3) → 第 3 个
  • :nth-child(2n) → 所有偶数（2, 4, 6...）
  • :nth-child(2n+1) → 所有奇数（1, 3, 5...）
💡 公式解释：2n 表示"2的倍数"，2n+1 表示"2的倍数加1"

📌 4.3 快捷方式：奇数偶数

CSS 提供了两个快捷关键字，不用写复杂的公式：

写法 等价于 含义
:nth-child(odd) :nth-child(2n+1) 奇数行（1, 3, 5...）
:nth-child(even) :nth-child(2n) 偶数行（2, 4, 6...）
✅ 经典应用："斑马纹表格" —— 偶数行灰色背景，方便阅读

👇 观察实验：运行代码，看看第一个、最后一个和偶数行的样式变化！

6. 排除逻辑伪类 :not()

🚫 什么是"排除逻辑"？

有时候我们想："选择所有按钮，但是不包括主按钮"。
如果一个个写 class 会很麻烦，这时候就用 :not()。

举例说明： 
教室里有 10 个学生，老师说：
"除了班长之外，所有人都去操场集合！"

这就是 :not() 的逻辑 → 排除某一个，选择其他所有人。

📌 5.1 :not() 的用法

语法：元素:not(排除条件)
例子：

  • button:not(.primary) → 选择所有按钮，但排除 class="primary" 的
  • li:not(:first-child) → 选择所有 li，但排除第一个
  • input:not([type="submit"]) → 选择所有 input，但排除提交按钮
✅ 实际场景：

网页有 4 个按钮："取消"、"保存"、"删除"、"确认"。
我们想让前 3 个普通按钮都是白底灰字，只有"确认"按钮是蓝底白字。
用 :not() 可以一次性设置好 3 个普通按钮，不用一个个写！

💡 记忆技巧：:not() = "不是...的" = "除了...之外"
⚠️ 注意：括号里只能写简单选择器，不能写太复杂的组合（比如后代选择器）
📝 对比学习：
传统写法（麻烦） 使用 :not()（简洁）
.btn-cancel { }
.btn-save { }
.btn-delete { }
需要给 3 个按钮分别写 class 		button:not(.primary) { }
一行搞定！

👇 实验任务：运行代码，观察普通按钮和主按钮的区别。然后试着在 CSS 里把颜色改成其他的！

7. 伪元素选择器

✨ 7.0 什么是"伪元素"？

伪元素（Pseudo-element）可以让你在 HTML 中不存在的地方创建元素。
就像"魔法"一样，用 CSS 就能凭空变出新内容！

🤔 伪类 vs 伪元素的区别：
伪类 选择已有元素的某种状态 一个冒号 :hover
伪元素 创建新元素（虚拟的） 两个冒号 ::before
💡 注意：CSS3 规定伪元素用两个冒号 ::，但为了兼容性，一个冒号 : 也能用。

📌 7.1 ::before 和 ::after（最常用）

::before → 在元素内容前面插入内容
::after → 在元素内容后面插入内容

<p>Hello</p>
↓ 应用伪元素后
[before内容] Hello [after内容]
✅ 实际应用：
  • 给链接自动加图标（如箭头、外链标志）
  • 制作引号、标签、徽章
  • 添加装饰性元素（不占用 HTML 结构）
⚠️ 重要：必须有 content 属性，否则伪元素不会显示！
即使不想显示内容，也要写 content: "";

📌 7.2 ::first-letter（首字母）

语法：p::first-letter { }
作用：选择元素的第一个字母，常用于制作首字下沉效果（杂志风格）

✅ 经典应用：新闻文章、小说的首字母放大并变色

📌 7.3 ::first-line（首行）

语法：p::first-line { }
作用：选择元素的第一行文本，无论第一行有多长

✅ 应用场景：让段落的第一行字体稍大或变色，突出重点

📚 课程总结

🎯 今天学到了什么？

1️⃣ 属性选择器
[disabled] 有这个属性的
[type="text"] 属性值相等的
2️⃣ 字符串匹配
^= 开头匹配
$= 结尾匹配
*= 包含匹配
3️⃣ 交互伪类
:hover 鼠标悬停
:focus 获得焦点
:active 正在点击
4️⃣ LVHA 链接伪类
:link 未访问
:visited 已访问
顺序：LVHA
5️⃣ 结构伪类
:first-child 第一个
:last-child 最后一个
:nth-child() 第N个
6️⃣ 排除与伪元素
:not() 排除选择
::before 前插入
::after 后插入

💡 快速记忆口诀

📌 [属性] 有就选，[属性="值"] 要相等
📌 ^ 是开头，$ 是结尾，* 是包含
📌 :hover 悬浮变，:focus 焦点亮，:active 点击闪
📌 LVHA 爱恨情仇，链接顺序不能错
📌 :first 是老大，:last 是老幺，:nth 选第几
📌 :not() 是排除，反向选择更轻松
📌 ::before 在前插，::after 在后加，content 不能忘
