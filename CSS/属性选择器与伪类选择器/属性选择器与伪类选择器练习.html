📝 练习 1: LVHA 链接伪类 重点

任务说明

按照 LVHA 顺序为导航链接添加完整的状态样式：

📋 要求（必须按 LVHA 顺序编写）：
  • :link - 未访问的链接设为蓝色 #0066CC
  • :visited - 已访问的链接设为紫色 #6B46C1
  • :hover - 鼠标悬停时设为红色 #FF3B30，添加下划线
  • :active - 点击时设为深红色 #D73A49，字体加粗

📝 练习 2: 结构位置伪类（奇偶行）重点

任务说明

使用结构伪类为表格添加斑马纹效果和位置样式：

📋 要求：
  • 使用 :nth-child(odd) 给奇数行（1、3、5）设置背景色 #F9F9F9
  • 使用 :nth-child(even) 给偶数行（2、4）设置背景色 #E8F4FD
  • 使用 :first-child 给第一行添加左边框 4px solid green
  • 使用 :last-child 给最后一行添加左边框 4px solid red

📝 练习 4: 伪元素选择器 重点

任务说明

使用伪元素为内容添加装饰效果：

📋 要求：
  • 使用 ::before 在每个标题前添加 "📌 " 符号（content: "📌 ";）
  • 使用 ::after 在每个链接后添加 " →" 符号，颜色设为灰色
  • 使用 ::first-letter 将段落首字母放大到 24px，颜色改为蓝色 #0066CC
  • 使用 ::first-line 将段落第一行改为粗体

📚 知识回顾

本次练习涉及的选择器：

LVHA 链接伪类 :link → :visited → :hover → :active
⚠️ 顺序不能乱！
结构位置伪类 :first-child - 第一个
:last-child - 最后一个
:nth-child(odd) - 奇数位
:nth-child(even) - 偶数位
排除逻辑伪类 :not(选择器) - 排除符合条件的元素
伪元素选择器 ::before - 在元素前插入内容
::after - 在元素后插入内容
::first-letter - 首字母
::first-line - 首行
