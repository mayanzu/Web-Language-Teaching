📚 知识点总结

关键要点：

1. LVHA 顺序很重要

必须按照 :link → :visited → :hover → :active 顺序编写，否则某些状态会失效

2. :nth-child() 灵活运用

odd（奇数）、even（偶数）、具体数字(3)、公式(2n+1) 都可以使用

3. :not() 的强大功能

可以反向选择，避免写多余的类名

4. 伪元素 content 属性

::before 和 ::after 必须配合 content 属性使用，即使是空字符串也要写上
