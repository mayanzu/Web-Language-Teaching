📝 练习 1：色彩面板 Color

任务说明

为三张色卡设置不同的颜色表示法，掌握 color / background-color / border-color 的配合。

📋 要求：
  • .palette-card.primary：文字颜色 #0F62FE，背景使用 rgba(15,98,254,0.08)
  • .palette-card.warning：文字使用 HSL(32, 95%, 45%)，背景调低饱和度
  • .palette-card.success：color 设为 CSS 变量 var(--color-accent)，背景使用 linear-gradient
  • 让 .palette-chip 使用 currentColor，同时给卡片设置 2px 边框

十六进制 + RGBA 背景

Warning 橙

HSL / HSLA 调整

Success 品牌色

变量 + 渐变背景

💡 提示：可使用 .palette-card { border: 2px solid currentColor; } 让边框也继承颜色。

📝 练习 2：字体系统 Typography

任务说明

通过 font-family / font-size / font-weight / line-height 组合实现不同的排版风格。

📋 要求：
  • .type-card.serif 使用衬线字体，正文 18px，标题加粗
  • .type-card.modern 需写出三个字体候选，使用 rem 控制字号
  • .type-card.clean 调整 line-height: 1.8，并将摘要文字设为 #6B7280
  • 对 .type-card 内的 .type-title、.type-body 分别设置字重与字号

经典衬线标题

Serif 字体适合正文阅读，行距一般设为 1.5-1.7，更贴合传统印刷排版。

Modern Fallback

当第一种字体缺失时，浏览器会自动回退到下一种，确保排版风格一致。

无衬线资讯

选择易读的字体、合理的行高与字号组合，可以大幅提升资讯类页面的效率。

💡 提示：可以定义 .type-title 与 .type-body 的通用样式，再用修饰类覆盖。

📝 练习 3：文本装饰与间距 Text Style

任务说明

使用 text-align / text-transform / text-decoration / letter-spacing / word-spacing 等属性塑造排版氛围。

📋 要求：
  • .quote-box 居中对齐，背景 #F5F5F7，使用大写变换 + 0.2em 的 letter-spacing
  • .quote-body 维持正常大小写，但设置 1.6 的 line-height
  • .quote-author 放在右下角，使用 text-transform: lowercase; 并添加顶部虚线
  • 为 .quote-box 添加细微阴影 0 8px 20px rgba(15,23,42,0.08)

Typography Shapes Emotion

通过字间距与装饰线的细节控制，我们可以让一段普通文本呈现出品牌专属的语气。

DESIGN TEAM

💡 提示：可利用 text-transform 区分标题与作者的语气。

📝 练习 4：文本溢出处理 Overflow

任务说明

为资讯卡片设置固定宽度，并使用“溢出三件套”保证界面整齐。

📋 要求：
  • 让 .overflow-demo 固定宽度 220px，字号使用 1rem（可在 html 上修改基准）
  • 组合 white-space: nowrap;、overflow: hidden;、text-overflow: ellipsis;
  • 为卡片添加 10px 内边距及圆角 12px
  • 可选：增加 .overflow-demo:hover 时显示完整文本（使用 normal white-space）

本段文字用于测试文本溢出处理是否正确：当内容较长时，应显示省略号以保持布局整洁。

💡 提示：想要 hover 展开可结合 transition 实现平滑体验。
