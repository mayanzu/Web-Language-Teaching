# CSS基础选择器练习说明

## 练习目标
考查学生对CSS四种基础选择器的掌握程度：
1. 元素选择器
2. ID选择器  
3. 类选择器
4. 通用选择器

## 文件说明
- `基础选择器练习.html` - 学生练习文件（包含需要填空的CSS部分）
- `基础选择器练习-答案.html` - 教师参考答案文件
- `基础选择器练习说明.md` - 本说明文档

## 练习内容

### 第1题：元素选择器
**要求**：使用元素选择器，让所有的段落文字变成蓝色
**考查知识点**：元素选择器的基本语法和应用

### 第2题：ID选择器
**要求**：使用ID选择器，给id为"important"的元素添加红色背景和白色文字
**考查知识点**：ID选择器的语法（#id）和唯一性

### 第3题：类选择器
**要求**：使用类选择器，给所有class为"highlight"的元素添加粗体和黄色背景
**考查知识点**：类选择器的语法（.class）和可重复性

### 第4题：通用选择器
**要求**：使用通用选择器，给所有元素添加5px的外边距和Arial字体
**考查知识点**：通用选择器的语法（*）和全局应用

### 第5题：综合应用
**要求**：综合运用前面学过的选择器知识
**考查知识点**：多种选择器的组合使用和优先级理解

## 使用方法
1. 将`基础选择器练习.html`文件分发给学生
2. 学生在浏览器中打开文件，根据页面提示完成CSS代码填空
3. 学生可以通过刷新浏览器查看样式效果
4. 教师可参考`基础选择器练习-答案.html`文件进行批改

## 评分标准建议
- 每题20分，共100分
- 选择器语法正确：10分
- 样式效果实现：10分
- 鼓励学生尝试不同的样式属性组合

## 教学建议
- 练习前先复习四种基础选择器的语法
- 强调选择器的优先级：ID选择器 > 类选择器 > 元素选择器 > 通用选择器
- 提醒学生注意CSS属性的正确写法
- 鼓励学生在完成基本要求后尝试添加更多样式
