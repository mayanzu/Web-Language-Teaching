# CSS 层级选择器说明

## 1. 子代选择器 (Child Selector)

### 语法
```
父元素 > 子元素
```

### 说明
子代选择器只选择父元素的直接子元素，不会选择更深层的后代元素。

### 示例
```css
/* 只选择 .container 的直接子元素 p */
.container > p {
    color: blue;
}
```

## 2. 后代选择器 (Descendant Selector)

### 语法
```
祖先元素 后代元素
```

### 说明
后代选择器选择祖先元素内的所有指定后代元素，无论嵌套多深。

### 示例
```css
/* 选择 .box 内的所有 span 元素，无论嵌套多深 */
.box span {
    background-color: lightyellow;
}
```

## 3. 相邻兄弟选择器 (Adjacent Sibling Selector)

### 语法
```
元素1 + 元素2
```

### 说明
相邻兄弟选择器选择紧跟在元素1后面的第一个元素2，两者必须有相同的父元素。

### 示例
```css
/* 选择紧跟在 h2 后面的第一个 p 元素 */
h2 + p {
    color: red;
}
```

## 4. 通用兄弟选择器 (General Sibling Selector)

### 语法
```
元素1 ~ 元素2
```

### 说明
通用兄弟选择器选择元素1后面的所有元素2兄弟元素，两者必须有相同的父元素。

### 示例
```css
/* 选择 h3 后面的所有 li 兄弟元素 */
h3 ~ li {
    color: green;
}
```

## 练习解答

### 1. 使用子代选择器：将 container 的直接子元素 p 的文字颜色设为蓝色
```css
.container > p {
    color: blue;
}
```

### 2. 使用后代选择器：将 box 内的所有 span 元素的背景色设为浅黄色
```css
.box span {
    background-color: lightyellow;
}
```

### 3. 使用相邻兄弟选择器：将紧跟在 h2 后面的 p 段落文字设为红色
```css
h2 + p {
    color: red;
}
```

### 4. 使用通用兄弟选择器：将 h3 后面所有的兄弟 li 元素的文字设为绿色
```css
h3 ~ li {
    color: green;
}
```

### 5. 使用子代选择器：将 nav > ul > li 的直接子元素 a 的文字装饰设为无下划线
```css
nav > ul > li > a {
    text-decoration: none;
}
```

### 6. 使用后代选择器：将 article 内的所有 blockquote 的边框设为蓝色实线
```css
article blockquote {
    border: 1px solid blue;
}
```

### 7. 使用相邻兄弟选择器：将紧跟在 .highlight 后面的 p 段落文字加粗
```css
.highlight + p {
    font-weight: bold;
}
```

## 注意事项

1. 子代选择器 (>) 只选择直接子元素，不选择更深层的后代
2. 后代选择器 (空格) 选择所有后代元素，无论嵌套多深
3. 相邻兄弟选择器 (+) 只选择紧跟在后面的第一个兄弟元素
4. 通用兄弟选择器 (~) 选择后面的所有兄弟元素
5. 兄弟选择器要求元素必须有相同的父元素
6. 这些选择器可以组合使用，创建更复杂的选择规则
