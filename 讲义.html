一、下拉菜单

<select>和<option>标签用于创建下拉菜单，允许用户从预定义的选项中选择一个或多个选项。

💡 生活类比

下拉菜单就像餐厅的菜单一样——当你点菜时，服务员会给你一份菜单，你只能从菜单上已有的菜品中选择。 你不能自己编造菜名，只能从预设的选项中挑选。HTML的下拉菜单工作原理相同：选项是预先设定好的。

1.1 下拉菜单 vs 其他输入方式

输入方式 适用场景 优势
下拉菜单 (select) 选项较多（5个以上），只能单选或多选 节省空间，选项清晰
单选按钮 (radio) 选项较少（2-5个），需要用户一眼看到所有选项 所有选项可见，比较方便
复选框 (checkbox) 可以选多个选项，选项较少 多选直观，状态清晰
文本输入 (input) 用户自由输入，无法预设选项 灵活性高

1.2 基本下拉菜单

基本的下拉菜单允许用户从一组预定义选项中选择一个选项。下拉菜单由<select>和<option>标签组合使用。 

<label for="city">城市：</label>
<select id="city" name="city">
    <option value="">请选择城市</option>
    <option value="beijing">北京</option>
    <option value="shanghai">上海</option>
    <option value="guangzhou">广州</option>
    <option value="shenzhen">深圳</option>
</select>
💡 value vs 显示文本

注意value属性和显示文本的区别：

  • value：提交给服务器的值（通常是英文或代码）
  • 显示文本：用户看到的文字（可以是中文）
<option value="beijing">北京</option>
<!-- 用户看到"北京"，提交时发送"beijing" -->

1.3 默认选中项

我们可以使用selected属性来指定下拉菜单的默认选中项。 

<label for="city">城市：</label>
<select id="city" name="city">
    <option value="">请选择城市</option>
    <option value="beijing">北京</option>
    <option value="shanghai" selected>上海</option>
    <option value="guangzhou">广州</option>
    <option value="shenzhen">深圳</option>
</select>

1.4 多选下拉菜单

我们可以使用multiple属性来创建多选下拉菜单，允许用户从选项列表中选择多个选项。 

<label for="hobbies">爱好：</label>
<select id="hobbies" name="hobbies" multiple size="3">
    <option value="reading">阅读</option>
    <option value="music">音乐</option>
    <option value="sports">运动</option>
    <option value="travel">旅行</option>
    <option value="cooking">烹饪</option>
</select>
📖 多选操作提示

在多选下拉菜单中，用户可以：

  • 按住Ctrl键点击选择多个不连续的选项
  • 按住Shift键点击选择连续的多个选项
  • size属性控制显示几行选项

1.5 分组下拉菜单

对于包含大量选项的下拉菜单，我们可以使用<optgroup>标签来对选项进行逻辑分组。 

<label for="country">国家/地区：</label>
<select id="country" name="country">
    <option value="">请选择国家/地区</option>
    <optgroup label="亚洲">
        <option value="china">中国</option>
        <option value="japan">日本</option>
        <option value="korea">韩国</option>
    </optgroup>
    <optgroup label="欧洲">
        <option value="uk">英国</option>
        <option value="france">法国</option>
        <option value="germany">德国</option>
    </optgroup>
</select>

1.6 select标签的常用属性

属性 描述 示例
name 表单提交时的字段名 name="city"
id 元素的唯一标识，配合label使用 id="city"
multiple 允许多选 multiple
size 显示的选项行数 size="5"
disabled 禁用下拉菜单 disabled
required 必须选择一项 required

二、文本域

<textarea>标签用于创建多行文本输入框，允许用户输入和编辑大量文本内容，如评论、留言、反馈等。

💡 生活类比

如果说<input type="text">是一张便签条，那么<textarea>就是一整张稿纸。 当你需要写一句话时用便签条（input），当你需要写一段文章时用稿纸（textarea）。

2.1 input vs textarea对比

特性 input type="text" textarea
行数 单行 多行
适用场景 姓名、邮箱、标题等短文本 评论、留言、文章等长文本
默认值设置 通过value属性 在标签之间写内容
换行支持 不支持 支持
大小调整 固定宽度 可拖拽调整大小

2.2 基本文本域

基本的文本域使用<textarea>标签创建，我们可以使用rows和cols属性来指定文本域的可见行数和列数。 

<label for="comments">评论：</label>
<textarea id="comments" name="comments" rows="5" cols="50" placeholder="请输入您的评论..."></textarea>
⚠️ 注意：textarea是双标签！

与<input>不同，<textarea>必须有闭合标签： 

<!-- ❌ 错误写法 -->
<textarea />

<!-- ✅ 正确写法 -->
<textarea></textarea>

2.3 带有默认值的文本域

我们可以在<textarea>标签的开始标签和结束标签之间添加默认文本。 

<label for="feedback">反馈：</label>
<textarea id="feedback" name="feedback" rows="5" cols="50">请在此输入您的反馈意见...
感谢您的支持！</textarea>
💡 默认值注意事项

textarea内的空格和换行都会被保留！以下写法会产生意外的空白： 

<!-- 会有多余空格 -->
<textarea>
    默认文本
</textarea>

<!-- 正确写法：内容紧贴标签 -->
<textarea>默认文本</textarea>

2.4 文本域的核心属性

<textarea>标签支持多种属性，用于控制其外观和行为：

属性 描述 示例
rows 定义文本域的可见行数 rows="5"
cols 定义文本域的可见列数（字符宽度） cols="50"
placeholder 定义文本域为空时显示的提示文本 placeholder="请输入评论..."
required 指定文本域为必填项 required
maxlength 限制文本域的最大字符数 maxlength="500"
minlength 限制文本域的最小字符数 minlength="10"
readonly 只读，不可编辑但可提交 readonly
disabled 禁用，不可编辑且不提交 disabled

2.5 控制文本域的大小调整

默认情况下，用户可以拖拽调整textarea的大小。可以使用CSS来控制这个行为：

/* 禁止调整大小 */
textarea { resize: none; }

/* 只允许垂直调整 */
textarea { resize: vertical; }

/* 只允许水平调整 */
textarea { resize: horizontal; }

/* 允许双向调整（默认） */
textarea { resize: both; }

三、表单分组

对于包含多个字段的复杂表单，我们可以使用<fieldset>和<legend>标签来对相关的表单控件进行逻辑分组，使表单结构更加清晰。

💡 生活类比

想象一下填写纸质申请表：通常会把"个人信息"、"教育背景"、"工作经历"分成不同的区块， 每个区块都有一个小标题。<fieldset>就是这些区块，<legend>就是区块的小标题。

3.1 为什么要使用表单分组？

优势 说明
视觉组织 相关字段组合在一起，用户更容易理解和填写
语义清晰 屏幕阅读器能识别分组，提高无障碍访问
批量控制 可以一次性禁用整个分组的所有控件
样式管理 便于对不同分组应用不同的CSS样式

3.2 fieldset和legend标签的基本使用

<fieldset>标签用于定义表单中的一个逻辑分组，<legend>标签用于定义该分组的标题。 

<form>
    <fieldset>
        <legend>个人信息</legend>
        
        <label for="username">用户名：</label>
        <input type="text" id="username" name="username" placeholder="请输入用户名">
        
        <br><br>
        
        <label for="email">邮箱：</label>
        <input type="email" id="email" name="email" placeholder="请输入邮箱">
    </fieldset>
    
    <fieldset>
        <legend>密码信息</legend>
        
        <label for="password">密码：</label>
        <input type="password" id="password" name="password" placeholder="请输入密码">
        
        <br><br>
        
        <label for="confirm-password">确认密码：</label>
        <input type="password" id="confirm-password" name="confirm-password" placeholder="请确认密码">
    </fieldset>
    
    <br>
    
    <input type="submit" value="注册">
    <input type="reset" value="重置">
</form>
📖 fieldset的默认样式

浏览器会为<fieldset>添加默认样式：

  • 一个边框环绕整个分组
  • <legend>会嵌入到边框的顶部
  • 内部有一定的内边距

这些样式可以通过CSS自定义修改。

3.3 禁用整个字段集

我们可以使用disabled属性来禁用整个字段集，包含在其中的所有表单控件都会被自动禁用。 

<fieldset disabled>
    <legend>高级选项（暂不可用）</legend>
    
    <label for="preferences">偏好设置：</label>
    <select id="preferences" name="preferences">
        <option value="option1">选项1</option>
        <option value="option2">选项2</option>
        <option value="option3">选项3</option>
    </select>
</fieldset>
⚠️ disabled vs readonly

disabled的fieldset中的表单数据不会被提交！ 如果需要显示但不可编辑的数据，考虑使用readonly属性或CSS样式来实现。

3.4 嵌套fieldset

fieldset可以嵌套使用，形成更细致的分组层次：

<fieldset>
    <legend>送货地址</legend>
    
    <fieldset>
        <legend>国内地址</legend>
        <!-- 省、市、区、详细地址 -->
    </fieldset>
    
    <fieldset>
        <legend>海外地址</legend>
        <!-- 国家、城市、邮编、详细地址 -->
    </fieldset>
</fieldset>

四、表单验证基础

表单验证是确保用户输入的数据符合要求的重要手段，它可以在用户提交表单之前检测并提示错误，提高数据质量和用户体验。 HTML5提供了强大的内置表单验证功能，无需编写JavaScript代码即可实现基本的验证规则。

💡 为什么需要表单验证？

想象你在银行填写转账单，如果填错了账号格式，柜员会当场指出让你修改。 表单验证就是这个"柜员"，它在数据提交前检查：

  • 必填项是否已填写？
  • 邮箱格式是否正确？
  • 密码长度是否符合要求？
  • 年龄是否在合理范围？

4.1 客户端验证 vs 服务器端验证

验证类型 位置 优势 劣势
客户端验证（HTML5） 浏览器 即时反馈，用户体验好 可被绕过，不可完全信任
服务器端验证 服务器 安全可靠，不可绕过 需要网络往返，较慢
⚠️ 重要安全提示

HTML5客户端验证只是为了用户体验！真正的数据验证必须在服务器端进行。 恶意用户可以轻松绕过客户端验证，直接向服务器发送非法数据。

4.2 必填项验证

我们可以使用required属性来指定某个表单字段为必填项，当用户提交表单时，如果必填项为空，浏览器会显示错误提示。 

<!-- 文本输入框必填 -->
<label for="username">用户名：</label>
<input type="text" id="username" name="username" required placeholder="请输入用户名">

<!-- 密码框必填 -->
<label for="password">密码：</label>
<input type="password" id="password" name="password" required placeholder="请输入密码">

<!-- 下拉菜单必填 -->
<select name="city" required>
    <option value="">请选择城市</option>
    <option value="beijing">北京</option>
</select>

4.3 长度验证

我们可以使用minlength和maxlength属性来限制文本输入的最小长度和最大长度。 

<!-- 密码长度限制：6-20位 -->
<label for="password">密码：</label>
<input type="password" id="password" name="password" minlength="6" maxlength="20" placeholder="请输入6-20位密码">

4.4 数值范围验证

对于数字输入，我们可以使用min和max属性来限制数值的范围。 

<!-- 年龄范围限制：18-100岁 -->
<label for="age">年龄：</label>
<input type="number" id="age" name="age" min="18" max="100" placeholder="请输入18-100之间的年龄">

<!-- 步进值：只能输入5的倍数 -->
<label for="quantity">数量：</label>
<input type="number" id="quantity" name="quantity" min="0" max="100" step="5">

4.5 常用验证属性汇总

属性 适用类型 描述
required 所有可输入控件 必填项
minlength text, password, textarea 最小字符数
maxlength text, password, textarea 最大字符数
min number, range, date 最小值
max number, range, date 最大值
step number, range, date 步进值
pattern text, password, tel 正则表达式匹配

4.6 pattern属性（正则表达式验证）

pattern属性允许使用正则表达式来验证输入内容： 

<!-- 只允许字母 -->
<input type="text" pattern="[A-Za-z]+" title="只能输入英文字母">

<!-- 手机号格式（以1开头的11位数字） -->
<input type="tel" pattern="1[3-9]\d{9}" title="请输入正确的手机号">

<!-- 6位数字验证码 -->
<input type="text" pattern="\d{6}" title="请输入6位数字验证码">
💡 title属性的作用

当验证失败时，浏览器会显示title属性中的提示文字，帮助用户理解正确的输入格式。

课后练习

  1. 创建一个完整的在线调查问卷表单，包含以下字段：
    • 姓名（文本输入框，必填）
    • 年龄（数字输入框，范围18-100）
    • 性别（下拉菜单，必填）
    • 职业（下拉菜单，必填）
    • 兴趣爱好（多选下拉菜单）
    • 意见反馈（文本域，必填，最大长度500字）
  2. 使用<fieldset>和<legend>标签对表单进行分组
  3. 为所有必填字段添加required属性
  4. 为适当的字段添加长度或范围限制
