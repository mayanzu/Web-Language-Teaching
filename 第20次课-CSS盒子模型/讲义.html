一、盒子模型简介

CSS盒子模型是CSS布局的基础，它将HTML元素看作一个矩形的盒子，包括内容区域、内边距、边框和外边距四个部分。

盒子模型决定了元素在页面中的大小、位置和与其他元素的关系。

类比理解

把每个HTML元素想象成一个快递包裹：

  • 内容（Content） = 包裹里的物品本身
  • 内边距（Padding） = 物品周围的泡沫填充物，保护物品
  • 边框（Border） = 包裹的纸箱外壳
  • 外边距（Margin） = 多个包裹之间的间隔距离

1.1 为什么要学习盒子模型？

盒子模型是CSS布局的核心概念，掌握它能帮你：

  • 准确控制元素的尺寸和间距
  • 理解元素为什么会"撑大"或"挤压"
  • 解决常见的布局问题（如元素不对齐、间距异常等）
  • 为学习Flexbox和Grid布局打下基础
盒子模型的两种标准
模型类型width/height 包含计算方式使用场景
W3C标准盒模型 仅内容区域 总宽度 = width + padding + border CSS默认行为
IE盒模型（怪异模式） 内容 + padding + border 总宽度 = width（已包含padding和border） 使用 box-sizing: border-box

二、盒子模型组成

CSS盒子模型由以下四个部分组成，从内到外依次是：

盒子模型四层结构：
层次名称CSS属性描述
1（最内层） 内容区域 (Content) width, height 元素实际内容的区域，放置文本、图片等
2 内边距 (Padding) padding 内容与边框之间的空白区域
3 边框 (Border) border 围绕内边距的可见边框线
4（最外层） 外边距 (Margin) margin 元素与相邻元素之间的空白区域
可视化理解

想象一幅画：

  • 内容 = 画布上的图案
  • 内边距 = 画布边缘到画框之间的留白
  • 边框 = 画框本身
  • 外边距 = 这幅画与旁边其他画之间的距离

2.1 使用开发者工具查看盒子模型

在浏览器中，你可以使用开发者工具（F12）直观地查看任何元素的盒子模型：

  1. 按 F12 打开开发者工具
  2. 点击左上角的「选择元素」按钮（或按 Ctrl+Shift+C）
  3. 在页面上点击要检查的元素
  4. 在右侧面板中找到「Computed」或「计算样式」标签
  5. 你会看到一个彩色的盒子模型图，展示各层的尺寸

三、内容区域 (Content)

内容区域是元素实际内容的区域，由 width 和 height 属性控制。这是盒子最核心的部分。

3.1 设置内容尺寸

/* 固定尺寸 */
.box {
    width: 300px;    /* 内容区域宽度 */
    height: 200px;   /* 内容区域高度 */
}

/* 百分比尺寸（相对于父元素） */
.responsive-box {
    width: 50%;      /* 父元素宽度的50% */
    height: auto;    /* 高度自动适应内容 */
}

/* 最大/最小尺寸 */
.flexible-box {
    min-width: 200px;   /* 最小宽度 */
    max-width: 800px;   /* 最大宽度 */
    min-height: 100px;  /* 最小高度 */
    max-height: 500px;  /* 最大高度 */
}

3.2 常用尺寸单位

单位类型说明示例
px 绝对单位 像素，固定大小 width: 300px;
% 相对单位 相对于父元素 width: 50%;
em 相对单位 相对于当前元素字体大小 padding: 1.5em;
rem 相对单位 相对于根元素（html）字体大小 margin: 2rem;
vw/vh 视口单位 视口宽度/高度的1% width: 100vw;
注意事项
  • width 和 height 属性仅对块级元素和替换元素有效
  • 对于行内元素（如 <span>），设置宽高不会生效
  • 如果想让行内元素有宽高，需要设置 display: inline-block; 或 display: block;
常见问题：内容溢出

当内容超出设定的尺寸时，默认会溢出显示。使用 overflow 属性控制溢出行为：

.overflow-control {
    width: 200px;
    height: 100px;
    overflow: visible;  /* 默认，内容溢出可见 */
    overflow: hidden;   /* 隐藏溢出内容 */
    overflow: scroll;   /* 显示滚动条 */
    overflow: auto;     /* 需要时显示滚动条 */
}

四、内边距 (Padding)

内边距是内容区域与边框之间的空白区域，由 padding 属性控制。内边距会撑大元素的总尺寸（在标准盒模型下）。

4.1 padding 的写法

/* 方式1：单独设置每个方向 */
.box {
    padding-top: 10px;
    padding-right: 20px;
    padding-bottom: 30px;
    padding-left: 40px;
}

/* 方式2：简写形式 - 四个值（顺时针：上 右 下 左）*/
.box {
    padding: 10px 20px 30px 40px;
}

/* 方式3：简写形式 - 三个值（上 左右 下）*/
.box {
    padding: 10px 20px 30px;  /* 上10px, 左右20px, 下30px */
}

/* 方式4：简写形式 - 两个值（上下 左右）*/
.box {
    padding: 10px 20px;  /* 上下10px, 左右20px */
}

/* 方式5：简写形式 - 一个值（四个方向相同）*/
.box {
    padding: 20px;  /* 上下左右都是20px */
}
记忆技巧：顺时针方向

当使用多个值时，从上方开始，顺时针旋转：上 → 右 → 下 → 左

可以联想时钟：12点（上）→ 3点（右）→ 6点（下）→ 9点（左）

4.2 padding 的特点

  • 会增加元素的总尺寸（在标准盒模型下）
  • 背景色会延伸到内边距区域（与内容区域相同）
  • 不能使用负值（与 margin 不同）
  • 可以使用百分比，相对于父元素的宽度计算
实际应用场景
  • 按钮：给文字周围添加呼吸空间，提升点击体验
  • 卡片：让内容不紧贴边框，更美观
  • 输入框：让用户输入的文字不紧贴边框
常见问题：padding 导致元素变大 
/* 问题示例：期望宽度300px，实际变成340px */
.problem-box {
    width: 300px;
    padding: 20px;  /* 左右各加20px */
    /* 实际宽度 = 300 + 20 + 20 = 340px */
}

/* 解决方案：使用 border-box */
.fixed-box {
    box-sizing: border-box;  /* padding 不会撑大元素 */
    width: 300px;
    padding: 20px;
    /* 实际宽度 = 300px（内容区域自动缩小） */
}

五、边框 (Border)

边框是围绕内容区域和内边距的可见边界线，由 border 属性控制。边框也会增加元素的总尺寸。

5.1 边框的三要素

边框由三个部分组成：宽度、样式、颜色。

/* 完整写法 */
.box {
    border-width: 2px;       /* 边框宽度 */
    border-style: solid;     /* 边框样式（必须指定，否则不显示） */
    border-color: #2c3e50;   /* 边框颜色 */
}

/* 简写形式（推荐）：宽度 样式 颜色 */
.box {
    border: 2px solid #2c3e50;
}

/* 单独设置某一边 */
.box {
    border-top: 2px solid red;
    border-right: 3px dashed blue;
    border-bottom: 4px dotted green;
    border-left: 5px double orange;
}

5.2 边框样式（border-style）

值效果说明
none无边框默认值，不显示边框
solid━━━━实线（最常用）
dashed- - - -虚线
dotted····点线
double═══双线
groove凹槽效果3D凹槽
ridge凸脊效果3D凸脊
inset内凹效果嵌入效果
outset外凸效果突出效果

5.3 圆角边框（border-radius）

使用 border-radius 可以创建圆角效果：

/* 四个角相同圆角 */
.rounded {
    border-radius: 10px;
}

/* 四个角不同圆角（顺时针：左上 右上 右下 左下） */
.custom-rounded {
    border-radius: 10px 20px 30px 40px;
}

/* 圆形（宽高相等时） */
.circle {
    width: 100px;
    height: 100px;
    border-radius: 50%;  /* 或 50px */
}

/* 胶囊形状（椭圆） */
.capsule {
    width: 200px;
    height: 50px;
    border-radius: 25px;  /* 高度的一半 */
}
实用技巧
  • 想要圆形？设置 border-radius: 50%;（宽高需相等）
  • 想要胶囊？设置 border-radius 为高度的一半
  • 想要只有部分圆角？使用四个值分别指定
边框的特点
  • 必须指定 border-style，否则边框不显示
  • 边框宽度会增加元素的总尺寸
  • 可以单独设置每一边的边框样式
  • border-radius 可以创建圆角效果

六、外边距 (Margin)

外边距是元素与其他元素之间的空白区域，由 margin 属性控制。外边距不会增加元素自身的尺寸，但会影响元素在页面中的位置。

6.1 margin 的写法

margin 的语法与 padding 完全相同（顺时针方向）：

/* 单独设置每个方向 */
.box {
    margin-top: 10px;
    margin-right: 20px;
    margin-bottom: 30px;
    margin-left: 40px;
}

/* 简写形式 */
.box {
    margin: 10px 20px 30px 40px;  /* 上 右 下 左 */
    margin: 10px 20px 30px;       /* 上 左右 下 */
    margin: 10px 20px;            /* 上下 左右 */
    margin: 20px;                 /* 四个方向相同 */
}

6.2 使用 margin 实现水平居中

这是 margin 最常用的技巧之一：

/* 块级元素水平居中 */
.center-block {
    width: 300px;          /* 必须设置宽度 */
    margin: 0 auto;        /* 上下0，左右自动 */
}

/* 也可以这样写 */
.center-block {
    width: 300px;
    margin-left: auto;
    margin-right: auto;
}
margin: auto 的原理

auto 让浏览器自动计算左右外边距，使其相等，从而实现居中。

注意：这只对块级元素有效，且必须设置明确的宽度。

6.3 margin 的特点

特点说明与 padding 对比
负值 可以使用负值，让元素重叠 padding 不能使用负值
背景 外边距区域透明，显示父元素背景 padding 区域显示本元素背景
auto 可用于水平居中 padding 不支持 auto
合并 垂直方向上会发生外边距合并 padding 不会合并

6.4 负 margin 的应用

/* 使用负 margin 让元素重叠 */
.overlap {
    margin-top: -20px;  /* 向上移动20px，覆盖上方元素 */
}

/* 使用负 margin 扩展元素 */
.extend {
    margin-left: -20px;
    margin-right: -20px;
    /* 元素会超出父元素左右各20px */
}
常见问题：子元素的 margin-top 跑到父元素外面

这是「外边距合并」的一种表现，稍后会详细解释。

七、box-sizing 属性（重要！）

box-sizing 属性决定了 width 和 height 的计算方式。这是现代CSS中最重要的属性之一。

7.1 两种盒模型对比

属性值width/height 包含实际总宽度计算
content-box（默认） 仅内容区域 width + padding-left + padding-right + border-left + border-right
border-box（推荐） 内容 + padding + border width（padding 和 border 从 width 中扣除）

7.2 具体计算示例

/* 标准盒模型（content-box） */
.content-box-demo {
    box-sizing: content-box;  /* 默认值 */
    width: 200px;
    padding: 20px;
    border: 10px solid black;
    /* 
     * 内容区域宽度 = 200px
     * 实际占用宽度 = 200 + 20*2 + 10*2 = 260px
     */
}

/* IE盒模型（border-box） */
.border-box-demo {
    box-sizing: border-box;   /* 推荐使用 */
    width: 200px;
    padding: 20px;
    border: 10px solid black;
    /* 
     * 实际占用宽度 = 200px（固定）
     * 内容区域宽度 = 200 - 20*2 - 10*2 = 140px
     */
}
为什么推荐使用 border-box？
  • 更直观：设置 width: 200px，元素就是 200px，不用心算
  • 响应式友好：使用百分比宽度时，不用担心 padding 撑破布局
  • 现代开发标准：Bootstrap、Tailwind 等框架都默认使用

7.3 全局设置 border-box（最佳实践）

/* 推荐：在 CSS 文件开头添加 */
*, *::before, *::after {
    box-sizing: border-box;
}

/* 或者使用继承的方式（更灵活） */
html {
    box-sizing: border-box;
}
*, *::before, *::after {
    box-sizing: inherit;
}
注意事项
  • 如果项目中途引入 border-box，可能会影响已有布局
  • 第三方库可能使用不同的 box-sizing，需要注意兼容
  • 建议在项目一开始就统一设置

八、外边距合并（Margin Collapse）

外边距合并是CSS中一个经常让人困惑的特性：当两个垂直方向的外边距相遇时，它们会合并成一个外边距，取较大的那个值。

关键要点
  • 外边距合并只发生在垂直方向（上下），水平方向不会
  • 只发生在普通文档流中的块级元素之间
  • 合并后的外边距 = max(margin1, margin2)

8.1 三种外边距合并情况

情况1：相邻兄弟元素

<div style="margin-bottom: 30px;">上面的盒子</div>
<div style="margin-top: 20px;">下面的盒子</div>
<!-- 两个盒子之间的间距不是 50px，而是 30px（取较大值） -->

情况2：父元素与第一个/最后一个子元素

<div class="parent" style="margin-top: 0;">
    <div class="child" style="margin-top: 30px;">子元素</div>
</div>
<!-- 子元素的 margin-top 会"穿透"到父元素外面！ -->

情况3：空元素

/* 如果一个元素没有内容、padding、border */
.empty {
    margin-top: 30px;
    margin-bottom: 20px;
}
/* 这个空元素的实际高度为 0，上下 margin 会合并成 30px */

8.2 如何避免外边距合并

解决父子元素 margin 合并的方法： 
/* 方法1：给父元素添加 padding */
.parent {
    padding-top: 1px;  /* 哪怕1px也能阻止合并 */
}

/* 方法2：给父元素添加 border */
.parent {
    border-top: 1px solid transparent;
}

/* 方法3：给父元素添加 overflow */
.parent {
    overflow: hidden;  /* 或 auto */
}

/* 方法4：使用 Flexbox 或 Grid */
.parent {
    display: flex;
    flex-direction: column;
}

/* 方法5：父元素创建 BFC（块级格式化上下文） */
.parent {
    display: flow-root;  /* 最干净的方式 */
}
实际开发建议
  • 了解外边距合并的存在，遇到奇怪的间距问题时首先排查它
  • 使用开发者工具检查元素的盒模型，看看 margin 是否符合预期
  • 现代布局（Flexbox、Grid）不会发生外边距合并，推荐使用
  • 如果不确定，可以统一只使用 margin-bottom，避免上下 margin 相遇

本课小结

知识点回顾

恭喜你！学完了CSS盒子模型这个核心概念：

  • 盒子模型组成：内容（Content）→ 内边距（Padding）→ 边框（Border）→ 外边距（Margin）
  • 内容区域：由 width/height 控制，只对块级元素有效
  • 内边距：撑大元素，背景色可见，不能为负
  • 边框：三要素（宽度、样式、颜色），border-radius 创建圆角
  • 外边距：可为负值，margin: auto 实现居中
  • box-sizing：推荐全局使用 border-box
  • 外边距合并：垂直方向发生，多种方法可避免

重点记忆

概念要点代码示例
顺时针方向 padding/margin 四个值的顺序 padding: 上 右 下 左;
水平居中 块级元素设置宽度后 margin: 0 auto;
推荐盒模型 width/height 包含 padding 和 border box-sizing: border-box;
圆形 宽高相等的元素 border-radius: 50%;

最佳实践

开发建议
  • 在项目开始时就全局设置 box-sizing: border-box;
  • 使用开发者工具（F12）检查元素的盒模型
  • 遇到奇怪的间距问题，首先检查外边距合并
  • 优先使用 Flexbox/Grid 布局，它们不会发生外边距合并
  • 统一使用 margin-bottom 控制垂直间距，避免 margin 相遇
