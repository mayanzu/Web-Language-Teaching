第一部分：CSS 颜色 (CSS Colors)

颜色是网页传达情感和品牌调性最直接的方式。CSS 提供了极其丰富的色彩定义工具。

第1章：颜色表示法

在 CSS 中，我们可以用多种“语言”来描述同一个颜色。

表示法 格式示例 详细说明
关键字
(Keywords)		 red, transparent 预定义的颜色名称，包含140+个标准色。适合快速测试，但不适合精确设计。
十六进制
(Hex)		 #FF0000 (红)
#F00 (简写)		 最常用。使用 0-9 和 A-F 表示。每两位分别代表红(R)、绿(G)、蓝(B)。
RGB / RGBA rgb(255, 0, 0)
rgba(0, 0, 0, 0.5)		 直接控制红绿蓝通道（0-255）。Alpha (A) 通道控制透明度，0 为全透明，1 为不透明。
HSL / HSLA hsl(0, 100%, 50%) 最直观。H(色相 0-360), S(饱和度 %), L(亮度 %)。调整明暗或制作配色方案时非常方便。

第2章：常用颜色属性

不仅仅是文字颜色，CSS 可以控制页面几乎所有元素的色彩。

属性 (Property) 作用 常用值示例
color 前景色。主要影响文字、文本装饰线、边框（默认跟随）。 #333, rgb(50,50,50)
background-color 背景颜色。填充在元素内容、内边距(padding)区域。 #f5f5f7, transparent
border-color 边框颜色。可以分别设置四条边。 #ccc, transparent
opacity 不透明度。注意：这会影响整个元素（包括子元素）。 0 (隐藏), 0.5 (半透明), 1 (显示)

九、课程小结

本节课我们学习了CSS常用元素样式，包括颜色、文字排版、长度单位、边框样式、表格样式和表单样式等内容。

9.1 知识点回顾

  • CSS颜色：掌握了多种颜色表示法，包括关键字、十六进制、RGB/RGBA和HSL/HSLA
  • 文字排版：学习了字体属性、文本样式与装饰、文本间距控制以及文本溢出与换行
  • 长度单位：了解了绝对单位和相对单位的区别，以及视口单位的应用
  • 边框样式：掌握了边框属性、圆角与阴影的使用
  • 表格样式：学习了如何美化表格，包括边框合并和样式设置
  • 表单样式：了解了如何美化各种表单元素，包括输入框、按钮和选择器

9.2 重点记忆

🎯 核心要点

1. 使用HSL颜色模式更便于调整颜色明暗和饱和度

2. 行高推荐使用无单位数值，如1.5

3. 响应式设计优先使用rem和视口单位

4. 边框样式使用简写属性border更高效

5. 表格样式首先设置border-collapse: collapse
