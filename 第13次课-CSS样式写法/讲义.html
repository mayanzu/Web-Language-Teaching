一、CSS基础概念

CSS（Cascading Style Sheets，层叠样式表）是一种用于描述HTML文档外观和格式的样式语言。它定义了网页元素如何在屏幕上显示，包括颜色、字体、间距、布局等。

1.1 CSS的核心作用

  • 美化网页：为HTML元素添加颜色、字体、背景等样式
  • 内容与表现分离：HTML负责结构，CSS负责样式，便于维护和修改
  • 样式复用：一份CSS可以应用到多个页面，实现统一风格
  • 响应式设计：根据不同设备屏幕尺寸调整样式

1.2 CSS的基本工作原理

CSS通过选择器找到HTML中的元素，然后为这些元素应用样式规则。

/* CSS语法结构 */
选择器 {  /* 选择要样式化的HTML元素 */
    属性1: 值1;  /* 样式规则1 */
    属性2: 值2;  /* 样式规则2 */
    /* 这是CSS注释 */
}

1.3 CSS的基本语法规则

CSS语法要点
  • CSS规则由选择器和声明块组成
  • 声明块用花括号{}包裹
  • 每个声明由属性和值组成，用冒号:分隔
  • 多个声明之间用分号;分隔
  • CSS注释以/*开头，以*/结尾

二、CSS注释

CSS注释用于解释CSS代码，提高代码的可读性和可维护性。浏览器会忽略注释内容，不会将其渲染到页面上。

2.1 CSS注释的语法

/* 这是一个单行CSS注释 */

/* 这是一个
   多行CSS注释 */

p {
    color: red; /* 这是一个行内注释，说明颜色属性 */
    font-size: 16px;
}

2.2 CSS注释的使用建议

  • 为复杂的CSS规则添加注释说明
  • 使用注释分隔不同功能的样式区块
  • 在CSS文件开头添加注释，说明文件用途和作者信息
  • 避免过度注释，只注释必要的内容

三、内联样式

内联样式是直接在HTML元素的style属性中定义的CSS样式，是CSS样式应用的最直接方式。

3.1 内联样式的语法

<!DOCTYPE html>
<html lang="zh-CN">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>内联样式示例</title>
</head>
<body>
    <h1 style="color: blue; text-align: center;">这是一个蓝色居中的标题</h1>
    <p style="color: red; font-size: 18px;">这是一个红色、18像素的段落。</p>
    <div style="background-color: yellow; padding: 20px;">
        这是一个黄色背景、带有内边距的div元素。
    </div>
</body>
</html>

3.2 内联样式的特点

  • 优先级最高：内联样式会覆盖其他样式写法
  • 作用范围小：仅作用于当前HTML元素
  • 编写简单：直接在元素上添加，无需额外文件
  • 样式与结构混合：不利于维护和修改
  • 复用性差：无法在多个元素间共享样式

3.3 内联样式的适用场景

内联样式适用于以下场景：

  • 需要为单个元素应用特殊样式
  • 调试样式时临时添加
  • 动态生成的内容需要添加样式
注意事项

在实际开发中，应尽量避免使用内联样式，因为它违反了内容与表现分离的原则，不利于样式的维护和复用。

四、内部样式表

内部样式表是将CSS样式定义在HTML文档的head标签中，使用style标签包裹。这种方式将样式与结构分离到同一文件的不同部分，比内联样式更有利于维护。

4.1 内部样式表的语法

<!DOCTYPE html>
<html lang="zh-CN">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>内部样式表示例</title>
    <style>
        /* 这是CSS注释 */
        /* 为body元素设置样式 */
        body {
            font-family: Arial, sans-serif;
            background-color: #f5f5f5;
            color: #333;
        }
        
        /* 为h1元素设置样式 */
        h1 {
            color: green;
            text-align: center;
        }
        
        /* 为p元素设置样式 */
        p {
            color: blue;
            font-size: 18px;
            line-height: 1.6;
        }
        
        /* 为class="highlight"的元素设置样式 */
        .highlight {
            background-color: yellow;
            padding: 5px;
        }
    </style>
</head>
<body>
    <h1>内部样式表示例</h1>
    <p>这是一个使用内部样式表的段落。</p>
    <p class="highlight">这是一个带有高亮样式的段落。</p>
</body>
</html>

4.2 内部样式表的特点

  • 样式与结构分离：样式集中管理，便于维护
  • 作用范围：仅作用于当前HTML文档
  • 样式复用：可以在同一文档内复用样式
  • 支持CSS高级特性：可以使用伪类、伪元素、媒体查询等

4.3 内部样式表的适用场景

内部样式表适用于以下场景：

  • 单页面网站
  • 测试和调试样式
  • 需要在HTML文件中包含所有内容的场景
最佳实践

1. 始终将style标签放在head标签中

2. 使用CSS注释组织样式，提高可读性

3. 按逻辑顺序组织样式，便于查找和修改

五、外部样式表

外部样式表是将CSS样式定义在一个独立的.css文件中，然后通过link标签在HTML文档中引入。这是Web开发中最常用的样式应用方式，也是内容与表现分离的最佳实践。

5.1 外部样式表的使用步骤

  1. 创建一个扩展名为.css的样式文件
  2. 在.css文件中编写CSS样式规则
  3. 在HTML文档的head标签中使用link标签引入.css文件

5.2 外部样式表示例

步骤1：创建CSS文件（style.css）

/* style.css - 外部样式表文件 */

/* 为body元素设置样式 */
body {
    font-family: Arial, sans-serif;
    background-color: #f0f0f0;
    color: #333;
}

/* 为h1元素设置样式 */
h1 {
    color: #2c3e50;
    text-align: center;
}

/* 为p元素设置样式 */
p {
    font-size: 16px;
    line-height: 1.5;
    margin: 10px;
}

/* 为class="box"的元素设置样式 */
.box {
    background-color: white;
    padding: 20px;
    margin: 10px;
    border: 1px solid #ddd;
    border-radius: 5px;
}

/* 为class="highlight"的元素设置样式 */
.highlight {
    background-color: yellow;
    padding: 5px;
}

步骤2：在HTML中引入CSS文件

<!DOCTYPE html>
<html lang="zh-CN">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>外部样式表示例</title>
    
    <link rel="stylesheet" href="style.css">
</head>
<body>
    <div class="box">
        <h1>外部样式表示例</h1>
        <p>这是一个使用外部样式表的段落。</p>
        <p class="highlight">这是一个带有高亮样式的段落。</p>
    </div>
</body>
</html>

5.3 外部样式表的特点

  • 内容与表现完全分离：HTML负责结构，CSS负责样式
  • 样式复用：一份CSS文件可以应用到多个HTML页面
  • 浏览器缓存：CSS文件会被浏览器缓存，提高页面加载速度
  • 便于维护：修改一处样式，所有引用该文件的页面都会更新
  • 支持所有CSS特性：可以使用伪类、伪元素、媒体查询等高级特性

5.4 外部样式表的适用场景

外部样式表是Web开发中最常用的样式写法，适用于：

  • 多页面网站
  • 大型Web应用
  • 需要统一风格的网站
  • 团队协作开发
最佳实践

1. 使用有意义的文件名，如style.css、main.css等

2. 将CSS文件放在专门的css目录中，便于管理

3. 按功能组织CSS代码，如先重置样式，再基础样式，最后组件样式

4. 使用CSS注释分隔不同功能的样式区块

六、样式优先级

当一个HTML元素应用了多种样式时，CSS会根据特定的优先级规则来决定最终应用哪个样式。理解样式优先级对于调试和维护CSS代码至关重要。

6.1 优先级的基本规则

CSS样式优先级从高到低的顺序：

  1. !important声明：可以覆盖任何其他样式
  2. 内联样式：直接写在元素的style属性中
  3. ID选择器：以#开头，如#header
  4. 类选择器：以.开头，如.highlight
  5. 元素选择器：如div、p、h1
  6. 浏览器默认样式：浏览器内置的样式表

6.2 优先级示例

<!DOCTYPE html>
<html lang="zh-CN">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>样式优先级示例</title>
    <style>
        /* 元素选择器 */
        p {
            color: blue;
            font-size: 16px;
        }
        
        /* 类选择器 */
        .highlight {
            color: green;
        }
        
        /* ID选择器 */
        #special {
            color: red;
        }
    </style>
</head>
<body>
    <p>蓝色文本（元素选择器）</p>
    <p class="highlight">绿色文本（类选择器）</p>
    <p class="highlight" id="special">红色文本（ID选择器）</p>
    <p class="highlight" id="special" style="color: purple;">紫色文本（内联样式）</p>
</body>
</html>

6.3 !important声明

!important声明可以覆盖任何其他样式，包括内联样式。它的语法是在属性值后添加!important：

p {
    color: red !important; /* 优先级最高 */
    font-size: 16px;
}
!important使用建议

尽量避免使用!important，因为它会破坏CSS的正常优先级规则，导致样式难以维护。只有在特殊情况下，如覆盖第三方库样式时，才考虑使用。

6.4 优先级的最佳实践

最佳实践

1. 优先使用类选择器，避免过度依赖ID选择器

2. 保持选择器简单，避免复杂的嵌套选择器

3. 合理组织样式顺序，后定义的样式会覆盖先定义的相同优先级样式

4. 尽量避免使用!important

七、CSS常用单位

CSS属性值可以使用多种单位，不同的单位适用于不同的场景。

7.1 常用长度单位

单位描述示例
px 像素，固定单位，最常用 font-size: 16px;
em 相对单位，相对于父元素的字体大小 font-size: 1.2em;
rem 相对单位，相对于根元素（html）的字体大小 font-size: 1.2rem;
% 百分比，相对于父元素的宽度或高度 width: 50%;
vw 视口宽度的1% width: 50vw;
vh 视口高度的1% height: 50vh;

7.2 单位使用建议

最佳实践

1. 字体大小建议使用rem或em，便于响应式调整

2. 固定尺寸使用px，如边框宽度、内边距等

3. 百分比常用于宽度设置，实现自适应布局

4. vw/vh用于视口相关的响应式设计

八、CSS最佳实践

遵循CSS最佳实践可以提高代码质量、可读性和可维护性，确保样式代码易于理解和修改。

8.1 CSS命名规范

使用一致的命名规范可以提高CSS代码的可读性和可维护性。对于初学者，推荐使用简单易懂的命名方式，如描述性类名。

8.2 常见的CSS命名规范

  • 描述性命名：使用能够描述元素用途的类名，如 .header, .nav-bar, .button-primary
  • BEM命名法：Block__Element--Modifier格式，如 .card__title--large（适合大型项目）
  • 驼峰命名：如 .mainContent, .navItem（较少使用）

8.3 CSS代码组织

合理组织CSS代码可以提高可维护性：

  • 按功能或组件组织样式
  • 使用注释分隔不同的样式区块
  • 将相关样式放在一起
  • 先定义通用样式，再定义特殊样式

8.4 基础最佳实践

核心最佳实践
  • 使用外部样式表：将样式与结构分离，便于维护
  • 优先使用类选择器：比ID选择器更灵活，比元素选择器更具体
  • 保持选择器简单：避免复杂的嵌套选择器，如 div ul li a
  • 避免使用!important：它会破坏样式的正常优先级
  • 使用CSS变量：统一管理颜色、字体等样式值
  • 为图片添加max-width: 100%：确保图片响应式
  • 使用box-sizing: border-box：简化盒模型计算

8.5 CSS Reset和Normalize.css

不同浏览器对HTML元素有不同的默认样式，可以使用CSS Reset或Normalize.css来消除这些差异：

  • CSS Reset：完全重置浏览器默认样式，如 * { margin: 0; padding: 0; }
  • Normalize.css：保留有用的默认样式，同时消除浏览器差异
