第3课：HTML列表

欢迎来到HTML列表的学习！列表是网页中常用的内容组织方式，它可以使内容更加结构化、清晰易读。HTML提供了三种主要的列表类型：无序列表、有序列表和定义列表。

无序列表 有序列表 定义列表 列表嵌套 列表语法 列表应用

一、无序列表

无序列表用于展示一组没有特定顺序的项目，每个项目前面会显示一个默认的项目符号（通常是圆点）。

生活类比

无序列表就像超市购物清单：

  • 你可以按任意顺序购买清单上的物品
  • 牛奶、面包、鸡蛋——先买哪个都可以
  • 重要的是"买什么"，而不是"先买什么"

所以当你的内容没有顺序要求时，就用无序列表！

1.1 无序列表的基本语法

无序列表使用<ul>标签定义，列表中的每个项目使用<li>标签定义。

标签 英文全称 作用
<ul> Unordered List 定义无序列表的容器
<li> List Item 定义列表中的每一项
示例：无序列表基本语法 只读 
<ul>
    <li>苹果</li>
    <li>香蕉</li>
    <li>橙子</li>
    <li>葡萄</li>
</ul>

1.2 无序列表的默认样式

无序列表的默认项目符号会根据嵌套层级自动变化：

嵌套层级 默认符号 CSS值 (list-style-type)
第一层 ● 实心圆点 disc
第二层 ○ 空心圆圈 circle
第三层 ■ 实心方块 square
样式自定义

虽然可以使用CSS的list-style-type属性自定义项目符号，但在纯HTML阶段，我们先了解默认行为。更多自定义将在CSS课程中学习。

1.3 无序列表的使用场景

无序列表适用于展示没有特定顺序的项目，常见的使用场景包括：

使用场景 示例 为什么用无序列表
商品分类 电子产品、服装、食品 分类没有先后之分
功能特性 产品的多个卖点 特性并列展示，无主次
导航菜单 首页、关于、联系 链接地位平等
标签列表 文章的分类标签 标签无顺序要求
常见错误
  • 忘记闭合标签：每个<li>都需要闭合
  • 直接放文本：<ul>内只能放<li>，不能直接放文本
  • 不缩进代码：虽不影响显示，但影响代码可读性
<!--  错误：直接放文本 -->
<ul>
    苹果
    香蕉
</ul>

<!--  正确：使用li包裹 -->
<ul>
    <li>苹果</li>
    <li>香蕉</li>
</ul>

二、有序列表

有序列表用于展示一组有特定顺序的项目，每个项目前面会显示一个默认的数字（通常是阿拉伯数字）。

生活类比

有序列表就像菜谱的制作步骤：

  • 第1步：准备食材
  • 第2步：切菜
  • 第3步：下锅炒
  • 第4步：出锅装盘

顺序很重要！不能先炒菜再切菜。当你的内容有顺序要求时，就用有序列表！

2.1 有序列表的基本语法

有序列表使用<ol>标签定义，列表中的每个项目同样使用<li>标签定义。

标签 英文全称 作用
<ol> Ordered List 定义有序列表的容器
<li> List Item 定义列表中的每一项
示例：有序列表基本语法 只读 
<ol>
    <li>收集材料</li>
    <li>准备工具</li>
    <li>开始制作</li>
    <li>完成作品</li>
</ol>

2.2 有序列表的HTML属性

HTML提供了一些属性来控制有序列表的行为：

属性 描述 示例 效果
start 指定起始编号 <ol start="5"> 从5开始编号
reversed 反转编号顺序 <ol reversed> 从大到小排列
type 编号类型 <ol type="A"> 使用字母编号

2.3 编号类型详解

type属性支持多种编号类型：

type值 编号类型 显示效果
1 阿拉伯数字（默认） 1, 2, 3, 4...
A 大写字母 A, B, C, D...
a 小写字母 a, b, c, d...
I 大写罗马数字 I, II, III, IV...
i 小写罗马数字 i, ii, iii, iv...
示例：有序列表属性应用 只读 
<!-- 从第5名开始的排名 -->
<ol start="5">
    <li>第五名：张三</li>
    <li>第六名：李四</li>
</ol>

<!-- 倒计时效果 -->
<ol reversed>
    <li>出发！</li>
    <li>准备</li>
    <li>预备</li>
</ol>

<!-- 使用字母编号的考试选项 -->
<ol type="A">
    <li>HTML</li>
    <li>CSS</li>
    <li>JavaScript</li>
    <li>Python</li>
</ol>

2.4 有序列表的使用场景

有序列表适用于展示有特定顺序的项目，常见的使用场景包括：

使用场景 示例 为什么用有序列表
操作步骤 安装软件的步骤 步骤必须按顺序执行
排名列表 销售排行榜 名次有先后之分
食谱步骤 做菜的制作过程 工序顺序不能乱
法律条款 合同条款1、2、3 条款需要编号引用
选择技巧：有序还是无序？

问自己一个问题："如果打乱顺序，内容还有意义吗？"

  • 如果打乱后意义不变 → 使用无序列表（如购物清单）
  • 如果打乱后意义改变 → 使用有序列表（如操作步骤）

三、定义列表

定义列表用于展示一组术语及其定义，类似于字典的条目。它是三种列表类型中结构最特殊的一种。

生活类比

定义列表就像一本词典或百科全书：

  • 词条（dt）：你要查找的词语
  • 解释（dd）：这个词语的含义

比如查"HTML"这个词，词典会告诉你它是"超文本标记语言"。

3.1 定义列表的基本语法

定义列表使用<dl>标签定义，术语使用<dt>标签定义，术语的定义使用<dd>标签定义。

标签 英文全称 作用
<dl> Definition List 定义列表的容器
<dt> Definition Term 定义术语/名词
<dd> Definition Description 定义术语的解释/描述
示例：定义列表基本语法 只读 
<dl>
    <dt>HTML</dt>
    <dd>超文本标记语言，用于创建网页的结构</dd>
    
    <dt>CSS</dt>
    <dd>层叠样式表，用于控制网页的样式</dd>
    
    <dt>JavaScript</dt>
    <dd>脚本语言，用于为网页添加交互功能</dd>
</dl>

3.2 定义列表的特殊用法

定义列表有一些灵活的用法：

用法 说明 示例场景
一个dt对应多个dd 一个术语有多个定义或解释 一词多义的词条
多个dt对应一个dd 多个术语共享一个定义 同义词解释
dd可以包含其他元素 解释部分可以包含段落、列表等 复杂的产品说明
示例：定义列表的特殊用法 只读 
<!-- 一个术语多个定义 -->
<dl>
    <dt>打开</dt>
    <dd>使关闭着的东西不再关闭（打开门窗）</dd>
    <dd>拆开、展开（打开包裹）</dd>
    <dd>使开始运转（打开电视）</dd>
</dl>

<!-- 多个术语一个定义（同义词） -->
<dl>
    <dt>HTML</dt>
    <dt>超文本标记语言</dt>
    <dd>一种用于创建网页的标准标记语言</dd>
</dl>

3.3 定义列表的使用场景

定义列表适用于展示术语及其定义，常见的使用场景包括：

使用场景 dt内容 dd内容
词汇表/术语表 专业术语 术语的定义
常见问题(FAQ) 问题 答案
产品规格 参数名（如"尺寸"） 参数值（如"10×20cm"）
联系方式 联系类型（如"电话"） 具体信息（如"12345678"）
元数据展示 标签名（如"作者"） 值（如"张三"）
定义列表 vs 表格

有些场景定义列表和表格都能实现，如何选择？

  • 用定义列表：数据是"名称-描述"的关系，一对一或一对多
  • 用表格：数据是规整的多列结构，有明确的行列关系

四、列表嵌套

在HTML中，我们可以将一个列表嵌套在另一个列表中，创建复杂的层级结构。这是组织复杂内容的重要方式。

生活类比

列表嵌套就像文件夹的结构：

  • 文档（一级文件夹）
    • 工作文档（二级文件夹）
    • 个人文档（二级文件夹）

大分类下面可以有小分类，小分类下面还可以有更细的分类。

4.1 嵌套列表的基本语法

列表嵌套是指在一个列表项内部再创建一个完整的列表。嵌套列表可以是相同类型的列表，也可以是不同类型的列表。

嵌套位置注意

嵌套的子列表必须放在<li>标签内部，而不是<li>标签之后！

<!--  错误：子列表放在li外面 -->
<ul>
    <li>水果</li>
    <ul>
        <li>苹果</li>
    </ul>
</ul>

<!--  正确：子列表放在li里面 -->
<ul>
    <li>水果
        <ul>
            <li>苹果</li>
        </ul>
    </li>
</ul>
示例：嵌套列表基本语法 只读 
<ul>
    <li>水果
        <ul>
            <li>苹果</li>
            <li>香蕉</li>
            <li>橙子</li>
        </ul>
    </li>
    <li>蔬菜
        <ul>
            <li>西红柿</li>
            <li>黄瓜</li>
            <li>土豆</li>
        </ul>
    </li>
</ul>

4.2 不同类型列表的嵌套

我们也可以将不同类型的列表嵌套在一起，例如将有序列表嵌套在无序列表中，或者将无序列表嵌套在有序列表中。

嵌套组合 适用场景 示例
ul 嵌套 ul 多级分类 商品分类导航
ol 嵌套 ol 多级步骤 详细操作指南
ol 嵌套 ul 有序主题含无序细节 课程大纲（章节-知识点）
ul 嵌套 ol 无序分类含有序步骤 多个产品各自的使用步骤
示例：不同类型列表的嵌套 只读 
<ol>
    <li>HTML基础
        <ul>
            <li>HTML文档结构</li>
            <li>HTML标签</li>
            <li>HTML属性</li>
        </ul>
    </li>
    <li>CSS基础
        <ul>
            <li>CSS选择器</li>
            <li>CSS属性</li>
            <li>CSS盒模型</li>
        </ul>
    </li>
</ol>

4.3 嵌套层级建议

最佳实践
  • 层级不超过3层：过深的嵌套会降低可读性
  • 保持缩进：每层缩进2-4个空格，便于阅读
  • 语义清晰：嵌套的子列表应该与父级内容有明确的从属关系
  • 考虑移动端：在小屏幕上，多层嵌套可能不够友好

4.4 三种列表对比总结

对比项 无序列表 ul 有序列表 ol 定义列表 dl
默认标记 圆点符号 数字编号 无标记
子元素 li li dt + dd
顺序重要 否 是 否
典型场景 导航、分类 步骤、排名 术语、FAQ

本课小结

知识点回顾

恭喜你！今天你学会了HTML列表的使用：

  • 无序列表：使用<ul>和<li>标签，用于展示没有特定顺序的项目
  • 有序列表：使用<ol>和<li>标签，用于展示有特定顺序的项目
  • 定义列表：使用<dl>、<dt>和<dd>标签，用于展示术语及其定义
  • 列表嵌套：可以在一个列表内部嵌套另一个列表，创建复杂的列表结构
  • 列表属性：了解了start和reversed等属性的使用

重点记忆

列表类型 标签 用途
无序列表 <ul> + <li> 展示没有特定顺序的项目
有序列表 <ol> + <li> 展示有特定顺序的项目
定义列表 <dl> + <dt> + <dd> 展示术语及其定义

最佳实践

HTML列表编写建议
  • 根据内容的性质选择合适的列表类型
  • 保持列表项简洁，每个列表项只包含一个核心概念
  • 合理使用列表嵌套，避免嵌套层级过深（建议不超过3层）
  • 为列表添加适当的标题，明确列表的用途
  • 保持列表项的一致性，使用相同的语法结构和标点符号
