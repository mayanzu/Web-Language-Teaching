第25课：JS运算符与表达式

上一课我们学会了用变量存储数据，但静态的数据毫无用处。本课我们将学习如何使用“运算符”来处理、比较和组合这些数据，创造出能产生动态结果的“表达式”。这是构建所有复杂逻辑的基石。

赋值 = += -= 算术 + - * / % 比较 > < === !== 逻辑 && || ! 优先级 类型转换
今日目标 适合初学者
  • 理解“表达式”和“语句”的核心区别。
  • 熟练使用赋值、算术、比较和逻辑运算符。
  • 解释并始终选择 === 而不是 ==。
  • 掌握 ++, --, 和 % (取余) 的实用场景。

  • 了解运算符的优先级，并学会用括号 () 保证运算顺序。

表达式与语句：有何不同？

在编程中，我们需要区分两个核心概念：表达式（Expression）和语句（Statement）。

  • 表达式 (Expression): 任何可以被计算并产生一个值的代码片段。可以把它想象成一个数学式子，它总会得出一个结果。
  • 语句 (Statement): 指示计算机执行一个动作的完整指令。可以把它想象成一个完整的句子，它命令计算机“做某事”。
类型示例核心特征好记的判断方法

age >= 18		 总能“算”出一个值 能放在 console.log() 里打印出来的东西。
语句 let name = 'Alice';

💡 一个简单的类比

在句子“我买了 两个苹果”中，“两个苹果”就像一个表达式（它指向一个具体的值），而整个句子就像一条语句（它描述了一个完整的动作）。
在 JavaScript 中，let price = 9.9 * 2; 是一条语句，而其中的 9.9 * 2 是一个表达式。

1. 赋值运算符：给变量存入数据

赋值运算符是我们最早接触的运算符，它的作用就是把右边的值存入左边的变量中。

运算符名称等价于示例
=赋值-let x = 10;
+=加法赋值x = x + yx += 5; (x 变为 15)
-=减法赋值x = x - yx -= 3; (x 变为 12)
*=乘法赋值x = x * yx *= 2; (x 变为 24)
/=除法赋值x = x / yx /= 4; (x 变为 6)
%=取余赋值x = x % yx %= 5; (x 变为 1)
为什么需要复合赋值？

它们是代码的“简写形式”，在对一个变量自身进行更新时非常有用，例如累加分数、计算总价等。这让代码更简洁、意图更明确。

let score = 100;
// 敌人攻击，分数减少 10
score -= 10; // 等价于 score = score - 10;
console.log(score); // 90

// 捡到道具，分数增加 20
score += 20; // 等价于 score = score + 20;
console.log(score); // 110

3. 一元运算符：对单个值操作

一元运算符只需要一个操作数。它们通常用于增加、减少数值或改变值的正负。

运算符名称示例说明
++递增x++ 或 ++x将变量的值加 1。
--递减x-- 或 --x将变量的值减 1。
+一元加+'3'尝试将操作数转换为数字。结果为 3。
-一元减-x取操作数的负值。
💡 x++ 和 ++x 的区别

虽然它们都将 x 的值加 1，但在表达式中的行为不同：

  • 后递增 (x++): 先返回 x 的原始值，然后再加 1。
  • 前递增 (++x): 先将 x 加 1，然后返回新值。
let a = 5;
console.log(a++); // 打印 5, 然后 a 变为 6

let b = 5;
console.log(++b); // b 变为 6, 然后打印 6

建议：为避免混淆，初学阶段最好将 x++; 或 x--; 作为独立的语句使用，而不是在复杂的表达式中。

4. 比较运算符：比较两个值

比较运算符用于比较两个值，并返回一个布尔值（true 或 false）。这是实现条件判断（如 if 语句）的基础。

运算符含义示例结果
>大于10 > 5true
<小于10 < 5false
>=大于或等于5 >= 5true
<=小于或等于5 <= 4false
字符串比较

当比较两个字符串时，JavaScript 会按字典顺序（类似查字典）逐个比较字符的编码。

console.log('a' < 'b');      // true
console.log('apple' < 'banana'); // true
console.log('2' > '10');     // true, 因为 '2' 的字典序大于 '1'

这就是为什么直接比较数字字符串可能会得到意外结果的原因。在比较大小前，最好先将它们转换为数字。

5. 相等运算符：判断是否相等 (== vs ===)

这是 JavaScript 中一个极其重要的知识点。我们有两种方式判断相等，但你应该始终使用 ===。

运算符名称比较方式示例结果
==相等只比较值，如果类型不同会尝试转换'18' == 18true
===严格相等同时比较值和类型，不做转换'18' === 18false
!=不等== 的反面'18' != 18false
!==严格不等=== 的反面'18' !== 18true
为什么必须用 ===？

== 的自动类型转换规则复杂且不直观，是许多常见错误的根源。例如 0 == false 是 true，'' == false 也是 true。而 === 的行为完全符合预期，让代码更可靠、更易读。

养成习惯：从第一天起，就只用 === 和 !==。

6. 逻辑运算符：组合多个条件

逻辑运算符用于组合或反转布尔值，常用于创建复杂的判断逻辑。

运算符名称含义示例
&&逻辑与 (AND)两边都为 true，结果才为 trueage >= 18 && hasTicket (已成年且有票)
||逻辑或 (OR)只要有一边为 true，结果就为 trueisVIP || isStaff (是VIP或是员工)
!逻辑非 (NOT)取反，true 变 false，false 变 true!isLoggedIn (未登录)

短路求值 (Short-circuiting)

这是逻辑运算符的一个关键特性：如果仅通过左边的表达式就能确定整个表达式的结果，那么右边的表达式将不会被执行。

  • 对于 &&: 如果左边是 false，整个表达式必为 false，右边不执行。
  • 对于 ||: 如果左边是 true，整个表达式必为 true，右边不执行。
function check() {
  console.log('函数被执行了！');
  return true;
}

// && 短路
false && check(); // 左边是 false，右边的 check() 不会执行，控制台无输出

// || 短路
true || check(); // 左边是 true，右边的 check() 不会执行，控制台无输出
💡 短路求值的妙用

1. 条件执行: 替代简单的 if 语句。

isAllowed && grantAccess(); // 仅当 isAllowed 为 true 时才执行 grantAccess()

2. 提供默认值: 这是一个非常常见的技巧。

const name = receivedName || 'Guest'; // 如果 receivedName 是空字符串或 null，则 name 为 'Guest'

7. 运算符优先级

当一个表达式中包含多个不同的运算符时，JavaScript 会按照一个预设的顺序（即“优先级”）来执行它们。这和我们小学学的“先乘除后加减”是一个道理。

你不需要背下完整的优先级表，但需要记住几个关键规则：

优先级 (从高到低)运算符类别示例
最高括号 ()(1 + 2) * 3 (括号总是最先)
高一元运算符 (++, --, !)!true && false (!true 先算)
中高算术 (先 **, 再 * / %, 最后 + -)5 + 2 * 3 (2 * 3 先算)
中比较运算符 (>, <)3 > 2 && 1 > 0 (3 > 2 先算)
中低相等运算符 (===, !==)a > b === true (a > b 先算)
低逻辑运算符 (先 &&, 后 ||)isVIP || age > 18 && hasTicket (&& 先算)
最低赋值运算符 (=, +=)x = 5 + 3 (右边全部算完再赋值)
💡 终极法则：不确定就加括号！

编写代码时，清晰性远比炫技重要。如果你不确定运算顺序，或者想让代码的意图更明显，请毫不犹豫地使用括号 ()。

// 不清晰的写法
const isValid = age >= 18 && age <= 65 || isVIP;

// 清晰的写法
const isAdult = age >= 18 && age <= 65;
const isValid = isAdult || isVIP;

// 或者使用括号
const isValid = (age >= 18 && age <= 65) || isVIP;

8. 隐式类型转换 (Implicit Coercion)

当运算符两边的操作数类型不同时，JavaScript 引擎会自动尝试将它们转换为相同的类型，这个过程就叫“隐式类型转换”。这是 JavaScript 灵活性的体现，但也是许多错误的来源。

常见转换场景

  • + 运算符: 一边是字符串，另一边会被转换成字符串进行拼接。
  • -, *, /, % 运算符: 操作数会被转换成数字进行计算。
  • 逻辑判断: 在 if 或逻辑运算中，非布尔值会被转换成布尔值。
// 减法 -> 转数字
console.log('10' - 5); // 5 (字符串 '10' 被转为数字 10)

// 加法 -> 转字符串
console.log('10' + 5); // "105" (数字 5 被转为字符串 '5')

// 逻辑判断 -> 转布尔
if ('hello') { // 字符串 'hello' 被转为 true
    console.log('This will run');
}
if (0) { // 数字 0 被转为 false
    console.log('This will NOT run');
}
如何避免转换陷阱？
  • 始终使用 === 和 !== 进行比较。
  • 在进行数学运算前，确保你的变量是数字类型。可以使用 Number() 或 parseInt() 进行显式转换。
  • 了解哪些值会转换为 false：0, "" (空字符串), null, undefined, NaN。其他所有值都转换为 true。

9. 综合案例与本课小结

综合案例：商品折扣计算

假设一个场景：计算一件商品在不同优惠活动下的最终价格。

const originalPrice = 120; // 商品原价
const memberDiscount = 0.8;  // 会员折扣 8折
const couponValue = 10;      // 优惠券减10元

const isMember = true;
const hasCoupon = false;

// 计算会员价 (如果不是会员，价格不变)
// 这里用了逻辑与的短路特性，如果 isMember 是 false，右边不执行
let priceAfterDiscount = originalPrice;
isMember && (priceAfterDiscount *= memberDiscount); // 相当于 if(isMember){ priceAfterDiscount *= memberDiscount }

// 计算用券价 (如果有券，再减去券额)
hasCoupon && (priceAfterDiscount -= couponValue);

// 最终价格不能低于 0
const finalPrice = priceAfterDiscount < 0 ? 0 : priceAfterDiscount;

// toFixed()方法：将数字格式化为指定小数位数的字符串
// 参数指定保留几位小数，这里保留2位小数
console.log('最终价格: ' + finalPrice.toFixed(2));
// 例如：如果finalPrice是99.9，输出"最终价格: 99.90"

本课小结

  • 表达式产生值，语句执行动作。
  • 赋值运算符 (=, +=) 用于更新变量。
  • 算术运算符 (+, -, *, /, %) 用于数学计算，注意 + 的拼接功能。
  • 比较运算符 (>, <) 和 相等运算符 (===, !==) 产生布尔值，是逻辑判断的基础。始终用 ===。
  • 逻辑运算符 (&&, ||, !) 用于组合条件，它们的短路特性非常有用。
  • 当不确定运算顺序时，使用括号 () 来明确意图。
