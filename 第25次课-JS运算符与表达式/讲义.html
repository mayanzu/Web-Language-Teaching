第25课：JS运算符与表达式

上一课我们学会了用变量存储数据，但静态的数据毫无用处。本课我们将学习如何使用"运算符"来处理、比较和组合这些数据，创造出能产生动态结果的"表达式"。这是构建所有复杂逻辑的基石。

一、表达式与语句

在编程中，我们需要区分两个核心概念：表达式（Expression）和语句（Statement）。

类型 示例 核心特征 判断方法
表达式 3.14
score
1 + 2
age >= 18		 总能"算"出一个值 能放在 console.log() 里打印的东西
语句 let name = 'Alice';
if (x > 0) { ... }		 执行一个动作 通常以分号 ; 结尾的完整指令
一个简单的类比

在句子"我买了 两个苹果"中，"两个苹果"就像一个表达式（它指向一个具体的值），而整个句子就像一条语句（它描述了一个完整的动作）。

在 JavaScript 中，let price = 9.9 * 2; 是一条语句，而其中的 9.9 * 2 是一个表达式。

二、赋值运算符

赋值运算符的作用是把右边的值存入左边的变量中。除了基础赋值，还有一系列"复合赋值"运算符。

运算符 名称 等价于 示例
= 赋值 - let x = 10;
+= 加法赋值 x = x + y x += 5; (x 变为 15)
-= 减法赋值 x = x - y x -= 3; (x 变为 12)
*= 乘法赋值 x = x * y x *= 2; (x 变为 24)
/= 除法赋值 x = x / y x /= 4; (x 变为 6)
%= 取余赋值 x = x % y x %= 5; (x 变为 1)
为什么需要复合赋值？

复合赋值是代码的"简写形式"，在对变量自身进行更新时非常有用。例如累加分数、计算总价等场景。

let score = 100;

// 敌人攻击，分数减少 10
score -= 10;  // 等价于 score = score - 10;
console.log(score);  // 90

// 捡到道具，分数增加 20
score += 20;  // 等价于 score = score + 20;
console.log(score);  // 110

三、算术运算符

算术运算符用于对数字进行基础的数学运算，是最常用的运算符类型。

运算符 含义 示例 结果 关键点
+ 加法 10 + 5 15 也可用于字符串拼接
- 减法 10 - 5 5 -
* 乘法 10 * 5 50 -
/ 除法 10 / 5 2 结果可为浮点数 (5 / 2 是 2.5)
% 取余 (模) 10 % 3 1 常用于判断奇偶、循环等
** 幂 10 ** 2 100 计算一个数的N次方
注意 + 的双重身份！

当 + 的两边至少有一个是字符串时，它会执行"拼接"操作，而不是数学加法。

console.log(1 + 2);           // 3 (数字 + 数字 → 数学加法)
console.log('a' + 'b');       // "ab" (字符串 + 字符串 → 拼接)
console.log('Score: ' + 100); // "Score: 100" (字符串 + 数字 → 拼接)

3.1 取余运算符的妙用

取余运算符 % 返回除法的余数，在实际编程中有很多妙用：

取余运算符应用示例 只读 
// 1. 判断奇偶数
let num = 7;
if (num % 2 === 0) {
    console.log('偶数');
} else {
    console.log('奇数');  // 输出: 奇数
}

// 2. 循环计数（如轮播图）
let index = 0;
const total = 5;  // 共5张图片
index = (index + 1) % total;  // 0 → 1 → 2 → 3 → 4 → 0 → 1 ...

// 3. 判断能否整除
console.log(100 % 25 === 0);  // true，100能被25整除
console.log(100 % 30 === 0);  // false，100不能被30整除

四、一元运算符

一元运算符只需要一个操作数。它们通常用于增加、减少数值或改变值的正负。

运算符 名称 示例 说明
++ 递增 x++ 或 ++x 将变量的值加 1
-- 递减 x-- 或 --x 将变量的值减 1
+ 一元加 +'3' 尝试将操作数转换为数字，结果为 3
- 一元减 -x 取操作数的负值
x++ 和 ++x 的区别

虽然它们都将 x 的值加 1，但在表达式中的行为不同：

  • 后递增 (x++)：先返回 x 的原始值，然后再加 1
  • 前递增 (++x)：先将 x 加 1，然后返回新值
let a = 5;
console.log(a++);  // 打印 5，然后 a 变为 6

let b = 5;
console.log(++b);  // b 变为 6，然后打印 6

建议：为避免混淆，初学阶段最好将 x++; 或 x--; 作为独立的语句使用。

五、比较运算符

比较运算符用于比较两个值，并返回一个布尔值（true 或 false）。这是实现条件判断的基础。

运算符 含义 示例 结果
> 大于 10 > 5 true
< 小于 10 < 5 false
>= 大于或等于 5 >= 5 true
<= 小于或等于 5 <= 4 false
字符串比较

当比较两个字符串时，JavaScript 会按字典顺序逐个比较字符的编码：

console.log('a' < 'b');       // true
console.log('apple' < 'banana');  // true
console.log('2' > '10');      // true，因为 '2' 的字典序大于 '1'

⚠️ 这就是为什么比较数字字符串时可能得到意外结果。在比较前，最好先转换为数字。

六、相等运算符 (== vs ===)

这是 JavaScript 中一个极其重要的知识点。有两种判断相等的方式，但你应该始终使用 ===。

运算符 名称 比较方式 示例 结果
== 相等 只比较值，类型不同会尝试转换 '18' == 18 true
=== 严格相等 同时比较值和类型，不做转换 '18' === 18 false
!= 不等 == 的反面 '18' != 18 false
!== 严格不等 === 的反面 '18' !== 18 true
为什么必须用 ===？

== 的自动类型转换规则复杂且不直观，是许多常见错误的根源：

// ❌ == 的奇怪行为
console.log(0 == false);       // true
console.log('' == false);      // true
console.log(null == undefined); // true

// ✅ === 的行为符合预期
console.log(0 === false);      // false
console.log('' === false);     // false
console.log(null === undefined); // false

养成习惯：从第一天起，就只用 === 和 !==。

七、逻辑运算符

逻辑运算符用于组合或反转布尔值，常用于创建复杂的判断逻辑。

运算符 名称 含义 示例
&& 逻辑与 (AND) 两边都为 true，结果才为 true age >= 18 && hasTicket
|| 逻辑或 (OR) 只要有一边为 true，结果就为 true isVIP || isStaff
! 逻辑非 (NOT) 取反，true 变 false !isLoggedIn
逻辑运算符真值表 参考
A B A && B A || B !A
true true true true false
true false false true false
false true false true true
false false false false true

7.1 短路求值 (Short-circuiting)

短路求值是逻辑运算符的一个关键特性：如果仅通过左边的表达式就能确定结果，右边的表达式将不会被执行。

运算符 短路条件 说明
&& 左边是 false 整个表达式必为 false，右边不执行
|| 左边是 true 整个表达式必为 true，右边不执行 
function check() {
    console.log('函数被执行了！');
    return true;
}

// && 短路：左边是 false，右边的 check() 不会执行
false && check();  // 控制台无输出

// || 短路：左边是 true，右边的 check() 不会执行
true || check();   // 控制台无输出
短路求值的妙用

1. 条件执行：替代简单的 if 语句

isAllowed && grantAccess();  // 仅当 isAllowed 为 true 时执行

2. 提供默认值：这是非常常见的技巧

const name = receivedName || 'Guest';  // 如果为空则使用默认值

八、运算符优先级

当一个表达式中包含多个不同的运算符时，JavaScript 会按照预设的顺序（即"优先级"）执行。这和"先乘除后加减"是一个道理。

优先级 运算符类别 示例
最高 括号 () (1 + 2) * 3 (括号总是最先)
高 一元运算符 (++, --, !) !true && false
中高 算术 (先 **, 再 * / %, 最后 + -) 5 + 2 * 3
中 比较运算符 (>, <) 3 > 2 && 1 > 0
中低 相等运算符 (===, !==) a > b === true
低 逻辑运算符 (先 &&, 后 ||) a || b && c
最低 赋值运算符 (=, +=) x = 5 + 3
终极法则：不确定就加括号！

编写代码时，清晰性远比炫技重要。如果你不确定运算顺序，请毫不犹豫地使用括号：

// ❌ 不清晰的写法
const isValid = age >= 18 && age <= 65 || isVIP;

// ✅ 清晰的写法（使用变量拆分）
const isAdult = age >= 18 && age <= 65;
const isValid = isAdult || isVIP;

// ✅ 或者使用括号明确意图
const isValid = (age >= 18 && age <= 65) || isVIP;

九、隐式类型转换

当运算符两边的操作数类型不同时，JavaScript 会自动尝试转换类型。这是 JavaScript 灵活性的体现，但也是许多错误的来源。

9.1 常见转换场景

运算符 转换规则 示例 结果
+ 有字符串则拼接 '10' + 5 "105"
- * / 转为数字计算 '10' - 5 5
逻辑运算 转为布尔值 if ('hello') true

9.2 假值 (Falsy Values)

以下值在布尔上下文中会被转换为 false：

JavaScript 中的假值列表 参考 
// 以下值都会被转换为 false
false        // 布尔值 false
0            // 数字零
-0           // 负零
""           // 空字符串
null         // 空值
undefined    // 未定义
NaN          // 非数字

// 其他所有值都转换为 true（包括空数组和空对象！）
[]           // true
{}           // true
"false"      // true（非空字符串）
如何避免转换陷阱？
  • 始终使用 === 和 !== 进行比较
  • 在数学运算前，用 Number() 或 parseInt() 显式转换
  • 了解哪些值会转换为 false，避免意外的判断结果

十一、本课小结

知识点回顾

  • 表达式产生值，语句执行动作
  • 赋值运算符 (=, +=) 用于更新变量
  • 算术运算符 (+, -, *, /, %) 用于数学计算，注意 + 的拼接功能
  • 比较运算符 (>, <) 和 相等运算符 (===, !==) 产生布尔值，始终用 ===
  • 逻辑运算符 (&&, ||, !) 用于组合条件，掌握短路特性
  • 当不确定运算顺序时，使用括号 () 明确意图

重点记忆

运算符类型 核心要点 示例
赋值 复合赋值是简写形式 x += 5 = x = x + 5
算术 + 可拼接字符串 'a' + 1 = 'a1'
相等 始终用严格相等 === 和 !==
逻辑 短路求值提供默认值 name || 'Guest'
