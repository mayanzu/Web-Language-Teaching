第26课：JS控制结构

前面三课，我们学会了存储数据、进行运算和比较。但这些还不够——真正的程序需要能够"做决定"和"重复执行"。本课将学习控制结构：让程序根据条件选择不同的执行路径，或让某段代码重复执行指定次数。这是编程从"计算器"升级为"智能程序"的关键一步。

if / else if / else switch 三元运算符 for 循环 while 循环 break / continue

一、为什么需要控制结构？

到目前为止，我们写的代码都是"从上到下、一行接一行"执行的，这叫做顺序结构。但现实世界的逻辑往往更复杂：

  • 分支逻辑：如果下雨，就带伞；否则，不带伞。
  • 重复逻辑：每天早上都要刷牙、洗脸，重复365天。

在编程中，我们用控制结构来实现这两种逻辑：

控制结构类型 作用 JavaScript 关键字
分支结构 (条件) 根据条件的真假，选择不同的执行路径 if, else, switch
循环结构 (重复) 让某段代码重复执行多次 for, while, do...while
生活中的控制结构
  • 条件：如果成绩>=60，显示"及格"；否则显示"不及格"
  • 循环：发送100封邮件，每封邮件执行相同的发送操作

二、if 语句基础

if 语句是最基础的条件控制。它的语法非常直观：如果条件为真，就执行某段代码。

let temperature = 30;

if (temperature > 25) {
    console.log('今天很热，记得多喝水！');
}
// 输出: 今天很热，记得多喝水！

2.1 语法结构

  • if 关键字后面必须跟一对圆括号 ()，里面是条件表达式
  • 如果条件为 true，就执行花括号 {} 内的代码块
  • 如果条件为 false，花括号内的代码会被跳过
代码块与花括号

虽然当代码块只有一行时可以省略花括号，但强烈建议始终使用花括号，这能避免很多潜在的错误：

// ❌ 不推荐（容易出错）
if (age >= 18) console.log('成年人');

// ✅ 推荐（清晰、安全）
if (age >= 18) {
    console.log('成年人');
}

2.2 if...else：二选一

当我们需要在"条件为真"和"条件为假"时分别执行不同代码时，可以使用 else。

let age = 16;

if (age >= 18) {
    console.log('你是成年人，可以投票。');
} else {
    console.log('你还未成年，暂时不能投票。');
}
// 输出: 你还未成年，暂时不能投票。
if...else 的执行逻辑：

程序会先检查 if 后的条件。如果为 true，执行 if 代码块；如果为 false，执行 else 代码块。两个代码块永远只会执行一个。

2.3 if...else if...else：多重分支

当有多个互斥的条件需要判断时，使用 else if 可以构建多分支逻辑。

let score = 85;

if (score >= 90) {
    console.log('优秀 A');
} else if (score >= 80) {
    console.log('良好 B');
} else if (score >= 70) {
    console.log('中等 C');
} else if (score >= 60) {
    console.log('及格 D');
} else {
    console.log('不及格 F');
}
// 输出: 良好 B
重要特性：互斥执行

if...else if...else 结构中，只有第一个条件为 true 的分支会被执行，后面所有分支都会被跳过，即使它们的条件也为 true：

let num = 15;

if (num > 10) {
    console.log('大于10');  // ✅ 这个会执行
} else if (num > 5) {
    console.log('大于5');   // ❌ 不会执行，虽然条件也为 true
}

三、高级条件判断

3.1 嵌套 if：条件中的条件

有时候，我们需要在一个条件成立后，再检查另一个条件。这时可以使用嵌套的 if 语句：

let age = 20;
let hasLicense = true;

if (age >= 18) {
    console.log('你已成年');
    
    if (hasLicense) {
        console.log('可以开车');
    } else {
        console.log('需要先考驾照');
    }
} else {
    console.log('未成年，不能开车');
}
避免过度嵌套

虽然嵌套 if 很强大，但过深的嵌套会让代码难以阅读。通常建议嵌套不超过 2-3 层。如果逻辑太复杂，考虑：

  • 使用逻辑运算符 (&&, ||) 合并条件
  • 将部分逻辑提取为单独的函数

3.2 三元运算符：简洁的二选一

对于简单的"二选一"逻辑，可以使用三元运算符 ? :，它是 if...else 的简写形式。

写法 代码示例 特点
if...else if (age >= 18) { status = '成年'; } else { status = '未成年'; } 清晰，适合复杂逻辑
三元运算符 let status = age >= 18 ? '成年' : '未成年'; 简洁，适合简单赋值

语法： 条件 ? 值1 : 值2

如果条件为 true，表达式的值是 值1；否则是 值2。

何时使用三元运算符？
  • ✅ 适合：简单的二选一赋值
  • ❌ 不适合：复杂逻辑或需要执行多条语句

3.3 switch 语句：多值匹配

当需要根据一个变量的不同值执行不同代码时，switch 语句比多个 if...else if 更清晰。

let day = 3;
let dayName;

switch (day) {
    case 1:
        dayName = '星期一';
        break;
    case 2:
        dayName = '星期二';
        break;
    case 3:
        dayName = '星期三';
        break;
    case 4:
        dayName = '星期四';
        break;
    case 5:
        dayName = '星期五';
        break;
    case 6:
        dayName = '星期六';
        break;
    case 7:
        dayName = '星期日';
        break;
    default:
        dayName = '无效的日期';
}

console.log(dayName);  // "星期三"

语法要点

  • switch 后的括号里是要判断的表达式
  • 每个 case 后面跟一个可能的值，使用 === 进行严格比较
  • 必须使用 break 来结束每个 case，否则会"穿透"
  • default 是可选的，匹配所有未被 case 覆盖的情况
别忘了 break！

如果忘记写 break，代码会"穿透"到下一个 case：

let fruit = 'apple';
switch (fruit) {
    case 'apple':
        console.log('苹果');
        // 忘记写 break
    case 'banana':
        console.log('香蕉');
        break;
}
// 输出: 苹果
//       香蕉  （意外的穿透！）

四、for 循环

循环结构让我们能够重复执行某段代码。for 循环是最常用的循环类型，适合"我知道要循环多少次"的场景。

// 打印 1 到 5
for (let i = 1; i <= 5; i++) {
    console.log(i);
}
// 输出: 1, 2, 3, 4, 5

4.1 for 循环的结构

for 循环由三个部分组成：

部分 示例 作用 执行时机
初始化 let i = 1; 声明并初始化循环变量 只在循环开始前执行一次
条件 i <= 5 决定是否继续循环 每次循环开始前检查
更新 i++ 修改循环变量 每次循环体执行完后执行
循环的执行流程

让我们一步步看 for (let i = 1; i <= 3; i++) 是如何执行的：

  1. 初始化：let i = 1; (只执行一次)
  2. 检查条件：i <= 3 → true，进入循环
  3. 执行循环体：打印 1
  4. 更新：i++ → i 变为 2
  5. 检查条件：2 <= 3 → true，继续循环
  6. 重复步骤 3-5...
  7. 检查条件：4 <= 3 → false，退出循环

4.2 常见的 for 循环模式

for 循环常见模式 参考 
// 1. 倒序循环（从大到小）
for (let i = 5; i >= 1; i--) {
    console.log(i);
}
// 输出: 5, 4, 3, 2, 1

// 2. 步长为2（打印偶数）
for (let i = 0; i <= 10; i += 2) {
    console.log(i);
}
// 输出: 0, 2, 4, 6, 8, 10

// 3. 遍历数组
const fruits = ['苹果', '香蕉', '橙子'];
for (let i = 0; i < fruits.length; i++) {
    console.log(fruits[i]);
}
// 输出: 苹果, 香蕉, 橙子

五、while 循环

while 循环适合"不知道具体要循环多少次，只知道什么时候该停止"的场景。

let count = 1;

while (count <= 5) {
    console.log(count);
    count++;
}
// 输出: 1, 2, 3, 4, 5

5.1 语法要点

  • while 后的括号里是条件表达式
  • 每次循环开始前都会检查条件，如果为 true 就执行循环体
  • 必须确保循环体内会修改条件变量，否则会陷入死循环！
避免死循环！

如果循环条件永远为 true，程序会一直循环下去，导致页面卡死：

// ❌ 错误示例：死循环！
let i = 1;
while (i <= 5) {
    console.log(i);
    // 忘记写 i++，i 永远是 1
}

// ✅ 正确示例
let i = 1;
while (i <= 5) {
    console.log(i);
    i++;  // 别忘了更新循环变量！
}

5.2 for 和 while 的选择

循环类型 适用场景 示例
for 知道循环次数（或有明确的起止点） 打印 1 到 100、遍历数组
while 不确定循环次数，只知道停止条件 等待用户输入、读取文件直到结束

5.3 do...while 循环：至少执行一次

do...while 是 while 的变体，区别在于它先执行循环体，再检查条件，因此至少会执行一次。

let num = 10;

do {
    console.log('这行至少会执行一次');
    num++;
} while (num < 5);

// 虽然条件 num < 5 一开始就是 false，
// 但循环体还是执行了一次
while vs do...while
  • while：先检查条件，可能一次都不执行
  • do...while：先执行一次，再检查条件

六、break 和 continue

有时候，我们需要在循环进行中提前退出，或者跳过某些特定的循环。

6.1 break：立即退出整个循环

break 会立即终止当前循环，不再执行剩余的循环。

// 查找第一个大于10的数
for (let i = 1; i <= 20; i++) {
    if (i > 10) {
        console.log('找到了: ' + i);
        break;  // 找到后立即退出循环
    }
}
// 输出: 找到了: 11
// 循环不会继续执行到 20

6.2 continue：跳过本次循环，继续下一次

continue 会跳过本次循环剩余的代码，直接进入下一次循环。

// 打印 1 到 10 中的所有奇数
for (let i = 1; i <= 10; i++) {
    if (i % 2 === 0) {
        continue;  // 跳过偶数
    }
    console.log(i);
}
// 输出: 1, 3, 5, 7, 9
关键字 作用 典型场景
break 立即退出整个循环 找到目标后停止搜索
continue 跳过本次循环，继续下一次 过滤掉不符合条件的项

八、本课小结

知识点回顾

  • 控制结构让程序能够"做决定"和"重复执行"，是智能程序的基础
  • if...else if...else 用于构建多分支逻辑，只有第一个为真的分支会执行
  • switch 语句适合多值匹配场景，记得每个 case 后加 break
  • 三元运算符 ? : 是简单二选一逻辑的简写形式
  • for 循环适合已知次数的重复，while 适合条件驱动的重复
  • break 立即退出循环，continue 跳过本次循环继续下一次
  • 编写循环时，务必确保循环条件最终会变为 false，避免死循环

重点记忆

控制结构 核心要点 示例
if...else 条件分支，互斥执行 if (x > 0) { } else { }
switch 多值匹配，别忘 break switch (day) { case 1: break; }
for 三部分：初始化、条件、更新 for (let i=0; i<5; i++)
while 先检查条件再执行 while (x > 0) { x--; }
