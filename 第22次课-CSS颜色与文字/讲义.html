第一部分：CSS 颜色 (CSS Colors)

颜色是网页传达情感和品牌调性最直接的方式。CSS 提供了极其丰富的色彩定义工具。

1. 颜色表示法详解

在 CSS 中，我们可以用多种“语言”来描述同一个颜色。

表示法 格式示例 详细说明
关键字
(Keywords)		 red, transparent 预定义的颜色名称，包含140+个标准色。适合快速测试，但不适合精确设计。
十六进制
(Hex)		 #FF0000 (红)
#F00 (简写)		 最常用。使用 0-9 和 A-F 表示。每两位分别代表红(R)、绿(G)、蓝(B)。
RGB / RGBA rgb(255, 0, 0)
rgba(0, 0, 0, 0.5)		 直接控制红绿蓝通道（0-255）。Alpha (A) 通道控制透明度，0 为全透明，1 为不透明。
HSL / HSLA hsl(0, 100%, 50%) 最直观。H(色相 0-360), S(饱和度 %), L(亮度 %)。调整明暗或制作配色方案时非常方便。

当前状态：无样式 (Raw)

CSS (可编辑)
/* ---实验目标 --- */ /* HSL 让调色更直观：hsl(色相, 饱和度, 亮度) */ .hsl-container { display: flex; gap: 15px; padding: 20px; } .box { width: 100px; height: 100px; display: flex; align-items: center; justify-content: center; color: white; font-size: 12px; text-align: center; border-radius: 8px; } /* 1. 基准色: 红色 */ .base { background-color: hsl(0, 100%, 50%); } /* 2. 改变色相 (0-360): 尝试改成 120 (绿) 或 240 (蓝) */ .hue { background-color: hsl(240, 100%, 50%); } /* 3. 改变亮度 (0-100%): 尝试改成 20% (暗) 或 80% (亮) */ .light { background-color: hsl(0, 100%, 80%); color: black; }

技巧：currentColor

currentColor 是一个特殊的变量，代表元素当前的 color 属性值。常用于让边框、阴影或 SVG 图标自动跟随文字颜色变化，便于制作主题或 hover 效果。

CSS (可编辑)
/* ---实验目标 --- */ /* 修改 .icon-button 的 color，观察边框和图标的变化 */ .icon-button { /* 修改这里！尝试 red, #0066CC, rgb(0,128,0) */ color: #0066CC; display: inline-flex; align-items: center; gap: 8px; padding: 10px 20px; font-weight: bold; /* 关键点：边框使用 currentColor */ border: 2px solid currentColor; border-radius: 8px; background: #fff; cursor: pointer; } .icon-button svg { /* 关键点：SVG 填充使用 currentColor */ fill: currentColor; } .icon-button:hover { /* 只需改变颜色，边框和图标自动跟随 */ color: #d32f2f; }

2. 常用颜色属性

不仅仅是文字颜色，CSS 可以控制页面几乎所有元素的色彩。

属性 (Property) 作用 常用值示例
color 前景色。主要影响文字、文本装饰线、边框（默认跟随）。 #333, rgb(50,50,50)
background-color 背景颜色。填充在元素内容、内边距(padding)区域。 #f5f5f7, transparent
border-color 边框颜色。可以分别设置四条边。 #ccc, transparent
opacity 不透明度。注意：这会影响整个元素（包括子元素）。 0 (隐藏), 0.5 (半透明), 1 (显示)

第二部分：CSS 文字排版 (Typography)

优秀的排版能让内容像呼吸一样自然。CSS 提供了从宏观布局到微观字距的全面控制。

3. 字体属性 (Font)

3.1 font-family (字体族)

指定文本使用的字体。通常使用**“字体栈” (Font Stack)** 的方式编写，从首选字体到后备字体。

最佳实践

始终在列表末尾添加一个通用字体族作为保底：sans-serif (无衬线), serif (衬线), monospace (等宽)。

3.2 font-size (字号) & font-weight (字重)

属性 常见值 说明
font-size 16px
1.2em
1rem		 px: 绝对单位，精确。
rem: 相对根元素(html)，推荐用于响应式。
em: 相对父元素，常用于局部组件。
font-weight normal (400)
bold (700)
100-900		 定义文字粗细。注意：所选字体必须包含对应的粗细变体，否则浏览器会进行“伪粗体”渲染（效果通常不佳）。
font-style normal, italic 主要用于设置斜体。

5. 文本间距控制

微调间距可以增加设计的精致感。

  • letter-spacing (字间距): 增加字母/汉字之间的距离。常用于全大写的英文标题，增加 1px 或 0.05em 会显得更高级。
  • word-spacing (词间距): 增加单词之间的距离。对中文通常不起作用（因为中文没有空格分词）。
  • text-indent (首行缩进): 传统的段落排版，如 2em (缩进两个字)。

CSS (可编辑)
.spacing-box h2 { font-family: sans-serif; text-transform: uppercase; background: #333; color: #fff; padding: 10px; text-align: center; /* 尝试 letter-spacing: 5px */ letter-spacing: 0px; } .spacing-box p { font-size: 14px; border: 1px solid #eee; padding: 10px; /* 尝试 text-indent: 2em */ text-indent: 0; }

6. 文本溢出与换行

当容器太小放不下文字时，我们需要决定如何处理。

6.1 单行省略号 (经典三件套)

要实现 "Very long text..." 的效果，必须同时使用以下三个属性：

white-space: nowrap; /* 1. 强制不换行 */
overflow: hidden; /* 2. 隐藏超出部分 */
text-overflow: ellipsis; /* 3. 用省略号表示 */

6.2 其他换行属性

属性 常用值 说明
white-space nowrap
pre-wrap		 控制空白符和换行。nowrap 禁止换行；pre-wrap 保留源码中的空格和换行（类似 <pre>）。
word-break break-all
keep-all		 控制单词如何断行。break-all 允许在单词内强行断开（适合处理长串 URL 撑破容器的问题）。

.card { width: 200px; border: 1px solid #ddd; padding: 10px; background: #fff; } .card h3 { /*实验：实现单行省略号 */ white-space: nowrap; overflow: hidden; text-overflow: ellipsis; color: #333; font-size: 16px; } .card p { background: #f0f0f0; color: #0066CC; /*实验：防止长 URL 撑破容器 */ word-break: break-all; }

第三部分：CSS长度单位 (CSS Length Units)

7. 绝对 vs 相对单位

掌握不同长度单位的特点，可以让排版更加灵活。

单位 类型 基准 适用场景
px 绝对 物理像素（逻辑上） 边框粗细、阴影位移、不需要缩放的固定元素。
em 相对 当前元素的字体大小 按钮内边距（padding），使其随字号自动缩放。
rem 相对 根元素(html)的字体大小 全局布局首选。字号、间距、容器宽度，方便实现整体缩放。
% 相对 父元素的大小 流式布局宽度（如 width: 50%）。
实验 06：rem 的响应式魔法
当前状态：无样式 (Raw)
HTML (只读)
<!-- 这是一个模拟根元素的容器 --> <div class="root-container"> <div class="box box-px">我是 px (固定)</div> <div class="box box-rem">我是 rem (弹性)</div> </div>
CSS (可编辑)
/*实验：修改 .root-container 的 font-size 观察哪个盒子会变大？ */ .root-container { /* 尝试改成 20px, 12px */ font-size: 16px; border: 2px dashed #ccc; padding: 20px; display: flex; gap: 20px; } .box { padding: 10px; background: #e3f2fd; border: 1px solid #90caf9; } .box-px { /* 固定大小，死板 */ font-size: 16px; width: 150px; } .box-rem { /* 随根元素变化 (1.5倍) */ /* 注意：在真实页面中 rem 是相对于 html 标签的 */ /* 这里为了演示效果，用 em 模拟 rem 的行为 */ font-size: 1.5em; width: 10em; }
效果预览
我是 px (固定)
我是 rem (弹性)

8. 视口单位应用

视口单位基于浏览器窗口的可见区域大小。

  • 1vw = 视口宽度的 1%
  • 1vh = 视口高度的 1%
常见应用

height: 100vh; 常用于制作“全屏首图” (Hero Section)，让背景图铺满整个屏幕高度。

第四部分：边框样式 (Borders)

9. 边框属性

边框是盒模型的重要组成部分。最常用的简写属性是 border。

border: [width] [style] [color];
例如: border: 1px solid #ccc;
属性 说明
border-style solid(实线), dashed(虚线), dotted(点线), double(双线)。
border-width thin, medium, thick 或具体数值如 2px。

10. 圆角与阴影

这两个属性是现代 UI 设计“扁平化”与“卡片式设计”的基石。

10.1 border-radius (圆角)

可以接受 px 或 %。border-radius: 50%; 可以将正方形变成圆形（常用于头像）。

10.2 box-shadow (盒子阴影)

格式：offset-x offset-y blur spread color
