第2课：HTML排版与文本格式化

在本节课中，我们将学习如何使用HTML进行文本排版和格式化。 良好的排版是网页设计的基础，它能够使内容更加清晰易读，提升用户体验。 通过本节课的学习，你将掌握HTML中各种文本排版和格式化的标签和技巧。

1. 标题与段落

在HTML中，标题和段落是最基本的文本元素。标题用于强调页面的主要内容和结构，而段落则用于组织正文内容。

1.1 标题标签

HTML提供了6级标题标签，从<h1>到<h6>，其中<h1>是最高级别的标题， <h6>是最低级别的标题。标题标签不仅能改变文本大小，还能告诉搜索引擎页面的结构和重要性。

实验 01：标题标签的使用 未运行
HTML (可编辑)
<!DOCTYPE html> <html lang="zh-CN"> <head> <meta charset="UTF-8"> <title>标题标签示例</title> </head> <body> <h1>这是一级标题</h1> <h2>这是二级标题</h2> <h3>这是三级标题</h3> <h4>这是四级标题</h4> <h5>这是五级标题</h5> <h6>这是六级标题</h6> </body> </html>
预览效果

1.2 段落标签

段落标签<p>用于定义一段文本。浏览器会自动在段落前后添加空白，使内容更易读。

实验 02：段落标签的使用 未运行
HTML (可编辑)
<!DOCTYPE html> <html lang="zh-CN"> <head> <meta charset="UTF-8"> <title>段落标签示例</title> </head> <body> <h1>我的自我介绍</h1> <p>大家好，我是一名HTML初学者。</p> <p>我正在学习HTML、CSS和JavaScript，希望将来能够成为一名优秀的前端开发者。</p> <p>我喜欢阅读、编程和旅行。我相信通过不断学习和实践，我一定能够实现我的目标。</p> </body> </html>
预览效果

2. 文本样式

HTML提供了多种文本格式化标签，用于改变文本的外观，如粗体、斜体、下划线等。 这些标签可以使文本更加突出，强调重要内容。

实验 03：文本样式标签 未运行
HTML (可编辑)
<!DOCTYPE html> <html lang="zh-CN"> <head> <meta charset="UTF-8"> <title>文本样式示例</title> </head> <body> <h1>文本样式示例</h1> <p>这是普通文本。</p> <p>这是<strong>粗体文本</strong>，用于强调重要内容。</p> <p>这是<em>斜体文本</em>，用于强调语气。</p> <p>这是<u>下划线文本</u>。</p> <p>这是<s>删除线文本</s>。</p> <p>这是<mark>高亮文本</mark>。</p> <p>H<sub>2</sub>O 是水的化学式。</p> <p>2<sup>3</sup> = 8</p> </body> </html>
预览效果
💡 语义化vs样式化

在HTML中，<strong>和<em>是语义化标签，它们不仅改变文本的外观，还传达了文本的重要性； 而<b>和<i>只是样式化标签，它们只改变文本的外观，不传达任何语义信息。 在实际开发中，我们应该优先使用语义化标签。

3. 换行与水平线

在HTML中，我们可以使用特定的标签来控制文本的换行和分隔。

实验 04：换行与水平线标签 未运行
HTML (可编辑)
<!DOCTYPE html> <html lang="zh-CN"> <head> <meta charset="UTF-8"> <title>换行与水平线示例</title> </head> <body> <h1>换行与水平线示例</h1> <h2>换行标签</h2> <p>第一行<br>第二行<br>第三行</p> <hr> <h2>水平线标签</h2> <p>这是水平线上面的内容。</p> <hr> <p>这是水平线下面的内容。</p> </body> </html>
预览效果

4. 特殊字符

在HTML中，有些字符具有特殊含义，如小于号<和大于号>，它们用于定义HTML标签。 如果你想在页面中显示这些特殊字符，就需要使用HTML实体（HTML Entities）。

实验 05：特殊字符的使用 未运行
HTML (可编辑)
<!DOCTYPE html> <html lang="zh-CN"> <head> <meta charset="UTF-8"> <title>特殊字符示例</title> </head> <body> <h1>特殊字符示例</h1> <p>HTML标签的格式是：&lt;标签名&gt; 内容 &lt;/标签名&gt;</p> <p>版权符号：&copy; 2025 我的网站</p> <p>注册商标符号：&reg;</p> <p>度符号：30&deg;C</p> <p>乘号：2 &times; 3 = 6</p> <p>除号：6 &divide; 2 = 3</p> <p>空格：第一个单词&nbsp;&nbsp;&nbsp;&nbsp;第二个单词</p> </body> </html>

5. 课后练习

请完成以下练习，巩固本节课所学的知识：

  1. 创建一个HTML页面，包含所有6级标题
  2. 使用段落标签组织一段关于你自己的介绍

  4. 使用水平线分隔不同的内容区域
  5. 在页面中使用至少3个特殊字符
  6. 保存文件并在浏览器中查看效果
