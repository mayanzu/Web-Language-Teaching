第7课：HTML表格进阶

在本节课中，我们将学习HTML表格的进阶知识。上节课我们学习了表格的基础知识，本节课我们将深入学习如何合并单元格、设置表格样式、创建复杂表格以及表格的语义化。 通过本节课的学习，你将掌握创建复杂表格的技巧，能够设计出更加美观、功能更强大的表格。

1. 合并单元格

在HTML中，我们可以使用colspan和rowspan属性来合并单元格，从而创建复杂的表格结构。

1.1 colspan属性

colspan属性用于合并水平方向的单元格，它指定了一个单元格应该跨越的列数。 

<table border="1" cellpadding="10" cellspacing="0">
    <tr>
        <th colspan="2">个人信息</th>
    </tr>
    <tr>
        <td>姓名</td>
        <td>张三</td>
    </tr>
    <tr>
        <td>年龄</td>
        <td>18</td>
    </tr>
</table>

colspan属性效果预览

1.2 rowspan属性

rowspan属性用于合并垂直方向的单元格，它指定了一个单元格应该跨越的行数。 

<table border="1" cellpadding="10" cellspacing="0">
    <tr>
        <th rowspan="2">个人信息</th>
        <td>姓名</td>
        <td>张三</td>
    </tr>
    <tr>
        <td>年龄</td>
        <td>18</td>
    </tr>
</table>

2. 表格样式

在现代Web开发中，我们通常使用CSS来设置表格的样式，而不是使用HTML属性。CSS提供了更强大、更灵活的样式控制能力。

2.1 基本表格样式

<style>
    .styled-table {
        width: 100%;
        border-collapse: collapse;
        margin: 25px 0;
        font-size: 16px;
        text-align: left;
        border-radius: 8px 8px 0 0;
        overflow: hidden;
        box-shadow: 0 0 20px rgba(0, 0, 0, 0.15);
    }

    .styled-table thead tr {
        background-color: #0066CC;
        color: #ffffff;
        text-align: left;
        font-weight: bold;
    }

    .styled-table th,
    .styled-table td {
        padding: 12px 15px;
    }

    .styled-table tbody tr {
        border-bottom: 1px solid #dddddd;
    }

    .styled-table tbody tr:nth-of-type(even) {
        background-color: #f3f3f3;
    }

    .styled-table tbody tr:last-of-type {
        border-bottom: 2px solid #0066CC;
    }

    .styled-table tbody tr:hover {
        background-color: #f5f5f5;
        font-weight: bold;
    }
</style>

4. 表格语义化

语义化是指使用合适的HTML标签来表达内容的含义，而不仅仅是为了呈现效果。 对于表格，HTML5提供了一些语义化标签，用于提高表格的可访问性和可读性。

4.1 语义化表格结构

一个语义化的表格应该包含以下结构：

  • <caption>：表格标题，描述表格的内容
  • <thead>：表头，包含列标题
  • <tbody>：表体，包含表格的主要数据
  • <tfoot>：表尾，包含表格的汇总数据

4.2 表格的可访问性

为了提高表格的可访问性，我们可以使用以下属性：

  • scope：指定表头单元格关联的行或列
  • id和headers：建立单元格与表头的关联
<table border="1" cellpadding="10" cellspacing="0">
    <caption>学生成绩表</caption>
    <thead>
        <tr>
            <th scope="col">学号</th>
            <th scope="col">姓名</th>
            <th scope="col">数学</th>
            <th scope="col">英语</th>
        </tr>
    </thead>
    <tbody>
        <tr>
            <th scope="row">001</th>
            <td>张三</td>
            <td>85</td>
            <td>92</td>
        </tr>
        <tr>
            <th scope="row">002</th>
            <td>李四</td>
            <td>90</td>
            <td>88</td>
        </tr>
    </tbody>
</table>
💡 语义化的重要性

语义化的表格具有以下优点：

  • 提高可访问性：屏幕阅读器可以更好地理解表格结构
  • 提高可读性：开发者可以更容易地理解表格的结构和内容
  • 有利于SEO：搜索引擎可以更好地理解表格内容
