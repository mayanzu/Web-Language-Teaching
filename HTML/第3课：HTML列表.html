第3课：HTML列表

在本节课中，我们将学习HTML中的列表元素。列表是网页中常用的内容组织方式，它可以使内容更加结构化、清晰易读。 HTML提供了三种主要的列表类型：无序列表、有序列表和定义列表。通过本节课的学习，你将掌握如何使用这些列表类型来组织和展示不同类型的内容。

1. 无序列表

无序列表（Unordered List）用于展示一组没有特定顺序的项目，每个项目前面会显示一个默认的项目符号（通常是圆点）。 无序列表使用<ul>标签定义，列表中的每个项目使用<li>标签定义。 

<ul>
    <li>苹果</li>
    <li>香蕉</li>
    <li>橙子</li>
    <li>葡萄</li>
</ul>

1.1 无序列表的样式

虽然HTML本身不直接控制列表的样式，但我们可以通过CSS来改变无序列表的项目符号类型。 常见的项目符号类型包括：disc（默认，实心圆点）、circle（空心圆点）和square（实心方块）。 

<style>
    ul.disc { list-style-type: disc; }
    ul.circle { list-style-type: circle; }
    ul.square { list-style-type: square; }
    ul.none { list-style-type: none; }
</style>

<h4>disc（默认）：</h4>
<ul class="disc">
    <li>项目1</li>
    <li>项目2</li>
</ul>

<h4>circle：</h4>
<ul class="circle">
    <li>项目1</li>
    <li>项目2</li>
</ul>

<h4>square：</h4>
<ul class="square">
    <li>项目1</li>
    <li>项目2</li>
</ul>

<h4>none：</h4>
<ul class="none">
    <li>项目1</li>
    <li>项目2</li>
</ul>

2. 有序列表

有序列表（Ordered List）用于展示一组有特定顺序的项目，每个项目前面会显示一个默认的数字（通常是阿拉伯数字）。 有序列表使用<ol>标签定义，列表中的每个项目使用<li>标签定义。 

<ol>
    <li>起床</li>
    <li>刷牙洗脸</li>
    <li>吃早餐</li>
    <li>去上学</li>
</ol>

2.1 有序列表的样式

与无序列表类似，我们可以通过CSS来改变有序列表的编号类型。 常见的编号类型包括：decimal（默认，阿拉伯数字）、lower-roman（小写罗马数字）、upper-roman（大写罗马数字）、 lower-alpha（小写字母）和upper-alpha（大写字母）。 

<style>
    ol.decimal { list-style-type: decimal; }
    ol.lower-roman { list-style-type: lower-roman; }
    ol.upper-roman { list-style-type: upper-roman; }
    ol.lower-alpha { list-style-type: lower-alpha; }
    ol.upper-alpha { list-style-type: upper-alpha; }
</style>

<h4>decimal（默认）：</h4>
<ol class="decimal">
    <li>项目1</li>
    <li>项目2</li>
</ol>

<h4>lower-roman：</h4>
<ol class="lower-roman">
    <li>项目1</li>
    <li>项目2</li>
</ol>

<h4>upper-roman：</h4>
<ol class="upper-roman">
    <li>项目1</li>
    <li>项目2</li>
</ol>

<h4>lower-alpha：</h4>
<ol class="lower-alpha">
    <li>项目1</li>
    <li>项目2</li>
</ol>

<h4>upper-alpha：</h4>
<ol class="upper-alpha">
    <li>项目1</li>
    <li>项目2</li>
</ol>

2.2 有序列表的起始值

我们可以使用start属性来指定有序列表的起始编号，使用value属性来指定单个列表项的编号。 

<!-- 从5开始编号 -->
<ol start="5">
    <li>项目1</li>
    <li>项目2</li>
    <li>项目3</li>
</ol>

<!-- 自定义列表项编号 -->
<ol>
    <li>项目1</li>
    <li value="5">项目2</li>
    <li>项目3</li>
</ol>

3. 定义列表

定义列表（Definition List）用于展示一组术语及其定义，类似于字典的条目。 定义列表使用<dl>标签定义，术语使用<dt>标签定义，术语的定义使用<dd>标签定义。 

<dl>
    <dt>HTML</dt>
    <dd>超文本标记语言，用于创建网页的标准标记语言。</dd>
    
    <dt>CSS</dt>
    <dd>层叠样式表，用于描述网页的外观和格式。</dd>
    
    <dt>JavaScript</dt>
    <dd>一种脚本语言，用于为网页添加交互功能。</dd>
</dl>

4. 列表嵌套

在HTML中，我们可以将一个列表嵌套在另一个列表中，创建复杂的列表结构。 嵌套列表可以是相同类型的列表，也可以是不同类型的列表。

4.1 无序列表嵌套

<ul>
    <li>水果
        <ul>
            <li>苹果</li>
            <li>香蕉</li>
            <li>橙子</li>
        </ul>
    </li>
    <li>蔬菜
        <ul>
            <li>西红柿</li>
            <li>黄瓜</li>
            <li>胡萝卜</li>
        </ul>
    </li>
</ul>

4.2 混合列表嵌套

我们也可以将不同类型的列表嵌套在一起，例如将有序列表嵌套在无序列表中，或者将无序列表嵌套在有序列表中。 

<ol>
    <li>准备食材
        <ul>
            <li>鸡蛋2个</li>
            <li>面粉100g</li>
            <li>牛奶50ml</li>
        </ul>
    </li>
    <li>制作步骤
        <ol>
            <li>将鸡蛋打散</li>
            <li>加入面粉和牛奶，搅拌均匀</li>
            <li>平底锅加热，倒入面糊</li>
            <li>煎至两面金黄</li>
        </ol>
    </li>
</ol>
