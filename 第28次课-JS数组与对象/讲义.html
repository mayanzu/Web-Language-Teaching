第28课：JS数组与对象

如果说变量是存储单个数据的盒子,那么数组就是一排编号的盒子,对象就是带标签的盒子。本课学习如何用数组管理列表数据,用对象组织复杂信息,它们是JavaScript中最重要的数据结构。

数组创建与访问 数组方法 数组遍历 对象属性与方法 JSON数据格式 嵌套结构

一、为什么需要数组和对象?

假设你要管理一个班级30个学生的信息,如果用单个变量:

let student1 = "张三";
let student2 = "李四";
let student3 = "王五";
// ... 要写30个变量!

这样做有几个问题:变量太多难以管理、无法批量处理、代码重复冗长。数组和对象就是为了解决这些问题而生。

生活中的类比
  • 数组 = 编号的储物柜:每个柜子有编号(索引),按顺序排列,适合存储同类物品(如学生名单、成绩列表)
  • 对象 = 带标签的文件夹:每个资料有名称标签(属性名),方便查找,适合存储不同类型的相关信息(如用户信息:姓名、年龄、邮箱)
  • JSON = 通用数据格式:就像快递单,不同公司都能看懂的标准格式,用于程序间传递数据

使用数组和对象后,代码变得简洁高效:

// 用数组管理学生列表
const students = ["张三", "李四", "王五", /*...*/];

// 用对象管理单个学生的详细信息
const student = {
  name: "张三",
  age: 18,
  grade: "高一",
  score: 95
};

数组和对象让我们能够:

  • 批量管理:用一个变量管理多个相关数据
  • 结构化组织:让复杂数据井井有条
  • 高效操作:提供丰富的方法进行增删改查
  • 数据传输:通过JSON格式在前后端传递数据

二、数组基础

2.1 什么是数组?

数组（Array）是一种有序的数据集合,可以存储多个值。每个值都有一个索引（下标）,从0开始。可以把数组想象成一排编号的盒子,每个盒子可以放一个数据。

概念说明示例
索引 (Index) 元素在数组中的位置编号,从0开始 fruits[0] 表示第1个元素
元素 (Element) 数组中存储的每一个值 "苹果"、"香蕉" 都是元素
长度 (Length) 数组包含的元素个数 fruits.length 返回元素数量

2.2 创建和访问数组

// 创建数组
const fruits = ["苹果", "香蕉", "橙子"];
const numbers = [1, 2, 3, 4, 5];
const mixed = [1, "hello", true, null];  // 可以包含不同类型

// 空数组
const empty = [];

// 访问元素
console.log(fruits[0]);  // "苹果"（第一个元素）
console.log(fruits[1]);  // "香蕉"（第二个元素）
console.log(fruits[2]);  // "橙子"（第三个元素）

// 数组长度
console.log(fruits.length);  // 3
数组的特点
  • 索引从0开始，最后一个元素的索引是 length - 1
  • 可以存储任意类型的数据
  • 长度可以动态改变
  • 是引用类型（传递引用而非值）

1.2 修改数组元素

const colors = ["红", "绿", "蓝"];

// 修改元素
colors[1] = "黄";
console.log(colors);  // ["红", "黄", "蓝"]

// 添加元素（通过索引）
colors[3] = "紫";
console.log(colors);  // ["红", "黄", "蓝", "紫"]

// 获取最后一个元素
const last = colors[colors.length - 1];
console.log(last);  // "紫"

1.3 多维数组

// 二维数组（数组的数组）
const matrix = [
  [1, 2, 3],
  [4, 5, 6],
  [7, 8, 9]
];

console.log(matrix[0][0]);  // 1
console.log(matrix[1][2]);  // 6
console.log(matrix[2][1]);  // 8

三、数组的常用方法

JavaScript为数组提供了丰富的内置方法,让数据操作变得简单高效。掌握这些方法是操作数组的关键。

3.1 添加和删除元素

const arr = ["a", "b", "c"];

// push()方法：在数组末尾添加一个或多个元素
// 返回新数组的长度
arr.push("d");
console.log(arr);  // ["a", "b", "c", "d"]

// pop()方法：删除并返回数组最后一个元素
// 原数组会被修改
const last = arr.pop();
console.log(last);  // "d"
console.log(arr);   // ["a", "b", "c"]

// unshift()方法：在数组开头添加一个或多个元素
// 返回新数组的长度
arr.unshift("z");
console.log(arr);  // ["z", "a", "b", "c"]

// shift()方法：删除并返回数组第一个元素
// 原数组会被修改
const first = arr.shift();
console.log(first);  // "z"
console.log(arr);    // ["a", "b", "c"]

3.2 splice：万能方法

splice() 方法可以删除、插入和替换元素,是操作数组最强大的方法之一。

const numbers = [1, 2, 3, 4, 5];

// splice()方法参数：(起始索引, 删除数量, 新元素...)
// 删除元素：splice(起始索引, 删除数量)
numbers.splice(2, 1);  // 从索引2开始删除1个元素
console.log(numbers);  // [1, 2, 4, 5]

// 插入元素：splice(起始索引, 0, 新元素...)
numbers.splice(2, 0, 3);  // 在索引2处插入3
console.log(numbers);  // [1, 2, 3, 4, 5]

// 替换元素：splice(起始索引, 删除数量, 新元素...)
numbers.splice(1, 2, 10, 20);  // 从索引1开始，删除2个，插入10和20
console.log(numbers);  // [1, 10, 20, 4, 5]

3.3 查找和判断

const fruits = ["苹果", "香蕉", "橙子", "香蕉"];

// indexOf()方法：查找元素第一次出现的索引
// 如果找不到返回-1
console.log(fruits.indexOf("香蕉"));     // 1（第一次出现）
console.log(fruits.indexOf("葡萄"));     // -1（不存在）

// includes()方法：判断数组是否包含某个元素
// 返回布尔值
console.log(fruits.includes("苹果"));    // true
console.log(fruits.includes("葡萄"));    // false

// find()方法：查找满足条件的第一个元素
// 参数是回调函数，返回第一个使回调函数返回true的元素
const numbers = [1, 5, 10, 15, 20];
const found = numbers.find(num => num > 10);
console.log(found);  // 15

// findIndex()方法：查找满足条件的第一个元素的索引
// 如果找不到返回-1
const index = numbers.findIndex(num => num > 10);
console.log(index);  // 3

3.4 数组转换方法

这些方法用于将数组转换为其他形式,是数据处理的核心方法。

const arr = [1, 2, 3, 4, 5];

// map()方法：转换每个元素，返回新数组
// (在第5课已学习，这里复习)
const doubled = arr.map(num => num * 2);
console.log(doubled);  // [2, 4, 6, 8, 10]

// filter()方法：筛选符合条件的元素
// (在第5课已学习，这里复习)
const evens = arr.filter(num => num % 2 === 0);
console.log(evens);  // [2, 4]

// reduce()方法：累积计算，归约为单个值
// (在第5课已学习，这里复习)
const sum = arr.reduce((total, num) => total + num, 0);
console.log(sum);  // 15

// join()方法：将数组所有元素用分隔符连接成字符串
// 参数是分隔符，默认为逗号
const str = arr.join(", ");
console.log(str);  // "1, 2, 3, 4, 5"

// slice()方法：提取数组的一部分，返回新数组
// 参数：(起始索引, 结束索引)，不包括结束索引
// 不会修改原数组
const sub = arr.slice(1, 3);
console.log(sub);  // [2, 3]

3.5 排序和反转

const numbers = [3, 1, 4, 1, 5, 9];

// sort()方法：对数组进行排序（会修改原数组）
// 参数是比较函数：(a, b) => a - b 表示升序
numbers.sort((a, b) => a - b);  // 升序
console.log(numbers);  // [1, 1, 3, 4, 5, 9]

// 降序排列：返回 b - a
numbers.sort((a, b) => b - a);  // 降序
console.log(numbers);  // [9, 5, 4, 3, 1, 1]

// reverse()方法：反转数组（会修改原数组）
const arr = [1, 2, 3, 4, 5];
arr.reverse();
console.log(arr);  // [5, 4, 3, 2, 1]

四、数组遍历方法

遍历就是依次访问数组的每个元素。掌握数组遍历方法是处理列表数据的核心技能。

4.1 for循环遍历

const numbers = [10, 20, 30, 40, 50];

// 传统for循环
for (let i = 0; i < numbers.length; i++) {
  console.log(`索引${i}: ${numbers[i]}`);
}

// for...of循环（ES6）
for (let num of numbers) {
  console.log(num);
}

4.2 forEach方法

forEach()方法在第5课已经学习过，这里是复习。

const fruits = ["苹果", "香蕉", "橙子"];

// forEach()方法：遍历每个元素（第5课已学）
fruits.forEach(function(fruit, index) {
  console.log(`${index}: ${fruit}`);
});

// 箭头函数版本
fruits.forEach((fruit, index) => {
  console.log(`${index}: ${fruit}`);
});

4.3 高级遍历方法

const numbers = [1, 2, 3, 4, 5];

// every()方法：检查是否所有元素都满足条件
// 返回布尔值，所有元素都满足才返回true
const allPositive = numbers.every(num => num > 0);
console.log(allPositive);  // true

// some()方法：检查是否至少有一个元素满足条件
// 返回布尔值，只要有一个满足就返回true
const hasEven = numbers.some(num => num % 2 === 0);
console.log(hasEven);  // true

// map()方法：转换为新数组（第5课已学，这里复习）
const squared = numbers.map(num => num * num);
console.log(squared);  // [1, 4, 9, 16, 25]

五、对象基础

5.1 什么是对象?

对象（Object）是一种无序的键值对集合,用于存储结构化数据。每个键值对称为对象的属性。如果说数组是按编号存储,对象就是按名称(标签)存储。

概念说明示例
属性 (Property) 对象中的键值对,键是属性名,值是属性值 name: "张三"
方法 (Method) 属性值为函数的属性 greet: function() { }
访问方式 点语法或方括号语法 obj.name 或 obj["name"]

5.2 创建和访问对象

// 创建对象
const person = {
  name: "张三",
  age: 25,
  city: "北京",
  isStudent: false
};

// 访问属性
console.log(person.name);      // "张三"（点语法）
console.log(person["age"]);    // 25（方括号语法）

// 空对象
const empty = {};
📌 对象的特点
  • 键（key）通常是字符串，值（value）可以是任意类型
  • 无序的键值对集合
  • 引用类型
  • 可以包含方法（函数作为值）

4.2 对象方法

const calculator = {
  x: 10,
  y: 5,
  
  // 方法：对象中的函数
  add: function() {
    return this.x + this.y;
  },
  
  // ES6简写语法
  subtract() {
    return this.x - this.y;
  },
  
  // 箭头函数（注意：this行为不同）
  multiply: () => {
    // 箭头函数没有自己的this
    return "使用箭头函数时this不指向对象";
  }
};

console.log(calculator.add());       // 15
console.log(calculator.subtract());  // 5

4.3 this关键字

const user = {
  name: "李四",
  greet: function() {
    console.log(`你好，我是${this.name}`);
  },
  
  introduce() {
    console.log(`我的名字是${this.name}`);
  }
};

user.greet();      // "你好，我是李四"
user.introduce();  // "我的名字是李四"

六、对象的高级操作

除了基本的属性访问,JavaScript还提供了许多强大的对象操作方法,让对象管理更加灵活。

6.1 添加、修改、删除属性

const person = {
  name: "王五",
  age: 30
};

// 添加新属性
person.city = "上海";
person["country"] = "中国";

// 修改属性
person.age = 31;

// 删除属性
delete person.country;

console.log(person);
// { name: "王五", age: 31, city: "上海" }

5.2 检查属性

const car = {
  brand: "Tesla",
  model: "Model 3",
  year: 2023
};

// in 操作符
console.log("brand" in car);    // true
console.log("color" in car);    // false

// hasOwnProperty 方法
console.log(car.hasOwnProperty("model"));  // true
console.log(car.hasOwnProperty("price"));  // false

6.3 遍历对象

const student = {
  name: "赵六",
  age: 20,
  grade: "大二"
};

// for...in 循环
for (let key in student) {
  console.log(`${key}: ${student[key]}`);
}

// Object.keys()方法：获取对象所有键，返回数组
const keys = Object.keys(student);
console.log(keys);  // ["name", "age", "grade"]

// Object.values()方法：获取对象所有值，返回数组
const values = Object.values(student);
console.log(values);  // ["赵六", 20, "大二"]

// Object.entries()方法：获取对象所有键值对，返回二维数组
const entries = Object.entries(student);
console.log(entries);
// [["name", "赵六"], ["age", 20], ["grade", "大二"]]

// 遍历键值对
Object.entries(student).forEach(([key, value]) => {
  console.log(`${key}: ${value}`);
});

6.4 对象复制

const original = { x: 1, y: 2 };

// Object.assign()方法：浅拷贝对象
// 第一个参数是目标对象，后面的是源对象
const copy1 = Object.assign({}, original);

// 浅拷贝：展开运算符（ES6）
const copy2 = { ...original };

// 合并对象
const obj1 = { a: 1, b: 2 };
const obj2 = { b: 3, c: 4 };
const merged = { ...obj1, ...obj2 };
console.log(merged);  // { a: 1, b: 3, c: 4 }

七、JSON数据格式

7.1 什么是JSON?

JSON（JavaScript Object Notation）是一种轻量级的数据交换格式,是前后端通信的标准语言。就像快递单的标准格式,让不同的程序都能读懂彼此的数据。

为什么需要JSON?
  • 前端JavaScript对象无法直接传给后端
  • 需要一种文本格式,方便网络传输
  • JSON既是JavaScript原生支持,又是跨语言通用格式
  • 几乎所有编程语言都能解析JSON

7.2 JSON的语法规则

JSON的特点
  • 键必须用双引号包裹
  • 值可以是：字符串、数字、对象、数组、布尔值、null
  • 不能包含函数、undefined、Symbol
  • 广泛用于数据传输和存储

7.3 JSON与JavaScript对象的转换

// JavaScript对象
const person = {
  name: "小红",
  age: 22,
  hobbies: ["读书", "旅游"]
};

// JSON.stringify()方法：将JavaScript对象转换为JSON字符串
// 用于数据传输或存储
const jsonString = JSON.stringify(person);
console.log(jsonString);
// '{"name":"小红","age":22,"hobbies":["读书","旅游"]}'

// JSON.parse()方法：将JSON字符串转换为JavaScript对象
// 用于接收和解析数据
const jsonStr = '{"name":"小刚","age":25,"city":"北京"}';
const obj = JSON.parse(jsonStr);
console.log(obj.name);  // "小刚"

// JSON.stringify()的第三个参数：格式化输出
// 第二个参数为null，第三个参数指定缩进空格数
const formatted = JSON.stringify(person, null, 2);
console.log(formatted);
/*
{
  "name": "小红",
  "age": 22,
  "hobbies": [
    "读书",
    "旅游"
  ]
}
*/

7.4 深拷贝技巧

const original = {
  name: "原对象",
  data: { x: 1, y: 2 }
};

// 使用JSON实现深拷贝（有局限性）
// 先转成JSON字符串，再解析回对象，得到完全独立的副本
const deepCopy = JSON.parse(JSON.stringify(original));

deepCopy.data.x = 100;
console.log(original.data.x);  // 1（不受影响）
console.log(deepCopy.data.x);  // 100

// 注意：这种方法无法复制函数、undefined等特殊值

八、嵌套结构的实战应用

实际开发中,数据往往是数组和对象的组合嵌套。掌握嵌套结构的处理是操作复杂数据的关键能力。

8.1 数组中包含对象

最常见的数据结构：对象数组，用于表示列表数据。

const students = [
  { name: "张三", age: 20, score: 85 },
  { name: "李四", age: 21, score: 92 },
  { name: "王五", age: 19, score: 78 }
];

// 访问元素
console.log(students[0].name);  // "张三"
console.log(students[1].score);  // 92

// 遍历
students.forEach(student => {
  console.log(`${student.name}: ${student.score}分`);
});

// 筛选
const topStudents = students.filter(s => s.score >= 90);
console.log(topStudents);  // [{ name: "李四", age: 21, score: 92 }]

// 计算平均分
const avgScore = students.reduce((sum, s) => sum + s.score, 0) / students.length;
console.log(avgScore);  // 85

7.2 对象包含数组

const班级 = {
  name: "高三(1)班",
  teacher: "王老师",
  students: ["张三", "李四", "王五"],
  scores: {
    math: [85, 92, 78],
    english: [88, 90, 82]
  },
  
  getAverage(subject) {
    const scores = this.scores[subject];
    const sum = scores.reduce((a, b) => a + b, 0);
    return sum / scores.length;
  }
};

console.log(班级.students[0]);  // "张三"
console.log(班级.getAverage("math"));  // 85

7.3 复杂嵌套结构

const company = {
