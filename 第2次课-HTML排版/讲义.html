一、标题与段落

HTML提供了多种标签来定义不同级别的标题和段落，帮助你组织页面内容结构，提高可读性和SEO效果。

1.1 标题标签

HTML提供了6级标题标签，从<h1>到<h6>，其中<h1>是最高级别的标题，<h6>是最低级别的标题。标题标签不仅用于视觉样式，还用于SEO和屏幕阅读器，因此正确使用标题标签非常重要。

示例：标题标签效果 只读 
<h1>一级标题：页面主标题</h1>
<h2>二级标题：章节标题</h2>
<h3>三级标题：小节标题</h3>
<h4>四级标题：内容细分</h4>
<h5>五级标题：更细致的分类</h5>
<h6>六级标题：最细致的分类</h6>

一级标题：页面主标题

二级标题：章节标题

三级标题：小节标题

四级标题：内容细分

五级标题：更细致的分类
六级标题：最细致的分类
标题级别 重要性 视觉大小 使用场景 每页建议数量
<h1> 最高 最大 页面主标题，整个页面的核心主题 1个
<h2> 很高 大 主要章节标题，页面的主要内容区块 3-5个
<h3> 高 中 小节标题，对h2内容的细分 每个h2下2-4个
<h4> 中等 小 子小节标题，对h3内容的进一步细分 视需要而定
<h5> 低 更小 辅助标题，用于补充说明 视需要而定
<h6> 最低 最小 最细粒度的标题，极少使用 尽量避免
💡 标题标签的最佳实践
  • 每个页面只使用一个<h1>标签，代表页面的主标题
  • 按照层级顺序使用标题，不要跳过级别（如从<h1>直接跳到<h3>）
  • 标题应该准确反映内容结构，便于用户理解页面组织
  • 避免使用标题标签仅用于样式，应该使用CSS来控制文本样式
  • 标题内容应该简洁明了，突出重点，建议不超过20个字
  • 在标题中包含关键词，有助于提高SEO效果
  • 保持标题的一致性，使用相同的语法和风格
⚠️ 标题标签常见错误
  • 在一个页面中使用多个<h1>标签
  • 跳过标题级别，如从<h1>直接使用<h3>
  • 使用标题标签来实现文本加粗或增大字体
  • 标题内容过长或不相关
  • 不使用标题标签，导致页面结构不清晰

1.2 段落标签

段落标签<p>用于定义HTML中的段落，浏览器会自动在段落前后添加空白，使内容更易读。段落是HTML中最常用的文本容器之一，用于组织连续的文本内容。

<p>这是一个完整的段落。浏览器会自动在段落前后添加空白，使内容更易读。段落标签是HTML中最常用的文本容器之一。</p>

<p>这是另一个段落。每个段落都应该包含一个独立的思想或主题，这样可以使页面内容结构清晰，便于用户阅读和理解。</p>

1.3 段落标签的嵌套使用

段落标签可以嵌套使用其他文本格式化标签，如<strong>、<em>、<mark>等，以增强文本的表现力和语义。

<p>这是一个包含<strong>重要内容</strong>的段落。<em>强调部分</em>可以帮助用户快速抓住重点。</p>

<p>在段落中，我们可以使用<mark>高亮标记</mark>来突出显示需要特别注意的内容，或者使用<code>代码标签</code>来表示计算机代码。</p>

1.4 段落长度与可读性

段落长度对页面的可读性有很大影响。过长的段落会让用户感到疲惫，难以阅读和理解。建议每个段落不超过5-6行，或者包含1-2个完整的思想。

💡 段落使用的最佳实践
  • 每个段落应该包含一个独立的思想或主题
  • 避免过长的段落，建议每个段落不超过5-6行
  • 使用空行分隔不同的段落，提高可读性
  • 在段落内部使用其他文本格式化标签，如<strong>、<em>等，增强文本的表现力
  • 保持段落之间的逻辑关系清晰，使用过渡词连接不同的段落
  • 使用短句和简单的语言，提高内容的可理解性
  • 在段落开头使用主题句，让用户快速了解段落的主要内容
  • 使用主动语态，使内容更生动、直接
  • 避免使用复杂的术语和行话，确保内容通俗易懂

二、文本样式

HTML提供了多种标签来格式化文本，使文本具有不同的视觉效果和语义含义。这些标签可以分为两类：语义化标签和样式化标签。

2.1 语义化文本格式化标签

语义化标签不仅改变文本的视觉样式，还提供了额外的语义信息，有助于搜索引擎理解内容，提高可访问性。

标签 描述 语义 示例 显示效果 使用场景
<strong> 粗体文本 重要性 <strong>重要内容</strong> 重要内容 警告信息、关键数据、法律条款
<em> 斜体文本 强调 <em>重点内容</em> 重点内容 关键词、专业术语、特殊强调
<mark> 高亮文本 标记重点 <mark>高亮内容</mark> 高亮内容 搜索结果、重点提示、需要注意的内容
<small> 小号文本 附属信息 <small>辅助信息</small> 辅助信息 版权声明、免责条款、注释说明
<s> 删除线文本 过时信息 <s>已删除内容</s> 已删除内容 产品原价、过时的信息、不再有效的内容
<del> 删除线文本 删除操作 <del>已删除内容</del> 已删除内容 文档修订、内容对比、删除记录
<ins> 下划线文本 插入操作 <ins>新添加内容</ins> 新添加内容 文档修订、内容对比、新增记录

2.1.1 语义化标签的重要性

语义化标签不仅改变文本的视觉样式，还提供了额外的语义信息，这对于：

  • 搜索引擎优化（SEO）：搜索引擎可以更好地理解页面内容，提高排名
  • 可访问性：屏幕阅读器可以正确解读内容的重要性和结构
  • 代码可读性：开发者可以更容易理解和维护代码
  • 未来兼容性：语义化标签更符合Web标准，具有更好的未来兼容性

2.2 样式化文本格式化标签

样式化标签主要用于改变文本的视觉样式，不提供额外的语义信息。在现代HTML中，推荐使用CSS来控制文本样式，而不是使用这些标签。

标签 描述 示例 显示效果 替代方案
<b> 粗体文本（仅样式，无语义） <b>粗体文本</b> 粗体文本 <strong> 或 CSS font-weight: bold;
<i> 斜体文本（仅样式，无语义） <i>斜体文本</i> 斜体文本 <em> 或 CSS font-style: italic;
<u> 下划线文本（仅样式，无语义） <u>下划线文本</u> 下划线文本 <ins>（如果有插入语义）或 CSS text-decoration: underline;
注意：

在现代HTML开发中，推荐使用语义化标签而不是样式化标签。样式化标签（如<b>、<i>、<u>）仅改变文本样式，不提供任何语义信息。而语义化标签（如<strong>、<em>、<mark>）不仅改变样式，还提供了有价值的语义信息，有助于搜索引擎理解内容，提高页面的可访问性。

如果只是想改变文本的视觉样式而不需要语义，建议使用CSS来实现，例如：

<!-- 不推荐 -->
<p><b>粗体文本</b></p>

<!-- 推荐：使用语义化标签 -->
<p><strong>重要内容</strong></p>

<!-- 推荐：使用CSS改变样式 -->
<p style="font-weight: bold;">粗体文本</p>

三、换行与水平线

在HTML中，你可以使用特定标签来控制文本的换行和添加水平线，以增强页面的可读性和视觉层次感。

3.1 换行标签

换行标签<br>用于在文本中插入换行符，它是一个自闭合标签，不需要结束标签。换行标签可以在不创建新段落的情况下，将文本从当前位置强制换行。

<p>这是一个段落。<br>
这里使用了换行标签，所以这一行会另起一行显示。<br>
换行标签可以在不创建新段落的情况下强制换行。</p>

3.1.1 换行标签的使用场景

换行标签适用于需要在同一内容块内强制换行的场景，例如：

示例：换行标签的使用场景 只读
📧 地址格式：
<p>张三<br>
北京市朝阳区建国路88号<br>
邮编：100022</p>
🎵 诗歌格式：
<p>床前明月光，<br>
疑是地上霜。<br>
举头望明月，<br>
低头思故乡。</p>
📞 联系方式：
<p>电话：138-0013-8000<br>
邮箱：example@example.com<br>
微信：example_wechat</p>
💡 换行标签使用的最佳实践
  • 仅在需要在段落内部换行时使用<br>标签
  • 避免过度使用换行标签，建议使用段落标签来组织主要内容块
  • 在诗歌、地址、歌词等需要精确换行的情况下，可以适当使用换行标签
  • 不要使用多个连续的<br>标签来创建空白空间，应该使用CSS的margin或padding属性
  • 在HTML5中，<br>标签不需要闭合斜杠（如<br/>），但为了兼容旧版浏览器，有些开发者仍会使用闭合形式
⚠️ 常见错误

不要使用<br>标签来创建段落，这会导致语义不清晰，影响搜索引擎和屏幕阅读器的理解。正确的做法是使用<p>标签来定义段落。

❌ 不良示例：
<div>
  这是第一行内容<br>
  这是第二行内容<br><br>
  这是第三行内容<br>
  这是第四行内容<br>
</div>
✅ 良好示例：
<p>这是第一行内容<br>这是第二行内容</p>
<p>这是第三行内容<br>这是第四行内容</p>

3.2 水平线标签

水平线标签<hr>用于在页面中插入一条水平线，用于分隔不同的内容区块，增强页面的视觉层次感。水平线标签也是一个自闭合标签，不需要结束标签。

<h2>第一部分内容</h2>
<p>这是第一部分的内容...</p>

<hr>

<h2>第二部分内容</h2>
<p>这是第二部分的内容...</p>

3.2.1 水平线的属性

HTML5中，水平线标签支持一些全局属性，如id、class、style等，可以通过CSS来控制水平线的样式，如颜色、宽度、高度、对齐方式等。

<!-- 使用CSS样式控制水平线 -->
<hr style="color: blue; width: 50%; height: 2px; text-align: center;">

<!-- 使用class属性应用预定义样式 -->
<hr class="dashed-hr">

<!-- 使用id属性为特定水平线添加样式 -->
<hr id="section-divider">

3.2.2 水平线样式示例

通过CSS，你可以创建各种样式的水平线，如实线、虚线、点线、渐变线等：

示例：不同样式的水平线 只读
1. 实线水平线（默认）：
<hr>
2. 虚线水平线：
<hr style="border-style: dashed; border-color: #ccc;">
3. 点线水平线：
<hr style="border-style: dotted; border-color: #999;">
4. 双线水平线：
<hr style="border-style: double; border-color: #666;">
5. 渐变水平线：
<hr style="height: 3px; background: linear-gradient(to right, #ff0000, #00ff00, #0000ff); border: none;">

3.2.3 水平线的语义

在HTML5中，<hr>标签不仅是一个视觉元素，还具有语义含义，表示内容的主题转换。它用于分隔两个不同主题的内容区块，而不仅仅是为了美观。

💡 水平线使用的最佳实践
  • 使用水平线分隔页面中不同主题或功能的内容区块
  • 保持水平线样式的一致性，避免在同一页面中使用多种不同样式的水平线
  • 使用CSS来控制水平线的样式，而不是使用HTML的 deprecated 属性（如size、width、align等）
  • 避免过度使用水平线，建议每2-3个主要内容区块使用一条水平线
  • 考虑使用其他分隔方式，如间距、边框、背景色变化等，以增加页面的视觉多样性
  • 确保水平线的颜色与页面整体风格协调，不要使用过于刺眼或与主题不符的颜色

五、HTML排版实战技巧

在实际开发中，HTML排版需要考虑多个因素，包括可读性、可访问性、SEO和视觉设计等。以下是一些实用的HTML排版技巧，帮助你创建高质量的HTML文档。

5.1 页面结构设计

一个良好的页面结构应该包括清晰的层级关系，使用适当的标题标签来组织内容。

💡 页面结构最佳实践
  1. 使用<h1>作为页面的主标题，每个页面只使用一个<h1>
  2. 使用<h2>作为主要章节的标题
  3. 使用<h3>-<h6>作为小节标题，形成清晰的层级结构
  4. 使用水平线<hr>分隔不同的内容区块
  5. 使用适当的段落和换行来控制文本流

5.2 文本可读性优化

文本可读性是HTML排版的重要考虑因素，直接影响用户体验和内容的传播效果。

💡 文本可读性最佳实践
  1. 保持段落简短，每个段落不超过5-6行
  2. 使用适当的行高和字间距，提高文本的可读性
  3. 使用语义化标签来增强文本的表现力
  4. 避免使用过多的文本样式，保持页面简洁
  5. 使用列表标签来组织相关内容，提高可读性

5.3 SEO优化

HTML排版对SEO有重要影响，合理使用标题标签和语义化标签可以提高页面在搜索引擎中的排名。

💡 SEO优化最佳实践
  1. 使用准确的标题标签来描述页面内容
  2. 在标题中包含关键词，但避免关键词堆砌
  3. 使用语义化标签，帮助搜索引擎理解内容
  4. 保持页面结构清晰，便于搜索引擎爬行
  5. 使用适当的alt属性为图片提供描述

六、本课小结

知识点回顾

  • 标题标签：
    • HTML提供了6级标题标签，从<h1>到<h6>
    • h1最高级，每页只用一个；h6最低级，尽量少用
    • 按层级顺序使用，不要跳过级别
    • 标题内容应简洁明了，突出重点
  • 段落标签：
    • 使用<p>标签定义段落，浏览器自动添加间距
    • 每个段落包含一个独立思想或主题
    • 避免过长段落，建议不超过5-6行
    • 可嵌套其他文本格式化标签
  • 文本样式：
    • 语义化标签：<strong>、<em>、<mark>、<s>、<del>、<ins>、<small>
    • 样式化标签：<b>、<i>、<u>（不推荐）
    • 特殊标签：<code>、<pre>、<kbd>、<samp>、<var>、<blockquote>、<q>、<abbr>、<dfn>
    • 上下标标签：<sub>、<sup>（用于数学公式、化学符号等）
  • 换行与水平线：
    • <br>：段落内换行，自闭合标签
    • <hr>：分隔内容区块，具有语义含义
    • 可通过CSS自定义水平线样式
  • 特殊字符：
    • 使用HTML实体表示特殊字符，如&lt;、&gt;、&amp;
    • 实体格式：&实体名称; 或 &#实体编号;
    • 必须使用实体的场景：显示HTML标签、在属性中使用引号、使用&符号
    • 常用实体：版权符号、货币符号、数学符号、希腊字母等
  • 排版最佳实践：
    • 页面结构清晰，使用合适的标题层级
    • 文本可读性优先，避免过长段落
    • 语义化标签优先于样式化标签
    • CSS控制样式，HTML负责结构和语义
