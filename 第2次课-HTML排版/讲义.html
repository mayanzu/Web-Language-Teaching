第2课：HTML排版与文本格式化

在本节课中，我们将学习HTML中的排版与文本格式化，包括标题、段落、文本样式、换行和特殊字符等内容。 通过本节课的学习，你将能够创建结构清晰、样式丰富的HTML文本内容。

1. 标题与段落

HTML提供了多种标签来定义不同级别的标题和段落，帮助你组织页面内容结构。

1.1 标题标签

HTML提供了6级标题标签，从<h1>到<h6>，其中<h1>是最高级别的标题，<h6>是最低级别的标题。

实验 01：标题标签的使用 未运行
HTML (可编辑)<!DOCTYPE html> <html lang="zh-CN"> <head> <meta charset="UTF-8"> <title>标题标签示例</title> </head> <body> <h1>一级标题</h1> <h2>二级标题</h2> <h3>三级标题</h3> <h4>四级标题</h4> <h5>五级标题</h5> <h6>六级标题</h6> </body> </html>

1.2 段落标签

段落标签<p>用于定义HTML中的段落。

5. 课后练习

现在，让我们通过一个简单的练习来巩固本节课所学的内容。

练习：创建一个简单的HTML文档 Beginner

练习目标

创建一个包含标题、段落、文本样式和特殊字符的HTML文档。

练习步骤

  1. 创建一个新的HTML文件，命名为exercise-2.html
  2. 添加HTML基本结构（DOCTYPE、html、head、body标签）
  3. 在head标签中添加title标签，设置页面标题为"HTML排版练习"
  4. 在body标签中添加以下内容：
    • 一个一级标题"HTML排版练习"
    • 一个段落，包含粗体、斜体和下划线文本
    • 一个水平线
    • 一个二级标题"文本格式化示例"
    • 一个段落，包含下标和上标文本
    • 一个段落，包含特殊字符（小于号、大于号、和号）
    • 一个段落，包含版权符号和商标符号
  5. 保存文件并在浏览器中打开，查看效果

示例输出

exercise-2.html

<!DOCTYPE html>
<html lang="zh-CN">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>HTML排版练习</title>
</head>
<body>
    <h1>HTML排版练习</h1>
    <p><strong>这是粗体文本</strong>，<em>这是斜体文本</em>，<u>这是下划线文本</u></p>
    <hr>
    <h2>文本格式化示例</h2>
    <p>H<sub>2</sub>O 是水的化学式，2<sup>3</sup> = 8</p>
    <p>5 < 10，10 > 5，AT&T是一家电信公司</p>
    <p>版权所有 © 2025，注册商标 ®，商标 ™</p>
</body>
</html>
