第16课：CSS层级选择器

CSS层级选择器允许你根据元素在文档结构中的位置来选择元素。它们是CSS中基础但非常重要的选择器类型，让样式应用更加精确和灵活。本节课将学习后代选择器、子代选择器和兄弟选择器的用法。

1. 复习：基本选择器与交并集选择器

在学习层级选择器之前，我们先回顾一下基本选择器和交并集选择器的用法。

1.1 基本选择器

/* 元素选择器 */
p {
  color: blue;
}

/* 类选择器 */
.highlight {
  background-color: yellow;
}

/* ID选择器 */
#header {
  font-size: 24px;
}

对应的HTML结构：

<p>这是一个普通段落</p>
<p class="highlight">这是一个高亮段落</p>
<div id="header">页面标题</div>

1.2 交并集选择器

/* 交集选择器：同时具有两个类 */
.button.primary {
  background-color: blue;
  color: white;
}

/* 并集选择器：具有任意一个类 */
.button, .link {
  text-decoration: none;
}

对应的HTML结构：

<button class="button primary">主要按钮</button>
<a class="link" href="#">链接</a>

2. 介绍

CSS层级选择器允许你根据元素在文档结构中的位置来选择元素。它们是CSS中基础但非常重要的选择器类型，让样式应用更加精确和灵活。

为什么重要？

层级选择器让你能够精确控制样式应用，避免不必要的样式冲突，提高代码的可维护性。理解层级选择器是掌握CSS的关键。

3. 后代选择器（Descendant Selector）

后代选择器使用空格来选择某个元素的后代元素。后代元素可以是子元素、孙元素等任意层级的后代。

简单理解

后代选择器就像是"家族选择器"，它会选择指定祖先元素的所有后代，无论嵌套多少层。

3.1 语法

ancestor descendant {
    /* CSS 规则 */
}

3.2 示例

选择 .box 内的所有 span 元素，将其背景色设为浅黄色。

.box span {
    background-color: lightyellow;
}

对应的HTML结构：

<div class="box">
    <p>这是一个段落，包含 <span>span 元素</span>。</p>
    <div>
        <p>嵌套段落中的 <span>另一个 span</span>。</p>
    </div>
</div>
选择器 描述 说明
article p 选择article内的所有段落 无论嵌套几层都会选中
nav a 选择导航栏内的所有链接 包括子菜单中的链接
.container .highlight 选择容器内的所有高亮元素 类选择器的组合使用

4. 子代选择器（Child Selector）

子代选择器使用 > 来选择某个元素的直接子元素。与后代选择器不同，它只选择直接的子元素。

简单理解

子代选择器就像是"直系子女"，只选择直接的孩子，不选择孙子孙女。

4.1 语法

parent > child {
    /* CSS 规则 */
}

4.2 示例

.article > h2,
.article > p {
    font-weight: bold;
    color: #0066cc;
    padding: 8px;
    margin: 8px 0;
}

对应的HTML结构：

<!-- 演示子代选择器只选择直接子元素 -->
<div class="article">
    <!-- 这些是.article的直接子元素，会被.article > h2, .article > p选中 -->
    <h2>直接子元素标题（加粗蓝色）</h2>
    <p>直接子元素段落（加粗蓝色）</p>
    
    <div class="content">
        <!-- 这些元素在.content内，不是.article的直接子元素，不会受影响 -->
        <h2>嵌套在div中的标题（正常样式）</h2>
        <p>嵌套在div中的段落（正常样式）</p>
        <div>
            <h2>更深层嵌套的标题（正常样式）</h2>
            <p>更深层嵌套的段落（正常样式）</p>
        </div>
    </div>
    
    <p>另一个直接子元素段落（加粗蓝色）</p>
</div>

5. 相邻兄弟选择器（Adjacent Sibling Selector）

相邻兄弟选择器使用 + 来选择紧跟在指定元素后面的第一个兄弟元素。

简单理解

相邻兄弟选择器就像是"紧挨着的弟弟妹妹"，只选择紧跟在后面的第一个兄弟元素。

5.1 语法

element + sibling {
    /* CSS 规则 */
}

5.2 示例

h2 + p {
    color: red;
}

.highlight + p {
    font-weight: bold;
}

对应的HTML结构：

<h2>章节标题</h2>
<p>紧跟在h2后的段落（红色）</p>
<p>不紧跟h2的段落（不受影响）</p>

<p class="highlight">高亮段落</p>
<p>紧跟在高亮段落后的段落（加粗）</p>
<p>另一个段落（不受影响）</p>

6. 通用兄弟选择器（General Sibling Selector）

通用兄弟选择器使用 ~ 来选择指定元素后面的所有兄弟元素。

简单理解

通用兄弟选择器就像是"所有的弟弟妹妹"，选择指定元素之后的所有兄弟元素。

6.1 语法

element ~ siblings {
    /* CSS 规则 */
}

6.2 示例

h3 ~ li {
    color: green;
}

.active ~ .item {
    background-color: #e3f2fd;
}

对应的HTML结构：

<h3>小节标题</h3>
<li>列表项1（绿色）</li>
<li>列表项2（绿色）</li>
<p>段落元素</p>
<li>列表项3（绿色）</li>
<li>列表项4（绿色）</li>

<div class="active">激活的项目</div>
<div class="item">项目1（蓝色背景）</div>
<div class="item">项目2（蓝色背景）</div>
<div>普通div（不受影响）</div>
<div class="item">项目3（蓝色背景）</div>

    7. 实践应用

    层级选择器在实际开发中有许多应用场景。

    最佳实践

    层级选择器可以与其他选择器组合使用，创建精确的样式控制。例如：.nav > ul > li > a:hover

    7.1 常见应用场景

    /* 导航菜单：直接子元素 */
nav > ul > li {
    display: inline-block;
}

nav > ul > li > a {
    text-decoration: none;
}

/* 文章布局：相邻兄弟 */
article > h2 + p {
    font-size: 1.1em;
    color: #666;
}

/* 列表样式：通用兄弟 */
.list > li ~ li {
    border-top: 1px solid #ddd;
    padding-top: 10px;
}
