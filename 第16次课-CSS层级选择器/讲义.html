第16课：CSS层级选择器

CSS层级选择器允许你根据元素在文档结构中的位置关系来选择元素。它们是CSS中基础但非常重要的选择器类型，让样式应用更加精确和灵活。本节课将深入学习四种层级选择器的用法和最佳实践。

后代选择器 子代选择器 相邻兄弟选择器 通用兄弟选择器 CSS选择器

1. CSS层级选择器概述

CSS层级选择器是基于HTML文档的层级结构（树形结构）来选择元素的选择器。HTML文档中的元素通过嵌套关系形成父子、兄弟等层级关系，层级选择器正是利用这些关系来精确定位元素。

什么是文档树结构？

HTML文档可以看作是一个倒置的树，根节点是<html>元素，其他元素都是它的子节点。每个元素可以有父元素、子元素和兄弟元素，这种关系被称为DOM（文档对象模型）树结构。

1.1 层级选择器的类型

选择器类型 语法 描述
后代选择器 ancestor descendant 选择祖先元素的所有后代元素
子代选择器 parent > child 只选择父元素的直接子元素
相邻兄弟选择器 element + sibling 选择元素的下一个直接相邻兄弟元素
通用兄弟选择器 element ~ siblings 选择元素后面的所有兄弟元素

1.2 层级选择器的优势

  • 更精确地定位目标元素
  • 避免样式冲突
  • 提高代码的可维护性
  • 利用HTML结构关系编写更简洁的CSS

2. 后代选择器（Descendant Selector）

后代选择器使用空格来选择某个元素的后代元素。后代元素可以是子元素、孙元素等任意层级的后代。

简单理解

后代选择器就像是"家族选择器"，它会选择指定祖先元素的所有后代，无论嵌套多少层。

2.1 语法

ancestor descendant {
    /* CSS 规则 */
}

2.2 示例

实验 01：后代选择器 动手实践
HTML (可编辑)
<div class="box"> <p>这是一个段落，包含 <span>span 元素</span>。</p> <div> <p>嵌套段落中的 <span>另一个 span</span>。</p> </div> </div>
CSS (可编辑)
/* 后代选择器：选择.box内的所有span元素 */ .box span { background-color: lightyellow; padding: 2px 4px; }
预览效果

2.3 后代选择器的特点

  • 选择器之间用空格分隔
  • 选择所有层级的后代元素，无论嵌套多深
  • 可以连续使用多个选择器，如 div ul li a
  • 优先级高于单独的选择器

3. 子代选择器（Child Selector）

子代选择器使用 > 来选择某个元素的直接子元素。与后代选择器不同，它只选择直接的子元素。

简单理解

子代选择器就像是"直系子女"，只选择直接的孩子，不选择孙子孙女。

3.1 语法

parent > child {
    /* CSS 规则 */
}

3.2 示例

实验 02：子代选择器 动手实践
HTML (可编辑)
<div class="article"> <h2>直接子元素标题（加粗蓝色）</h2> <p>直接子元素段落（加粗蓝色）</p> <div class="content"> <!-- 这些元素在.content内，不是.article的直接子元素，不会受影响 --> <h2>嵌套在div中的标题（正常样式）</h2> <p>嵌套在div中的段落（正常样式）</p> </div> <p>另一个直接子元素段落（加粗蓝色）</p> </div>
CSS (可编辑)
/* 子代选择器：只选择.article的直接子元素h2和p */ .article > h2, .article > p { font-weight: bold; color: #0066cc; padding: 8px; margin: 8px 0; }
预览效果

3.3 子代选择器的特点

  • 选择器之间用>符号分隔
  • 只选择直接子元素，不匹配深层嵌套的后代元素
  • 优先级高于后代选择器
  • 适合精确选择特定层级的元素

4. 相邻兄弟选择器（Adjacent Sibling Selector）

相邻兄弟选择器使用 + 来选择紧跟在指定元素后面的第一个兄弟元素。

简单理解

相邻兄弟选择器就像是"紧挨着的弟弟妹妹"，只选择紧跟在后面的第一个兄弟元素。

4.1 语法

element + sibling {
    /* CSS 规则 */
}

4.2 示例

实验 03：相邻兄弟选择器 动手实践
HTML (可编辑)
<h2>章节标题</h2> <p>紧跟在h2后的段落（红色斜体）</p> <p>不紧跟h2的段落（不受影响）</p> <p class="highlight">高亮段落</p> <p>紧跟在高亮段落后的段落（加粗黄色）</p> <p>另一个段落（不受影响）</p>
CSS (可编辑)
/* 相邻兄弟选择器：选择h2后面的第一个p元素 */ h2 + p { color: red; font-style: italic; padding: 10px; background: #ffe6e6; } /* 相邻兄弟选择器：选择.highlight后面的第一个p元素 */ .highlight + p { font-weight: bold; background: #fff3cd; padding: 10px; color: #856404; }
预览效果

4.3 相邻兄弟选择器的特点

  • 选择器之间用+符号分隔
  • 只选择紧接在第一个元素后面的直接相邻的兄弟元素
  • 两个元素必须拥有相同的父元素
  • 只匹配下一个兄弟元素，不匹配前面的兄弟元素

5. 通用兄弟选择器（General Sibling Selector）

通用兄弟选择器使用 ~ 来选择指定元素后面的所有兄弟元素。

简单理解

通用兄弟选择器就像是"所有的弟弟妹妹"，选择指定元素之后的所有兄弟元素。

5.1 语法

element ~ siblings {
    /* CSS 规则 */
}

5.2 示例

实验 04：通用兄弟选择器 动手实践
HTML (可编辑)
<h3>小节标题</h3> <li>列表项1（绿色）</li> <li>列表项2（绿色）</li> <p>段落元素</p> <li>列表项3（绿色）</li> <li>列表项4（绿色）</li> <div class="active">激活的项目</div> <div class="item">项目1（蓝色背景）</div> <div class="item">项目2（蓝色背景）</div> <div>普通div（不受影响）</div> <div class="item">项目3（蓝色背景）</div>
CSS (可编辑)
/* 通用兄弟选择器：选择h3后面所有的li兄弟元素 */ h3 ~ li { color: green; font-weight: bold; padding: 8px; margin: 5px 0; } /* 通用兄弟选择器：选择.active后面所有的.item兄弟元素 */ .active ~ .item { background-color: #e3f2fd; border-left: 4px solid #0066cc; padding: 10px; margin: 8px 0; }
预览效果

5.3 通用兄弟选择器的特点

  • 选择器之间用~符号分隔
  • 选择某个元素后面的所有兄弟元素，无论中间有多少其他元素
  • 两个元素必须拥有相同的父元素
  • 只匹配后面的兄弟元素，不匹配前面的兄弟元素
  • 可以匹配多个兄弟元素

七、课程小结

本节课我们学习了CSS层级选择器，它们是根据元素在文档结构中的位置来选择元素的强大工具。

7.1 知识点回顾

  • 后代选择器：使用空格分隔，选择所有后代元素，如div p
  • 子代选择器：使用>分隔，只选择直接子元素，如div > p
  • 相邻兄弟选择器：使用+分隔，选择下一个直接相邻元素，如h2 + p
  • 通用兄弟选择器：使用~分隔，选择所有后面的兄弟元素，如h2 ~ p

7.2 重点记忆

📌 选择器优先级

层级选择器的优先级取决于其组成部分的优先级，组合选择器不会改变单个选择器的优先级。

ID选择器 > 类选择器 > 元素选择器

7.3 最佳实践

  1. 优先使用较简单的选择器，避免过度复杂的嵌套
  2. 合理使用层级选择器，提高样式的精确性和可维护性
  3. 结合其他选择器使用，创建更强大的选择规则
  4. 考虑选择器的性能，避免不必要的层级嵌套
