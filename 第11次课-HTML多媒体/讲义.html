一、音频标签基本使用

HTML5的<audio>标签允许我们在网页中直接播放音频文件，无需使用第三方插件。

1.1 基本语法

最简单的音频播放器只需要使用<audio>标签和src属性，再加上controls属性显示播放控件。 

<!-- 基本音频播放器 -->
<audio src="音频文件路径" controls>
    您的浏览器不支持音频播放
</audio>

1.2 支持多种音频格式

不同浏览器支持的音频格式可能不同，为了确保音频在所有浏览器中都能正常播放，我们可以提供多种格式的音频文件。 

<!-- 支持多种音频格式 -->
<audio controls>
    <source src="music.mp3" type="audio/mpeg">
    <source src="music.ogg" type="audio/ogg">
    您的浏览器不支持音频播放
</audio>

1.3 常用属性

<audio>标签支持多种属性，用于控制音频的播放行为：

属性 描述
src 指定音频文件的路径
controls 显示浏览器默认的播放控件
autoplay 页面加载完成后自动播放
loop 循环播放音频
muted 静音播放

二、视频标签基本使用

HTML5的<video>标签允许我们在网页中直接播放视频文件，无需使用第三方插件。

2.1 基本语法

最简单的视频播放器只需要使用<video>标签和src属性，再加上controls属性显示播放控件。 

<!-- 基本视频播放器 -->
<video src="视频文件路径" controls width="640" height="360">
    您的浏览器不支持视频播放
</video>

2.2 支持多种视频格式

不同浏览器支持的视频格式可能不同，为了确保视频在所有浏览器中都能正常播放，我们可以提供多种格式的视频文件。 

<!-- 支持多种视频格式 -->
<video controls width="640" height="360">
    <source src="video.mp4" type="video/mp4">
    <source src="video.webm" type="video/webm">
    您的浏览器不支持视频播放
</video>

2.3 常用属性

<video>标签支持多种属性，用于控制视频的播放行为：

属性 描述
src 指定视频文件的路径
controls 显示浏览器默认的播放控件
width 设置视频的宽度
height 设置视频的高度
autoplay 页面加载完成后自动播放
loop 循环播放视频
muted 静音播放
poster 设置视频播放前显示的封面图片

三、iframe嵌入外部内容

<iframe>标签允许我们在网页中嵌入另一个网页或外部内容，如地图、视频、社交媒体帖子等。

3.1 基本语法

基本的<iframe>标签使用src属性指定要嵌入的内容的URL。 

<!-- 基本iframe用法 -->
<iframe src="要嵌入的网页地址" width="600" height="400" title="描述文本">
    您的浏览器不支持iframe
</iframe>

3.2 常用属性

属性 描述
src 指定要嵌入的内容的URL
width 设置iframe的宽度
height 设置iframe的高度
title 为iframe添加描述，提高可访问性
frameborder 设置是否显示边框（0=不显示，1=显示）

3.3 常见应用示例

3.3.1 嵌入地图

<!-- 嵌入百度地图 -->
<iframe src="https://map.baidu.com/" width="600" height="400" title="百度地图" frameborder="0">
    您的浏览器不支持iframe
</iframe>

3.3.2 嵌入网页

<!-- 嵌入W3Schools网站 -->
<iframe src="https://www.w3schools.com" width="600" height="400" title="W3Schools网站" frameborder="0">
    您的浏览器不支持iframe
</iframe>
