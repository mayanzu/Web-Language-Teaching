一、音频标签基本使用

1.1 多媒体时代的网页

在HTML5之前，要在网页中播放音频需要使用Flash等插件，这带来了很多问题：

💭 Flash时代的问题
  • 用户需要安装Flash插件
  • 移动设备（iOS）不支持Flash
  • 安全漏洞频繁，被攻击风险高
  • 消耗大量系统资源

2020年底，Adobe正式终止了Flash的支持。HTML5的 <audio> 和 <video> 标签成为了标准解决方案。

1.2 基本语法

HTML5的<audio>标签允许我们在网页中直接播放音频文件，无需使用第三方插件。

最简单的音频播放器只需要使用<audio>标签和src属性，再加上controls属性显示播放控件。

<!-- 基本音频播放器 -->
<audio src="音频文件路径" controls>
    您的浏览器不支持音频播放
</audio>
降级处理

开始标签和结束标签之间的文字是"后备内容"（fallback content），只有当浏览器不支持 <audio> 标签时才会显示。现代浏览器基本都支持该标签，所以这段文字通常不会出现。

1.3 支持多种音频格式

不同浏览器支持的音频格式可能不同，为了确保音频在所有浏览器中都能正常播放，我们可以使用 <source> 标签提供多种格式的音频文件。

<!-- 支持多种音频格式 -->
<audio controls>
    <source src="music.mp3" type="audio/mpeg">
    <source src="music.ogg" type="audio/ogg">
    <source src="music.wav" type="audio/wav">
    您的浏览器不支持音频播放
</audio>

1.4 音频格式对比

格式扩展名MIME类型特点浏览器支持
MP3.mp3audio/mpeg最通用、压缩比高 全部支持
OGG.oggaudio/ogg开源免费、音质好Chrome、Firefox、Opera
WAV.wavaudio/wav无损格式、文件大 全部支持
AAC.aacaudio/aac苹果主推、音质好Chrome、Safari、Edge
格式选择建议

为了最佳兼容性，建议至少提供 MP3 格式。如果追求更好的音质和开源，可以额外提供 OGG 格式。浏览器会按顺序尝试，使用第一个能播放的格式。

1.5 常用属性详解

属性值描述示例
srcURL 指定音频文件的路径 src="music.mp3"
controls布尔 显示浏览器默认的播放控件 controls
autoplay布尔 页面加载完成后自动播放 autoplay
loop布尔 循环播放音频 loop
muted布尔 默认静音 muted
preloadnone/metadata/auto 预加载策略 preload="auto"

1.6 preload属性详解

值描述适用场景
none不预加载音频用户可能不会播放，节省带宽
metadata只预加载元数据（时长等）默认值，平衡带宽和体验
auto预加载整个音频用户很可能会播放
自动播放的限制

现代浏览器为了改善用户体验，对自动播放做了限制：

  • 有声音的音频无法自动播放（除非用户已与页面交互）
  • 静音的音频可以自动播放：autoplay muted
  • 这是为了防止网站突然播放声音打扰用户

二、视频标签基本使用

2.1 视频在网页中的重要性

视频已经成为现代网页的重要组成部分：

  • 产品展示：电商网站展示商品细节
  • 教育培训：在线课程、教学视频
  • 背景视频：网站首页的动态背景
  • 用户生成内容：社交媒体、视频平台

HTML5的<video>标签允许我们在网页中直接播放视频文件，无需使用第三方插件。

2.2 基本语法

最简单的视频播放器只需要使用<video>标签和src属性，再加上controls属性显示播放控件。

<!-- 基本视频播放器 -->
<video src="视频文件路径" controls width="640" height="360">
    您的浏览器不支持视频播放
</video>

2.3 支持多种视频格式

不同浏览器支持的视频格式可能不同，为了确保视频在所有浏览器中都能正常播放，我们可以使用 <source> 标签提供多种格式的视频文件。

<!-- 支持多种视频格式 -->
<video controls width="640" height="360">
    <source src="video.mp4" type="video/mp4">
    <source src="video.webm" type="video/webm">
    <source src="video.ogg" type="video/ogg">
    您的浏览器不支持视频播放
</video>

2.4 视频格式对比

格式扩展名视频编码音频编码浏览器支持
MP4.mp4H.264AAC 全部支持（推荐）
WebM.webmVP8/VP9Vorbis/OpusChrome、Firefox、Opera、Edge
OGG.ogvTheoraVorbisChrome、Firefox、Opera
格式选择建议

MP4 (H.264) 是目前最通用的格式，所有现代浏览器都支持。如果只能选一种格式，就选 MP4。

如果追求更好的压缩率和开源，可以额外提供 WebM (VP9) 格式。

2.5 常用属性详解

属性值描述示例
srcURL 指定视频文件的路径 src="video.mp4"
controls布尔 显示播放控件（播放/暂停、进度条、音量等） controls
width像素 设置视频的宽度 width="640"
height像素 设置视频的高度 height="360"
posterURL 视频播放前显示的封面图片 poster="cover.jpg"
autoplay布尔 页面加载完成后自动播放 autoplay
loop布尔 循环播放视频 loop
muted布尔 默认静音播放 muted
preloadnone/metadata/auto 预加载策略 preload="metadata"
playsinline布尔 在iOS上内联播放（不全屏） playsinline

2.6 poster属性的重要性

poster 属性用于设置视频的封面图片，这很重要：

  • 提升用户体验：用户可以在播放前看到视频内容预览
  • 加载时显示：在视频加载过程中显示封面，避免空白
  • 节省带宽：用户可以先看封面再决定是否播放
<!-- 带封面图片的视频 -->
<video controls width="640" height="360" poster="video-cover.jpg">
    <source src="video.mp4" type="video/mp4">
    您的浏览器不支持视频播放
</video>

2.7 背景视频的实现

很多现代网站使用视频作为背景，实现方法如下：

<!-- 背景视频 -->
<style>
    .video-background {
        position: fixed;
        top: 0;
        left: 0;
        width: 100%;
        height: 100%;
        object-fit: cover;  /* 覆盖整个区域 */
        z-index: -1;        /* 放在最底层 */
    }
</style>

<video class="video-background" autoplay muted loop playsinline>
    <source src="background.mp4" type="video/mp4">
</video>
背景视频注意事项
  • 必须使用 muted，否则无法自动播放
  • 使用 playsinline，防止iOS全屏播放
  • 视频文件要压缩，避免加载过慢
  • 提供静态图片作为后备方案
  • 考虑用户的网络和电量消耗

三、iframe嵌入外部内容

3.1 什么是iframe？

<iframe>（Inline Frame，内联框架）标签允许我们在网页中嵌入另一个网页或外部内容，就像在页面中开了一个“窗口”，可以显示其他网站的内容。

iframe的常见用途
  • 嵌入地图：在网页中显示百度地图、高德地图
  • 嵌入视频：嵌入B站、YouTube等平台的视频
  • 嵌入社交内容：微博、推特帖子
  • 嵌入第三方工具：在线表单、日历、聊天窗口
  • 广告展示：展示第三方广告内容

3.2 基本语法

基本的<iframe>标签使用src属性指定要嵌入的内容的URL。

<!-- 基本iframe用法 -->
<iframe src="要嵌入的网页地址" width="600" height="400" title="描述文本">
    您的浏览器不支持iframe
</iframe>

3.3 常用属性详解

属性值描述示例
srcURL 指定要嵌入的内容的URL src="https://example.com"
width像素/% 设置iframe的宽度 width="600" 或 width="100%"
height像素 设置iframe的高度 height="400"
title文本 描述iframe内容（重要！提高可访问性） title="地图位置"
name文本 iframe的名称，用于链接跳转 name="myframe"
loadingeager/lazy 延迟加载策略 loading="lazy"
sandbox多种值 安全限制（见下文） sandbox="allow-scripts"
allowfullscreen布尔 允许全屏显示 allowfullscreen

3.4 sandbox安全属性

sandbox 属性可以限制iframe中的内容行为，提高安全性：

值描述
sandbox（空值）启用所有限制
allow-scripts允许执行脚本
allow-forms允许提交表单
allow-same-origin允许同源访问
allow-popups允许弹出窗口
iframe安全注意事项
  • 只嵌入你信任的网站内容
  • 使用 sandbox 属性限制不必要的权限
  • 某些网站（如Google）禁止被iframe嵌入
  • 注意跨域安全问题

3.5 常见应用示例

3.5.1 嵌入B站视频

<!-- 嵌入B站视频（从B站分享获取代码）-->
<iframe src="//player.bilibili.com/player.html?bvid=BV1xx411c7mD" 
        width="640" height="360" 
        scrolling="no" border="0" frameborder="no" framespacing="0" 
        allowfullscreen="true"
        title="B站视频">
</iframe>

3.5.2 嵌入地图

<!-- 嵌入百度地图 -->
<iframe src="https://map.baidu.com/search/..." 
        width="600" height="400" 
        title="公司位置" 
        loading="lazy"
        style="border: none;">
</iframe>

3.5.3 响应式iframe

使用CSS让iframe自适应宽度：

<style>
    .iframe-container {
        position: relative;
        width: 100%;
        padding-bottom: 56.25%; /* 16:9比例 */
        height: 0;
        overflow: hidden;
    }
    .iframe-container iframe {
        position: absolute;
        top: 0;
        left: 0;
        width: 100%;
        height: 100%;
        border: none;
    }
</style>

<div class="iframe-container">
    <iframe src="video-url" title="视频" allowfullscreen></iframe>
</div>
性能优化建议
  • 使用 loading="lazy" 延迟加载不在视口中的iframe
  • 只在需要时加载iframe（如用户点击后）
  • 避免在页面中使用过多iframe
  • 为iframe设置合适的尺寸，避免重排

知识点回顾

恭喜你完成了HTML多媒体的学习！本节课我们学习了：

  • 音频标签：<audio> 基本使用、多格式支持、常用属性
  • 视频标签：<video> 基本使用、poster封面、背景视频
  • iframe嵌入：嵌入地图、视频、第三方内容
  • 媒体格式：MP3、OGG、MP4、WebM等格式的选择
  • 安全与性能：sandbox属性、延迟加载

标签对比表

标签用途常用属性注意事项
<audio> 播放音频 src, controls, autoplay, loop, muted 提供MP3格式确保兼容
<video> 播放视频 src, controls, width, height, poster 提供MP4格式确保兼容
<source> 指定媒体源 src, type 放在audio/video内部
<iframe> 嵌入外部内容 src, width, height, title, sandbox 注意安全性，使用sandbox

最佳实践

开发建议
  • 提供多种格式：音频用MP3+OGG，视频用MP4+WebM

  • 设置poster：为视频添加封面图片，提升用户体验
  • 注意自动播放：有声媒体需配合 muted 才能自动播放
  • 使用延迟加载：iframe使用 loading="lazy"
  • 添加title属性：为iframe添加描述，提高可访问性
