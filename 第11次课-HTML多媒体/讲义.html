第11课：HTML多媒体

在本节课中，我们将学习HTML多媒体元素。多媒体是现代网页的重要组成部分，它包括音频、视频、动画等多种形式。 HTML5提供了强大的多媒体支持，允许我们直接在网页中嵌入和播放音频、视频等媒体内容。 通过本节课的学习，你将掌握如何在HTML中使用音频、视频和嵌入内容等多媒体元素。

1. 音频标签

<audio>标签用于在HTML中嵌入音频内容，它支持多种音频格式，如MP3、WAV、OGG等。

1.1 基本音频播放器

基本的音频播放器使用<audio>标签和controls属性创建，controls属性会显示浏览器默认的音频控制控件。 

<audio src="audio.mp3" controls>
    您的浏览器不支持音频播放
</audio>

1.2 支持多种音频格式

不同的浏览器支持不同的音频格式，为了确保音频能够在所有浏览器中正常播放，我们可以使用<source>标签提供多种音频格式。 

<audio controls>
    <source src="audio.mp3" type="audio/mpeg">
    <source src="audio.ogg" type="audio/ogg">
    您的浏览器不支持音频播放
</audio>

1.3 音频属性

<audio>标签支持多种属性，用于控制音频的播放行为：

属性 描述
src 指定音频文件的URL
controls 显示音频控制控件
autoplay 自动播放音频
loop 循环播放音频
muted 静音播放音频
preload 指定音频的预加载方式（none、metadata、auto）
volume 指定音频的音量（0.0-1.0）

2. 视频标签

<video>标签用于在HTML中嵌入视频内容，它支持多种视频格式，如MP4、WebM、OGG等。

2.1 基本视频播放器

基本的视频播放器使用<video>标签和controls属性创建，controls属性会显示浏览器默认的视频控制控件。 

<video src="video.mp4" controls width="640" height="360">
    您的浏览器不支持视频播放
</video>

2.2 支持多种视频格式

不同的浏览器支持不同的视频格式，为了确保视频能够在所有浏览器中正常播放，我们可以使用<source>标签提供多种视频格式。 

<video controls width="640" height="360">
    <source src="video.mp4" type="video/mp4">
    <source src="video.webm" type="video/webm">
    您的浏览器不支持视频播放
</video>

2.3 视频属性

<video>标签支持多种属性，用于控制视频的播放行为：

属性 描述
src 指定视频文件的URL
controls 显示视频控制控件
width 指定视频的宽度
height 指定视频的高度
autoplay 自动播放视频
loop 循环播放视频
muted 静音播放视频
preload 指定视频的预加载方式（none、metadata、auto）
poster 指定视频播放前显示的封面图片
playsinline 在移动设备上内联播放视频，而不是全屏播放

3. 嵌入内容

在HTML中，我们可以使用<iframe>标签来嵌入其他网页或外部内容，如地图、视频、社交媒体帖子等。

3.1 基本iframe用法

基本的<iframe>标签使用src属性指定要嵌入的内容的URL。 

<iframe src="https://www.example.com" width="600" height="400" title="Example Website">
    您的浏览器不支持iframe
</iframe>

3.2 iframe属性

<iframe>标签支持多种属性，用于控制嵌入内容的显示和行为：

属性 描述
src 指定要嵌入的内容的URL
width 指定iframe的宽度
height 指定iframe的高度
title 指定iframe的标题，用于可访问性
frameborder 指定是否显示边框（0或1）
scrolling 指定是否显示滚动条（auto、yes、no）
allowfullscreen 允许嵌入的内容全屏显示
sandbox 启用沙箱模式，限制嵌入内容的权限

3.3 常用iframe嵌入示例

3.3.1 嵌入百度地图

<iframe src="https://map.baidu.com/" width="600" height="400" title="百度地图">
    您的浏览器不支持iframe
</iframe>

3.3.2 嵌入YouTube视频

<iframe width="560" height="315" src="https://www.youtube.com/embed/dQw4w9WgXcQ" 
        title="YouTube视频" frameborder="0" 
        allow="accelerometer; autoplay; clipboard-write; encrypted-media; gyroscope; picture-in-picture" 
        allowfullscreen>
</iframe>

使用<iframe>嵌入外部内容时，可能会带来安全风险，如跨站脚本攻击（XSS）等。 为了提高安全性，我们可以使用sandbox属性来限制嵌入内容的权限，或者使用referrerpolicy属性来控制发送的Referer信息。

4. 媒体属性与事件

HTML5多媒体元素支持多种属性和事件，我们可以使用JavaScript来控制和响应用户与媒体元素的交互。

4.1 媒体属性

我们可以使用JavaScript来访问和修改媒体元素的属性，如播放状态、音量、当前播放时间等。 

<video id="myVideo" src="video.mp4" controls></video>

<script>
    const video = document.getElementById('myVideo');
    
    // 访问属性
    console.log(video.currentTime); // 当前播放时间
    console.log(video.duration); // 总时长
    console.log(video.volume); // 当前音量
    console.log(video.paused); // 是否暂停
    
    // 修改属性
    video.volume = 0.5; // 设置音量为50%
    video.currentTime = 10; // 跳转到第10秒
</script>

4.2 媒体方法

媒体元素提供了多种方法，用于控制媒体的播放、暂停、加载等操作。

方法 描述
play() 播放媒体
pause() 暂停媒体
load() 重新加载媒体
canPlayType() 检查浏览器是否支持指定的媒体类型

4.3 媒体事件

媒体元素支持多种事件，用于响应媒体的播放状态变化，如播放、暂停、结束等。 

<video id="myVideo" src="video.mp4" controls></video>

<script>
    const video = document.getElementById('myVideo');
    
    // 播放开始时触发
    video.addEventListener('play', () => {
        console.log('视频开始播放');
    });
    
    // 暂停时触发
    video.addEventListener('pause', () => {
        console.log('视频暂停');
    });
    
    // 播放结束时触发
    video.addEventListener('ended', () => {
        console.log('视频播放结束');
    });
    
    // 播放时间更新时触发
    video.addEventListener('timeupdate', () => {
        console.log('当前播放时间:', video.currentTime);
    });
</script>
