第19课：CSS样式写法

本课程将详细介绍CSS样式的各种写法，包括内联样式、内部样式表和外部样式表，并讲解它们的优先级和适用场景。学习本课，你将能够灵活运用不同的CSS样式写法来组织和管理网页样式。

一、内联样式

内联样式是直接在HTML元素的style属性中定义的CSS样式。

内联样式的特点是优先级最高，直接作用于单个元素，但是不利于样式的复用和维护。

<p style="color: red; font-size: 20px;">这是一个红色的段落。</p>
注意事项
  • 内联样式使用style属性，属性值是CSS声明的集合。
  • 多个CSS声明之间用分号分隔。
  • 内联样式的优先级最高，会覆盖其他样式写法。
  • 内联样式不利于样式的复用和维护，仅在特殊情况下使用。

二、内部样式表

内部样式表是在HTML文档的head标签中使用style标签定义的CSS样式。

内部样式表的特点是作用于当前HTML文档，样式可以复用，但是不利于在多个HTML文档之间共享样式。

<!DOCTYPE html>
<html lang="zh-CN">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>内部样式表示例</title>
    <style>
        p {
            color: blue;
            font-size: 18px;
        }
        h1 {
            color: green;
        }
    </style>
</head>
<body>
    <h1>这是一个标题</h1>
    <p>这是一个蓝色的段落。</p>
</body>
</html>
注意事项
  • 内部样式表使用style标签，位于head标签中。
  • style标签中的CSS样式作用于当前HTML文档。
  • 内部样式表有利于样式的复用，但是仅作用于当前文档。

三、外部样式表

外部样式表是将CSS样式定义在一个独立的.css文件中，然后在HTML文档中通过link标签引入。

外部样式表的特点是可以在多个HTML文档之间共享样式，有利于样式的复用和维护，是实际开发中最常用的样式写法。

外部样式表的使用步骤
  1. 创建一个.css文件，例如style.css。
  2. 在.css文件中定义CSS样式。
  3. 在HTML文档的head标签中使用link标签引入.css文件。
/* style.css */
p {
    color: red;
    font-size: 20px;
}

h1 {
    color: blue;
}
<!DOCTYPE html>
<html lang="zh-CN">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>外部样式表示例</title>
    <link rel="stylesheet" href="style.css">
</head>
<body>
    <h1>这是一个标题</h1>
    <p>这是一个红色的段落。</p>
</body>
</html>
外部样式表的优点
  • 样式可以在多个HTML文档之间共享，有利于样式的复用和维护。
  • 可以缓存.css文件，提高网页加载速度。
  • 将HTML结构和CSS样式分离，有利于代码的组织和管理。

四、样式优先级

当一个HTML元素应用了多种样式写法时，CSS会根据一定的优先级规则来决定最终应用哪个样式。

样式优先级从高到低依次为：

  1. !important声明
  2. 内联样式
  3. ID选择器
  4. 类选择器、属性选择器、伪类选择器
  5. 元素选择器、伪元素选择器
  6. 通配符选择器
  7. 继承的样式
注意事项
  • !important声明会覆盖所有其他样式，但是应尽量避免使用，因为它会破坏样式的正常优先级关系。
  • 选择器的优先级可以通过计算选择器的特异性来确定。
  • 当多个样式的优先级相同时，后面定义的样式会覆盖前面定义的样式。

五、CSS语法规则

CSS语法由选择器和声明块组成。

选择器 {
    属性1: 值1;
    属性2: 值2;
    /* 注释 */
}
CSS语法详解
  • 选择器：用于选择要应用样式的HTML元素。
  • 声明块：用花括号{}包裹，包含一个或多个CSS声明。
  • CSS声明：由属性和值组成，属性和值之间用冒号:分隔，多个声明之间用分号;分隔。
  • 注释：用于解释CSS代码，不会被浏览器解析。

CSS属性值的单位

CSS属性值可以使用多种单位，常见的单位包括：

单位描述示例
px 像素，固定单位 font-size: 16px;
em 相对于父元素的字体大小 font-size: 1.2em;
rem 相对于根元素的字体大小 font-size: 1.2rem;
% 百分比，相对于父元素的宽度或高度 width: 50%;
vw 视口宽度的1% width: 50vw;
vh 视口高度的1% height: 50vh;

六、CSS注释

CSS注释用于解释CSS代码，提高代码的可读性和可维护性。

CSS注释以/*开头，以*/结尾，中间可以包含任意文本。

/* 这是一个CSS注释 */
p {
    color: red; /* 这是设置段落文本颜色为红色 */
    font-size: 16px;
}
CSS注释的使用建议
  • 在CSS文件的开头添加注释，说明文件的用途和作者信息。
  • 在重要的样式规则前添加注释，说明样式的用途。
  • 使用注释来分隔不同的样式模块，提高代码的组织性。
  • 避免使用过多的注释，只在必要时添加。

七、实验：三种样式写法对比

实验：三种样式写法对比 Hands-on

目标：通过实际操作，对比内联样式、内部样式表和外部样式表的优缺点。

  1. 创建一个HTML文件，包含标题、段落和链接等元素。
  2. 使用内联样式为这些元素添加样式。
  3. 将内联样式改为内部样式表。
  4. 将内部样式表改为外部样式表。
  5. 对比三种样式写法的优缺点，总结它们的适用场景。

八、实验：样式优先级测试

实验：样式优先级测试 Hands-on

目标：测试不同样式写法和选择器的优先级关系。

  1. 创建一个HTML文件，包含一个div元素，设置id和class属性。
  2. 使用内联样式为div元素设置背景颜色为红色。
  3. 使用内部样式表，通过id选择器为div元素设置背景颜色为蓝色。
  4. 使用内部样式表，通过类选择器为div元素设置背景颜色为绿色。
  5. 使用内部样式表，通过元素选择器为div元素设置背景颜色为黄色。
  6. 观察div元素的最终背景颜色，理解样式优先级的规则。
  7. 在某个样式声明中添加!important，观察效果。

九、本课小结

本课程详细介绍了CSS样式的各种写法，包括：

  • 内联样式：直接在HTML元素的style属性中定义，优先级最高，但是不利于样式的复用和维护。
  • 内部样式表：在HTML文档的head标签中使用style标签定义，作用于当前HTML文档，样式可以复用。
  • 外部样式表：将CSS样式定义在独立的.css文件中，通过link标签引入，是实际开发中最常用的样式写法。
  • 样式优先级：!important声明 > 内联样式 > ID选择器 > 类选择器 > 元素选择器 > 通配符选择器 > 继承的样式。
  • CSS语法：由选择器和声明块组成，声明块包含一个或多个CSS声明。
  • CSS注释：用于解释CSS代码，提高代码的可读性和可维护性。
学习建议
  • 在实际开发中，优先使用外部样式表来组织和管理CSS样式。
  • 理解样式优先级的规则，避免使用!important声明。
  • 使用CSS注释来提高代码的可读性和可维护性。
  • 通过实验和练习，熟练掌握不同的CSS样式写法。
