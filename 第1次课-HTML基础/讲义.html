第1课：HTML基础入门

欢迎来到HTML的世界！HTML是制作网页的基础语言，就像建房子需要砖块一样。这节课我们将学习HTML最基本的概念和语法，让你能够创建自己的第一个网页。

HTML概念 文档结构 标签语法 HTML属性 HTML注释

一、什么是HTML

1.1 HTML的定义

HTML是HyperText Markup Language的缩写，中文名叫「超文本标记语言」。

名词解释
  • 超文本（HyperText）：不仅包含普通文字，还包含链接、图片、视频等多种元素
  • 标记（Markup）：使用特殊的标签来标识内容的类型和结构
  • 语言（Language）：有固定的语法规则，计算机能够理解和执行
简单理解

你可以把HTML想象成搭积木的说明书。它告诉浏览器："这里放一个标题，那里放一段文字"。就像给房子规划房间的位置一样。

1.2 HTML的历史

HTML的发展历程：

年份版本重要事件
1991年HTML 1.0Tim Berners-Lee发明了HTML
1995年HTML 2.0第一个正式标准
1997年HTML 3.2添加了表格、脚本等功能
1999年HTML 4.01引入CSS支持，成为长期使用的版本
2014年HTML 5现代标准，支持视频、音频、Canvas等
趣味知识

HTML的发明者蒂姆·伯纳斯-李（Tim Berners-Lee）被称为"互联网之父"。1989年，他在欧洲核子研究中心（CERN）工作时，为了方便科学家们共享研究文档，发明了万维网（WWW）和HTML。今天我们能够浏览网页，都要感谢他的伟大发明！

1.3 HTML的作用

HTML在网页中扮演着非常重要的角色：

  • 定义内容结构：告诉浏览器哪些是标题、哪些是段落
  • 组织页面内容：让网页内容有条理、易于阅读
  • 提供语义信息：让搜索引擎和屏幕阅读器理解网页内容
  • 链接资源：连接图片、视频、样式表等外部资源
  • 创建表单：收集用户输入的信息

1.4 HTML与CSS、JavaScript的关系

一个完整的网页由三个核心技术组成，它们各司其职：

技术 作用 类比 学习顺序
HTML 网页的结构和内容 建筑的框架和房间 第1步（本课程）
CSS 网页的样式和外观 建筑的装修和颜色 第2步（第13课开始）
JavaScript 网页的交互和行为 电梯、自动门等活动部件 第3步（第23课开始）
重要提示

HTML只负责网页的结构，不负责样式和交互！

  • HTML不能改变文字颜色（需要CSS）
  • HTML不能实现动画效果（需要CSS/JavaScript）
  • HTML不能响应用户点击（需要JavaScript）

二、HTML文档结构

每个HTML文档都有一个固定的基本结构，就像每栋房子都有地基、墙壁和屋顶一样。理解这个结构是学习HTML的第一步。

2.1 基本结构

一个完整的HTML文档包含以下几个部分：

<!DOCTYPE html>
<html lang="zh-CN">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>我的第一个网页</title>
</head>
<body>
    <!-- 这里放网页的内容 -->
    <h1>欢迎！</h1>
    <p>这是我的第一个HTML页面。</p>
</body>
</html>
结构图解 
┌─────────────────────────────────┐
│  <!DOCTYPE html>   ← 文档类型声明  │
│  ┌───────────────────────────┐  │
│  │  <html>        ← 根元素    │  │
│  │  ┌─────────────────────┐  │  │
│  │  │  <head>   ← 头部    │  │  │
│  │  │  ├─ meta (字符集)    │  │  │
│  │  │  ├─ meta (视口)      │  │  │
│  │  │  └─ title (标题)     │  │  │
│  │  └─────────────────────┘  │  │
│  │  ┌─────────────────────┐  │  │
│  │  │  <body>   ← 主体    │  │  │
│  │  │  ├─ 标题             │  │  │
│  │  │  ├─ 段落             │  │  │
│  │  │  └─ 其他内容...      │  │  │
│  │  └─────────────────────┘  │  │
│  └───────────────────────────┘  │
└─────────────────────────────────┘

2.2 各部分详细说明

标签/代码 名称 作用 必须？
<!DOCTYPE html> 文档类型声明 告诉浏览器这是HTML5文档，必须放在第一行 必须
<html lang="zh-CN"> 根元素 包含整个网页的所有内容，lang指定语言 必须
<head> 文档头部 包含网页的元信息（不在页面上显示） 必须
<meta charset="UTF-8"> 字符编码 让网页能正确显示中文和特殊符号 必须
<meta name="viewport"...> 视口设置 让网页在手机上正确显示 ⭐ 推荐
<title> 页面标题 显示在浏览器标签页上的文字 必须
<body> 文档主体 包含所有在页面上显示的内容 必须

2.3 <head> 中常见的元素

head标签内通常包含以下内容：

<head>
    <!-- 1. 字符编码 - 必须放在最前面 -->
    <meta charset="UTF-8">
    
    <!-- 2. 视口设置 - 响应式设计必备 -->
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    
    <!-- 3. 页面标题 - 显示在标签页上 -->
    <title>页面标题</title>
    
    <!-- 4. 页面描述 - 搜索引擎会显示 -->
    <meta name="description" content="这是网页的简短描述">
    
    <!-- 5. 关键词 - 帮助SEO -->
    <meta name="keywords" content="关键词1, 关键词2">
    
    <!-- 6. 作者信息 -->
    <meta name="author" content="作者姓名">
    
    <!-- 7. 网站图标 - 显示在标签页上的小图标 -->
    <link rel="icon" href="favicon.ico">
    
    <!-- 8. CSS样式表 -->
    <link rel="stylesheet" href="styles.css">
</head>
常见错误
  • 忘记写 <!DOCTYPE html> - 可能导致浏览器进入"怪异模式"
  • 忘记设置字符编码 - 中文可能显示为乱码
  • 把内容写在 <head> 里 - head里的内容不会显示在页面上
  • 多个 <body> 标签 - 一个HTML文档只能有一个body
为什么需要 UTF-8？

UTF-8是一种通用的字符编码，可以正确显示世界上几乎所有语言的字符，包括中文、日文、韩文、阿拉伯文等。如果不设置字符编码，中文可能会显示成"锟斤拷"这样的乱码。

三、HTML标签语法

HTML标签是HTML文档的基本组成单位，它们遵循特定的语法规则。掌握标签语法是编写HTML的基础。

3.1 什么是标签？

标签（Tag）是HTML的基本单位，用尖括号 <> 包围。标签告诉浏览器如何处理其中的内容。

标签的基本形式 
  开始标签        结束标签
     ↓               ↓
   <p>  这是一段文字  </p>
         ↑
      标签内容

3.2 标签的两种类型

标签类型 语法结构 示例 说明
双标签（成对标签） <标签名>内容</标签名> <p>段落内容</p> 包含开始和结束标签，内容在中间
单标签（自闭合标签） <标签名> 或 <标签名 /> <br>, <img>, <hr> 没有内容，不需要结束标签

3.3 常见的双标签

标签名称用途示例
<h1>~<h6>标题定义标题（1最大，6最小）<h1>一级标题</h1>
<p>段落定义一段文字<p>这是一段话</p>
<div>区块定义一个区域<div>内容</div>
<span>行内区块标记文本中的一部分<span>文字</span>
<a>链接创建超链接<a href="url">链接</a>
<strong>加粗重要文本<strong>重要</strong>
<em>斜体强调文本<em>强调</em>

3.4 常见的单标签

标签名称用途示例
<br>换行在文本中换行第一行<br>第二行
<hr>水平线插入一条分隔线<hr>
<img>图片插入图片<img src="图片.jpg">
<input>输入框创建表单输入<input type="text">
<meta>元信息定义页面元数据<meta charset="UTF-8">
<link>链接资源引入外部资源<link rel="stylesheet"...>

3.5 标签的嵌套

标签可以嵌套使用，但必须正确闭合，遵循"后进先出"的原则：

<!--  正确的嵌套 -->
<p>这是<strong>重要的</strong>内容。</p>

<!--  错误的嵌套（标签交叉）-->
<p>这是<strong>重要的</p></strong>内容。
嵌套规则
  • 标签必须成对闭合，不能交叉
  • 块级元素（如div、p）可以包含行内元素（如span、a）
  • 行内元素不应该包含块级元素
  • 保持良好的缩进，使嵌套结构清晰

四、HTML属性

属性是HTML标签的附加信息，它们提供了关于标签的更多细节。属性可以改变标签的行为或提供额外的信息。

4.1 属性的基本语法

属性总是在开始标签中定义，格式为 属性名="属性值"。

属性语法图解 
    属性名   属性值
      ↓       ↓
<p align="center">这段文字居中显示</p>
   └────┬────┘
      属性

4.2 属性的语法规则

  • 属性写在开始标签内，标签名之后
  • 属性名和属性值之间用 = 连接
  • 属性值用双引号或单引号包围（推荐双引号）
  • 多个属性之间用空格分隔
  • 属性名通常使用小写字母
<!-- 单个属性 -->
<p align="center">居中文字</p>

<!-- 多个属性 -->
<img src="图片地址" alt="图片描述" width="300">

<!-- 带有多个属性的链接 -->
<a href="https://www.example.com" target="_blank" title="点击访问">访问示例网站</a>

4.3 全局属性

全局属性是可以用于任何HTML标签的属性：

属性 作用 示例 说明
id 唯一标识符 id="header" 在整个页面中必须唯一
class 类名 class="highlight" 可以有多个，用空格分隔
style 内联样式 style="color: red;" 直接定义CSS样式
title 提示文本 title="鼠标悬停提示" 鼠标悬停时显示
hidden 隐藏元素 hidden 布尔属性，不需要值
lang 语言 lang="zh-CN" 指定内容的语言

4.4 特定标签的属性

有些属性只能用于特定的标签：

标签常用属性示例
<a> href, target <a href="url" target="_blank">
<img> src, alt, width, height <img src="图片.jpg" alt="描述">
<input> type, name, value, placeholder <input type="text" name="user">
<form> action, method <form action="submit.php" method="post">

4.5 布尔属性

有些属性不需要值，只需要属性名即可：

<!-- 布尔属性示例 -->
<input type="text" disabled>        <!-- 禁用输入框 -->
<input type="checkbox" checked>     <!-- 默认选中 -->
<input type="text" required>        <!-- 必填字段 -->
<video controls autoplay muted>     <!-- 视频自动播放 -->
属性使用建议
  • 属性名使用小写字母
  • 属性值用双引号包围
  • id在页面中必须唯一
  • 为图片添加alt属性，提高可访问性
  • 使用title属性为用户提供额外提示

五、HTML注释

注释是HTML文档中不会被浏览器显示的文本，它们用于解释代码，方便开发者理解和维护。

5.1 注释的语法

注释的语法是 <!-- 注释内容 -->。

<!-- 这是一个HTML注释，浏览器不会显示它 -->
<p>这段文字会显示在浏览器中</p>
<!-- 
    这是一个多行注释
    可以跨越多行
 -->
注释的作用
  • 解释代码的功能和用途
  • 临时隐藏代码，方便调试
  • 提高代码的可读性和可维护性
