一、什么是HTML

HTML是HyperText Markup Language的缩写，翻译成中文是「超文本标记语言」。

HTML是用于创建网页的标准标记语言，它的主要作用是定义内容结构、描述网页内容和连接互联网。

💡 超文本的含义

「超文本」指的是包含链接的文本，用户可以通过点击链接从一个页面跳转到另一个页面，这也是互联网能够连接全球信息的基础。

二、HTML文档结构

一个完整的HTML文档包含固定的结构，由多个标签嵌套组成。让我们从最基础的HTML文档结构开始学习。

2.1 基本HTML文档结构

每个HTML文档都应该包含以下基本结构：

标签 作用 说明
<!DOCTYPE html> 文档类型声明 告诉浏览器这是一个HTML5文档，必须放在最前面
<html> HTML根元素 所有其他HTML元素都嵌套在这个标签内
<head> 头部元素 包含文档的元数据，如字符集、标题等，这些内容不会直接显示在页面上
<body> 主体元素 包含浏览器显示的所有页面内容，如文本、图片、链接等

三、常用文本标签

HTML提供了许多用于格式化文本的标签，让我们从最常用的文本标签开始学习。

3.1 标题标签

HTML提供了6级标题标签，从<h1>到<h6>，其中<h1>级别最高，<h6>级别最低。

3.2 段落和换行标签

<p>标签用于定义段落，<br>标签用于插入换行符。

实验 01：HTML 基础标签练习

这是一个 HTML 实验，学生可以编辑左侧代码，点击运行后在右侧查看效果。

实验 01：HTML 基础标签练习 动手实践

四、创建你的第一个HTML页面

现在，让我们动手创建你的第一个完整HTML页面。

4.1 动手实践

按照以下步骤操作，创建你的第一个HTML页面：

  1. 打开一个文本编辑器（如记事本、VS Code等）
  2. 输入HTML代码（可以参考下面的实验）
  3. 将文件保存为 index.html
  4. 使用浏览器打开这个文件，你将看到你的第一个HTML页面

实验 02：创建第一个HTML页面

动手创建你的第一个完整HTML页面，实践本节课所学的所有知识。

实验 02：创建第一个HTML页面 动手实践
HTML (可编辑)
<!DOCTYPE html> <html lang="zh-CN"> <head> <meta charset="UTF-8"> <meta name="viewport" content="width=device-width, initial-scale=1.0"> <title>我的第一个HTML页面</title> </head> <body> <h1>欢迎来到我的网页！</h1> <p>大家好，我是一名HTML初学者。</p> <p>这是我的第一个HTML页面，我感到非常兴奋！</p> <h2>我的爱好</h2> <p>我喜欢：阅读、编程、旅行...</p> <h2>我的目标</h2> <p>我希望能够学会HTML、CSS和JavaScript，成为一名优秀的前端开发者。</p> </body> </html>
