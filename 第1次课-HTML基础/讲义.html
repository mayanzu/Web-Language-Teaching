📝 课程小结

第1课：HTML基础入门

欢迎来到HTML的世界！HTML是制作网页的基础语言，就像建房子需要砖块一样。这节课我们将学习HTML最基本的概念和标签，让你能够创建自己的第一个网页。

HTML概念 文档结构 标题标签 段落标签 文本格式化

一、什么是HTML

1.1 HTML的定义

HTML是HyperText Markup Language的缩写，中文名叫「超文本标记语言」。

💡 简单理解

你可以把HTML想象成搭积木的说明书。它告诉浏览器："这里放一个标题，那里放一段文字"。就像给房子规划房间的位置一样。

1.2 HTML的历史与发展

HTML由英国物理学家蒂姆·伯纳斯-李（Tim Berners-Lee）在1989年发明，用于在CERN（欧洲核子研究中心）的科学家之间共享文档。HTML经历了多个版本的发展：

版本 发布年份 主要特点
HTML 1.0 1993 基础的超文本标记功能
HTML 2.0 1995 增加了表单、表格等功能
HTML 3.2 1997 引入了CSS支持
HTML 4.01 1999 更完善的语义化标签和样式分离
HTML5 2014 增加了语义化标签、多媒体支持、Canvas等现代特性

1.3 HTML的作用

HTML在网页中扮演着非常重要的角色：

  • 定义内容结构：告诉浏览器哪些是标题、哪些是段落
  • 组织页面内容：让网页内容有条理、易于阅读
  • 提供语义信息：让搜索引擎和屏幕阅读器理解网页内容

1.4 HTML与CSS、JavaScript的关系

一个完整的网页由三个核心技术组成：

技术 作用 类比
HTML 网页的结构 建筑的框架结构
CSS 网页的样式 建筑的外观装修
JavaScript 网页的交互 建筑的电梯、门窗等活动部件
🌟 生活中的类比

想象你在写一篇作文：

  • 作文标题 = HTML中的 <h1> 标签
  • 每个段落 = HTML中的 <p> 标签
  • 加粗的重点 = HTML中的 <strong> 标签

二、HTML文档结构

每个HTML文档都有一个固定的基本结构，就像每栋房子都有地基、墙壁和屋顶一样。让我们来认识这个结构。

2.1 基本结构

一个完整的HTML文档包含以下几个部分：

<!DOCTYPE html>
<html lang="zh-CN">
<head>
    <meta charset="UTF-8">
    <title>我的第一个网页</title>
</head>
<body>
    <!-- 这里放网页的内容 -->
    <h1>欢迎！</h1>
    <p>这是我的第一个HTML页面。</p>
</body>
</html>

2.2 各部分说明

标签 作用 说明
<!DOCTYPE html> 文档类型声明 告诉浏览器这是HTML5文档，必须放在第一行
<html> 根元素 包含整个网页的所有内容
<head> 头部 包含网页的信息（标题、字符集等），不在页面上显示
<meta charset="UTF-8"> 字符编码 让网页能正确显示中文
<title> 标题 显示在浏览器标签页上的文字
<body> 主体 包含所有在页面上显示的内容

2.3 HTML标签语法

HTML标签是HTML文档的基本组成单位，它们遵循特定的语法规则：

标签类型 语法结构 示例 说明
双标签 <标签名>内容</标签名> <p>段落内容</p> 包含开始和结束标签，内容在中间
单标签（自闭合） <标签名 /> <br />, <img /> 没有内容，自行闭合

2.4 HTML属性

属性是HTML标签的附加信息，它们提供了关于标签的更多细节。属性总是在开始标签中定义，格式为 属性名="属性值"。

<p align="center">这段文字居中显示</p>
<img src="图片地址" alt="图片描述" width="300">
<a href="https://www.example.com" target="_blank">访问示例网站</a>
属性 作用 示例值
align 设置内容对齐方式 left, center, right
src 指定资源地址（用于图片、脚本等） 图片路径或URL
alt 提供替代文本（用于图片等） 图片的文字描述
width 设置宽度 像素值或百分比
href 指定链接目标（用于标签） URL地址
target 指定链接打开方式 _self, _blank

2.5 HTML注释

注释是HTML文档中不会被浏览器显示的文本，它们用于解释代码，方便开发者理解和维护。注释的语法是 <!-- 注释内容 -->。

<!-- 这是一个HTML注释，浏览器不会显示它 -->
<p>这段文字会显示在浏览器中</p>
<!-- 
    这是一个多行注释
    可以跨越多行
 -->
💡 注释的作用
  • 解释代码的功能和用途
  • 临时隐藏代码，方便调试
  • 提高代码的可读性和可维护性
🎯 记忆要点：

<head> 是"幕后工作者"，<body> 是"台前演员"。用户看到的所有内容都在 <body> 里面！

三、标题与段落

现在我们学习HTML中最常用的两种标签：标题和段落。

3.1 标题标签（h1-h6）

HTML提供了6级标题标签，从 <h1> 到 <h6>，<h1> 最大最重要，<h6> 最小。

示例：6级标题的效果 只读 
<h1>一级标题 - 页面主标题</h1>
<h2>二级标题 - 大章节标题</h2>
<h3>三级标题 - 小节标题</h3>
<h4>四级标题</h4>
<h5>五级标题</h5>
<h6>六级标题</h6>

一级标题 - 页面主标题

二级标题 - 大章节标题

三级标题 - 小节标题

四级标题

五级标题
六级标题
标题级别 重要性 使用场景 示例
<h1> 最高 页面主标题 网站名称、文章标题
<h2> 很高 大章节标题 产品分类、文章章节
<h3> 高 小节标题 产品子分类、章节小节
<h4> 中等 子小节标题 详细说明、功能介绍
<h5> 低 补充说明标题 注意事项、提示信息
<h6> 最低 最小标题 辅助说明、版权信息
💡 使用建议
  • 每个页面只用一个 <h1>，作为整个页面的大标题
  • 标题要按顺序使用，不要跳过级别（比如从h1直接跳到h3）
  • 把标题想象成书的目录结构：书名(h1) → 章(h2) → 节(h3)
  • 标题应该简洁明了，准确概括内容主题
⚠️ 常见错误
  • 不要为了改变文字大小而使用标题标签（应该用CSS）
  • 不要在一个页面中使用多个 <h1> 标签
  • 不要跳过标题级别（比如h1之后直接用h3）

3.2 段落标签（p）

<p> 标签用来创建段落，浏览器会自动在段落前后添加一些空白，让内容看起来更整齐。

<p>这是第一段文字。浏览器会在这个段落前后自动留出空白。</p>
<p>这是第二段文字。每个段落都是独立的，互不影响。</p>

3.3 换行标签（br）

<br> 标签用来在同一段落内换行。注意：它是自闭合标签，不需要写 </br>。

<p>
    这是第一行文字<br>
    这是第二行文字<br>
    这是第三行文字
</p>

3.4 预格式化文本（pre）

<pre> 标签用来显示预格式化的文本，保留原有的空格和换行符。常用于显示代码、诗歌等需要精确格式的内容。

<pre>
    function sayHello() {
        console.log("Hello, World!");
    }
</pre>

3.5 水平线（hr）

<hr> 标签用来创建一条水平线，用于分隔不同的内容区块。它也是自闭合标签。

<p>第一部分内容</p>
<hr>
<p>第二部分内容</p>
🎯 标签对比
标签 作用 前后空白 使用场景
<p> 创建段落 大 正文内容
<br> 换行 小 同一内容内换行
<pre> 预格式化 保留原有格式 代码、诗歌等
<hr> 水平线 上下有空白 分隔内容区块

四、文本格式化

为了让文字更有表现力，HTML提供了丰富的格式化标签，用于强调、标记和美化文本内容。

4.1 常用格式化标签

标签 效果 语义 说明
<strong> 加粗文字 重要性 表示非常重要的内容，浏览器默认加粗显示
<em> 倾斜文字 强调 表示强调，浏览器默认倾斜显示
<u> 下划线 标记 为文字添加下划线，注意不要与链接混淆
<mark> 高亮显示 标记重点 像荧光笔一样标记重点内容
<s> 删除线 删除 表示已删除或不再有效的内容
<del> 删除线 删除 与<s>类似，但更强调语义
<ins> 插入线 插入 表示新插入的内容，通常带有下划线
<small> 小号文字 附属信息 表示小号文字，常用于版权信息、注释等
<sub> H2O 下标 用于数学公式、化学符号等
<sup> 23=8 上标 用于幂运算、脚注等

4.2 组合使用示例

这些标签可以组合使用，创造更丰富的文本效果：

<p>这段文字包含 <strong>加粗</strong> 和 <em>倾斜</em> 效果。</p>
<p>你也可以 <strong><em>同时使用加粗和倾斜</em></strong>。</p>
<p>用 <mark>高亮</mark> 标记特别重要的内容。</p>
<p>原价：<s>¥199</s>，现价：<strong>¥99</strong></p>
<p>H<sub>2</sub>O 是水的化学式，2<sup>3</sup> 等于8</p>
<p><small>© 2024 版权所有</small></p>

4.3 语义化与表现性标签

HTML标签分为语义化标签和表现性标签：

类型 特点 示例标签 推荐程度
语义化标签 有明确的含义，便于搜索引擎和屏幕阅读器理解 <strong>, <em>, <mark> ✅ 强烈推荐
表现性标签 主要用于改变外观，语义较弱 <b>, <i>, <u> ⚠️ 谨慎使用
⚠️ 注意事项
  • 避免使用纯表现性标签，优先选择语义化标签
  • 不要过度使用格式化标签，以免影响可读性
  • 对于复杂的样式，建议使用CSS而非HTML标签

4.4 HTML实体

在HTML中，有些字符是特殊的，需要使用HTML实体来表示。例如：

特殊字符 HTML实体 说明
< &lt; 小于号
> &gt; 大于号
& &amp; 和号
" &quot; 引号
' &apos; 单引号
© &copy; 版权符号
® &reg; 注册商标
  &nbsp; 非换行空格
🌟 记忆口诀
  • <strong> = 强调 = 加粗
  • <em> = Emphasis(强调) = 倾斜
  • <u> = Underline = 下划线
  • <mark> = Marker = 荧光笔
  • <s> = Strikethrough = 删除线

最佳实践

💡 HTML编写建议
  • 语义优先：优先使用语义化标签，避免纯表现性标签
  • 结构清晰：保持良好的文档结构，合理使用标题层级
  • 简洁明了：代码简洁易读，避免冗余标签
  • 注释恰当：使用注释解释复杂代码，提高可维护性
  • 缩进规范：统一缩进格式，增强代码可读性
  • 大小写一致：HTML标签和属性推荐使用小写
  • 引号规范：属性值统一使用双引号

常见错误避免

⚠️ 注意事项
  • 不要忘记写文档类型声明 <!DOCTYPE html>
  • 不要在一个页面中使用多个 <h1> 标签
  • 不要跳过标题级别，保持正确的层级关系
  • 不要为了样式而滥用HTML标签，样式应该使用CSS
  • 不要忘记闭合标签，特别是双标签
  • 不要在HTML中直接使用特殊字符，应该使用HTML实体
