第1课：HTML基础入门

欢迎来到HTML的世界！在这门课程中，我们将一起探索HTML的基础知识，了解它如何构建网页的骨架。 这节课我们会从最基础的概念开始，让零基础的你也能轻松入门。

1. 什么是HTML

HTML是HyperText Markup Language的缩写，翻译成中文是「超文本标记语言」。

1.1 HTML的作用

HTML是用于创建网页的标准标记语言，它的主要作用是：

  • 定义内容结构：HTML使用各种标签来定义网页中的不同内容，如标题、段落、图片、链接等。
  • 描述网页内容：HTML标签告诉浏览器页面上有什么内容，以及这些内容是什么类型。
  • 连接互联网：HTML通过链接（Hyperlink）将不同的网页连接起来，形成了庞大的互联网。
💡 超文本的含义

「超文本」指的是包含链接的文本，用户可以通过点击链接从一个页面跳转到另一个页面， 这也是互联网能够连接全球信息的基础。

2. HTML文档结构

一个完整的HTML文档包含固定的结构，由多个标签嵌套组成。 让我们从最基础的HTML文档结构开始学习。

2.1 基本HTML文档结构

每个HTML文档都应该包含以下基本结构：

实验 01：HTML文档基本结构 未运行
HTML (可编辑)
<!DOCTYPE html> <html lang="zh-CN"> <head> <meta charset="UTF-8"> <meta name="viewport" content="width=device-width, initial-scale=1.0"> <title>我的第一个HTML页面</title> </head> <body> <h1>欢迎来到HTML世界！</h1> <p>这是我的第一个HTML页面。</p> <p>我正在学习HTML，这很有趣！</p> </body> </html>
预览效果

2.2 结构说明

标签 作用 说明
<!DOCTYPE html> 文档类型声明 告诉浏览器这是一个HTML5文档，必须放在最前面
<html> HTML根元素 所有其他HTML元素都嵌套在这个标签内
<head> 头部元素 包含文档的元数据，如字符集、标题等，这些内容不会直接显示在页面上
<body> 主体元素 包含浏览器显示的所有页面内容，如文本、图片、链接等

3. 常用文本标签

HTML提供了许多用于格式化文本的标签，让我们从最常用的文本标签开始学习。

3.1 标题标签

HTML提供了6级标题标签，从<h1>到<h6>，其中<h1>级别最高，<h6>级别最低。

实验 02：标题标签的使用 未运行
HTML (可编辑)
<!DOCTYPE html> <html lang="zh-CN"> <head> <meta charset="UTF-8"> <title>标题标签示例</title> </head> <body> <h1>这是一级标题</h1> <h2>这是二级标题</h2> <h3>这是三级标题</h3> <h4>这是四级标题</h4> <h5>这是五级标题</h5> <h6>这是六级标题</h6> </body> </html>
预览效果

3.2 段落和换行标签

<p>标签用于定义段落，<br>标签用于插入换行符。

实验 03：段落和换行标签 未运行
HTML (可编辑)
<!DOCTYPE html> <html lang="zh-CN"> <head> <meta charset="UTF-8"> <title>段落和换行示例</title> </head> <body> <h1>我的第一篇作文</h1> <p>这是第一段内容。HTML中的段落标签会自动在段落前后添加空白，使内容更易读。</p> <p>这是第二段内容。<br> 这里使用了换行标签，所以这一行会另起一行显示。</p> <p>这是第三段内容。</p> </body> </html>

4. 第一个HTML页面

现在，让我们动手创建你的第一个完整HTML页面。

4.1 动手实践

按照以下步骤操作，创建你的第一个HTML页面：

  1. 打开一个文本编辑器（如记事本、VS Code等）
  2. 输入HTML代码（可以参考下面的实验）
  3. 将文件保存为 index.html
  4. 使用浏览器打开这个文件，你将看到你的第一个HTML页面
实验 04：创建你的第一个HTML页面 未运行
HTML (可编辑)
<!DOCTYPE html> <html lang="zh-CN"> <head> <meta charset="UTF-8"> <meta name="viewport" content="width=device-width, initial-scale=1.0"> <title>我的第一个HTML页面</title> </head> <body> <h1>欢迎来到我的网页！</h1> <p>大家好，我是一名HTML初学者。</p> <p>这是我的第一个HTML页面，我感到非常兴奋！</p> <h2>我的爱好</h2> <p>我喜欢：</p> <p>阅读、编程、旅行...</p> <h2>我的目标</h2> <p>我希望能够学会HTML、CSS和JavaScript，成为一名优秀的前端开发者。</p> </body> </html>

4.2 扩展练习

你可以尝试修改上面的代码，添加更多的内容，比如：
